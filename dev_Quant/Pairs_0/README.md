# Simple Pair Trading Monitor

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 핵심 기능
- 두 종목만 선택
- 두 종목이 실제 페어 후보인지 간단 검정
- 괴리 신호를 그래프와 표로 표시
- 신호 기준 단순 백테스트
- 초기 투자금 설정

## 의도
기능을 최소화해,
1. 두 종목이 서로 비슷한 흐름인지
2. 페어 트레이딩 준비가 되었는지
3. 괴리 신호가 언제 났는지
4. 그 신호를 따라갔을 때 수익률이 어땠는지

이 4가지만 직관적으로 보는 앱입니다.
