## 이름 규칙

- 폴더 이름은 `번호. 이름` 형식을 사용합니다.
- 같은 프로그램의 여러 버전은 `프로그램명_v1.0`처럼 버전을 붙입니다.
- 업무 프로그램은 `1. 실내공기질`, `2. 수질환경`처럼 업무 분야별로, 학습·연습 자료는 언어별(`3. Python`, `4. R`)로 둡니다.
