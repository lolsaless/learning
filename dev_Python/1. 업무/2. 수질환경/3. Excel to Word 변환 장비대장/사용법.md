# 시험장비 관리대장 생성기 — 매뉴얼

## 1. 최초 기획
- 목적: 엑셀 장비대장(+components)과 장비 사진 폴더로 `ledger.docx` 양식(앞면·뒷면 2쪽)의 시험장비관리대장을 자동 생성.
- 기존 흐름(엑셀 → hwpx 변환)에서 방향 전환: 엑셀 → Word(docx), 사진 자동 삽입 추가.
- 요구사항: HTML 단일 파일 / 사진 폴더 지정(파일명=관리번호) / HEIC 등 다양한 형식 변환 / 1MB 이상 사진은 300KB 이하로 축소.

## 2. 개발 과정
| 단계 | 내용 |
|---|---|
| 양식 분석 | ledger.docx = 표 3개(제목·앞면·뒷면) + 쪽 나눔. 칸별 위치·병합 구조 파악 |
| 매핑 | 물품명(내부)·관리번호·물품번호·규격·제조사(제조국)·취득일(확정)·내부금액·입고시 상태(신품/중고)·도입 회사명·주소·연락처·용도·내용(→주요 성능 및 특징)·장비구성 시트(→장비구성내역) |
| 구현 | 양식 docx를 HTML 안에 내장 → 브라우저에서 XML 편집 후 docx 재조립 (SheetJS·JSZip·heic2any·UTIF 내장, 인터넷 불필요) |
| 사진 처리 | 형식 자동 판별 → HEIC/WEBP/BMP/TIFF 등 JPG 변환 → EXIF 회전 보정 → 1MB 이상이면 해상도·화질을 단계적으로 낮춰 300KB 이하 |
| 자동 맞춤 | 긴 규격·내용은 글자 크기를 6~10pt로 자동 축소해 2쪽 구성이 깨지지 않게 함 |
| 검증 | 47대 × 2쪽 = 94쪽 생성, HEIC·대용량 JPG/PNG·WEBP·BMP·TIFF·EXIF 회전 사진 테스트 |

## 3. 설치 및 사용
**설치**: 없음. `장비관리대장_생성기.html`을 Chrome 또는 Edge에서 더블클릭해 연다.
1. 엑셀 선택 — `장비대장` 시트 자동 인식, `장비구성` 시트(있으면) 자동 선택.
2. 사진 폴더 선택(선택사항) — 파일명이 관리번호와 같아야 함(`04-장비-05.jpg`, `04-장비-05.HEIC`). `04-장비-05_1.jpg`처럼 뒤에 구분기호가 붙어도 인식.
3. 옵션 — 출력 방식(하나의 docx / 장비별 docx ZIP), 날짜 표기, 압축 기준(기본 1024KB)·목표(기본 300KB).
4. 표에서 대상 확인(체크 해제로 제외, 사진 없는 장비만 보기).
5. [Word 문서 만들기] → 다운로드. 필요하면 [변환된 사진 ZIP 저장].

**엑셀 규칙**
- 장비대장: `관리번호, 물품번호, 물품명(내부), 규격, 제조사, 제조국, 취득일(확정), 내부금액(원), 도입 회사명, 도입처 주소, 연락처, 용도, 상태(마지막 ‘상태’=신품/중고품), 내용`
- 장비구성: `관리번호, 연번, 내용(→장비명), 수량, 단위` (연번 순서대로 반영) — 장비당 최대 10행(5행 초과 시 행 높이·글자 자동 축소).
- 같은 관리번호가 2행이면 별개 장비로 각각 한 세트 생성(사진 공유).

## 4. 배포 방법
- HTML 파일 1개(약 2.5MB)를 메일·공유폴더·USB로 전달. 설치·서버·인터넷 불필요(내부망 가능).
- 권장 브라우저: Chrome / Edge 최신 버전.
- 양식 변경 시: 개발자가 새 ledger.docx로 HTML을 다시 빌드(양식이 파일 안에 내장됨).

## 5. 카탈로그 (`장비카탈로그_날짜.html`)
- Word 문서를 만들 때 함께 생성(옵션 ‘카탈로그도 함께 만들기’, 또는 [카탈로그만 만들기]). 인터넷 없이 열리는 HTML 1개이며 사진이 안에 들어 있어 단독 배포 가능. ‘장비별 파일→ZIP’ 출력이면 ZIP 안에 `장비카탈로그.html`로 포함.
- 필터: **관리번호**, **물품명**(각각 쉼표로 여러 개 = OR, 일부만 입력해도 검색, 일치 글자 강조), 통합검색(규격·제조사·도입처·용도·내용), 도입연도, 제조국, 금액 범위(원/만원/억원, 단가/총액), 사진 있는 장비만, 정렬, 카드/표 보기.
- 카드/행 클릭 → 상세(큰 사진·전체 항목·장비구성내역), ←/→ 키로 이동, `결과 CSV 저장`(엑셀에서 열림).

## 6. Python 판 (`장비관리대장_생성기.py`)
- 설치: `pip install openpyxl lxml pillow pillow-heif`
- 실행: `python 장비관리대장_생성기.py` (창) 또는 `--xlsx 장비.xlsx --images 사진폴더 --out 결과.docx [--zip] [--only 04-장비-05,...]`
- HTML 판과 동일한 매핑·사진 처리 규칙. 양식은 파일 안에 내장(`--template`으로 교체 가능).

## 7. 주의
- 시험 환경 기준 Word 실물 확인 전이므로 첫 사용 시 몇 장을 Word에서 열어 쪽 구성을 확인할 것(글꼴 ‘경기천년바탕’ 미설치 PC는 글자 폭이 달라질 수 있음).
- 사진이 없는 장비는 사진 칸을 비워 둠.
- 폴더 끌어놓기가 안 되는 환경이면 영역을 클릭해 폴더를 직접 선택(같은 결과).
