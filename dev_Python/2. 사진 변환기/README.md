# 사진 변환기

여러 형식의 사진을 **JPG로 변환**하고 **크기를 조절**하는 프로그램입니다.
`사진변환기.html` 파일 하나만 열면 동작하며, 설치나 인터넷 연결이 필요 없습니다.

- HEIC(아이폰 사진) 포함 다양한 형식 지원
- 사진·폴더 드래그 앤 드롭 (하위 폴더까지 한 번에)
- 변환 결과는 `사진변환파일` 폴더에 자동 저장
- 사진은 내 PC 안에서만 처리되며 외부로 전송되지 않음

---

## 1. 시작하기

1. `사진변환기.html`을 더블클릭합니다.
   - **Chrome** 또는 **Edge**로 열어 주세요. (Windows 기본 브라우저인 Edge 권장)
   - 다른 브라우저로 열리면: 파일 우클릭 → **연결 프로그램** → Edge 또는 Chrome
2. 사진이나 폴더를 화면에 **끌어다 놓습니다.**
   - 또는 **사진 선택** / **폴더 선택** 버튼을 누릅니다.
3. 크기와 화질을 정하고 **변환 시작**을 누릅니다.
4. 처음 저장할 때 브라우저가 *"파일 수정을 허용할까요?"* 라고 물으면 **허용**을 누릅니다.

---

## 2. 저장 위치

변환된 사진은 항상 `사진변환파일` 폴더 안에 저장됩니다.

| 넣은 것 | 저장 위치 |
|---|---|
| **폴더** | 그 폴더 안에 `사진변환파일`이 자동으로 만들어짐 |
| **사진만** | 변환 시작 시 위치를 한 번 고르면, 그 안에 `사진변환파일`이 만들어짐 |

- 저장 위치는 화면의 **변경** 버튼으로 직접 바꿀 수 있습니다.
- 예) `장비 사진` 폴더를 넣은 경우

  ```
  장비 사진/
  ├─ IMG_0001.HEIC
  ├─ 2층/
  │  └─ IMG_0002.HEIC
  └─ 사진변환파일/          ← 자동 생성
     ├─ IMG_0001.jpg
     └─ 2층/
        └─ IMG_0002.jpg
  ```

- 다시 변환해도 `사진변환파일` 폴더 안의 사진은 변환 대상에서 자동으로 제외됩니다.

## 3. 옵션

### 크기 조절

| 방식 | 설명 | 예시 |
|---|---|---|
| **원본 크기** | 크기 그대로 JPG로만 변환 | - |
| **최대 크기 제한** | 지정한 크기를 넘는 사진만 비율을 유지하며 줄임 | 가로 1920 입력 → 가로 1920 초과 사진만 축소 |
| **비율(%)** | 원본 대비 비율로 조절 (5~200%) | 50% → 4000×3000이 2000×1500 |
| **크기 지정** | 한쪽만 입력하면 비율 유지, 둘 다 입력하면 그 크기로 맞춤 | 가로 800만 입력 → 세로는 자동 계산 |

### 기타 옵션

| 옵션 | 설명 | 기본값 |
|---|---|---|
| **JPG 화질** | 10~100. 높을수록 선명하고 용량이 큼 (권장 85~95) | 90 |
| **작은 사진도 확대** | '최대 크기 제한'에서 기준보다 작은 사진도 키움 | 꺼짐 |
| **폴더 구조 유지** | 끄면 하위 폴더 없이 한 폴더에 모두 저장 | 켜짐 |
| **같은 이름은 덮어쓰기** | 끄면 `사진_1.jpg`, `사진_2.jpg` 처럼 번호를 붙여 저장 | 꺼짐 |

### 자동 처리
- 휴대폰 사진의 **회전 방향을 자동 보정**합니다.
- PNG 등의 **투명 배경은 흰색**으로 채웁니다.
- 확장자는 `.jpg`인데 실제로는 HEIC인 파일도 자동으로 인식합니다.

---

## 4. 지원 형식

| 형식 | 확장자 |
|---|---|
| 아이폰 사진 | `.heic` `.heif` |
| 일반 이미지 | `.jpg` `.jpeg` `.jfif` `.png` `.webp` `.bmp` `.dib` `.gif` `.avif` `.ico` |
| TIFF | `.tif` `.tiff` |

- GIF 움직이는 이미지는 첫 장면만 변환됩니다.
- 그 밖의 파일(문서, 동영상 등)은 넣어도 자동으로 무시됩니다.

---

## 5. 브라우저별 동작

| 브라우저 | 저장 방식 |
|---|---|
| **Edge, Chrome** (권장) | 폴더에 바로 저장 |
| Safari, Firefox | 폴더에 직접 저장할 수 없어 `사진변환파일.zip`으로 다운로드 |

## 6. 문제 해결

| 증상 | 해결 방법 |
|---|---|
| 변환 시작을 눌러도 저장되지 않음 | 권한 요청 창에서 **허용**을 눌렀는지 확인. 거부했다면 다시 변환 시작을 눌러 허용 |
| `사진변환파일.zip`으로 받아짐 | Safari/Firefox로 열린 상태. Edge나 Chrome으로 다시 열기 |
| 일부 사진이 "읽을 수 없는 이미지" | 파일이 손상되었거나 지원하지 않는 형식 |
| HEIC 변환이 느림 | 정상입니다. HEIC는 해독에 시간이 걸려 한 장씩 처리합니다 (장당 수 초) |
| 사진 선택 창에 HEIC가 안 보임 | 파일 선택 창 오른쪽 아래 형식이 '사용자 지정 파일'인지 확인. 또는 드래그 앤 드롭 사용 |

### 알아둘 점
- 촬영 정보(날짜·위치 등 EXIF)는 변환된 JPG에 남지 않습니다.
- 매우 많은 사진(수천 장)을 한 번에 넣으면 브라우저가 느려질 수 있으니 나눠서 변환하세요.

## 7. 코드 수정 방법

`사진변환기.html`은 `소스코드` 폴더의 파일을 합쳐서 만든 결과물입니다.
**직접 고치지 말고** 아래 순서로 수정하세요.

```
3. Office tool/
├─ 사진변환기.html      ← 실제로 쓰는 파일 (build.py가 생성)
├─ README.md           ← 이 설명서
└─ 소스코드/
   ├─ index.html       화면 구성 (버튼, 문구)
   ├─ style.css        디자인 (색, 크기, 배치)
   ├─ app.js           동작 (파일 추가, 변환, 저장)
   ├─ build.py         위 파일들을 합쳐 사진변환기.html 생성
   └─ lib/             외부 라이브러리 (수정 금지)
```

1. `소스코드` 폴더의 `index.html`, `style.css`, `app.js` 중 필요한 파일을 수정합니다.
2. `소스코드` 폴더에서 다음을 실행합니다. (Python 필요, 코드 수정 시에만)

   ```bash
   python build.py
   ```
   Mac에서는 `python3 build.py`

3. 상위 폴더의 `사진변환기.html`이 새로 만들어집니다.

### app.js 주요 부분

| 구역 (주석 제목) | 하는 일 |
|---|---|
| `옵션 화면` | 크기 조절 방식 선택에 따라 입력칸 표시 |
| `저장 위치` | 저장 폴더 표시·변경 |
| `파일 추가` | 드래그 앤 드롭, 사진/폴더 선택 처리 |
| `목록` | 선택된 사진 목록 표시 |
| `이미지 읽기` | 형식별 해독 (HEIC → heic-to, TIFF → UTIF, 나머지 → 브라우저) |
| `크기 계산 · JPG 만들기` | 크기 계산(`calcSize`), JPG 생성(`toJpeg`) |
| `저장` | 폴더 저장(`writeFile`), ZIP 생성(`makeZip`) |
| `변환 실행` | 변환 시작 버튼 전체 흐름 |

자주 바꿀 만한 값:
- 저장 폴더 이름 → `app.js`의 `OUT_NAME`
- 지원 확장자 → `app.js`의 `EXT`
- 화질 기본값·비율 범위 → `index.html`의 `quality`, `pct` 입력칸
