# 실내공기질 데이터 처리 - 브라우저 실행 버전 (stlite)

기존 Streamlit 버전은 Python 설치, 가상환경, `pip install`, 터미널 명령어 실행이 모두 필요했습니다.
이 버전은 **`index.html` 파일 하나만 더블클릭해서 열면** 웹 브라우저 안에서 프로그램 전체가 실행됩니다.

## 사용 방법 (사용자용)

1. `index.html` 파일을 더블클릭해서 엽니다 (Chrome, Edge 권장).
2. 처음 열 때 화면이 뜨기까지 10~30초 정도 걸립니다 (파이썬 실행 환경을 브라우저 안에 준비하는 과정입니다). 인터넷 연결이 필요한 순간은 이때뿐입니다.
3. "실험노트 파일 업로드", "조회통계 파일 업로드"에 각각 `.xlsx` 파일을 올립니다.
4. 자동으로 1~6단계가 처리되고, 화면 상단에 "📥 최종 통합 데이터.xlsx 다운로드" 버튼이 나타납니다.
5. 중간 단계별 파일이 필요하면 아래쪽 "1단계 ~ 5단계" 항목을 펼쳐서 개별적으로 받을 수 있습니다.

## 데이터 보안

- 업로드한 엑셀 파일 내용은 **브라우저 밖으로 전혀 전송되지 않습니다.** 서버가 없고, 모든 계산이 사용자 PC의 브라우저 안(WebAssembly)에서 실행됩니다.
- 인터넷 연결은 최초 실행 시 프로그램 실행 환경(Pyodide/Streamlit 라이브러리)을 CDN에서 내려받을 때만 필요하며, 이 통신에는 업로드한 데이터가 포함되지 않습니다.
- 완전한 폐쇄망(오프라인)에서 계속 써야 한다면, 최초 1회는 인터넷이 되는 PC에서 실행해 브라우저 캐시를 만들어두거나, CDN 파일들을 사내망에 미러링해두는 방법을 고려해야 합니다 (필요하면 안내해드릴 수 있습니다).

## 파일 구성 (관리자/개발자용)

| 파일 | 역할 |
|---|---|
| `app.py` | 실제 데이터 처리 로직 (원본 `1.vscode_main.py`와 동일한 6단계 로직 + 컬럼 검증 추가). **로직을 수정할 때는 이 파일을 편집하세요.** |
| `index_template.html` | 배포용 HTML의 틀. stlite 런타임(CDN)을 불러오고 `__APP_PY_CODE__` 자리에 `app.py` 내용을 끼워 넣습니다. |
| `build.py` | `app.py` + `index_template.html` → 최종 `index.html`을 생성하는 빌드 스크립트. |
| `index.html` | **실제로 배포/공유하는 파일.** 더블클릭으로 실행됩니다. `app.py`를 고친 뒤에는 반드시 `python build.py`를 다시 실행해야 반영됩니다. |

### 로직 수정 절차

```bash
# 1. app.py 수정
# 2. 빌드 (index.html 재생성)
python build.py
# 3. index.html만 더블클릭해서 확인
```

## 원본 Streamlit 버전과의 차이점

- 설치 과정 없음 (Python, pip, 가상환경, 터미널 명령어 불필요).
- 서버 실행/종료 개념 없음 (그냥 파일을 열고 닫으면 됨).
- 최종 결과(6단계 통합 파일) 다운로드 버튼을 상단에 배치하고, 1~5단계 중간 파일은 접어서 필요할 때만 펼쳐보도록 정리했습니다.
- 업로드한 파일에 필요한 열(`접수번호`, `검체유형` 등)이 없을 경우 원인을 알려주는 오류 메시지를 추가했습니다.
- 최초 실행 시 라이브러리를 내려받는 데 10~30초 정도 걸리는 점만 감안하면, 이후 동작 방식은 기존 Streamlit 버전과 동일합니다.
