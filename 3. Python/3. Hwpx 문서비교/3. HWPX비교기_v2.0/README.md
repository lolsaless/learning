# HWPX 비교기 v2.0 — 비교 · 관계도 · 병합 · 고치기 · 이력 관리

같은 한글 문서(HWPX)의 여러 버전을 넣으면:

1. **원본과 버전 관계를 찾아** 관계도(나무 그림)로 보여 줍니다 — 누가 어느 문서를 고쳤는지, 갈래가 나뉘었는지
2. **바뀐 곳을 문서 모양 그대로** 보여 줍니다
3. **원하는 변경만 골라 깨짐 없이 병합**합니다 — 원본 서식 그대로, 바뀐 부분만 갈아 끼움
4. **문서를 직접 고쳐** 새 수정본을 만듭니다 — 새 글자는 앞 글자 서식을 이어받음
5. **프로젝트 폴더**에 원본·수정본·최종본을 나눠 저장하고 이력(project.json)을 남깁니다

- 파이썬 3.9 이상만 있으면 됩니다 (추가 설치 없음, 인터넷 없이도 동작 — 내부망 사용 가능)
- 파일은 내 컴퓨터 안에서만 처리됩니다 (127.0.0.1 로컬 서버)
- (선택) pywin32 를 설치하면 **한글로 다시 저장·PDF 저장**까지 됩니다 → `설치_pywin32.bat`

## 실행

| 컴퓨터 | 방법 |
|---|---|
| Windows | `실행_windows.bat` 더블클릭 |
| Mac | `실행_mac.command` 더블클릭 (처음 한 번 `chmod +x 실행_mac.command`) |
| VSCode/터미널 | `python HWPX비교기.py` (프로젝트 바로 열기: `python HWPX비교기.py --project 폴더`) |

## 화면 안내

| 탭 | 하는 일 |
|---|---|
| **요약** | 단계별 변경 건수. 갈래가 나뉜 문서면 알림과 [관계도]·[병합] 바로가기 |
| **관계도** | 문서 사이 관계 그림. **노드를 끌어 옮기고**, 빈 곳을 끌어 화면 이동, 휠로 확대. 노드를 누르면 오른쪽에서 **원본/수정본/최종본/보관 지정**, 부모 문서 바꾸기, 문서 보기·고치기·이 문서 기준 병합·한글에서 열기·내려받기. 선을 누르면 두 문서 비교 |
| **문서 보기·고치기** | 문서 모양 그대로 바뀐 곳 표시 (한 화면 / 나란히 / 원본만). **[✎ 이 문서 고치기]** → 문단·표 칸을 눌러 글자 고치기 → [수정본으로 저장] |
| **병합** | 기준(원본)과 합칠 버전을 고르면 원본 위에 변경 표시. **표시 위에 마우스를 올리면 버전별 변경이 말풍선으로** 나오고 바로 고를 수 있음. 빨강 = 충돌(직접 골라야 함). [결과 미리보기] → [최종본으로 저장] |
| 두 버전 비교 · 이력 추적표 · 문서 정보 | v1 과 같음 |

## 원본·최종본은 어떻게 찾나

- **원본**: ① 다른 모든 문서의 글자모양 목록이 이 문서 목록을 이어받음 (한글은 고칠 때 새 모양을 목록 끝에 붙임) ② 저장 시각이 가장 이름 ③ 내용이 가운데. 점수와 근거를 관계도 오른쪽에 보여 줍니다.
- **최신 저장 ≠ 최종본**: 가장 늦게 저장된 문서라도 다른 갈래의 수정을 담지 않았을 수 있습니다. 끝 문서가 여럿이면 병합해서 최종본을 만드세요.
- 추정이 틀리면 관계도에서 직접 지정하면 됩니다 (프로젝트에 기록).

## 여러 버전은 이렇게 비교하세요

저장 시각 순서로 줄 세워 비교하면, **원본에서 갈래로 나뉜 문서**를 '고쳤다가 되돌린 것'으로 잘못 보게 됩니다.
올바른 순서: **원본 찾기 → 관계도 확인 → [병합] 탭에서 원본 기준으로 모든 버전 비교 → 충돌만 골라서 병합**.

## 프로젝트 (이력 관리)

상단 **[새 프로젝트로 저장]** → 폴더 고르기(찾아보기 또는 경로 입력) → 아래처럼 만들어집니다.

```
내 폴더/
  project.json   이력 (문서 목록·역할·부모 관계·관계도 위치·작업 기록·병합 기록)
  1_원본/        원본
  2_수정본/      수정본들 (직접 고친 것 포함)
  3_최종본/      최종본 1개 — 새 최종본이 생기면 이전 것은 4_보관 으로 옮겨지고 교체
  4_보관/        예전 최종본 (지우지 않음, 이름 앞에 보관 시각)
  5_보고서/      보고서 저장 시 함께 저장
```
- 최종본을 고치면 고친 문서가 새 최종본이 됩니다.
- **[프로젝트 열기]**로 언제든 이어서 작업합니다. 목록에서 뺀 문서도 파일은 4_보관 에 남습니다.

## 한글 연동

| 기능 | 필요한 것 |
|---|---|
| 한글에서 열기 (파일 목록의 `한`, 관계도) | 없음 (한글이 .hwpx 기본 프로그램이면) |
| 한글로 다시 저장 (미리보기·줄 배치를 한글 방식으로 새로 만듦), PDF 저장 | pywin32 — `설치_pywin32.bat` |

**pywin32 를 프로그램에 함께 넣기 (내부망)**: 인터넷 되는 PC 에서 `vendor\받기_pywin32.bat` 실행 → 폴더째 복사 →
내부망 PC 에서 `설치_pywin32.bat`. 오른쪽 위에 **한글 자동화 ✓** 가 보이면 됩니다.

## 화면 없이 (명령줄)

```bash
python HWPX비교기.py 원본.hwpx 수정1.hwpx 수정2.hwpx --report     # 결과 글로 출력
python HWPX비교기.py --folder D:\감사자료 --merge 최종.hwpx          # 원본 판정 + 모든 갈래 병합 (충돌은 원본 유지)
python HWPX비교기.py --folder D:\감사자료 --html 변경이력.html
```

## 자동으로 못 하는 것 (v2.0)

- `.hwp`(옛 형식) — 한글에서 HWPX 로 저장해 넣기
- 병합: 그림이 든 변경, 머리말·각주 안 새 글, 표 행·열 추가 → 이유가 표시되니 한글에서 직접
- 고치기: 표·글상자를 품은 문단 → 한글에서 직접
- 문서 보기는 한글 화면과 완전히 같지 않음 (그림은 `[그림]`, 쪽 구분은 추정)
