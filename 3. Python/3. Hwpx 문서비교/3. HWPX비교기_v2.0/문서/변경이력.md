# 변경이력

## v2.0.0 — 2026-11-02 (관계도 · 병합 · 고치기 · 프로젝트 · 한글 연동)

- **관계도** 탭: 원본·최종본 추정(점수와 근거), 버전 나무 그림(갈래·병합·고침 구분), 노드 끌어 옮기기·화면 이동·확대,
  역할 지정(원본/수정본/최종본/보관), 부모 문서 지정, 선 누르면 두 문서 비교
- **병합** 탭: 원본 기준으로 여러 버전을 한 번에 비교 → 항목별 고르기(충돌·같은 변경·자동 불가 표시),
  변경 표시 위에 마우스를 올리면 버전별 변경 말풍선에서 바로 고르기, 결과 미리보기, 최종본/수정본으로 저장
  - 깨짐 없는 쓰기: 원본 XML 은 그대로 두고 바뀐 문단·표 칸만 바이트째 갈아 끼움, 모양 번호(글자·문단모양·테두리·탭·스타일·글꼴) 자동 맞춤
  - 첨부 문서 병합 결과가 한글에서 정상 열림 확인한 파일과 바이트 단위 동일
- **고치기**: 문서 보기에서 문단·표 칸 글자 고치기 → 새 수정본 (새 글자는 앞 글자 서식 이어받기, 고친 글자 색 표시 선택,
  수식 필드·구역 설정 보존). 최종본을 고치면 새 최종본
- **프로젝트**: 폴더(1_원본·2_수정본·3_최종본·4_보관·5_보고서) + project.json(문서·역할·부모·관계도 위치·작업·병합 기록),
  새 최종본이 생기면 이전 최종본은 4_보관 으로 교체, 프로젝트 열기로 이어서 작업, 폴더 고르기 창
- **한글 연동**: 한글에서 열기(기본), pywin32 있으면 한글로 다시 저장·PDF 저장. `설치_pywin32.bat`, `vendor/받기_pywin32.bat`
- 같은 파일은 한 번만 들어감(내용 지문으로 판별), 파일 목록에 역할 배지·한글 열기·내려받기
- 요약 탭: 갈래가 나뉜 문서 알림 (v1.1 의 '되돌림' 해석이 갈래 문서에서는 잘못일 수 있음을 안내)
- 명령줄: `--merge 출력.hwpx`(원본 판정 + 모든 갈래 병합), `--project 폴더`
- 시험 32개 (v2 14개 추가: 병합·충돌·같은 변경·삭제·표 제목 문단·모양/글꼴 맞춤·고치기·계보·프로젝트·작업공간 흐름)

## v1.1.0 — 2026-11-02 (원본 문서 모양 보기)

- **[문서 보기] 탭 추가**: 한글 문서 모양 그대로 그리고 바뀐 곳 표시
  - 재현: 용지 너비·여백, 문단 정렬·여백·들여쓰기/내어쓰기·문단 간격·줄간격, 글꼴·크기·색·굵게·기울임·밑줄·취소선·음영·자간,
    표(칸 합치기, 칸 너비·높이, 테두리 종류·굵기·색, 배경색, 세로 정렬), 머리말·꼬리말·각주·글상자, 쪽 구분(추정)
  - 보기 방식: 한 화면에 표시(지운 글자·문단도 제자리에 빨간 취소선) / 나란히 A|B(함께 스크롤) / 원본만
  - 이전·다음 변경 이동, 바뀐 곳 목록, 문서 위 표시를 누르면 목록 선택, 폭 맞춤·확대
  - [요약]의 '문서로 보기', [두 버전 비교]의 '문서에서 보기'로 바로 이동
- 보고서: **문서 모양 + 바뀐 곳 표시 HTML** (단독 파일, 변경 목록에서 이동, 인쇄)
- 엔진: 파서가 배치 트리(layout)·문단모양·테두리/배경·용지 설정을 함께 기록,
  글자 차이 조각에 이전 버전 글자("a"), 서식 변경에 글자 위치 범위 추가
- 화면: 좁은 화면에서 탭 이름이 줄바꿈되던 문제 수정
- 폴더 정리: `3. Python/3. Hwpx 문서비교/` 아래 `1. HWPX비교기_v0.1`(보관), `2. HWPX비교기_v1.1`(작업본)
- 시험 18개 (엔진 9, 문서 보기 6, 서버 3)
