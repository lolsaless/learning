# 변경이력

## v0.1.0 — 2026-11-02 (최초 모델)

- HWPX 해석: 본문 문단, 표 셀(중첩 표 포함), 머리말·꼬리말·각주·미주·글상자, 그림/수식 표시
- 글자모양(charPr) → 실제 서식(글꼴·크기·색·굵게·기울임·밑줄·취소선·음영·장평·자간)으로 해석해 파일 간 비교
- 비교: 블록 짝짓기(순서 유지 + 유사도), 단어/글자 단위 차이, 서식 변경, 숫자·표·서식·공백 꼬리표, 문서 정보 변경
- 여러 버전: 수정일 순 자동 정렬(이름 순·직접 지정 가능), 단계별 요약, 이력 추적표(되돌림·추가됨·삭제됨)
- 대시보드: 끌어 놓기(폴더 포함)·파일/폴더 선택·경로 입력, 진행 막대·작업 로그, 비교 옵션, 4개 탭
- 보고서: 두 버전 비교 / 전체 이력 — HTML, CSV(엑셀)
- 명령줄: `--report`, `--html`, `--csv`, `--json`, `--folder`
- 시험 12개 (엔진 9, 서버 3)
