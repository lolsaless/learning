# HWPX 변경이력 비교기 v0.1

같은 한글 문서(HWPX)의 여러 버전을 넣으면 **무엇이 바뀌었는지** 찾아 브라우저 화면으로 보여 줍니다.
원본을 따로 지정하지 않아도 문서 속 **마지막 수정일 순서**로 버전을 세웁니다.

- 파이썬 3.9 이상만 있으면 됩니다 (추가 설치 없음, 인터넷 연결 없이도 동작 — 내부망 사용 가능)
- 파일은 내 컴퓨터 안에서만 처리됩니다 (127.0.0.1 로컬 서버, 외부 전송 없음)

## 실행

| 컴퓨터 | 방법 |
|---|---|
| Windows | `실행_windows.bat` 더블클릭 |
| Mac | `실행_mac.command` 더블클릭 (처음 한 번 터미널에서 `chmod +x 실행_mac.command`) |
| VSCode/터미널 | `python HWPX비교기.py` |

브라우저가 자동으로 열립니다 (안 열리면 창에 나온 주소 `http://127.0.0.1:8765` 를 직접 여세요).
끝낼 때는 화면 오른쪽 위 **[종료]** 또는 검은 창에서 `Ctrl+C`.

## 사용 순서

1. **파일 넣기** — HWPX 파일이나 폴더를 왼쪽 상자에 끌어 놓거나 [파일 선택]·[폴더 선택].
   폴더 경로를 직접 입력해 파이썬이 읽게 할 수도 있습니다 (하위 폴더 포함 가능).
2. **버전 순서** — 자동으로 수정일 순(v1 → 최신). [이름 순]으로 바꾸거나 ▲▼로 직접 조정.
   내용이 완전히 같은 파일은 ⚠ 표시.
3. **비교 옵션** — 공백 무시, 서식 변경 포함, 표 포함, 단어/글자 단위, 수정 판정 기준.
4. **결과 보기**
   - **요약**: 버전 흐름, 단계별(v1→v2, v2→v3…) 변경 건수와 주요 변경. 줄을 누르면 해당 비교로 이동.
   - **두 버전 비교**: 아무 두 버전을 골라 비교. 종류(수정·추가·삭제·서식·숫자·표)로 거르기, 검색,
     [변경 목록] / [나란히 보기]. <del>삭제</del>는 빨간 취소선, 추가는 초록 밑줄.
   - **이력 추적표**: 바뀐 위치마다 버전별 내용을 한 줄로. **바뀌었다가 원래대로 되돌아간 곳(되돌림)** 도 찾아 줍니다.
   - **문서 정보**: 작성자, 수정일, 문단·표·셀 수 등.
5. **보고서 저장** — 오른쪽 위 메뉴에서 HTML(인쇄·공유용) 또는 CSV(엑셀) 저장.

## 무엇을 찾아 주나

| 종류 | 예 |
|---|---|
| 수정 | ‘3.2’ → ‘2.2’, ‘북’ → ‘남’ (숫자가 바뀌면 `숫자` 꼬리표) |
| 추가·삭제 | 새로 생긴 문단·표 칸, 없어진 문단 |
| 서식 | 같은 글자의 글자색·크기·굵게·밑줄 등 변경, 새로 쓴 글자가 빨간색인지 등 |
| 위치 | 「본문 16번째 문단」, 「표 5 · 10행 5열」, 가까운 제목(□ 조사 결과), 약 n쪽 |
| 문서 정보 | 마지막 수정일·저장자·한글 버전 변경 |

## 화면 없이 쓰기 (명령줄)

```bash
python HWPX비교기.py 원본.hwpx 수정1.hwpx 수정2.hwpx --report      # 결과를 글자로 출력
python HWPX비교기.py --folder D:\감사자료 --html 변경이력.html        # 보고서 파일로 저장
python HWPX비교기.py --folder D:\감사자료 --csv 변경이력.csv
python HWPX비교기.py --help
```

## 안 되는 것 (v0.1)

- `.hwp`(옛 형식)는 읽지 못합니다 → 한글에서 [다른 이름으로 저장] → HWPX 로 저장해 넣으세요.
- 문단 정렬·줄간격, 표 모양(행 추가·셀 합치기), 그림 내용 변화는 비교하지 않습니다.
- 쪽 번호는 추정값이라 한글 화면과 다를 수 있습니다.
