## 새 버전 만들 때

1. 최신 폴더를 `N. HWPX비교기_vX.Y` 로 복사 (예: `4. HWPX비교기_v2.1`)
2. `hwpxdiff/__init__.py` VERSION, `문서/변경이력.md`, 그 폴더 `CLAUDE.md` 의 현재 버전·작업 기록 고치기
3. 이 파일과 `README.md` 의 '최신 버전' 과 표 갱신, 저장소 최상위 `README.md` 폴더 안내 확인
