# 취합검증 도우미(가칭) v2.1 — 유지보수 안내

프로그램을 고치거나 기능을 더할 사람을 위한 안내다. 구성요소 전체 목록·파일·함수는 **6 구성도 탭** 또는 `docs/파트지도.md`(자동 생성)에서 본다.

---

## 1. 다섯 층

```
[U] 화면          app/ui/          index.html(뼈대) · css/app.css · js/core.js · js/fsdialog.js
                                   pages/<이름>.html(모양) + js/pages/<이름>.js(동작) × 7
      │  api("/api/…")
[W] 화면 연결     app/web/         server.py(서버·주소표) · core_routes.py · eval_routes.py · demo.py
                                   fsbrowse.py · partmap.py
      │
[A] 조립부        app/             workspace.py(작업 조립부) · evaluation.py(평가 조립부) · main.py(시작점)
      │  파트를 만들고 값을 넘겨 연결(계산 없음)
[P] 기능 파트     app/parts/<이름>/  sources · document · verify · edit · history · export · clip · ai · compare · mockdata
      │
[B] 바탕          app/             config.py · common/ · formats/(registry + 14개 형식, 4.4) · store/
```

| 규칙 | 내용 | 검사 |
|---|---|---|
| R1 | 파트는 다른 파트·조립부·화면 연결을 import 하지 않는다 | tests/test_structure.py 1 |
| R2 | 바탕(common·formats·store)은 파트·조립부·화면 연결을 import 하지 않는다 | 2 |
| R3 | 켜진 파트 폴더에는 `__init__.py` · `part.py` · `routes.py` · `README.md` | 3 |
| R4 | 화면 주소가 겹치지 않고, 화면(js)이 부르는 주소는 서버에 모두 있다 | 4 |
| R5 | 파이썬 파일 하나 800줄 이하 | 5 |
| R6 | 표준 라이브러리만(설치 없이 실행), Python 3.8 이상 | 3.8로 run_all |
| R7 | 원본 파일은 읽기만, 새 파일은 작업 폴더·시연자료 폴더 안에만 | 기능 시험 |

파트끼리 값이 필요하면: 조립부가 A를 부르고 결과를 B에 **인자로** 넘기거나, A에 **알림 함수(콜백)** 를 연결한다(예: 원본을 읽으면 `on_load` → 검증 파트 색인에 추가).

## 4. 따라 하기

### 4.1 새 기능 파트 추가
1. `app/parts/<이름>/` 에 `__init__.py`(빈 파일) · `part.py` · `routes.py` · `README.md` 를 만든다.
2. `part.py`: `class <이름>Part: def __init__(self, ctx)`. 다른 파트는 import 하지 않는다.
3. `routes.py`: `def routes(app): return [("GET"|"POST", "/api/<이름>/…", 처리함수), …]`
4. `app/workspace.py` 에서 파트를 만들고, 다른 파트 값을 꺼내 넘겨 주는 함수를 추가한다.
5. `config.PARTS` 에 이름을 넣는다.
6. 화면이 필요하면 `ui/pages/<이름>.html` · `ui/js/pages/<이름>.js` 를 만들고 `index.html` 에 탭 버튼·`<section>`·`<script>` 를 한 줄씩, `js/core.js` 의 `showTab` 에 들어갈 때 부를 함수를 넣는다. 파트 지도에 탭 이름을 보이려면 `app/web/partmap.py` 의 `PAGE_NAMES` 에도 넣는다.
7. `python tests/run_all.py` → **전체 통과**.

### 4.2 시연자료에 새 자료 영역 추가
1. `app/parts/mockdata/domains.py` 에 `make_<이름>(rng, ctx)` 를 만들어 `DataTable` 을 돌려준다(행·열 이름, 진짜 값, 표시 자릿수, 합계·비율, 원본 머리글·배율).
2. `DOMAINS`, `DOMAIN_TITLES` 에 넣는다. 팀이 새로 필요하면 `vocab.TEAMS` 에 넣는다.
3. `python tools/evaluate.py --n 50` 으로 빨강 오탐 0 인지 확인한다(정상 표가 오류로 보이면 안 됨).

### 4.3 새 오류 종류 추가
1. `app/parts/mockdata/errors.py` 의 `KINDS` · `KIND_NAMES` · `EXPECT`(기대 판정)에 넣는다.
2. `Injector.e_<종류>()` 를 만든다: 문서 모형 글자를 바꾸고 `self.add(…)` 로 정답표 항목을 남긴다(합계·비율 연쇄는 자동).
3. 자동 평가로 검출률을 확인한다. 엔진이 못 찾으면 엔진을 고칠지, 기대 판정을 넓힐지 정한다.

### 4.4 새 파일 형식 추가
1. `app/formats/<형식>.py` 에 읽기 함수를 만든다. 시트형은 `Workbook`(`app/formats/xlsx/model.py` 의 `Sheet`·`Cell`)을, 문서형은 `{"blocks": [{"type": "p", "text"} | {"type": "table", "cells": [{r, c, rs, cs, text}], "nrow", "ncol"}], "warnings": []}` 를 돌려준다.
2. `app/formats/registry.py` 의 `FORMATS` 에 `".확장자": ("sheet" 또는 "doc", "화면에 보일 이름", "app.formats.<형식>:<함수>", False)` 한 줄을 넣는다.
3. `tests/fixtures/formats/` 에 **가상 값** 파일 하나를 넣고 `tests/test_formats.py` 의 `test_fixtures` 목록에 한 줄 추가.
4. 끝 — 원본 등록·검증 대상·재제출 비교·파일 고르기 창·형식 목록이 자동으로 새 형식을 쓴다.

### 4.5 AI 모델 바꾸기·비교
- 바꾸기: 7 설정 → AI 의 모델 이름(코드 수정 없음). 기본값 주소는 `config.AI_DEFAULT_URL`.
- 비교: `python tools/ai_eval.py --models ollama:A ollama:B --n 10` → `평가결과/AI모델비교_*.md`. **빨강 오탐은 어떤 모델이든 0 이어야 한다**(0이 아니면 AI 읽기 결과가 빨강으로 새고 있다는 뜻 — `parts/ai/part.py` 의 `_add` 상태 결정 확인).
- 지시문을 고치면 `mock`·실제 모델로 비교표를 다시 만든다.

### 4.6 엔진을 고칠 때
1. 고치기 전에 `python tools/evaluate.py --n 100 --seed 40000` 결과를 적어 둔다.
2. 고친 뒤 같은 명령으로 비교한다. **빨강 오탐이 늘면 되돌린다.**
3. `python tests/run_all.py` — 고정 시연 정답표 18/18 과 회귀 씨앗값 10개(tests/test_mockdata.py)가 지켜지는지 확인.

## 7. v2.0 에서 고친 엔진 규칙(2026-10-29)

| 증상(자동 평가에서 발견) | 원인 | 수정 | 결과 |
|---|---|---|---|
| 한 자리 수 "9"를 "0"으로 잘못 적은 칸이 '단위 다름'으로 나옴 | 9×0.001=0.009가 반올림 0이 되어 단위 환산으로 설명됨 | `_relation`: 0이거나 환산값이 표시 자릿수로 0이면 단위 다름 근거로 쓰지 않음 | '불일치'로 바르게 판정 |
| 숫자 2개뿐인 행에서 하나가 틀리면 행을 못 맞춰 '후보 여러 개' | 남은 숫자 하나로는 원본 행을 정할 수 없음 | `table_map._fill_rows_by_label`: 숫자로 못 맞춘 행만, 원본에 이름이 똑같은 행이 한 곳뿐이면 연결 | 불일치·충돌을 찾음 |
| 작은 정수만 있는 표가 원본과 아예 연결되지 않음 | 흔한 값이라 투표에서 빠짐 | 마지막 수단: 흔한 값 포함 재투표, 표 60% 이상이 정확히 한 덩어리(흩어짐 ≤1.5)일 때만 인정 | 연결됨, 빨강 오탐 0 유지 |

## 8. v2.1 에서 고친 규칙(2026-10-29)

| 증상(자동 평가에서 발견) | 원인 | 수정 | 결과 |
|---|---|---|---|
