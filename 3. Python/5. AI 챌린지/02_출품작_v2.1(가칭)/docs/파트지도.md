## 1. 한눈에 보기

```
[U] 화면
    U1:뼈대·공통  U2:1 작업 준비  U3:2 검증  U4:3 입력하기  U5:4 이력  U6:5 시연자료  U7:6 구성도  U8:7 설정·도움말
[W] 화면 연결
    W1:서버  W2:공통 주소  W3:평가 주소  W4:시연 준비  W5:폴더 탐색  W6:파트 지도
[A] 조립부
    A1:시작점  A2:작업 조립부  A3:평가 조립부
[P] 기능 파트
    P1:원본  P2:문서  P3:검증  P4:수정·입력  P5:이력  P6:내보내기  P7:클립보드  P8:AI(문장 검산)  P9:재제출 비교  P10:가상자료
[B] 바탕
    B1:설정  B2:공통 도구  B3:파일 형식  B4:저장소
```

위층은 아래층을 쓰고, 아래층은 위층을 모른다. 기능 파트(P)끼리는 서로 부르지 않는다.

### P9 재제출 비교

팀이 원본을 고쳐 다시 보냈을 때 **무엇이 바뀌었고 문서의 어느 칸을 고쳐야 하는지** 알려 준다.
1. 보관: 원본을 등록하거나 내용이 바뀔 때마다 그 판을 작업 폴더 `원본보관/` 에 복사(원본 파일은 그대로)

4. 짝 찾기: 이름이 바뀐 새 파일(`…(수정).xlsx`)이 어느 원본의 새 판인지 이름·내용으로 추정
