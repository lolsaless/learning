## 1. 한 줄 소개

> 행정사무감사 요구자료처럼 **여러 원본을 모아 만든 문서의 모든 숫자**를 원본과 대조해 틀린 곳·출처를 알려 주고, 팀이 다시 보낸 파일의 **바뀐 곳과 고쳐야 할 칸**을 찾아 주며, 문장 속 계산과 **AI가 쓴 글의 숫자**까지 다시 계산해 검증하는 도구.
> AI는 글을 읽는 일만 하고, **맞다·틀리다 판정은 언제나 프로그램 계산이 한다.**

## 4. 형식 등록부 — "어떤 파일이 와도"

### 4.1 두 가지 모양으로 정규화

모든 형식은 읽은 뒤 두 모양 중 하나가 된다. 검증 엔진·재제출 비교·화면은 이 두 모양만 안다.

| 모양 | 내용 | 형식 | 출처 주소 |
|---|---|---|---|
| **시트**(Workbook) | 시트 → (행, 열) → 값·표시 글자 | xlsx · xlsm · xls · ods · csv · tsv | `시트!B4` |
| **문서**(blocks) | 문단 `{"type":"p","text"}` · 표 `{"type":"table","cells":[{r,c,rs,cs,text}]}` | hwpx · hwp · docx · odt · pdf · txt · md · html | `표2 3행 4열` |

문서 모양은 `TextDoc`(읽기 전용) 또는 `HwpxDoc`(고칠 수 있음)이 되어 검증 대상으로 쓰이고, `table_grids()` 로 시트처럼 바뀌어 원본으로도 쓰인다.

### 4.2 형식별 읽기(모두 표준 라이브러리로 직접 구현)

| 형식 | 파일 | 방법 | 확인 |
|---|---|---|---|
| hwpx | formats/hwpx/ | zip + XML, 누름틀 | v1.0부터 |
| hwp(5.0) | hwp.py · ole.py | OLE 묶음 → FileHeader(압축·암호·배포용) → BodyText 레코드(문단 66·글자 67·컨트롤 71·목록 72·표 77), 칸 합치기·캡션 | 공개 시험용 hwp 28개 중 26개가 공개 도구(hwp5txt) 결과와 글자 동일(나머지 2개는 이 프로그램이 더 많이 읽음) · 시험용 작성기로 자동 시험 |
| xls | xls.py | BIFF8 레코드(SST·LABELSST·NUMBER·RK·MULRK·FORMULA·XF 서식). HTML 을 xls 로 저장한 파일도 자동 처리 | 6,657칸 0불일치(같은 자료 xlsx 대비) |
| ods · odt | odf.py | content.xml, 반복 행·열·합친 칸 | 6,657칸 0불일치 |
| docx | docx.py | document.xml, gridSpan·vMerge | 시험 통과 |
| csv · tsv · txt · md | text.py | UTF-8 → CP949 → EUC-KR 자동, 구분자 추정, 마크다운·탭 표 | 시험 통과 |
| html | html.py | 표 rowspan·colspan, 표 안의 표 | 시험 통과 |
| pdf | pdf/ | 객체·압축(Flate·LZW·A85·AHx·예측자)·ObjStm → 글꼴(ToUnicode·UCS2·Differences) → 글자 위치 → 줄 → **표 테두리선·간격으로 칸** → 표·문단. 쪽 넘김 표 잇기·머리글 반복 제거·줄바꿈 문장 잇기 | 실제 공정시험기준 PDF 40개: 숫자 12,808/12,809 · 표 60개 · 오류 0 · 3.9초 |

읽지 못하는 것과 안내: 스캔 PDF(글자 없음, OCR 없음) · 암호 hwp/PDF · 배포용 hwp · doc/ppt/pptx/hwt/그림(→ "PDF 나 docx 로 저장해 주세요" 안내, `registry.HINTS`).

### 4.3 검증 대상이 hwpx 가 아닐 때

hwpx 는 작업본(누름틀)을 만들어 바로 고친다. 그 밖의 형식은 **읽기 전용 검증**: 원본을 작업 폴더 `작업본/` 에 복사해 대조·재계산·출처대장·검증보고를 만들고, 고치기 버튼은 끈다. [글 붙여넣기]로 붙인 글(AI 초안)은 `입력글/*.md` 로 저장해 같은 방식으로 검증한다.

## 5. AI 파트(ai) — "AI 는 읽기, 판정은 계산"

### 5.1 하는 일

| 일 | AI 없이 | AI 있으면 |
|---|---|---|
| 문장 속 계산(차이·비중·배수·합계·평균) 검산 | **규칙 읽기**: 정해진 문형 4종(…보다 ○건 많음 / 전체 ○건 중 ○건(○%) / (○)의 ○배 / ○, ○을 합하여 총 ○) | 규칙이 못 읽은 문장(숫자 3개 이상 등)을 AI 가 **검산식(JSON)** 으로 바꿈 |
| 증감률(대비 ○% 증가) | 검증 엔진(v2.0부터) | — |
| 검증 결과 요약 | 규칙 요약(항상 정확) | AI 요약 초안 + **숫자 검사**(검증 결과에 없는 숫자 표시) |
| AI 가 쓴 보고서 검증 | [글 붙여넣기] → 원본 대조(지어낸 숫자 = 출처 미확인) | 같음 |

### 5.2 AI 출력 검증(코드)

```
문장 ─▶ AI ─▶ JSON {"checks":[{"type":"diff","a":"1,520","b":"1,208","c":"312","dir":"증가"}]}
                 │
                 ├─ ① JSON 인가? 종류·칸이 다 있나?            아니면 버림(탈락 기록)
                 ├─ ② 모든 숫자가 문장에 글자 그대로 있나?     아니면 버림("지어낸 숫자")
                 └─ ③ 프로그램이 계산: |1,520−1,208| = 312 → 문장의 312 와 비교(표시 자릿수 반올림)
                         맞음 → 초록(계산 확인) / 틀림 → 노랑(확인 필요: 문장 계산 다름, AI 읽기)
```

| 읽은 쪽 | 계산 맞음 | 계산 틀림 | 왜 |
|---|---|---|---|
| 규칙 | 초록 | **빨강**(계산 오류) | 문형이 정해져 있어 숫자 역할을 잘못 읽을 위험이 낮음 |
| AI | 초록 | **노랑**(확인 필요) | AI 가 숫자 역할을 잘못 짝지었을 수 있음 → 사람이 확인. 계산이 맞으면 우연히 맞을 확률이 낮으므로 초록 |

→ **AI 가 무엇을 답해도 빨강 오탐은 생기지 않는다.** (엉터리 답 50%를 섞은 시험에서도 빨강 오탐 0 — 9장)

### 5.3 모델 교체(모델 비종속)

| 항목 | 내용 |
|---|---|
| 연결 | `providers.py`: Ollama(`/api/chat`) · OpenAI 호환(`/v1/chat/completions`: LM Studio·llama.cpp·vLLM 등) · 시험용 모의 AI |
| 바꾸는 법 | 설정 화면에서 종류·주소·모델 이름(예: `exaone3.5:7.8b`, `qwen2.5:7b`) → `AI설정.json`. 코드 수정 없음 |
| 지시문 | `prompts.py` 한 곳(모델과 무관하게 같은 지시문, 예시 4개) |
| 보안 | 기본은 내 컴퓨터(127.0.0.1·localhost)만 허용(`config.AI_ALLOW_REMOTE=False`). 문서 내용이 밖으로 나가지 않음 |

## 6. 재제출 비교 파트(compare)

| 항목 | 설계 |
|---|---|
| 보관 | 원본 등록·변경 때마다 작업 폴더 `원본보관/<번호>_<내용고유값12자>.<확장자>` 로 복사(원본 파일은 그대로) |
| 같은 이름으로 덮어씀 | [원본 변경 확인] → 내용고유값이 바뀐 원본은 보관본(이전 판)과 칸 단위 비교 |
| 이름을 바꿔 보냄 | [다시 받은 파일 비교] → 이름(`(수정)`·`_최종`·날짜 떼고 비교)·내용(시트 이름·글자 칸 겹침) 점수로 짝 후보 → 비교 → 확인하면 원본 교체 |
| 비교 | 형식 무관(`flatten`): xlsx ↔ ods ↔ csv ↔ pdf ↔ docx … 행이 끼워지거나 빠지면 행 이름으로 줄 맞춤(difflib). 시트 하나뿐인 자료(CSV)는 이름이 달라도 짝 |
| 영향 | 바뀐 칸을 마지막 검증에서 출처로 쓴 문서 칸 + **새 값으로 바꾸면 문서에 적힐 값**(배율·자릿수 반영). 교체 후 다시 검증하면 그 칸이 빨강 |
| 한계 | 여러 칸의 평균·합으로 만든 값(월평균 등)은 새 값을 미리 계산하지 않음(다시 검증하면 빨강으로 보임) · 인쇄 문서 원본은 끝자리 1 차이 가능 |

## 7. 새 파트·새 형식 추가하는 법

**새 파트**: ① `app/parts/<이름>/`(`__init__.py`·`part.py`·`routes.py`·`README.md`) ② `class <이름>Part(ctx)` — 다른 파트 import 금지 ③ `routes(app)` ④ `workspace.py` 에서 만들고 값 연결 ⑤ `config.PARTS` 에 추가 ⑥ 화면 `ui/pages`·`ui/js/pages` ⑦ `python tests/run_all.py`

**새 형식**: ① `app/formats/<형식>.py` 에 읽기 함수 — 시트형은 `Workbook`, 문서형은 `{"blocks": […], "warnings": […]}` 를 돌려줌 ② `registry.FORMATS` 에 `".확장자": ("sheet"|"doc", "이름", "모듈:함수", False)` 한 줄 ③ `tests/test_formats.py` 에 고정 자료 하나 → 끝(검증·비교·화면은 자동으로 따라옴)
