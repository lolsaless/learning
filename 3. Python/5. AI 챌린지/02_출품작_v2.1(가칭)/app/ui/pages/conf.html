AI(선택 기능)

AI 는 문장 속 계산을 검산식으로 읽기와 요약 초안만 합니다. 맞고 틀림은 프로그램이 계산해서 정하고, AI 답에 문장에 없는 숫자가 있으면 버립니다. 기본은 내 컴퓨터(127.0.0.1)의 AI 만 쓸 수 있어 문서가 밖으로 나가지 않습니다. 모델은 이름만 바꾸면 교체됩니다(Ollama: ollama pull exaone3.5:7.8b 후 이름 입력). AI 를 쓰지 않아도 모든 기능이 동작합니다.

복사 순간 출처 기록 (Windows)

켜 두면 엑셀에서 Ctrl+C로 복사할 때마다 파일 경로·시트·칸을 기록합니다. 한글에 붙여 넣은 숫자는 검증할 때 이 기록과 맞춰 출처로 표시됩니다. 엑셀에서 복사한 것만 기록하며, 기록은 이 PC의 작업 폴더에만 저장됩니다.

사용 순서

  1. 작업 준비: 작업 폴더를 열고, 검증할 문서와 원본을 등록합니다. 한글(hwp·hwpx)·엑셀(xls·xlsx·ods·csv)·워드(docx·odt)·PDF·txt·md·html 을 읽습니다(고치기는 hwpx 만, 나머지는 읽기 전용 검증). AI 가 쓴 글은 [글 붙여넣기]로 검증합니다.
  2. 검증: 숫자마다 색이 칠해집니다. 숫자를 누르면 어느 파일 어느 칸에서 왔는지, 원본 값이 무엇인지 보입니다.
  3. 틀린 칸은 [이 값으로 고치기], 출처가 여러 곳이면 맞는 출처를 골라 [이 출처로 확정]합니다.
  4. 입력하기: 빈 칸·고칠 칸을 누르고 원본 셀을 끌어 고른 뒤 [입력하기] → 값과 출처가 함께 기록됩니다.
  5. 저장(새 버전): 작업본 v002, v003…이 만들어지고 바뀐 칸이 모두 이력에 남습니다.
  6. 내보내기: 출처대장(xlsx), 검증표시본(hwpx, 틀린 칸 빨강·확인 필요 노랑), 검증보고(html — 문장 검산·효과 추정 포함).
  7. 팀이 원본을 다시 보내면: [원본 변경 확인](같은 이름으로 덮어쓴 경우) 또는 [다시 받은 파일 비교](이름이 다른 경우) → 바뀐 칸과 고쳐야 할 문서 칸을 보여 줍니다.
  8. 문장 속 계산(…보다 ○건 많음, 전체 ○건 중 ○%, ○배, 합하여 총 ○건)은 검증할 때 자동으로 다시 계산합니다. 정해지지 않은 문형은 [AI 로 문장 읽기](AI 설정 필요).

색의 뜻

알아 둘 점

  • '일치'는 원본 값을 문서의 표시 자릿수로 반올림했을 때 같다는 뜻입니다(예: 2.338 → 2.3).
  • 여러 칸을 더한 값처럼 원본에 그대로 없는 숫자는 '출처 미확인'으로 표시됩니다. 틀렸다는 뜻이 아닙니다.
  • 작업본은 한글에서 열어 직접 고쳐도 됩니다. 다시 검증하면 바뀐 칸이 '한글에서 직접 수정'으로 이력에 남습니다.
