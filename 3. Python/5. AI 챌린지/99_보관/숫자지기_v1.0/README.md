# 숫자지기 v1.0

**한글(hwpx) 보고서의 숫자마다 원본 엑셀 출처를 찾아 대조하고, 고친 값과 출처를 이력으로 남기는 도구**

- 대상 업무: 의회 보고자료·행정사무감사 요구자료처럼 여러 팀이 엑셀에서 숫자를 옮겨 적고 취합하는 문서
- 형식: HTML 화면 + Python 로컬 서버(표준 라이브러리만 사용, 패키지 설치 없음, 인터넷 불필요)
- 판정: 규칙·계산 기반(저사양 PC에서도 동작). AI 모델은 v1.0에 포함하지 않음

## 실행

| OS | 방법 |
|---|---|
| Windows | `숫자지기_열기.bat` 더블클릭 (Python 3.8 이상 필요) |
| Mac·Linux | `python3 app/server.py` |

브라우저에 `http://127.0.0.1:8765` 화면이 열린다. **[시연 시작]** 을 누르면 가상 자료로 바로 시연된다.

## 주요 기능

1. **출처 자동 대조**: 행·열 이름이 달라도, 일부만 복사했거나 행·열이 뒤집혀 있어도 숫자 배열 모양으로 원본 위치를 찾는다(반올림·단위 환산 인식).
2. **오류 표시**: 불일치 · 단위 다름(원↔천원) · 합계/비율 재계산 · 증감률 문장 재계산 · 날짜 요일 · 원본 간 충돌 · 출처 미확인.
3. **바로 수정·입력**: [이 값으로 고치기], 원본 셀을 끌어 고른 뒤 [입력하기] → 작업본 새 버전(v002…)으로 저장.
4. **이력**: 칸마다 이전 값·새 값·방법·출처(전체 경로·시트·칸·SHA-256)·작업자. 한글에서 직접 고친 내용도 다음 검증 때 기록.
5. **원본 변경 감지**: 원본 파일 고유값 비교 → 다시 검증하면 상태가 바뀐 칸만 표시.
6. **내보내기**: 출처대장(xlsx 5시트), 검증표시본(hwpx, 빨강·노랑 표시), 검증보고(html).
7. **복사 순간 출처 기록**(Windows): 엑셀 Ctrl+C 때 파일·시트·칸 기록.

## 폴더

```
app/server.py        실행(로컬 서버)        app/config.py   바꿀 수 있는 설정값
app/core/            엔진                   app/ui/         화면
tools/make_demo.py   시연 자료 생성기       tests/          자동 시험·채점·화면 시험
docs/                설계서·매뉴얼          시연자료/       가상 기관 자료
```

## 시험

```
python tests/test_all.py          # 자동 시험 20개
python tests/score_demo.py        # 시연 정답표 채점
python tests/e2e_ui.py            # 화면 시험(서버 실행 후, Playwright 필요)
```

결과(2026-10-26): 정답표 18/18 일치·오탐 0, 자동 시험 20개 통과(Linux·Mac), 원본 18개 검증 1.2~3.2초.
