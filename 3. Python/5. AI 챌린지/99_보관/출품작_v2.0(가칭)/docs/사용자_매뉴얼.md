# 취합검증 도우미(가칭) v2.0 — 사용자 매뉴얼

- 한 줄 소개: **요구자료 취합 문서(hwpx)의 숫자마다 원본 엑셀 출처를 찾아 대조하고, 고친 값과 출처를 이력으로 남기는 도구**
- 이름은 가칭이다. 정식 이름은 `app/config.py` 의 `APP_NAME` 한 줄로 바꾼다.
- 작성: 2026-10-29

---

## 1. 무엇을 해 주나

| 고민 | 이 프로그램이 하는 일 |
|---|---|
| 여러 팀 엑셀을 옮겨 적다 숫자가 틀림 | 문서의 모든 숫자를 원본 엑셀·팀 제출 hwpx와 대조해 **빨강(틀림)·노랑(확인 필요)·연녹(일치)** 으로 칠한다 |
| 합계·비율·증감률·요일이 맞는지 일일이 계산 | 표 합계 행·열, 비율(%) 열, "전년 대비 ○% 증가" 문장, 날짜 요일을 다시 계산한다 |
| "이 숫자 어디서 왔지?" | 숫자마다 출처(파일 전체 경로·시트·칸·파일 고유값)를 찾아 보여 주고 **출처대장**으로 남긴다 |
| 팀이 엑셀을 고쳐 다시 보냄 | 원본이 바뀐 것을 알아채고, 다시 검증하면 상태가 바뀐 칸만 알려 준다 |
| 누가 언제 무엇을 고쳤는지 모름 | 값이 바뀔 때마다 이전 값·새 값·방법·출처·작업자를 이력에 쌓는다(지우지 않음) |
| 시연·평가용 자료가 없음 | **무작위 가상자료**(가상 기관의 원본·답변서·오류 심은 취합본·공문·참고자료·정답표)를 만들고 **자동 채점**한다 |

판정은 모두 **규칙과 계산**으로 한다. 원본 파일은 읽기만 하고, 고친 내용은 작업 폴더의 새 파일로 저장한다.

## 2. 설치와 실행

### 2.1 준비물

| 항목 | 내용 |
|---|---|
| 운영체제 | Windows 10·11(주 사용), macOS·Linux(시험용) |
| Python | **3.8 이상**(표준 라이브러리만 사용, 추가 설치 없음). 3.8.20·3.10(사용자 PC)·3.13에서 전체 시험 통과 |
| 브라우저 | Edge·Chrome(인터넷 연결 불필요) |
| 파일 형식 | 검증 대상: hwpx / 원본: xlsx·xlsm·hwpx / 가상 공문: hwpx·odt |

Python 설치(Windows): python.org 에서 내려받아 설치 화면 첫 장의 **"Add python.exe to PATH"** 를 체크한다. 설치가 어려우면 휴대용(embeddable) Python 을 프로그램 폴더 안 `python\` 폴더에 넣어 두면 그대로 쓴다.

### 2.2 실행 파일(더블클릭)

| Windows | Mac | 하는 일 |
|---|---|---|
| `실행_Windows.bat` | `실행_Mac.command` | **프로그램 실행**(브라우저 화면이 열림) |
| `시연자료_만들기_Windows.bat` | `시연자료_만들기_Mac.command` | 무작위 시연자료 3개 만들기 |
| `자동평가_Windows.bat` | `자동평가_Mac.command` | 무작위 시나리오 20개로 자동 평가 → 보고서 |
| `시험_전체실행_Windows.bat` | `시험_전체실행_Mac.command` | 자동 시험 전체(구조·기능·가상자료) |
| `기본시연자료_다시만들기_Windows.bat` | (명령: `python3 tools/make_demo.py`) | 고정 시연자료(한빛도) 다시 만들기 |

### 2.3 처음 실행
1. `실행_Windows.bat` 을 더블클릭한다. 검은 창이 뜨고 브라우저에 화면이 열린다.
2. 검은 창이 프로그램 본체다. **닫으면 프로그램이 꺼진다.**
3. 화면이 안 열리면 주소창에 `http://127.0.0.1:8765` 를 입력한다(사용 중이면 검은 창에 나온 번호).
4. 이 PC 안에서만 열리는 주소다. 다른 PC에서는 접속할 수 없다.

### 2.4 폴더 구성

```
출품작_v2.0(가칭)/

├─ app/                ← 프로그램(구성은 docs/파트지도.md)

```

## 4. 일상 업무 순서

1. **작업 준비**
   1. [작업 폴더 열기·만들기] → 이번 보고 건의 작업 폴더를 고르거나 만든다.
   2. [문서 선택] → 취합한 hwpx 를 고른다. **작업본 v001** 이 만들어진다(원본 문서는 그대로).
   3. [폴더째 추가] → 원본 엑셀·팀 제출 hwpx 가 든 폴더를 고른다(하위 폴더까지 등록).
2. **검증** → [검증 실행 →]
   - 빨강부터 본다. [다음 문제 ▶]로 차례로 이동한다.
   - 불일치: 오른쪽 원본 칸(주황 테두리)을 확인하고 **[이 값으로 고치기]**.
   - 출처 간 충돌: 어느 원본이 맞는지 판단해 맞는 값으로 고치거나 **[이 출처로 확정]**.
   - 출처 미확인: 계산한 값이면 근거를 확인한다. 원본이 따로 있으면 등록하거나 [입력하기]로 출처를 붙인다.
3. **입력하기**: 자릿수·배율(÷1,000 등)·쉼표를 고른 뒤 넣는다. 값이 이미 같으면 바꾸지 않고 출처만 확정한다.
4. **저장(새 버전)**: 메모를 적고 확인 → 작업본 v002 가 생기고 이력에 남는다.
5. **내보내기**: `작업 폴더\내보내기` 에 출처대장(xlsx)·검증표시본(hwpx)·검증보고(html).
6. 팀이 원본을 고쳐 보냈다면 → **[원본 변경 확인]** → 다시 검증 → '바뀐 칸'만 확인.

작업본은 한글에서 직접 고쳐도 된다. 저장 후 다시 검증하면 바뀐 칸이 '한글에서 직접 수정'으로 이력에 남는다.

### 4.1 내보내기 파일

| 파일 | 내용 |
|---|---|
| 출처대장_문서_날짜.xlsx | 검증결과(칸별 상태·출처 전체 경로·시트·칸·원본 값) / 값 이력 / 원본 목록(고유값) / 원본 변경 기록 / 작업본 버전 |
| 검증표시본_문서_v00N_날짜.hwpx | 작업본 사본. 틀린 칸 빨간 굵은 글씨, 확인 필요 칸 노란 배경 |
| 검증보고_문서_날짜.html | 인쇄용 요약(브라우저에서 Ctrl+P) |

## 5. 시연자료 만들기(5 시연자료 탭)

### 5.1 고정 시연자료와 무작위 시연자료

| 구분 | 고정 시연자료 | 무작위 시연자료 |
|---|---|---|
| 위치 | `시연자료/` | `시연자료_무작위/<도이름>_<씨앗값>/` |
| 기관 | 한빛도 보건환경연구원(항상 같음) | 가상 기관 8곳 중 무작위 |
| 쓰임 | 시연 영상·자동 시험 기준(정답표 18개) | 다양한 평가·시연, 기능 개발 시험 |
| 시작 | 1 작업 준비 → [시연 시작] | 5 시연자료 → [이 자료로 시연] |

### 5.2 만들기 설정

| 설정 | 뜻 |
|---|---|
| 씨앗값 | 같은 값이면 언제나 같은 자료가 만들어진다. 비우면 무작위 |
| 크기 | 작게(요구자료 5개)·보통(8개)·크게(12개) |
| 오류 수 | 취합본에 심을 오류 수(0~30). 표 수보다 많으면 문장 오류로 채운다 |
| 오류 종류 | 자리 바뀜·옮겨 적기 오타·합계·단위 혼동·비율·증감률·요일·출처 간 충돌·출처 없는 숫자 |
| 함께 만들 문서 | 공문(요구·검사 의뢰·결과 알림·협조 요청) / 참고자료(시험법 요약본·장비 점검 매뉴얼·작성 지침) / 작성틀 / 재제출본 |
| 공문 형식 | hwpx + odt, hwpx 만, odt 만 |

### 5.3 만들어지는 것

```
<도이름>_<씨앗값>/
├─ 공유폴더(가상)/2026 행정사무감사/
│  ├─ 00_공문함/     요구 공문, 검사 의뢰 2건, 결과 알림 2건, 협조 요청(hwpx·odt)
│  ├─ 01_원본자료/   팀별 원본 엑셀(머리글을 코드·다른 이름으로, 행·열 뒤집기, 원 단위, 월별 시트, 세부기록 등)
│  ├─ 02_팀제출/     팀 답변서 hwpx
│  ├─ 03_취합/       취합본(오류 심음), 작성틀
│  └─ 04_참고자료/   시험법 요약본 2개, 장비 점검 매뉴얼, 요구자료 작성 지침
├─ 나중에_받은_자료/  재제출본 2개(같은 이름 1개, '(수정)' 붙은 이름 1개)
├─ 정답표.json        자동 채점용: 대조 오류·연쇄·정상 사례 / 재제출 바뀐 칸 / 문서 판정
└─ 시나리오_안내.md   사람이 읽는 요약(심은 오류 표)
```

자료 영역 12종: 시험·검사 실적, 하천 수질(월별 평균), 대기 측정망(행·열 뒤바뀜), 세출예산(원→천원), 검사 의뢰 접수, 먹는물 검사, 폐수 검사(부적합률), 장비 보유, 인력, 악취 민원(증감률 문장), 생태하천 점검, 정도관리.

공문·설명서는 업무 폴더 문서에서 **여러 문서에 공통으로 나오는 서식의 틀**(수신·경유·제목·본문 번호·붙임·끝·발신명의·결재 줄·시행 번호·공개 구분 / 개요→시약·기구→시료 채취→분석 흐름→정도관리→주의 포인트)만 참고했다. **이름·기관·주소·번호·수치는 모두 지어낸 것**이다.

### 5.4 채점과 시연
- **[채점]**: 그 시나리오를 검증 엔진으로 돌려 정답표와 비교한다(맞음/틀림, 빨강 오탐, 노랑).
- **[이 자료로 시연]**: 시나리오 안에 `작업(시연)` 작업 폴더를 만들고 취합본·원본을 등록한 뒤 2 검증 탭으로 간다.
- **[폴더] [안내]**: 시나리오 폴더, 시나리오_안내.md 를 연다.

## 6. 자동 평가

무작위 시나리오를 여러 개 만들어 검증 엔진을 채점한다(5 시연자료 탭 → 3 자동 일괄 평가, 또는 `자동평가_Windows.bat`).

| 지표 | 뜻 |
|---|---|
| 심은 오류 검출 | 정답표의 오류 칸이 기대한 판정(예: 자리 바뀜 → 불일치)으로 나온 비율 |
| 정상 판정 | 정상 사례(반올림·단위 환산·행·열 뒤바뀜·머리글 다름 등)를 정상으로 본 비율 |
| 빨강 오탐 | 정답표에 없는 칸을 불일치·계산 오류·충돌로 칠한 수 — **0이어야 함** |
| 노랑 | 출처 미확인·후보 여러 개(사람 확인 필요). 오류가 아니라 '확인 권고' |
| 출처 위치 일치 | 정상 사례에서 엔진이 고른 첫 출처가 정답표의 파일·시트·칸과 같은 비율 |

**2026-10-29 개발 환경 평가(처음 보는 씨앗값 150개, 24,464칸)**

| 크기 | 심은 오류 검출 | 정상 판정 | 빨강 오탐 | 출처 위치 일치 |
|---|---|---|---|---|
| 작게 40개 | 360/360 | 403/403 | 0 | 400/400 |
| 보통 60개 | 717/717 | 974/974 | 0 | 960/960 |
| 크게 50개 | 599/600 | 1,234/1,234 | 0 | 1,197/1,200 |

놓친 1건은 작은 정수(한두 자리)만 있는 표에서 팀 제출본과 원본이 다른 경우다(10장 알려진 한계).

명령줄: `python tools/evaluate.py --n 100 --size 크게 --errors 12 --seed 40000`, 하나만: `python tools/evaluate.py --score 시연자료_무작위/가람도_777`

## 7. 6 구성도 보는 법

- 다섯 층: **U 화면 → W 화면 연결 → A 조립부 → P 기능 파트 → B 바탕**. 위층이 아래층을 쓰고, 아래층은 위층을 모른다.
- 상자 하나 = 구성요소 하나(번호 예: P3 검증). 누르면 오른쪽에 파일·줄 수·클래스·함수·화면 주소가 나온다.
- 파랑 = 고른 구성요소가 쓰는 것, 주황 = 그것을 쓰는 것.
- 아래 **고칠 곳 찾기** 표: "이걸 고치려면 어느 파일" 안내.
- 코드를 직접 읽어 만들므로 늘 최신이다. 같은 내용이 `docs/파트지도.md` 에도 있다(`python tools/part_map.py` 로 다시 만듦).

## 8. 문제 해결

| 증상 | 원인·조치 |
|---|---|
| "Python 3.8 이상이 필요합니다" | Python 미설치·PATH 미등록 → 2.1대로 설치하거나 휴대용 Python 을 `python\` 폴더에 |
| 검은 창이 바로 닫힘 | 명령 프롬프트에서 `실행_Windows.bat` 을 실행해 오류 문구 확인 |
| 브라우저가 안 열림 | 주소창에 `http://127.0.0.1:8765` (검은 창에 나온 번호) |
| "프로그램과 연결이 끊겼습니다" | 검은 창이 닫힘 → 다시 실행(작업은 작업 폴더에 남아 있음) |
| "구형 hwp 또는 암호가 걸린 문서" | 한글에서 hwpx 로 다시 저장, 암호 해제 |
| "이미 대상 문서가 있습니다" | 작업 폴더 1개 = 문서 1개. 새 문서는 새 작업 폴더에서 |
| 원본 '읽기 실패' | 손상·암호·구형 xls → 엑셀에서 xlsx 로 다시 저장 후 빼고 다시 추가 |
| 거의 모든 칸이 '출처 미확인' | 원본을 등록하지 않았거나 다른 원본을 등록함 |
| 맞는 값인데 '출처 미확인' | 여러 칸을 더한 값 등 계산값 → 근거 확인 후 그대로 두어도 됨 |
| "직접 고칠 수 없습니다" | 숫자가 한글 서식 때문에 여러 조각 → 한글에서 작업본을 고친 뒤 다시 검증 |
| 시연자료 만들기가 느림 | '크게'+공문+참고자료는 파일이 40개 가까이 됨. 평가만 할 때는 자동 평가(공문 등 생략)를 쓴다 |

## 9. 주의

1. **원본·대상 문서는 수정하지 않는다.** 수정은 작업본(v002…)에만 저장된다.
2. `작업장부.db`(이력 장부)를 지우면 이력이 사라진다. `백업` 폴더에 하루 1회 자동 백업이 있다.
3. '일치'는 **원본과 같다**는 뜻이지 원본이 맞다는 뜻이 아니다.
4. 대조는 숫자 글자 기준이다. 그림 속 숫자·서식은 보지 않는다.
5. 시연·개발에는 가상 자료만 쓴다. 실제 업무 자료를 쓰면 출처대장에도 그 값이 들어가므로 보관에 주의한다.
