## 모범 프롬프트

```
엑셀 VBA 매크로를 만들어 줘. VBA는 처음이야.

[시트 구성]
- '접수목록' 시트: 1행은 제목, 2행부터 데이터. A번호, B접수번호, C채취장소, D검체유형, E접수일.
  시료 수는 매번 달라.
- '시퀀스' 시트: 1행 제목(A Run#, B Run Name, C Vial). 2행부터 결과를 쓸 거야.

[규칙]
1. 맨 앞 고정 행: Wash(Vial 10), STD1~STD5(Vial 11~15), Blank1(Vial 1)
2. 그다음 접수목록 순서대로 시료를 넣어. Run Name은 접수번호, Vial은 21부터 1씩 증가.
3. 시료의 검체유형이 바로 앞 시료와 다르면, 그 시료 앞에 Blank를 하나 넣어.
   Blank 이름은 Blank2, Blank3...처럼 번호가 늘어나고, Vial은 그 번호(2, 3...)와 같아.
4. Run#은 1부터 차례로.
5. 실행할 때마다 '시퀀스' 시트 2행 아래 이전 내용을 지우고 새로 써.
6. Blank 행은 노란색 배경으로 표시해.

[예시 결과 앞부분]
1 | Wash | 10
2 | STD1 | 11
...
7 | Blank1 | 1
8 | (첫 시료 접수번호) | 21

한글 주석을 달고, 붙여 넣고 실행하는 방법도 알려 줘.
```

## 모범 코드

> 🧑‍🏫 **강사:** 수업 전에 실제 엑셀에서 한 번 실행해 확인하세요. 코드는 복사·붙여넣기로 넣습니다.

```vba
Option Explicit

' 접수목록 시트를 읽어 분석 시퀀스를 만든다.
' 규칙: Wash → STD1~5 → Blank1 → 시료(Vial 21부터), 검체유형이 바뀌면 Blank 추가
Sub MakeSequence()
    Dim wsIn As Worksheet, wsOut As Worksheet
    Dim lastRow As Long        ' 접수목록의 마지막 행
    Dim outRow As Long         ' 시퀀스 시트에 쓸 행
    Dim i As Long
    Dim vial As Long           ' 다음 시료의 Vial 번호
    Dim blankNo As Long        ' 지금까지 넣은 Blank 번호
    Dim prevType As String     ' 바로 앞 시료의 검체유형
    Dim curType As String      ' 지금 시료의 검체유형

    Set wsIn = ThisWorkbook.Worksheets("접수목록")
    Set wsOut = ThisWorkbook.Worksheets("시퀀스")

    ' 이전 결과 지우기 (값과 색 모두)
    wsOut.Range("A2:C1000").Clear

    outRow = 2
    ' 1) 고정 행: Wash, STD1~5, Blank1
    AddRow wsOut, outRow, "Wash", 10, False
    For i = 1 To 5
        AddRow wsOut, outRow, "STD" & i, 10 + i, False
    Next i
    blankNo = 1
    AddRow wsOut, outRow, "Blank1", 1, True

    ' 2) 시료 행
    lastRow = wsIn.Cells(wsIn.Rows.Count, "B").End(xlUp).Row
    vial = 21
    prevType = CStr(wsIn.Cells(2, "D").Value)      ' 첫 시료의 검체유형

    For i = 2 To lastRow
        curType = CStr(wsIn.Cells(i, "D").Value)
        If curType <> prevType Then                ' 검체유형이 바뀌면
            blankNo = blankNo + 1                  ' Blank 번호를 하나 늘리고
            AddRow wsOut, outRow, "Blank" & blankNo, blankNo, True
            prevType = curType
        End If
        AddRow wsOut, outRow, CStr(wsIn.Cells(i, "B").Value), vial, False
        vial = vial + 1
    Next i

    MsgBox "시퀀스 " & (outRow - 2) & "행을 만들었습니다."
End Sub

' 시퀀스 시트에 한 행을 쓰고, 다음 행으로 넘어간다.
Private Sub AddRow(ws As Worksheet, ByRef r As Long, runName As String, vialNo As Long, isBlank As Boolean)
    ws.Cells(r, 1).Value = r - 1          ' Run# (2행이 1번)
    ws.Cells(r, 2).Value = runName
    ws.Cells(r, 3).Value = vialNo
    If isBlank Then
        ws.Range(ws.Cells(r, 1), ws.Cells(r, 3)).Interior.Color = RGB(255, 242, 204)   ' 연한 노랑
    End If
    r = r + 1
End Sub
```

### 해설 포인트
| 코드 | 설명 |
|---|---|
| `Private Sub AddRow(... ByRef r As Long ...)` | 한 행 쓰기를 **작은 Sub로 분리**. 같은 일을 여러 번 하므로 묶어 둠. 3단계 "함수"의 예고편 |
| `ByRef r` | AddRow 안에서 `r = r + 1` 한 것이 바깥(outRow)에도 반영됨 |
| `prevType` / `curType` | "바로 앞 시료와 비교"하는 규칙을 코드로 옮긴 부분 |

### 규칙 바꿔 보기 정답 예 (5개마다 Blank)
- 시료 개수를 세는 변수(`sinceBlank`)를 두고, Blank를 넣을 때마다 0으로 되돌린 뒤, 시료를 넣을 때마다 1씩 늘림
- 조건을 `If curType <> prevType Or sinceBlank = 5 Then` 으로 바꿈

## 실제 업무 파일과의 차이 (강사 참고)
- 실제 `유기인 시퀀스.xltm`의 매크로(`UpdateRun`)는 `Sheet2`(접수 목록)의 **E열(검체유형)** 을 기준으로 Blank를 넣고 `Sheet1`에 시퀀스를 씁니다. 실습 파일은 이를 단순화하고 시트 이름을 한글로 바꿨습니다.
- 실제 템플릿을 열어 매크로 코드를 함께 읽어 보는 것도 좋은 마무리입니다. ("AI가 만든 코드와 무엇이 다른가?")
