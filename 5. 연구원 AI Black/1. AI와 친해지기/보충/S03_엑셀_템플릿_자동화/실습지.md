# S03. 엑셀 템플릿 자동화 — 분석 시퀀스 만들기 (보충 실습)

| 항목 | 내용 |
|---|---|
| 권장 시기 | 3주차 (05회 이후) |
| 시간 | 60~70분 |
| 준비물 | 데스크톱 엑셀, AI 채팅 계정 |
| 실습 파일 | `유기인_시퀀스_실습.xlsx` (가상 데이터), `해답_유기인_시퀀스_결과.xlsx` |
| 참고 자료 | `0. 업무자동화 강의/5. Excel/1.유기인 시퀀스 작성/유기인 시퀀스.xltm` (실제 업무용 템플릿) |

## 목표
- 기기 분석 **시퀀스(분석 순서표)** 를 접수 목록에서 자동으로 만드는 매크로를 AI와 함께 만든다.
- **규칙을 정확히 말로 설명하는 연습**을 한다. (규칙 설명이 곧 프롬프트)
- 매크로가 들어 있는 **엑셀 서식 파일(.xltm)** 을 만들어 매번 새 파일로 쓰는 법을 익힌다.

---

## 1. 오늘의 문제 (10분)

GC 등 분석 기기로 시료를 분석할 때는 **시퀀스**를 만듭니다. 어떤 순서로, 몇 번 자리(Vial)의 시료를 분석할지 정한 표입니다.

### 실습 파일 살펴보기
- `접수목록` 시트: 오늘 분석할 시료 9개 (접수번호, 채취장소, 검체유형 등)
- `시퀀스` 시트: 비어 있는 시퀀스 표 (Run#, Run Name, Vial)

### 시퀀스 작성 규칙

| 순서 | Run Name | Vial | 설명 |
|---|---|---|---|
| 1 | Wash | 10 | 세척 |
| 2~6 | STD1 ~ STD5 | 11 ~ 15 | 표준용액 5개 |
| 7 | Blank1 | 1 | 첫 바탕시료 |
| 8~ | 접수번호 | 21부터 1씩 증가 | 접수목록 순서대로 |
| (중간) | Blank2, Blank3 … | 2, 3 … | **검체유형이 바뀔 때마다** 그 시료 앞에 바탕시료 추가 |

### 손으로 하면?
매번 접수 목록을 보며 순서를 적고, 검체유형이 바뀌는 곳을 찾아 Blank를 끼워 넣고, Vial 번호를 하나씩 계산합니다. 시료가 40~50개면 실수하기 쉽습니다.

## 4. 서식 파일(.xltm)로 만들기 (10분)

매크로가 든 파일을 **서식 파일**로 저장하면, 열 때마다 **새 문서**로 열려 원본 템플릿이 망가지지 않습니다.

1. `시퀀스` 시트의 결과와 `접수목록` 시트의 데이터를 지웁니다. (제목 행만 남기기)
2. [파일] → [다른 이름으로 저장] → 파일 형식 **"Excel 매크로 사용 서식 파일 (*.xltm)"**
3. 저장한 `.xltm`을 더블클릭 → 제목이 `유기인 시퀀스1`처럼 **새 문서**로 열리는지 확인
4. 업무 때마다: 템플릿 열기 → 접수 목록 붙여 넣기 → 매크로 실행 → `.xlsx`로 저장

> 📎 실제 업무에서 쓰는 템플릿: `0. 업무자동화 강의/5. Excel/1.유기인 시퀀스 작성/유기인 시퀀스.xltm`
> (실제 파일의 `접수목록`에 해당하는 시트는 `Sheet2`, 시퀀스는 `Sheet1`입니다.)

## 정리
- 자동화의 핵심은 **규칙을 정확히 말로 쓰는 것**입니다. 규칙을 잘 쓰면 AI는 코드를 잘 씁니다.
- 결과는 **검증표**로 확인합니다. 특히 경계(검체유형이 바뀌는 곳, 마지막 행)를 꼭 봅니다.
