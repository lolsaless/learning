### 과제 3. 파이썬 코드
```python
# CO2 측정값 목록
values = [612, 845, 1020, 534, 980]

# 1000 이상인 값만 골라내기
over = [v for v in values if v >= 1000]

# 개수와 평균 출력
print("1000 이상인 값의 개수:", len(over))                # 1
print("1000 이상인 값의 평균:", sum(over) / len(over))     # 1020.0
print("전체 평균:", sum(values) / len(values))             # 798.2
```
- 질문의 "평균"이 **전체 평균인지, 1000 이상인 값의 평균인지 애매**합니다. AI가 어떻게 해석했는지 확인하고, 애매한 질문이 어떤 결과를 낳는지 토론하세요. → 02회 "구체적으로" 원칙의 복습
