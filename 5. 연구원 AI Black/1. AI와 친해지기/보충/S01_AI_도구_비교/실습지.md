|---|---|

## 1. 서비스 한눈에 보기 (10분)

> 서비스 기능과 무료 범위는 자주 바뀝니다. 아래는 일반적인 특징이며, 정확한 내용은 각 서비스 화면에서 확인하세요.

| 서비스 | 만든 곳 | 잘 알려진 강점 | 이럴 때 써 보기 |
|---|---|---|---|
| **ChatGPT** | OpenAI | 기능이 다양함 (파일 분석, 이미지 생성, 웹 검색, 음성 대화) | 엑셀 파일을 올려 분석하기, 그림·도표 만들기 |
| **Claude** | Anthropic | 긴 문서 읽기, 자연스러운 글쓰기, 코드 작성 | 긴 공문·보고서 요약, 코드 작성·설명 |
| **Gemini** | Google | 구글 서비스(드라이브·지메일·문서) 연동, 웹 검색 | 구글 드라이브 문서 활용, 최신 정보 검색 |
| **Copilot** | Microsoft | 엑셀·워드·파워포인트 등 오피스 연동 (기관 계약에 따라 다름) | 오피스 문서 안에서 바로 사용 |

### 무료 vs 유료 (일반적인 차이)
| 무료 | 유료 |
|---|---|
| 하루 사용량 제한이 있음 | 사용량이 많음 |
| 최신·고성능 모델은 제한적으로 사용 | 고성능 모델을 넉넉하게 사용 |
| 기본 기능 | 파일 분석, 긴 대화, 에이전트 기능 등 확장 |

## 2. 같은 문제, 다른 AI (35분)

아래 4가지 과제를 **두 개 이상의 AI**에 똑같이 보내고 비교하세요. (각각 **새 대화창**에서)

### 과제 1. 글쓰기 — 측정 결과 안내문
```
나는 환경 연구기관의 실내공기질 검사 연구원이야.
어린이집 원장님께 "교실 CO2 평균 1,050ppm으로 기준(1,000ppm)을 약간 넘었다"는 결과를
알리는 안내문을 써 줘. 걱정을 과하게 키우지 않으면서 환기 방법 3가지를 안내해 줘. 6문장 이내.
```

### 과제 2. 엑셀 — 수식 만들기
```
엑셀 A열에 "2025-04-08 10:21:12" 같은 측정 시각이 있어.
B열에 시각만(10:21), C열에 "오전/오후"를 표시하는 수식을 알려 줘.
```

### 과제 3. 코드 — 파이썬 맛보기
```
파이썬으로 CO2 측정값 리스트 [612, 845, 1020, 534, 980]에서
1000 이상인 값의 개수와 평균을 출력하는 코드를 써 줘. 초보자용 한글 주석을 달아 줘.
```

### 과제 4. 정확성 — 사실 확인
```
실내공기질 공정시험기준에서 이산화탄소를 측정하는 주 시험방법의 이름과 원리를 알려 줘.
근거 문서 이름도 함께 알려 줘.
```

### 비교표 (각 1~5점)

| 과제 | 기준 | AI ① ______ | AI ② ______ | AI ③ ______ |
|---|---|---|---|---|
| 1. 안내문 | 말투·길이·바로 쓰기 | | | |
| 2. 엑셀 | 수식이 정확한가 (실제로 넣어 보기) | | | |
| 3. 코드 | 설명이 쉬운가 / 결과가 맞나 (개수 2, 평균 1000.0) | | | |
| 4. 사실 | 근거를 밝히나 / 모르면 모른다고 하나 | | | |
| **합계** | | | | |

> 💡 과제 3의 정답: 1000 이상인 값은 1020 **1개**입니다. (980은 미만) 평균은 1020 하나의 평균이면 **1020.0**, 전체 평균이면 **798.2**. AI가 무엇의 평균을 낸 것인지, 질문이 애매하지 않았는지도 생각해 보세요.
