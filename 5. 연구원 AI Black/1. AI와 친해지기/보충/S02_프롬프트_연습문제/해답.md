# S02 해답 — 모범 프롬프트 20

> 모범 답안은 **하나의 예시**입니다. 5요소가 들어 있고 결과가 좋으면 모두 정답입니다.
> `[ ]`는 실제 상황에 맞게 채우는 부분입니다.

---

## A. 문서 작업

**1. 공문 요약**
```
나는 [수질환경팀] 연구원이야. 아래 공문을 팀원들에게 메신저로 공유하려고 해.
1) 한 줄 요약 2) 우리 팀이 할 일(할 일, 기한) 표 3) 제출 서류 목록 순서로 정리해 줘.
공문에 없는 내용은 쓰지 마. (공문 — 담당자 이름·연락처는 지움)
```

**2. 일정 안내 문자**
```
실내공기질 측정 대상인 [어린이집] 담당자에게 보낼 일정 안내 문자를 써 줘.
일시 [10월 14일(화) 10~12시], 요청 사항 [측정 30분 전 창문 닫기], 문의처 [연구원 대표번호].
3문장 이내, 정중하게.
```

**3. 분기 보고서**
```
너는 공공기관 보고서 작성 전문가야. 나는 실내공기질 검사 연구원이고 과장님께 [3분기] 결과를 보고해.
아래 자료로 개조식 1쪽 보고서 초안을 써 줘. 목차: 검사 개요 / 결과 / 기준 초과 및 조치 / 향후 계획.
자료에 없는 숫자·사실은 지어내지 말고 [작성 필요]로 비워 둬. (자료)
```

**4. 교육 자료 목차**
```
[어린이집 원장님 대상] [30분] 실내공기질 관리 교육 자료를 만들려고 해.
먼저 목차만 5~7개 제안해 줘. 각 목차마다 핵심 내용 한 줄과 예상 시간을 적어 줘.
내가 고르면 다음 단계로 내용을 채울 거야.
```

**5. 회의록**
```
아래 회의 메모를 회의록 양식으로 정리해 줘.
양식: 일시 / 참석자(직위만) / 안건 / 논의 내용(안건별 개조식) / 결정 사항 / 할 일(담당, 기한).
메모에 없는 결정은 만들지 말고, 불분명한 부분은 [확인 필요]로 표시해 줘. (메모)
```

**6. 문장 다듬기**
```
아래 보고서 문단을 과장님이 읽기 쉽게 다듬어 줘.
- 뜻과 숫자는 바꾸지 말 것
- 문장 길이는 40자 안팎으로 짧게
- 고친 문단 아래에 무엇을 바꿨는지 3줄로 설명
(문단)
```

## B. 엑셀 작업

**7. 평균과 판정**
```
엑셀 '측정' 시트 B3:B27에 CO2 값(ppm)이 있어. '요약' 시트 B2에 평균(소수점 1자리),
C2에 판정(평균이 H1 칸의 기준 이상이면 "부적합", 아니면 "적합") 수식을 알려 줘.
수식을 아래로 복사할 거야. 각 부분의 뜻도 설명해 줘.
```

**8. 다른 시트에서 찾아오기**
```
엑셀 '결과' 시트 A열에 접수번호가 있고, '접수' 시트 A열 접수번호, C열 시설명이 있어.
'결과' 시트 B열에 접수번호에 맞는 시설명을 가져오는 수식을 알려 줘.
못 찾으면 "없음"이라고 표시하고 싶어. 엑셀 버전은 [Microsoft 365 / 2016]이야.
XLOOKUP과 VLOOKUP 두 가지로 알려 줘.
```

**9. 분기 구하기**
```
엑셀 A열에 날짜(예: 2025-08-14, 날짜 형식)가 있어.
B열에 "3분기"처럼 분기를 표시하는 수식을 알려 줘. 1~3월=1분기 기준.
```

**10. 시트 이름 일괄 변경 매크로**
```
엑셀 VBA 매크로를 만들어 줘. VBA는 처음이야.
'요약' 시트를 뺀 모든 시트의 이름을 각 시트 A1 칸의 값으로 바꾸고 싶어.
A1이 비어 있거나 같은 이름이 이미 있으면 건너뛰고, 끝나면 바꾼 개수를 메시지로 보여 줘.
한글 주석과 실행 방법도 알려 줘.
```

**11. 중복 찾기**
```
엑셀 '접수목록' 시트 B열(B2:B500)에 접수번호가 있어.
중복된 접수번호를 찾고 싶어. 두 가지 방법을 알려 줘.
1) 조건부 서식으로 중복 칸 색칠하기 (메뉴 순서대로)
2) C열에 "중복" 표시하는 수식
```

## C. 데이터·분석

**12. 메모 → 표**
```
아래 측정 메모를 표로 만들어 줘. 열: 날짜, 시설, 측정지점, 항목, 측정값.
한 줄에 측정값 하나. 연도는 2025년.
예시) "4/8 효자동 어린이집 1층 CO2 평균 612" → | 2025-04-08 | 효자동 어린이집 | 1층 | CO2 | 612 |
메모에 없는 값은 만들지 말고, 표 아래에 측정값 개수를 적어 줘. (메모)
```

**13. 정상 범위 판단**
```
나는 실내공기질 검사 연구원이야. [노인요양시설] 생활실의 [폼알데하이드] 측정값이 [72 μg/㎥]야.
이 값을 해석할 때 확인해야 할 기준(법령 이름과 별표)을 알려 주고,
기준과 비교하는 방법을 설명해 줘. 기준 수치는 내가 원문에서 확인할 테니, 확실하지 않으면 그렇다고 말해 줘.
```

**14. 경향 분석**
```
너는 환경 데이터 분석 전문가야. [2022~2024년] 실내공기질 측정 결과(시설군, 측정일, 항목별 측정값) 데이터가 있어.
연도별·시설군별 경향을 보려면 어떤 분석을 하면 좋을지 3가지 제안하고,
각각 엑셀로 하는 방법과 파이썬으로 하는 방법을 간단히 비교해 줘. 데이터는 보여 줄 수 없어.
```

**15. 그래프**
```
엑셀에 시설별 CO2 평균(A열 시설명, B열 평균, 10개 시설)이 있어.
기준선(1000ppm)이 함께 보이는 막대그래프를 만드는 방법을 메뉴 순서대로 알려 줘.
기준을 넘는 막대만 빨간색으로 하고 싶어.
```

## D. 학습·문제 해결

**16. 용어 이해**
```
파이썬의 "가상환경(venv)"을 프로그래밍을 처음 배우는 사람에게 설명해 줘.
1) 비유 하나 2) 왜 필요한지 3줄 3) 안 쓰면 생기는 문제 예시 1개.
```

**17. 오류 해결**
```
엑셀 매크로를 실행했더니 오류가 났어. 원인과 해결 방법을 알려 줘.
- 하려던 일: [시트 이름 바꾸기]
- 오류 메시지 전체: [런타임 오류 '1004': ...]
- 노란색으로 표시된 줄: [ws.Name = parts(UBound(parts))]
- 코드 전체: (붙여넣기)
초보자도 알게 원인을 먼저 설명하고, 고친 코드 전체를 보여 줘.
```

**18. 자동화 방법 고르기**
```
너는 업무 자동화 컨설턴트야. 나는 프로그래밍 초보 연구원이야.
[매 분기 엑셀 파일 25개를 열어 같은 위치의 값 6개를 모아 하나의 표로 만드는 일]을 자동화하고 싶어.
엑셀 수식, 엑셀 매크로, 파이썬 세 가지 방법의 난이도·장단점을 표로 비교하고, 초보자에게 하나를 추천해 줘.
```

**19. 사실 확인**
```
방금 알려 준 내용 중 법령 이름, 조항·별표 번호, 기준 수치를 각각 근거와 함께 다시 정리해 줘.
확실하지 않은 항목은 "확인 필요"로 표시하고, 내가 원문을 확인할 수 있는 사이트를 알려 줘.
```

**20. 큰 작업 나누기**
```
[3분기 실내공기질 결과 보고서]를 만들 거야. 보고서 본문, 시설군별 결과 표, 그래프가 필요해.
한 번에 다 하지 말고 단계별로 하자.
1단계로 전체 작업 순서를 5단계 이내로 제안해 줘. 내가 확인하면 단계별로 진행할게.
```
