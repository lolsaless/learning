1. AI에게 **표 구조를 설명해서** 원하는 엑셀 수식을 받고, 직접 넣어 확인한다.

## 2. 오늘의 문제 (5분)

`이산화탄소_측정기록_실습.xlsx`를 열어 함께 봅니다. (**가상 데이터**입니다)

| 시트 | 내용 |
|---|---|
| `요약` | 측정지점별 평균·최대·최소·판정을 채울 빈 표. H1 칸에 기준값 1000 |
| `측정1`, `측정2`, `측정3` | 측정기에서 받은 5분 간격 CO2 기록 25개씩. A1 칸에 `0408_가상어린이집_1층교실` 같은 제목 |

### 지금까지의 방법 (손으로)
1. 시트마다 평균·최대·최소를 계산기로 구하거나 함수를 하나씩 입력
2. 결과를 `요약` 시트에 옮겨 적기
3. 기준과 비교해서 판정 적기
4. 시트 이름을 `측정1`에서 실제 지점 이름으로 하나씩 바꾸기

→ 측정지점이 3개면 할 만하지만, **30개 시설 × 지점 2~3개**라면? 이것이 오늘의 문제입니다.

> 💬 **강사 멘트 예시:** "이 파일은 실제 이산화탄소 성적서 작업(`0. 업무자동화 강의/5. Excel/2. 이산화탄소 성적서`)을 단순하게 만든 것입니다. 실제 파일에는 오늘 배우는 매크로가 들어 있습니다."

## 3. Part 1. AI로 수식 만들기 (20분)

### 핵심: AI는 내 엑셀 화면을 볼 수 없다
그래서 **표 구조를 말로 설명**해야 합니다. 03회의 5요소 중 **맥락**에 해당합니다.

| AI에게 알려 줄 것 | 예시 |
|---|---|
| 시트 이름 | `측정1`, `요약` |
| 데이터 위치 | CO2 값은 B3부터 B27까지 |
| 결과를 넣을 칸 | `요약` 시트 B2 칸 |
| 원하는 계산 | 평균을 소수점 첫째 자리까지 |

### 꼭 짚어 줄 개념
- **절대참조 `$H$1`:** 수식을 아래로 복사해도 **항상 H1 칸을 가리키게** 고정. 기준값을 한 칸에 두고 여러 수식이 같이 쓰게 할 때 필요합니다.
- **조건부 서식:** "부적합"이면 빨간색처럼 **조건에 따라 모양을 바꾸는** 기능
- **검증:** AI가 준 수식의 결과를 **다른 방법**(엑셀 아래쪽 상태 표시줄의 평균, 계산기)으로 한 번 확인

실습은 `실습지.md` Part 1을 따라 합니다.

## 4. 매크로와 VBA (5분)

### 매크로란?
엑셀에서 하는 일을 **버튼 하나로 반복**하게 만든 것입니다. 매크로는 **VBA**라는 언어로 쓰여 있습니다.

| 수식 | 매크로(VBA) |
|---|---|
| 칸 하나에 결과 하나 | 여러 칸·여러 시트를 한꺼번에 처리 |
| 값이 바뀌면 자동으로 다시 계산 | 실행 버튼을 눌러야 동작 |
| 시트 이름 바꾸기, 색칠하기 같은 **동작**은 못 함 | 사람이 마우스로 하는 **거의 모든 동작**을 할 수 있음 |

### 개발 도구 탭 켜기 (함께 따라 하기)
- **Windows:** [파일] → [옵션] → [리본 사용자 지정] → 오른쪽 목록에서 **[개발 도구]** 체크 → [확인]
- **Mac:** [Excel] 메뉴 → [환경설정] → [리본 및 도구 모음] → **[개발 도구]** 체크

### ⚠️ 매크로 안전 수칙
1. 매크로를 실행하기 전에 **원본 파일을 복사**해 두세요. 매크로가 한 일은 **[실행 취소(Ctrl+Z)]가 안 됩니다.**
2. 매크로를 저장하려면 **`.xlsm`(매크로 사용 통합 문서)** 으로 저장해야 합니다. `.xlsx`로 저장하면 매크로가 사라집니다.
3. 출처를 모르는 파일의 매크로는 실행하지 마세요. (매크로로 악성 동작도 가능합니다)

## 5. Part 2. AI로 매크로 만들기 (22분)

`실습지.md` Part 2를 따라 합니다.

1. **매크로 1 — 시트 이름 바꾸기:** A1 칸 제목의 마지막 부분(`1층교실`)으로 시트 이름 바꾸기
2. **매크로 2 — 요약표 만들기:** 모든 측정 시트를 돌면서 평균·최대·최소·판정을 `요약` 시트에 쓰기

### 진행 순서 (화면 공유로 함께)
1. AI에게 매크로 요청 (프롬프트는 실습지에)
2. [개발 도구] → **[Visual Basic]** (또는 `Alt + F11`) → [삽입] → **[모듈]**
3. AI가 준 코드를 **붙여 넣기**
4. 코드 안을 클릭하고 **F5** (또는 [실행] → [Sub/사용자 정의 폼 실행])
5. 엑셀로 돌아와 결과 확인

> 💬 **강사 진행 팁**
> - 오류가 나면 **좋은 기회**입니다. 오류 메시지를 그대로 AI에게 붙여 넣고 고쳐 달라고 하는 과정을 함께 보여 주세요. (20회 "오류 해결하기"의 예고편)
> - AI마다 코드가 조금씩 다릅니다. **결과가 같으면 정답**입니다.
> - Part 1에서 만든 수식이 있는 상태로 시트 이름을 바꾸면, 수식 속 시트 이름도 **자동으로 바뀌는** 것을 보여 주세요.

## 6. 정리 (8분)

### 오늘의 핵심 3줄
1. AI는 내 화면을 못 보므로 **시트 이름, 칸 위치, 원하는 결과**를 말로 설명한다.
2. **수식**은 칸 단위 계산, **매크로**는 여러 시트·여러 동작을 한 번에.
3. AI가 만든 결과는 **다른 방법으로 한 번 더 확인**하고, 매크로 실행 전엔 **백업**한다.

### 한 걸음 더: 엑셀 vs 파이썬
오늘 한 일은 4단계에서 **파이썬으로도** 해 봅니다. 엑셀 매크로는 엑셀 안에서 편하지만, 파일 수십 개를 한꺼번에 처리하거나 그래프·통계까지 하려면 파이썬이 더 편합니다. **같은 문제를 여러 도구로 풀 수 있다**는 것을 기억해 두세요. (확장 트랙 W01)

### 수업 전 준비
- **수업 전에 `해답.md`의 매크로를 실제 엑셀에서 한 번 실행해 보세요.** (Windows·Mac 엑셀 버전에 따라 메뉴 위치가 조금 다를 수 있습니다)
- 기관 PC에서 **매크로 실행이 정책으로 막혀 있는지** 확인하세요. 막혀 있으면 파일 속성에서 "차단 해제"하거나, 개인 PC로 실습합니다.
  - Windows: 파일 오른쪽 클릭 → [속성] → 아래쪽 **[차단 해제]** 체크 → [확인]

### 자주 나는 문제
| 증상 | 해결 |
|---|---|
| 매크로 실행 버튼이 회색 | `.xlsx` 파일이라서 → `.xlsm`으로 다른 이름으로 저장 |
| "이 파일의 매크로를 차단했습니다" | 위의 "차단 해제" 방법 |
| 코드의 한글이 `???`로 보임 | AI 답을 **복사·붙여넣기**로 넣으세요. `.bas` 파일 가져오기는 한글이 깨질 수 있습니다 |
| `런타임 오류 '9': 아래 첨자 사용이 잘못되었습니다` | 코드 속 시트 이름(`요약`)과 실제 시트 이름이 다름 |
| Mac에서 `Alt + F11`이 안 됨 | [도구] → [매크로] → [Visual Basic 편집기] 또는 `Option + F11` |
