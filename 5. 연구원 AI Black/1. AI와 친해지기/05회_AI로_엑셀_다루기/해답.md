## Part 1. 수식

### 정답 값

| 측정지점 | 평균 | 최대 | 최소 | 판정 |
|---|---|---|---|---|
| 측정1 (1층교실) | 667.4 | 760 | 565 | 적합 |
| 측정2 (2층교실) | 1052.8 | 1152 | 951 | **부적합** |
| 측정3 (3층사무실) | 554.9 | 631 | 489 | 적합 |

### 수식 (요약 시트 2행 기준)

| 칸 | 수식 | 뜻 |
|---|---|---|
| B2 | `=ROUND(AVERAGE('측정1'!B3:B27),1)` | 측정1 시트 B3~B27의 평균을 소수점 1자리로 반올림 |
| C2 | `=MAX('측정1'!B3:B27)` | 최댓값 |
| D2 | `=MIN('측정1'!B3:B27)` | 최솟값 |
| E2 | `=IF(B2>=$H$1,"부적합","적합")` | 평균이 H1(기준값) 이상이면 "부적합" |

- 3·4행은 시트 이름만 `'측정2'`, `'측정3'`으로 바꿉니다.
- **`$H$1`의 의미:** E2를 E3으로 복사할 때, `B2`는 `B3`으로 따라 바뀌지만 `$H$1`은 그대로 H1을 가리킵니다. `$`를 빼면 E3에서는 `H2`(빈칸)를 기준으로 삼아 **모두 "부적합"** 이 됩니다. → 꼭 직접 실험해 보게 하세요.
- **시트 이름의 작은따옴표 `'측정1'`:** 시트 이름에 한글·공백이 있을 때 안전하게 감싸는 표시입니다. 엑셀이 알아서 붙이기도 합니다.

### 조건부 서식 (Windows 엑셀)
1. E2:E10 선택
2. [홈] → [조건부 서식] → [셀 강조 규칙] → [같음]
3. 값에 `부적합` 입력 → 서식 [진한 빨강 텍스트가 있는 연한 빨강 채우기] → [확인]

## Part 2. 매크로

> ⚠️ 아래 코드는 **복사해서 VBA 편집기에 붙여 넣으세요.** `.bas` 파일로 가져오면 한글이 깨질 수 있습니다.
> 🧑‍🏫 **강사:** 수업 전에 사용하는 엑셀(Windows/Mac)에서 한 번 실행해 확인하세요.

### 매크로 1. 시트 이름 바꾸기

```vba
Option Explicit

' 요약 시트를 뺀 모든 시트의 이름을
' A1 칸 제목의 마지막 밑줄(_) 뒤 글자로 바꾼다.
' 예) "0408_가상어린이집_1층교실" → "1층교실"
Sub RenameSheets()
    Dim ws As Worksheet          ' 지금 다루는 시트
    Dim title As String          ' A1 칸의 제목
    Dim parts() As String        ' 제목을 밑줄로 나눈 조각들
    Dim count As Long            ' 이름을 바꾼 시트 수

    For Each ws In ThisWorkbook.Worksheets          ' 모든 시트를 하나씩 돌면서
        If ws.Name <> "요약" Then                    ' 요약 시트는 건너뛰고
            title = Trim(CStr(ws.Range("A1").Value)) ' A1 칸 제목을 읽어서
            If InStr(title, "_") > 0 Then            ' 밑줄이 있을 때만
                parts = Split(title, "_")            ' 밑줄 기준으로 나누고
                ws.Name = parts(UBound(parts))       ' 마지막 조각을 시트 이름으로
                count = count + 1
            End If
        End If
    Next ws

    MsgBox count & "개 시트의 이름을 바꿨습니다."
End Sub
```

### 매크로 2. 요약표 만들기

```vba
' 요약 시트를 뺀 모든 측정 시트의 CO2(B열) 평균·최대·최소를 구해
' 요약 시트에 한 줄씩 쓰고, H1 칸의 기준값으로 판정한다.
Sub MakeSummary()
    Dim wsSum As Worksheet       ' 요약 시트
    Dim ws As Worksheet          ' 지금 다루는 측정 시트
    Dim lastRow As Long          ' 측정 시트에서 마지막 값이 있는 행 번호
    Dim rng As Range             ' CO2 값이 있는 범위
    Dim r As Long                ' 요약 시트에 쓸 행 번호
    Dim limit As Double          ' 기준값
    Dim avgValue As Double       ' 평균

    Set wsSum = ThisWorkbook.Worksheets("요약")
    limit = wsSum.Range("H1").Value          ' 기준값 읽기
    wsSum.Range("A2:E100").ClearContents     ' 이전 결과 지우기
    r = 2                                    ' 2행부터 쓰기 시작

    For Each ws In ThisWorkbook.Worksheets
        If ws.Name <> "요약" Then
            ' B열의 맨 아래에서 위로 올라가며 마지막 값이 있는 행 찾기
            lastRow = ws.Cells(ws.Rows.Count, "B").End(xlUp).Row
            If lastRow >= 3 Then                       ' 측정값이 하나라도 있을 때만
                Set rng = ws.Range("B3:B" & lastRow)
                avgValue = Application.WorksheetFunction.Average(rng)

                wsSum.Cells(r, 1).Value = ws.Name                                     ' A열: 시트 이름
                wsSum.Cells(r, 2).Value = Application.WorksheetFunction.Round(avgValue, 1) ' B열: 평균
                wsSum.Cells(r, 3).Value = Application.WorksheetFunction.Max(rng)     ' C열: 최대
                wsSum.Cells(r, 4).Value = Application.WorksheetFunction.Min(rng)     ' D열: 최소

                If wsSum.Cells(r, 2).Value >= limit Then                             ' E열: 판정
                    wsSum.Cells(r, 5).Value = "부적합"
                Else
                    wsSum.Cells(r, 5).Value = "적합"
                End If
                r = r + 1                                                            ' 다음 줄로
            End If
        End If
    Next ws

    MsgBox (r - 2) & "개 측정지점을 요약했습니다."
End Sub
```

### 코드 해설 포인트 (수업에서 설명할 것)
| 코드 | 쉬운 설명 |
|---|---|
| `For Each ws In ThisWorkbook.Worksheets ... Next ws` | 파일의 모든 시트를 하나씩 꺼내 같은 일을 반복 |
| `If ws.Name <> "요약" Then` | 이름이 "요약"이 **아니면** (`<>`는 "같지 않다") |
| `Split(title, "_")` | 글자를 밑줄 기준으로 잘라 조각 목록으로 만듦 |
| `parts(UBound(parts))` | 조각 목록의 **마지막** 조각 |
| `Cells(Rows.Count, "B").End(xlUp).Row` | B열 맨 아래 칸에서 `Ctrl + ↑`를 누른 것처럼 마지막 값이 있는 행을 찾음 |
| `Application.WorksheetFunction.Average(rng)` | 엑셀의 `AVERAGE` 함수를 VBA에서 사용 |

> 💡 `Round` 대신 `Application.WorksheetFunction.Round`를 쓴 이유: VBA의 `Round` 함수는 0.5를 짝수 쪽으로 반올림(은행가 반올림)해서 엑셀 `ROUND` 결과와 다를 수 있습니다. AI가 `Round`를 쓴 코드를 줬다면, 이 차이를 질문해 보는 것도 좋은 검증 연습입니다.
