## Part 1. AI로 수식 만들기

### 1-1. 파일 살펴보기
- `측정1` 시트를 열어 보세요.
  - A1 칸: `0408_가상어린이집_1층교실`
  - 2행: 열 제목 (Date Time, CO2 ppm, Temperature ℃, Humidity %RH)
  - 3행~27행: 5분 간격 측정값 25개
- `요약` 시트를 열어 보세요. 1행에 열 제목이 있고, H1 칸에 기준값 `1000`이 있습니다.

### 1-2. 평균 수식 받기
AI에게 아래처럼 물어보세요.
```

[하고 싶은 것]

수식과 함께 수식의 각 부분이 무슨 뜻인지 설명해 줘.
```

## Part 2. AI로 매크로 만들기

> ⚠️ 시작 전에 **파일을 한 번 더 저장**하고, `파일 → 다른 이름으로 저장 → Excel 매크로 사용 통합 문서(*.xlsm)`로 저장하세요.

### 2-1. 매크로 1 — 시트 이름 바꾸기

```
엑셀 VBA 매크로를 만들어 줘. 나는 VBA를 처음 써.

[파일 구조]
- '요약' 시트 1개와 측정 시트 여러 개('측정1', '측정2', '측정3' ...)가 있어.
- 각 측정 시트의 A1 칸에는 "0408_가상어린이집_1층교실"처럼 밑줄(_)로 구분된 제목이 있어.

[하고 싶은 것]
'요약' 시트를 뺀 모든 시트의 이름을, A1 칸 제목에서 마지막 밑줄 뒤의 글자로 바꾸고 싶어.
예: "0408_가상어린이집_1층교실" → 시트 이름 "1층교실"

[조건]
- 코드에 한글 주석을 한 줄씩 달아 줘.
- A1 칸에 밑줄이 없으면 그 시트는 건너뛰어 줘.
- 끝나면 완료 메시지 창을 띄워 줘.
- VBA 편집기에 붙여 넣고 실행하는 방법을 단계별로 알려 줘.
```

**할 일**
1. `Alt + F11`(Mac: `Option + F11`) → [삽입] → [모듈] → 코드 붙여 넣기
2. 코드 안을 클릭하고 `F5`로 실행
3. 엑셀로 돌아와 시트 이름 확인 → `1층교실`, `2층교실`, `3층사무실`
4. **관찰:** Part 1에서 만든 `요약` 시트의 수식을 클릭해 보세요. 수식 속 시트 이름은 어떻게 됐나요?
