# 03회 해답 및 강사용 참고

## 실습 1. 공문 요약 — 모범 프롬프트

```
너는 공공기관 공문을 정리하는 행정 전문가야.
나는 보건환경연구원의 실내공기질 검사팀 연구원이고, 아래 공문을 팀원들에게 공유하려고 해.

공문을 읽고 다음 형식으로 정리해 줘.
1. 한 줄 요약
2. 우리 팀(보건환경연구원)이 해야 할 일 — 표(할 일, 기한)
3. 시·군이 해야 할 일 — 목록 (참고용)
4. 붙임 자료

공문에 적힌 내용과 날짜만 쓰고, 추측한 내용은 넣지 마.

(공문 붙여넣기)
```

### 기대하는 답
1. **한 줄 요약:** 2025년 하반기(10.1.~11.28.) 취약계층 이용 다중이용시설 실내공기질 지도·점검 계획 알림
2. **우리 팀이 할 일**

| 할 일 | 기한 |
|---|---|
| 시·군이 의뢰한 시설의 오염도 검사 실시 | 점검 기간 내 (2025.10.1.~11.28.) |
| 시·군의 검사 일정 협의 요청 응대 | 검사 희망일 2주 전까지 (시·군이 요청) |

3. **시·군이 할 일:** 지도·점검 실시(10.1.~11.28.), 오염도 검사 의뢰·일정 협의(희망일 2주 전), 결과 제출(12.5.까지)
4. **붙임:** 지도·점검 계획 1부, 점검 결과 제출 서식 1부

> 💬 **강사 포인트:** 이 공문은 수신자가 **시·군과 연구원 둘**입니다. "우리 팀 입장에서"라는 **맥락**을 주지 않으면 AI는 시·군이 할 일(결과 제출 12.5.)을 우리 팀 할 일처럼 정리하기 쉽습니다. 맥락의 중요성을 보여 주는 좋은 예입니다.

## 실습 2. 보고서 초안 — 모범 프롬프트

```
[역할] 너는 환경 연구기관의 보고서 작성을 돕는 전문가야.
[맥락] 나는 실내공기질 검사 담당 연구원이고, 과장님께 3분기 검사 결과를 보고하려고 해.
[할 일] 아래 자료로 내부 보고서 초안을 써 줘.
[형식] 제목, 1. 검사 개요, 2. 검사 결과(시설군별 표 포함), 3. 기준 초과 시설 및 조치, 4. 향후 계획.
       개조식(~함, ~임), A4 1쪽 이내.
[제약] 자료에 있는 숫자와 사실만 써. 자료에 없는 내용(원인, 향후 계획 등)은 지어내지 말고
       "[작성 필요]"라고 비워 둬.

(측정 결과 붙여넣기)
```

### 기대하는 답 (요약)
- 검사 개요: 기간 2025.7.1.~9.30., 30곳(어린이집 14, 노인요양시설 9, 의료기관 4, 산후조리원 3), 6개 항목
- 결과: 30곳 중 28곳 적합, 2곳 기준 초과 (초과율 6.7%)
- 초과 시설: A어린이집 CO2 1,180ppm(기준 1,000), B노인요양시설 총부유세균 1,050 CFU/㎥(기준 800)
- 조치: 9.30. 해당 시·군 통보
- 향후 계획: **[작성 필요]**

### 확인 포인트
- "28곳 적합", "초과율 6.7%"는 AI가 **계산한 값**입니다. 30 − 2 = 28, 2 ÷ 30 = 6.67% 로 맞는지 직접 확인하게 하세요.
- 제약을 줬는데도 "환기 부족이 원인으로 추정됨" 같은 문장이 나오면, **"원인 문장을 지워 줘. 자료에 없는 내용이야."** 라고 고치게 합니다.

## 실습 3. 메모 → 표 — 모범 프롬프트

```
아래 현장 메모를 표로 정리해 줘. 열은 날짜, 시설, 측정지점, 항목, 측정값이야.
한 줄에 측정값 하나씩 써. 연도는 2025년이야.

예시)
메모: "4/8 효자동 어린이집 1층 CO2 평균 612"
→ | 2025-04-08 | 효자동 어린이집 | 1층 | CO2 | 612 |

메모에 없는 값은 만들지 말고, 측정값 개수를 표 아래에 적어 줘.

메모)
4/8 효자동 어린이집 1층 CO2 평균 612 2층 845 / 4/8 오후 청평 요양원 면회실 CO2 534, 생활실 1,020
4/9 가평 산후조리원 신생아실 폼알 45.2 산모실 38 / 4/9 오후 상면 어린이집 폼알 1층 62.1
```

### 기대하는 답

| 날짜 | 시설 | 측정지점 | 항목 | 측정값 |
|---|---|---|---|---|
| 2025-04-08 | 효자동 어린이집 | 1층 | CO2 | 612 |
| 2025-04-08 | 효자동 어린이집 | 2층 | CO2 | 845 |
| 2025-04-08 | 청평 요양원 | 면회실 | CO2 | 534 |
| 2025-04-08 | 청평 요양원 | 생활실 | CO2 | 1,020 |
| 2025-04-09 | 가평 산후조리원 | 신생아실 | 폼알데하이드 | 45.2 |
| 2025-04-09 | 가평 산후조리원 | 산모실 | 폼알데하이드 | 38 |
| 2025-04-09 | 상면 어린이집 | 1층 | 폼알데하이드 | 62.1 |

측정값 개수: **7개**

> 💬 **강사 포인트:**
> - "측정값 개수를 적어 줘"는 **빠진 값이 없는지 AI 스스로 확인**하게 만드는 작은 기술입니다.
> - "폼알" → "폼알데하이드"처럼 AI가 줄임말을 풀어 주는 것은 편리하지만, **원본과 다르게 바꾼 부분이 없는지** 확인하는 습관을 들이게 하세요.
> - 이런 "지저분한 자료 → 표" 작업은 4단계(데이터 정제)에서 파이썬으로 자동화합니다.

## 과제 — 예시 답안 (템플릿 1개)

````
■ 템플릿 1: 장비 점검 결과 정리
- 언제 쓰나: 월간 장비 점검 후 점검 결과를 팀 보고용 표로 만들 때
- 템플릿:
```
너는 분석 장비 품질관리 담당자야.
나는 [수질 분석실] 연구원이고, [월] 장비 점검 결과를 팀장님께 보고하려고 해.
아래 점검 메모를 표로 정리해 줘.

열: 장비명, 점검 항목, 결과(정상/이상), 조치 내용, 다음 점검일
- 이상이 있는 장비를 표 위쪽에 먼저 써.
- 메모에 없는 내용은 빈칸으로 둬.
- 표 아래에 이상 장비 수를 한 줄로 요약해 줘.

예시)
메모: "GC-MS 진공도 정상, 튜닝 통과"
→ | GC-MS | 진공도 | 정상 | - | |
   | GC-MS | 튜닝 | 정상 | - | |

메모)
[점검 메모 붙여넣기]
```
- 시험해 보고 고친 점: 처음엔 이상 장비가 섞여 나와서 "이상이 있는 장비를 위쪽에 먼저"를 추가함.
````
