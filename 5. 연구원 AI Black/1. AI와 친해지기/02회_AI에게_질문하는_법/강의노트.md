## 오늘의 목표

1. **같은 일도 질문에 따라 답의 품질이 크게 달라진다**는 것을 직접 확인한다.
2. 좋은 질문의 **기본 원칙 4가지**(구체적으로, 맥락 주기, 형식 정하기, 나눠서 묻기)를 익힌다.
3. 첫 답이 마음에 들지 않을 때 **대화를 이어 가며 답을 고쳐 나가는 법**을 익힌다.

## 2. 좋은 질문 vs 나쁜 질문 (15분)

### 비유: AI는 "첫 출근한 아주 똑똑한 신입 직원"

- 아는 것은 엄청나게 많지만, **우리 기관·우리 팀·이 업무의 사정은 전혀 모릅니다.**
- "그거 좀 정리해 줘"라고 하면 무엇을 어떻게 정리할지 **짐작으로** 합니다.
- 신입에게 일을 맡기듯 **배경, 목적, 원하는 결과물 모양**을 알려 주면 훨씬 잘합니다.

### 비교 시연 (강사가 화면에 띄워 보여 주기)

**❌ 나쁜 질문**
```
실내공기질 보고서 써 줘.
```
→ AI는 누가 읽는지, 무슨 데이터인지, 얼마나 길게 쓸지 모르니 **일반적인 내용**만 길게 씁니다.

**✅ 좋은 질문**
```
나는 환경 연구기관에서 실내공기질 검사를 담당하는 연구원이야.
과장님께 올릴 3분기 실내공기질 검사 결과 내부 보고서 초안을 써 줘.

- 검사 기간: 7~9월
- 검사 시설: 어린이집 12곳, 의료기관 5곳, 노인요양시설 8곳 (총 25곳)
- 기준 초과: 어린이집 1곳(CO2), 노인요양시설 1곳(폼알데하이드)

형식: 개조식(~함), 제목 + 1. 검사 개요 / 2. 검사 결과 / 3. 향후 조치, A4 반 쪽 분량.
내가 준 숫자 외에는 지어내지 말고, 필요한 정보가 없으면 [ ]로 비워 둬.
```
→ 바로 고쳐 쓸 수 있는 수준의 초안이 나옵니다.

### 좋은 질문의 기본 원칙 4가지

| 원칙 | 설명 | 나쁜 예 → 좋은 예 |
|---|---|---|
| **① 구체적으로** | 무엇을, 얼마나, 언제까지 | "요약해 줘" → "**3줄로** 요약해 줘" |
| **② 맥락 주기** | 나는 누구고, 왜 필요하고, 누가 읽는지 | "메일 써 줘" → "**측정 대상 시설 담당자에게** 일정을 안내하는 메일" |
| **③ 형식 정하기** | 표, 목록, 개조식, 글자 수 | "정리해 줘" → "**표로**, 열은 항목·기준·측정값" |
| **④ 나눠서 묻기** | 큰 일은 단계로 쪼개기 | "보고서 다 써 줘" → "**먼저 목차만** 만들어 줘" → "1장을 써 줘" |

> 03회에서는 이 원칙을 **5요소(역할·맥락·할 일·형식·제약)** 공식으로 정리합니다.

## 3. 실습: 같은 일을 3가지 질문으로 (25분)

`실습지.md` Part 1~2를 진행합니다.

- 같은 일을 **수준 1(한 줄) → 수준 2(조금 자세히) → 수준 3(아주 자세히)** 로 시켜 보고, 답을 비교합니다.
- 비교 기준: **바로 쓸 수 있는가? 고칠 부분이 얼마나 되는가?**

> 💬 **강사 진행 팁**
> - 수준 1과 수준 3의 답을 **화면에 나란히** 띄워 비교하게 하세요.
> - "수준 3을 쓰는 데 1분 더 걸렸지만, 고치는 시간은 10분 줄었다"는 것을 느끼게 하는 것이 목표입니다.

## 4. 대화로 답 고쳐 나가기 (10분)

AI와의 대화는 **한 번에 끝나는 검색이 아닙니다.** 답을 보고 계속 요청하면 됩니다.

| 상황 | 이렇게 말하기 |
|---|---|
| 너무 길다 | "핵심만 5줄로 줄여 줘." |
| 너무 어렵다 | "처음 듣는 사람도 알게 쉬운 말로 다시 써 줘." |
| 형식이 다르다 | "표로 다시 정리해 줘." |
| 틀린 것 같다 | "○○ 부분이 맞는지 다시 확인해 줘. 근거도 알려 줘." |
| 방향이 완전히 틀렸다 | **새 대화**를 열어서 처음부터 다시 자세히 묻기 |

### 새 대화를 여는 게 나을 때
- 대화가 너무 길어져 AI가 앞의 내용을 헷갈릴 때
- 전혀 다른 주제로 넘어갈 때
- 처음 질문을 잘못해서 방향이 엉뚱하게 갔을 때

## 5. 정리 (5분)

### 오늘의 핵심 3줄
1. AI는 **똑똑하지만 우리 사정을 모르는 신입 직원**이다.
2. **구체적으로, 맥락을 주고, 형식을 정하고, 나눠서** 물으면 답이 좋아진다.
3. 첫 답은 초안일 뿐, **대화를 이어 가며 고쳐 나간다.**

| 질문 | 답변 예시 |
|---|---|
