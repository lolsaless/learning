# 02회 실습지 — 같은 일, 다른 질문

> **방법:** 각 과제마다 수준 1 → 수준 2 → 수준 3 질문을 **각각 새 대화창**에서 보내세요.
> (같은 대화창에서 이어서 보내면 앞의 정보가 섞여서 비교가 안 됩니다.)
> 답을 받으면 아래 평가표에 점수를 매깁니다.

### 평가 기준 (각 1~5점)
- **정확성:** 내가 원한 내용이 맞게 들어 있나?
- **바로 쓰기:** 고치지 않고 바로 쓸 수 있나?
- **형식:** 원하는 모양(표, 길이 등)인가?

## Part 1. 과제 A — 측정 일정 안내 메일

### 수준 1
```
메일 써 줘.
```

### 수준 2
```
실내공기질 측정 일정을 안내하는 메일을 써 줘.
```

### 수준 3
```
나는 환경 연구기관의 실내공기질 검사 담당 연구원이야.
측정 대상인 어린이집 원장님께 보낼 측정 일정 안내 메일을 써 줘.

- 측정 일시: 다음 주 화요일 오전 10시~12시
- 측정 장소: 1층 교실, 2층 교실 (각 1곳)
- 요청 사항: 측정 30분 전부터 창문을 닫아 주실 것, 측정 중 공기청정기 끄기
- 문의: 담당 연구원 [이름], [전화번호]

형식: 제목 1줄 + 본문 8줄 이내. 정중하지만 간결하게.
```

## Part 2. 과제 B — 측정 결과 설명

### 수준 1
```
CO2 1200ppm이면 어때?
```

### 수준 2
```
어린이집 교실에서 CO2가 1200ppm으로 측정됐어. 무슨 뜻인지 설명해 줘.
```

### 수준 3
```
나는 실내공기질 검사 연구원이야. 어린이집 교실의 CO2 측정 평균이 1,200ppm으로 나왔어.
어린이집 원장님께 결과를 설명하려고 해.

다음 순서로 설명 자료를 만들어 줘.
1. 이 수치가 어떤 의미인지 (전문 용어 없이 2문장)
2. 왜 높게 나왔을 가능성이 있는지 (3가지)
3. 원장님이 바로 할 수 있는 개선 방법 (3가지)

기준값은 내가 확인한 1,000ppm을 사용해. 건강 영향은 과장하지 말고, 확실하지 않은 내용은 "일반적으로"라고 표현해 줘.
```

## Part 3. 대화로 답 고쳐 나가기

Part 2의 **수준 3 대화창**에서 이어서 아래를 순서대로 보내 보세요.

1. 답이 길면:
   ```
   원장님이 문자로 받을 수 있게 전체를 5줄로 줄여 줘.
   ```
2. 이어서:
   ```
   2번(원인)을 표로 바꿔 줘. 열은 '원인', '확인 방법'으로.
   ```
3. 이어서:
   ```
   방금 답에서 확실하지 않거나 근거가 약한 내용이 있으면 표시해 줘.
   ```
