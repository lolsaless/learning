## 할 일 2. 2단계 설치 준비 확인

아래 표를 채워 제출하세요. 07회부터 설치를 시작하므로, **막히는 것이 있으면 미리** 알려 주세요.

| 확인 | 내 PC 정보 |
|---|---|
| 수업에 쓸 PC | 기관 PC / 개인 노트북 |
| 운영체제 | Windows 10 / Windows 11 / macOS (버전: ) |
| Mac이라면 칩 종류 | Apple 실리콘(M1·M2·M3·M4…) / Intel |
| 프로그램 설치 권한 | 있음 / 없음 / 모름 |
| 남은 저장 공간 | GB |
| GitHub 계정 | 만들었음 (아이디: ) / 아직 |

### Mac 칩 확인 방법
화면 왼쪽 위 사과(🍎) 메뉴 → **[이 Mac에 관하여]** → "칩" 또는 "프로세서" 항목

### Windows 버전 확인 방법
[시작] → [설정] → [시스템] → [정보] → "Windows 사양"의 "에디션"

### GitHub 가입 (미리 해 두면 좋음)
1. `https://github.com` 접속 → **[Sign up]**
2. 이메일, 비밀번호, 아이디(영문) 입력 → 이메일 인증
3. 아이디는 앞으로 계속 쓰니 **업무용으로 써도 괜찮은 이름**으로 정하세요.
