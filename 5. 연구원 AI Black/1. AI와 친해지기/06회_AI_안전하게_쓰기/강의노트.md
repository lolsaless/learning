## 2. AI에 넣으면 안 되는 정보 (10분)

### AI 창에 붙여 넣은 내용은 어디로 갈까?

```
 내 PC  ──(인터넷)──▶  AI 회사의 서버  ──▶  답변 생성  ──▶  내 PC
                         │
                         └─ 대화 기록 저장 (서비스·설정에 따라 학습에 쓰일 수도 있음)
```

- AI 채팅에 붙여 넣은 내용은 **외부 회사의 서버로 전송**됩니다.
- 많은 서비스에서 "대화 내용을 학습에 사용하지 않음"으로 설정할 수 있지만, **전송된다는 사실은 같습니다.**
- 기관마다 생성형 AI 사용 지침이 있을 수 있습니다. **기관 지침을 먼저 확인**하세요.

### 넣으면 안 되는 정보

`공통자료/AI_활용_안전_수칙.md`의 "1. 넣으면 안 되는 정보" 표를 함께 읽습니다.

| 구분 | 예시 |
|---|---|
| 개인정보 | 이름, 주민번호, 전화번호, 주소, 사번 |
| 업체 정보 + 결과 | "○○어린이집 CO2 1,200ppm 부적합" |
| 비공개 업무 자료 | 결재 전 문서, 미공개 검사 결과, 감사 자료 |
| 계정·보안 정보 | 비밀번호, 내부 시스템 주소, API 키 |

### 이 과정의 기본 원칙

> **"AI에게는 구조를, 내 PC에서는 실제 데이터를."**

1. AI에게는 **열 이름·형식**과 **가짜 예시 몇 줄**만 보여 준다.
2. AI가 만든 **수식·매크로·코드**를 받아서
3. **내 PC에서** 실제 데이터에 적용한다. → 실제 데이터는 밖으로 나가지 않는다.

> 💬 **강사 멘트 예시:** "05회에서 매크로를 만들 때, 우리는 시트 구조만 설명했지 실제 측정값을 AI에 보내지 않았습니다. 그래도 매크로는 잘 동작했죠? 이게 바로 안전하게 AI를 쓰는 방법입니다. 2단계부터 파이썬을 배우는 이유도 여기에 있습니다."

## 4. 실습: 환각 검증 (15분)

`실습지.md` Part 3을 진행합니다.

- AI에게 실내공기질 유지기준을 표로 받은 뒤, **국가법령정보센터 원문과 비교**합니다.
- 틀린 칸, 빠진 칸, 바뀐 단위를 찾아 표시합니다.

> 💬 **강사 진행 팁**
> - AI가 모두 맞힐 수도 있습니다. 그래도 **"원문을 확인했기 때문에 맞다고 말할 수 있다"** 는 점을 강조하세요.
> - 시설군 구분(어린이집·노인요양시설 등 민감 계층 시설과 일반 시설), 측정 단위(μg/㎥, ppm, CFU/㎥)를 자주 틀립니다.

### 검증 순서 (외워 두기)
1. **"근거가 뭐야?"** 라고 되묻기
2. **원문** 찾아서 비교하기 (법령, 공정시험기준, 공식 홈페이지)
3. 숫자는 **다른 방법으로 다시 계산**하기
4. 코드는 **작은 예제로 먼저 실행**하기

## 6. 2단계 준비 안내 (8분)

다음 주부터 **2단계. 개발 환경 만들기**가 시작됩니다. 내 PC에 파이썬과 VS Code를 설치합니다.

### 미리 확인할 것
| 확인 | 방법 |
|---|---|
| 내 PC의 운영체제 | Windows: [설정] → [시스템] → [정보] / Mac: 왼쪽 위 사과 메뉴 → [이 Mac에 관하여] |
| Mac 칩 종류 | [이 Mac에 관하여]에서 "칩: Apple M1/M2/M3…" 또는 "프로세서: Intel" |
| 관리자 권한 | 프로그램 설치가 가능한지 (기관 PC는 막혀 있을 수 있음 → 미리 정보화 담당자에게 문의) |
| 저장 공간 | 최소 10GB 이상 여유 |
| GitHub 계정 | 12회에서 사용. 미리 `https://github.com`에서 가입해 두면 좋음 |

### 오늘의 핵심 3줄
1. AI 창에 붙인 내용은 **외부 서버로 간다.** 개인정보·업체 결과·비공개 자료는 넣지 않는다.
2. **AI에게는 구조와 가짜 예시를, 실제 데이터는 내 PC에서.**
3. 기준값·법령·숫자는 **반드시 원문으로 검증**한다.
