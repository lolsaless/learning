# 06회 해답 및 강사용 참고

## Part 1. O / X 정답

| 번호 | 정답 | 해설 |
|---|---|---|
| 1 | **O** | 구조만 설명. 실제 값이 없음 |
| 2 | **X** | 실제 측정 결과 + 시설명이 그대로 전송됨 → 열 구조만 설명하고 판정 수식·코드를 받아 내 PC에서 실행 |
| 3 | **X** (주의) | 공문 본문은 공개 문서인 경우가 많지만, 담당자 이름·전화번호는 **지우고** 붙여 넣기 |
| 4 | **O** | 일반적인 질문. 시설 이름이 없음 |
| 5 | **X** | 계정 정보는 절대 넣지 않음. 오류 메시지만 붙이고 아이디·비밀번호는 지우기 |
| 6 | **X** (주의) | 경로에 실명 아이디가 들어 있음 → `C:\Users\사용자\...`로 바꿔서 붙이기 |
| 7 | **O** | 시설명을 A·B·C로 가명 처리함 |
| 8 | **X** | 민원인 개인정보 + 민원 내용 → 내용을 일반화하고 개인정보 제거 |
| 9 | **X** (기관 지침 확인) | 결재 전 비공개 문서. 기관 지침상 허용되는 경우에만, 민감한 숫자·이름을 빼고 |
| 10 | **O** | 공개된 시험 방법에 대한 일반 질문 (단, 답은 원문으로 확인) |

## Part 2. 가명 처리 — 모범 프롬프트

### 문제점
이름(김민수 등), 직원 코드(B2701234), 소속·직급, 출장 일정·지역이 함께 나가면 **특정 개인의 이동 기록**이 됩니다.

### 방법 A. 구조만 설명
```
엑셀 수식을 만들어 줘.

C열 '성명'은 "이름(영문1자+숫자7자리 코드)" 형식이야. 괄호 앞의 이름만 뽑고 싶어.
D열 '출장기간'은 "YYYY-MM-DD HH:MM ~ YYYY-MM-DD HH:MM" 형식이야.
시간이 없을 때는 HH:MM 자리에 "--:--"가 들어 있어.
이걸 출발일, 출발시간, 도착일, 도착시간 4개 열로 나누고 싶어. 시간이 "--:--"면 빈칸으로 둬.
중간에 "소계: 2건" 같은 줄이 섞여 있는데, 이 줄은 결과가 빈칸이 되면 돼.

데이터는 2행부터 시작해. 각 열에 넣을 수식을 알려 주고 설명해 줘.
```

### 방법 B. 가짜 예시로 바꾸기
```
아래와 같은 엑셀 데이터가 있어. (예시는 가짜 데이터야)

성명            | 출장기간
홍길동(X0000001) | 2025-01-01 09:00 ~ 2025-01-01 18:00
김철수(X0000002) | 2025-01-02 --:-- ~ 2025-01-02 --:--

원하는 결과:
이름   | 출발일     | 출발시간 | 도착일     | 도착시간
홍길동 | 2025-01-01 | 09:00   | 2025-01-01 | 18:00
김철수 | 2025-01-02 |         | 2025-01-02 |

성명은 A열, 출장기간은 B열이야. 결과 열에 넣을 엑셀 수식을 알려 줘.
```

### 수식 예시 (AI 답의 한 예, A열=성명, B열=출장기간, 2행 기준)

| 결과 | 수식 |
|---|---|
| 이름 | `=IFERROR(LEFT(A2,FIND("(",A2)-1),"")` |
| 출발일 | `=IFERROR(LEFT(B2,10),"")` |
| 출발시간 | `=IFERROR(IF(MID(B2,12,5)="--:--","",MID(B2,12,5)),"")` |
| 도착일 | `=IFERROR(MID(B2,FIND("~",B2)+2,10),"")` |
| 도착시간 | `=IFERROR(IF(RIGHT(B2,5)="--:--","",RIGHT(B2,5)),"")` |

> 💬 **강사 포인트:** 이 문제는 28회(데이터 정제 ①)에서 **파이썬으로 다시** 풉니다. 엑셀 수식이 길고 복잡해지는 것을 체감해 두면, 파이썬을 배울 이유가 분명해집니다.

## Part 3. 환각 검증 — 강사 안내

- **정답 값은 이 해답에 적지 않았습니다.** 기준은 개정될 수 있으므로, 수업 당일 **국가법령정보센터의 최신 별표**를 정답으로 삼으세요.
- 원문을 볼 때 확인할 점
  - 시설군 구분: 일반 다중이용시설 / 의료기관·산후조리원·노인요양시설·어린이집·실내 어린이놀이시설 / 실내주차장 등 **구분이 여러 개**입니다.
  - 단위: PM10·PM2.5·폼알데하이드는 **μg/㎥**, CO2·CO는 **ppm**, 총부유세균은 **CFU/㎥**
  - 일부 항목은 특정 시설군에만 적용됩니다.
- AI가 자주 틀리는 부분: 시설군 구분을 뭉뚱그리기, 실내주차장 기준을 섞기, 단위 바꿔 쓰기, 별표 번호
- **"모두 맞았어도 원문을 확인해야 하는 이유":** 이번에 맞았다고 다음에도 맞는다는 보장이 없고, 보고서에는 **근거(법령·별표)를 밝혀야** 하기 때문입니다.
