## 1. 과정 소개 (10분)

### 이 과정은 이런 과정입니다

> "프로그래머가 되는 과정"이 아니라
> **"AI를 부려서 내 업무 문제를 해결하는 사람"이 되는 과정**입니다.

요즘 AI는 코드를 아주 잘 씁니다. 그런데 AI에게 일을 잘 시키려면 사람이 해야 할 일이 있습니다.

| AI가 잘하는 일 | 사람이 해야 하는 일 |
|---|---|
| 코드 작성 | **무엇이 문제인지** 정하기 |
| 문서 초안 작성 | AI에게 **상황을 정확히 설명**하기 |
| 오류 원인 추측 | AI의 답이 **맞는지 확인**하기 |
| 여러 방법 제안 | 그중에서 **우리 상황에 맞는 것 고르기** |

그래서 이 과정에서는 문법을 외우는 대신, **문제를 찾고 → AI에게 설명하고 → 결과를 확인하고 → 고치는** 연습을 반복합니다.

## 2. 생성형 AI란 무엇인가 (15분)

### 아주 쉬운 비유: "엄청나게 똑똑한 자동완성"

휴대폰 키보드에서 "오늘 날씨가"를 치면 "좋네요"를 추천해 주지요?
생성형 AI(ChatGPT, Claude 등)는 이 **자동완성을 아주 크게 키운 것**입니다.

1. 인터넷의 책·논문·웹페이지·코드 등 **엄청난 양의 글을 읽고**
2. "이 말 다음에는 어떤 말이 올까?"를 **예측하는 연습을 수없이 반복**해서
3. 질문을 받으면 **가장 그럴듯한 답을 한 단어씩 이어서** 만들어 냅니다.

이런 AI를 **LLM(대규모 언어 모델)** 이라고 부릅니다.

### 이 원리에서 나오는 특징

| 특징 | 그래서 생기는 일 | 우리가 할 일 |
|---|---|---|
| 그럴듯한 말을 만든다 | 모르는 것도 **지어낼 수 있다** (환각) | 중요한 내용은 **원문으로 확인** |
| 질문에 따라 답이 달라진다 | 대충 물으면 대충 답한다 | **자세하게 질문**하기 (2·3회차에서 연습) |
| 학습한 시점까지만 안다 | 최신 법령·기준 변경을 모를 수 있다 | 최신 정보는 공식 사이트 확인 |
| 같은 질문에도 답이 조금씩 다르다 | 다시 물으면 다른 답이 나온다 | 여러 번 물어 **비교**하기 |

### AI가 잘하는 일 vs 못하는 일

| 잘하는 일 👍 | 조심해야 할 일 ⚠️ |
|---|---|
| 글 요약, 초안 작성, 말투 바꾸기 | 정확한 법령 조항·고시 번호 |
| 엑셀 수식·매크로, 파이썬 코드 작성 | 큰 숫자 계산 (암산처럼 틀릴 수 있음) |
| 오류 메시지 해석, 해결 방법 제안 | 최신 뉴스·바뀐 기준 |
| 개념을 쉬운 말로 설명 | 실제 존재하는지 모르는 논문·링크 |
| 여러 방법 비교, 아이디어 내기 | 우리 기관 내부 사정 (알려 주지 않으면 모름) |

### 대표적인 AI 서비스

| 서비스 | 만든 곳 | 특징 |
|---|---|---|
| **ChatGPT** | OpenAI | 가장 널리 쓰임. 파일 분석, 그림 생성 등 기능이 많음 |
| **Claude** | Anthropic | 긴 문서 읽기, 글쓰기, 코드 작성에 강함 |
| **Gemini** | Google | 구글 서비스(지메일, 드라이브)와 연결이 편함 |
| **Copilot** | Microsoft | 엑셀·워드 등 오피스와 연결 |

> 어느 하나가 "정답"은 아닙니다. 이 과정에서는 **두 가지 이상을 써 보고 비교**하는 습관을 들입니다. (보충 S01에서 자세히 비교)

## 3. 계정 만들기 (10분)

> ⚠️ **기관 PC 사용 시:** 기관에서 AI 서비스 접속을 막아 둔 경우가 있습니다. 미리 확인하고, 막혀 있으면 개인 노트북이나 휴대폰으로 실습합니다.

최소 **두 개** 서비스의 계정을 만듭니다. (무료 계정으로 충분합니다.)

### ChatGPT
1. 웹 브라우저에서 `https://chatgpt.com` 접속
2. 오른쪽 위 **[회원가입]** 클릭
3. **[Google로 계속하기]** 를 누르고 구글 계정 선택 (또는 이메일로 가입)
4. 이름·생년월일 입력 → 완료

### Claude
1. `https://claude.ai` 접속
2. **[Continue with Google]** (구글로 계속하기) 클릭 또는 이메일 입력
3. 이메일로 가입한 경우, 메일함에 온 **로그인 링크**를 클릭
4. 휴대폰 번호 인증이 나오면 인증 → 완료

### 확인
- 두 서비스 모두에서 "안녕하세요"를 보내고 답이 오면 성공입니다.

> 💡 **팁:** 웹 화면이 영어로 나오면 브라우저 오른쪽 클릭 → **[한국어로 번역]** 을 쓰거나, 설정(Settings)에서 언어를 한국어로 바꿉니다. AI에게는 한국어로 질문해도 됩니다.

## 5. 맛보기: AI가 만든 코드 실행해 보기 (10분)

아직 파이썬을 배우지 않았지만, **AI가 만든 코드가 실제로 동작하는 모습**을 먼저 봅니다.
설치 없이 웹에서 코드를 실행할 수 있는 **Google Colab**을 사용합니다.

### 따라 하기
1. 구글 계정으로 로그인한 상태에서 `https://colab.research.google.com` 접속
2. **[파일] → [노트북 업로드]** 클릭
3. 이 폴더의 `맛보기_AI가_만든_코드.ipynb` 파일을 선택
4. 첫 번째 코드 칸(셀)을 클릭하고 **Shift + Enter** → 다음 칸도 차례로 실행
5. 측정값 표, 평균, 판정 결과, 그래프가 나오는 것을 확인

> 💬 **강사 멘트 예시:** "이 코드는 AI에게 '실내 CO2 측정값의 평균을 내고 기준 1,000ppm 초과 여부를 판정해서 그래프로 그려 줘'라고 부탁해서 받은 것입니다. 지금은 코드를 이해하지 못해도 괜찮습니다. 3단계가 끝나면 한 줄 한 줄 읽을 수 있게 됩니다."
