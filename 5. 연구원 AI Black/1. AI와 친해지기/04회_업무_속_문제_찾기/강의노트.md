## 2. 왜 "문제 찾기"부터인가 (10분)

PDF `AI 활용, 업무 속 문제 찾기.pdf`의 앞부분을 함께 봅니다.

### 흔히 일어나는 일
- "이번 업무보고에 생성형 AI를 적극적으로 활용해서 보고하세요."
- "우리도 그 AI로 뭐 좀 만들어 봐."
- → 목적 없이 AI를 쓰다 보니 **AI 때문에 업무만 늘어나는 상황**이 생깁니다.

### 핵심 메시지
> AI는 **답을 만드는 도구**입니다. **문제를 정하는 것은 사람**입니다.
> 해결할 문제가 분명하지 않으면 AI도 쓸모 있는 답을 줄 수 없습니다.

### 문제를 찾는 습관
- "**조금 더 편하게 할 방법이 있지 않을까?**"를 계속 묻기
- 매번 **복사·붙여넣기**를 반복하는 일, 매번 **같은 양식**을 채우는 일을 의심하기
- "원래 이렇게 하는 거야"라는 말이 나오는 일을 다시 보기

## 3. 문제 → 질문 → 답: 실제 사례 (15분)

PDF에 나온 사례를 **문제 → 질문 → 답** 순서로 따라가 봅니다.

### 사례 1. 정보공개청구 출장기록 정리

**① 문제 (원하는 결과를 정확히)**

| 문제 | 원하는 결과 |
|---|---|
| 성명 칸이 `홍길동(B2708857)` | `홍길동` 만 뽑기 |
| 출장기간 칸이 `2021-04-16 09:40 ~ 2021-04-16 11:50` | 출발일 / 출발시간 / 도착일 / 도착시간 4칸으로 나누기 |
| 출장목적 | 작업 필요 없음 |

**② 질문 (자료를 분석하고 어려운 점을 찾기)**

| 질문 | 답 |
|---|---|
| 자료의 형식은? | 성명=이름+코드, 기간=날짜+시간이 `~`로 연결 |
| 작업을 어렵게 하는 것은? | 인쇄용 양식이라 **빈 줄, 병합된 소계 행, 반복되는 제목 행, 페이지 번호**가 섞여 있음 |
| 어떤 도구로 할까? | 이름 분리는 엑셀 함수로 가능. 날짜·시간 분리는 함수가 복잡 → **AI에게 방법을 묻자** |

**③ 답 (AI에게 자세히 설명해서 해결)**
- 자료 형식, 방해 요소, 원하는 결과를 **AI에게 자세히 설명**
- AI가 만든 코드로 정리 → 4단계(28회)에서 파이썬으로 직접 해 봅니다.

### 사례 2. 실내공기질 실적 보고

| 단계 | 내용 |
|---|---|
| 문제 | 따로 떨어진 여러 데이터(접수 정보, 측정 결과)를 하나의 보고 양식으로 합쳐야 함 |
| 질문 | 합치는 **기준**은? → 접수번호 / **방해 요소**는? → 재측정 데이터, 항목명이 제각각(`이산화탄소`, `CO2`, `CO₂`) / 같은 접수번호 2건의 평균은 어떻게? |
| 답 | 기준 열로 합치고, 항목명을 통일하고, 평균을 구하는 프로그램 → 30회 미니 프로젝트 |

> 💬 **강사 포인트:** 두 사례 모두 **"질문" 단계에서 방해 요소를 찾아낸 것**이 해결의 열쇠였습니다. AI에게 이 방해 요소를 알려 주지 않으면 AI가 만든 코드는 실제 자료에서 실패합니다.

### 자동화하기 좋은 문제의 특징

| 특징 | 설명 | 예 |
|---|---|---|
| **자주 반복** | 매일·매주·매분기 반복 | 분기 실적 보고 |
| **규칙이 분명** | 사람마다 판단이 달라지지 않음 | 기준 초과 판정 |
| **시간이 많이 듦** | 단순하지만 오래 걸림 | 엑셀 수십 개 합치기 |
| **자료가 디지털** | 엑셀·CSV·PDF 등 파일로 있음 | 측정기 출력 파일 |
| **실수가 잦음** | 복사·붙여넣기 실수 | 성적서 숫자 옮겨 적기 |

반대로 **사람의 판단·협상·현장 확인**이 핵심인 일은 자동화하기 어렵습니다. (AI가 **보조**는 할 수 있음)

## 4. 실습: 내 업무 문제 찾기 (25분)

`실습지.md`를 따라 진행합니다.

1. **업무 목록 만들기** — 01회 과제의 5가지에 더해 10가지 이상 적기
2. **점수 매기기** — 자동화 후보 점수표로 각 업무 평가
3. **후보 3개 고르기** — 점수가 높고 내가 해 보고 싶은 것
4. **문제 정의서 1장 쓰기** — 후보 1개를 골라 `문제정의서_양식.md` 작성

> 💬 **강사 진행 팁**
> - 업무를 "실내공기질 업무"처럼 크게 적으면 점수를 매기기 어렵습니다. "**측정기 데이터를 성적서 양식에 옮기기**"처럼 **작은 동작 단위**로 쪼개게 하세요.
> - 문제 정의서의 "방해 요소"를 꼭 채우게 하세요. 대부분 처음엔 비워 둡니다.

### 오늘의 핵심 3줄
1. AI 활용은 **문제 찾기**에서 시작한다.
2. **문제(원하는 결과) → 질문(자료 분석·방해 요소) → 답(AI와 해결)** 순서로 생각한다.
3. 자주 반복되고, 규칙이 분명하고, 시간이 많이 드는 일이 **좋은 자동화 후보**다.
