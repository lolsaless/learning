# 04회 과제 — 문제 정의서를 AI와 함께 다듬기

> **제출:** 다음 수업 시작 전까지
> **예상 소요 시간:** 30분

---

## 할 일

### 1. 수업 시간에 쓴 문제 정의서를 AI에게 검토받기

문제 정의서의 내용을 AI에게 붙여 넣고 아래처럼 물어보세요. (개인정보·업체명은 지우고)

```
너는 업무 자동화 컨설턴트야.
나는 프로그래밍 초보인 연구원이고, 아래 업무를 자동화하고 싶어서 문제 정의서를 썼어.

다음을 검토해 줘.
1. 내가 놓친 방해 요소가 있을 것 같으면 3가지 이내로 알려 줘.
2. 이 문제를 해결할 수 있는 방법을 쉬운 것부터 어려운 순서로 3가지 알려 줘.
   (엑셀 수식, 엑셀 매크로, 파이썬 등) 각각의 장단점도.
3. 초보자가 처음 시도하기에 가장 좋은 방법 1가지를 추천하고 이유를 알려 줘.

(문제 정의서 붙여넣기)
```

### 2. 문제 정의서 고치기
AI의 답을 보고 **맞다고 생각하는 것만** 반영해서 문제 정의서를 고칩니다.

### 3. 제출
```
[04회 과제]  이름: ________

1. 고친 문제 정의서 (파일 첨부 또는 붙여넣기)

2. AI가 찾아 준 방해 요소 중 반영한 것 / 반영하지 않은 것과 이유
   - 반영:
   - 반영 안 함:

3. AI가 추천한 해결 방법:
   - 이 방법을 지금 내가 할 수 있을 것 같은가? (예/아니오/모르겠음)
```
