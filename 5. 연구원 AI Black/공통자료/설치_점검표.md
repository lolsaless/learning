# 설치 점검표

> 2단계(07~12회)에서 설치하는 프로그램이 제대로 설치됐는지 확인하는 표입니다.
> 명령을 터미널(Mac) 또는 PowerShell(Windows)에 입력하고, **정상 결과**와 비슷하게 나오면 ✅ 표시하세요.
> 버전 숫자는 설치 시점에 따라 다를 수 있습니다. **숫자가 나오기만 하면** 정상입니다.

## Mac

| ✅ | 항목 | 확인 명령 | 정상 결과 (예) | 설치 회차 |
|---|---|---|---|---|
| ☐ | Homebrew | `brew --version` | `Homebrew 4.x.x` | 08회 |
| ☐ | Homebrew 위치 | `brew --prefix` | Apple 실리콘: `/opt/homebrew` · Intel: `/usr/local` | 08회 |
| ☐ | Git | `git --version` | `git version 2.x.x` | 08회 |
| ☐ | Python | `python3.13 --version` | `Python 3.13.x` | 09회 |
| ☐ | Python 위치 | `which python3.13` | `/opt/homebrew/bin/python3.13` (Intel: `/usr/local/bin/python3.13`) | 09회 |
| ☐ | pip | `python3.13 -m pip --version` | `pip 2x.x from ...` | 09회 |
| ☐ | VS Code | `code --version` | 버전 숫자 3줄 | 10회 |
| ☐ | 가상환경 | (프로젝트 폴더에서) `source .venv/bin/activate` 후 `which python` | `.../.venv/bin/python` | 11회 |
| ☐ | 라이브러리 | (가상환경 켠 상태) `python -c "import pandas; print(pandas.__version__)"` | `3.x.x` 또는 `2.x.x` | 11회 |
| ☐ | GitHub 로그인 | `gh auth status` | `Logged in to github.com account ...` | 12회 |
| ☐ | Git 사용자 | `git config --global user.name` | 내 이름 | 12회 |

## 한 번에 점검하기

09회부터는 `2. 개발 환경 만들기/09회_Python_설치/check_setup.py`를 실행하면 Python·pip·주요 라이브러리 상태를 한 번에 볼 수 있습니다.

```bash
python3.13 check_setup.py    # Mac
py -3.13 check_setup.py      # Windows
python check_setup.py        # 가상환경을 켠 뒤 (Mac·Windows 공통)
```

> 문제가 있으면 `공통자료/자주_나는_오류_모음.md`를 먼저 확인하세요.
