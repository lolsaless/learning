## 1단계. AI와 친해지기

| 용어 | 쉬운 설명 | 예시 |
|---|---|---|
| **생성형 AI** | 글·그림·코드 등을 새로 만들어 내는 인공지능 | ChatGPT, Claude, Gemini |
| **LLM (대규모 언어 모델)** | 엄청나게 많은 글을 읽고 "다음에 올 말"을 예측하도록 학습한 AI. 생성형 AI 채팅의 엔진 | GPT, Claude, Gemini 모델 |
| **챗봇** | 대화 형식으로 질문하고 답을 받는 프로그램 | ChatGPT 웹사이트 |
| **프롬프트 (prompt)** | AI에게 보내는 질문·지시문 | "아래 공문을 3줄로 요약해 줘" |
| **환각 (hallucination)** | AI가 사실이 아닌 내용을 그럴듯하게 지어내는 현상 | 없는 법 조항을 알려 줌 |
| **컨텍스트 (context)** | AI가 대화 중에 기억하고 참고하는 내용 전체 | 앞에서 알려 준 내 업무 설명 |
| **토큰 (token)** | AI가 글을 처리하는 단위(단어 조각). 길이 제한·요금 계산에 쓰임 | "안녕하세요" ≈ 몇 토큰 |
| **멀티모달** | 글뿐 아니라 사진·파일·음성도 이해하는 AI | 사진 속 표를 읽어 줌 |
| **AI 에이전트** | 질문에 답만 하지 않고, 직접 파일을 만들고 실행까지 하는 AI | Claude Code, Codex |
| **자동화** | 사람이 반복하던 일을 프로그램이 대신하게 만드는 것 | 성적서 자동 작성 |

## 엑셀

| 용어 | 쉬운 설명 | 예시 |
|---|---|---|
| **수식** | 셀에 `=`로 시작해 계산하게 하는 식 | `=AVERAGE(B2:B50)` |
| **함수** | 자주 쓰는 계산을 이름으로 묶어 둔 것 | `AVERAGE`, `IF`, `VLOOKUP` |
| **매크로** | 엑셀에서 하는 작업을 기록하거나 코드로 만들어 버튼 하나로 반복하게 하는 기능 | 시트 이름 일괄 변경 |
| **VBA** | 엑셀 매크로를 만드는 프로그래밍 언어 (Visual Basic for Applications) | `Sub 요약만들기() ... End Sub` |
| **.xlsx / .xlsm** | `.xlsx`는 일반 엑셀 파일, `.xlsm`은 **매크로가 들어 있는** 엑셀 파일 | 매크로를 저장하려면 `.xlsm`으로 |
| **.xltm** | 매크로가 들어 있는 엑셀 **서식 파일**(템플릿) | 유기인 시퀀스 템플릿 |
| **개발 도구 탭** | 매크로·VBA를 쓰려면 켜야 하는 엑셀 메뉴 | 파일 → 옵션 → 리본 사용자 지정 |

## 3단계. 파이썬 기초

| 용어 | 쉬운 설명 | 예시 |
|---|---|---|
| **변수** | 값에 붙인 이름표. `=`로 담는다 | `co2 = 1036` |
| **자료형** | 값의 종류 | `int`(정수), `float`(실수), `str`(문자열), `bool`(참·거짓) |
| **형 변환** | 자료형 바꾸기 | `int("612")`, `str(1036)` |
| **f-string** | 문자열 안에 `{변수}`를 넣는 방법 | `f"평균 {avg:.1f} ppm"` |
| **리스트** | 순서가 있는 값의 줄 | `[930, 1012, 1088]` |
| **인덱스** | 리스트 안의 위치 번호. **0부터** | `values[0]` |
| **슬라이싱** | 일부분 잘라 내기. 끝 번호는 포함 안 됨 | `values[1:3]` |
| **딕셔너리** | 이름표(키) → 값 짝 | `{"CO2": 1000}` |
| **튜플** | 바꿀 일 없는 값의 묶음 | `(37.56, 126.97)` |
| **조건문** | 조건에 따라 다른 일을 하게 하는 문법 | `if` / `elif` / `else` |
| **들여쓰기** | 줄 앞 공백 4칸. 파이썬에서는 문법의 일부 | |
| **반복문** | 같은 일을 여러 번 | `for`, `while` |
| **누적 변수** | 반복하며 키워 가는 값. 반복 **전에** 0으로 | `count += 1` |
| **리스트 컴프리헨션** | for + if + append를 한 줄로 | `[v for v in values if v >= 1000]` |
| **함수** | 이름 붙인 코드 묶음. 입력(매개변수)을 받아 결과를 돌려줌(`return`) | `def judge(value, limit):` |
| **매개변수 / 기본값** | 함수의 입력 / 생략하면 쓰는 값 | `limit=1000` |
| **반환값 (return)** | 함수가 돌려주는 결과. `print`와 다름 | `return "부적합"` |
| **docstring** | 함수·파일 맨 위의 설명문 | `"""설명"""` |
| **메서드** | 값 뒤에 점(.)을 찍고 쓰는 기능 | `s.split("-")`, `values.append(1)` |
| **정규표현식 (regex)** | 글자 패턴으로 찾기 | `re.findall(r"\d+", s)` |
| **인코딩** | 글자를 파일에 저장하는 규칙 | `utf-8`, 엑셀용 `utf-8-sig`, `cp949` |
| **CSV** | 쉼표로 구분된 글자 표 파일 | `측정.csv` |
| **Traceback** | 오류가 났을 때 나오는 메시지. **맨 아래 줄부터** 읽는다 | |
| **예외 처리** | 예상되는 오류를 미리 처리 | `try` / `except ValueError` |
| **논리 오류** | 오류 메시지는 없지만 결과가 틀린 것 | 누적 변수 초기화 위치 실수 |
| **표준 라이브러리** | 파이썬에 기본으로 들어 있는 도구 (설치 불필요) | `math`, `statistics`, `datetime`, `csv`, `json` |
| **import** | 라이브러리 불러오기 | `import statistics as st` |
| **datetime / timedelta** | 날짜·시각 / 기간 | `d + timedelta(days=90)` |
| **XML / JSON** | 웹·API가 데이터를 보내는 글자 형식 | `<item>...</item>`, `{"키": 값}` |
| **몬테카를로** | 무작위 실험을 많이 반복해 답을 추정하는 방법 | S09 |
