# 용어 사전

> 수업에서 처음 나오는 용어를 쉬운 말로 풀었습니다. 단계가 진행되면서 계속 추가합니다.
> 모르는 말이 나오면 여기서 먼저 찾고, 없으면 AI에게 "**○○를 초보자에게 설명해 줘**"라고 물어보세요.

---

## 1단계. AI와 친해지기

| 용어 | 쉬운 설명 | 예시 |
|---|---|---|
| **생성형 AI** | 글·그림·코드 등을 새로 만들어 내는 인공지능 | ChatGPT, Claude, Gemini |
| **LLM (대규모 언어 모델)** | 엄청나게 많은 글을 읽고 "다음에 올 말"을 예측하도록 학습한 AI. 생성형 AI 채팅의 엔진 | GPT, Claude, Gemini 모델 |
| **챗봇** | 대화 형식으로 질문하고 답을 받는 프로그램 | ChatGPT 웹사이트 |
| **프롬프트 (prompt)** | AI에게 보내는 질문·지시문 | "아래 공문을 3줄로 요약해 줘" |
| **환각 (hallucination)** | AI가 사실이 아닌 내용을 그럴듯하게 지어내는 현상 | 없는 법 조항을 알려 줌 |
| **컨텍스트 (context)** | AI가 대화 중에 기억하고 참고하는 내용 전체 | 앞에서 알려 준 내 업무 설명 |
| **토큰 (token)** | AI가 글을 처리하는 단위(단어 조각). 길이 제한·요금 계산에 쓰임 | "안녕하세요" ≈ 몇 토큰 |
| **멀티모달** | 글뿐 아니라 사진·파일·음성도 이해하는 AI | 사진 속 표를 읽어 줌 |
| **AI 에이전트** | 질문에 답만 하지 않고, 직접 파일을 만들고 실행까지 하는 AI | Claude Code, Codex |
| **자동화** | 사람이 반복하던 일을 프로그램이 대신하게 만드는 것 | 성적서 자동 작성 |

## 엑셀

| 용어 | 쉬운 설명 | 예시 |
|---|---|---|
| **수식** | 셀에 `=`로 시작해 계산하게 하는 식 | `=AVERAGE(B2:B50)` |
| **함수** | 자주 쓰는 계산을 이름으로 묶어 둔 것 | `AVERAGE`, `IF`, `VLOOKUP` |
| **매크로** | 엑셀에서 하는 작업을 기록하거나 코드로 만들어 버튼 하나로 반복하게 하는 기능 | 시트 이름 일괄 변경 |
| **VBA** | 엑셀 매크로를 만드는 프로그래밍 언어 (Visual Basic for Applications) | `Sub 요약만들기() ... End Sub` |
| **.xlsx / .xlsm** | `.xlsx`는 일반 엑셀 파일, `.xlsm`은 **매크로가 들어 있는** 엑셀 파일 | 매크로를 저장하려면 `.xlsm`으로 |
| **.xltm** | 매크로가 들어 있는 엑셀 **서식 파일**(템플릿) | 유기인 시퀀스 템플릿 |
| **개발 도구 탭** | 매크로·VBA를 쓰려면 켜야 하는 엑셀 메뉴 | 파일 → 옵션 → 리본 사용자 지정 |

## 2단계. 개발 환경 만들기

| 용어 | 쉬운 설명 | 예시 |
|---|---|---|
| **파이썬 (Python)** | 문법이 쉬워 데이터 분석·자동화에 많이 쓰는 프로그래밍 언어 | Python 3.13 |
| **코드 / 실행** | 컴퓨터에게 시킬 일을 적은 글 / 그 글을 컴퓨터가 읽고 그대로 해 보게 하는 것 | `python first_program.py` |
| **확장자** | 파일 이름 마지막 점 뒤의 글자. 파일 종류를 나타냄 | `.py`, `.ipynb`, `.xlsx` |
| **경로 (path)** | 파일이 어디 있는지 나타내는 주소 | `C:\Users\hong\Documents\data.xlsx` |
| **절대 경로 / 상대 경로** | 맨 처음부터 적은 전체 주소 / 지금 위치 기준 주소 | `/Users/hong/...` / `../data.xlsx` |
| **터미널** | 마우스 대신 글자로 명령을 입력해 컴퓨터를 다루는 창 | Mac 터미널, Windows PowerShell |
| **명령 (command)** | 터미널에 입력하는 지시 | `cd`, `ls`, `mkdir` |
| **숨김 파일** | 점(.)으로 시작해 평소에는 안 보이는 파일 | `.gitignore`, `.venv`, `.DS_Store` |
| **패키지 관리자** | 명령으로 프로그램을 설치·업데이트하는 도구 | Homebrew(`brew`), winget |
| **PATH** | 터미널이 프로그램을 찾아보는 폴더 목록. 여기 없으면 "command not found" | `brew shellenv` 설정 |
| **인터프리터** | 파이썬 코드를 읽고 실행하는 프로그램 | VS Code 오른쪽 아래 "Python 3.13" |
| **대화형 파이썬 (REPL)** | `>>>` 뒤에 한 줄씩 입력해 바로 결과를 보는 방식 | `python3.13` 실행 후 `1 + 2` |
| **주석** | `#` 뒤의 설명. 파이썬은 무시함 | `# 평균 계산` |
| **VS Code** | 코드 편집 + 실행 + 터미널을 합친 무료 프로그램 | |
| **확장 (extension)** | VS Code에 기능을 더하는 추가 프로그램 | Python, Jupyter |
| **주피터 노트북 (.ipynb)** | 설명 글, 코드, 실행 결과를 한 문서에 담는 파일 | `first_notebook.ipynb` |
| **셀 (cell)** | 노트북의 칸. 마크다운 셀(설명)과 코드 셀(코드) | |
| **커널 (kernel)** | 노트북의 코드를 실행하는 파이썬 | `.venv (Python 3.13)` |
| **마크다운 (.md)** | `#`, `-`, `**` 같은 기호로 제목·목록·굵은 글씨를 쓰는 문서 형식 | 이 용어 사전 |
| **라이브러리 (패키지)** | 다른 사람이 만들어 둔 코드 묶음. 설치해서 가져다 씀 | pandas, matplotlib |
| **pip** | 파이썬 라이브러리를 설치하는 도구 | `pip install pandas` |
| **가상환경 (venv)** | 프로젝트 전용 파이썬 + 라이브러리 공간 | `ai-black/.venv` |
| **requirements.txt** | 필요한 라이브러리 목록 파일. 이걸로 어느 PC에서나 같은 환경을 만듦 | `pip install -r requirements.txt` |
| **Google Colab** | 설치 없이 브라우저에서 노트북을 실행하는 구글 서비스. 데이터가 구글 서버로 감 | |
| **Git** | 파일의 변경 기록을 남기는 프로그램 | `git commit` |
| **GitHub** | Git 기록을 인터넷에 보관·공유하는 서비스 | `github.com/아이디/ai-black` |
| **저장소 (repository)** | Git이 기록을 관리하는 폴더 | `ai-black` |
| **커밋 / 푸시 / 풀 / 클론** | 기록하기 / GitHub로 올리기 / GitHub에서 받기 / 저장소를 처음 통째로 받기 | |
| **.gitignore** | Git이 무시할 파일 목록 | `.venv/`, `.DS_Store` |
| **충돌 (conflict)** | 두 곳에서 같은 줄을 다르게 고쳐 Git이 어느 쪽을 쓸지 묻는 상황 | `<<<<<<< HEAD` |
| **WSL2** | Windows 안에서 리눅스를 실행하는 기능 | S04 보충 실습 |
