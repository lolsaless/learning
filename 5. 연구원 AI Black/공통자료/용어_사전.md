# 용어 사전

> 수업에서 처음 나오는 용어를 쉬운 말로 풀었습니다. 단계가 진행되면서 계속 추가합니다.
> 모르는 말이 나오면 여기서 먼저 찾고, 없으면 AI에게 "**○○를 초보자에게 설명해 줘**"라고 물어보세요.

---

## 1단계. AI와 친해지기

| 용어 | 쉬운 설명 | 예시 |
|---|---|---|
| **생성형 AI** | 글·그림·코드 등을 새로 만들어 내는 인공지능 | ChatGPT, Claude, Gemini |
| **LLM (대규모 언어 모델)** | 엄청나게 많은 글을 읽고 "다음에 올 말"을 예측하도록 학습한 AI. 생성형 AI 채팅의 엔진 | GPT, Claude, Gemini 모델 |
| **챗봇** | 대화 형식으로 질문하고 답을 받는 프로그램 | ChatGPT 웹사이트 |
| **프롬프트 (prompt)** | AI에게 보내는 질문·지시문 | "아래 공문을 3줄로 요약해 줘" |
| **환각 (hallucination)** | AI가 사실이 아닌 내용을 그럴듯하게 지어내는 현상 | 없는 법 조항을 알려 줌 |
| **컨텍스트 (context)** | AI가 대화 중에 기억하고 참고하는 내용 전체 | 앞에서 알려 준 내 업무 설명 |
| **토큰 (token)** | AI가 글을 처리하는 단위(단어 조각). 길이 제한·요금 계산에 쓰임 | "안녕하세요" ≈ 몇 토큰 |
| **멀티모달** | 글뿐 아니라 사진·파일·음성도 이해하는 AI | 사진 속 표를 읽어 줌 |
| **AI 에이전트** | 질문에 답만 하지 않고, 직접 파일을 만들고 실행까지 하는 AI | Claude Code, Codex |
| **자동화** | 사람이 반복하던 일을 프로그램이 대신하게 만드는 것 | 성적서 자동 작성 |

## 엑셀

| 용어 | 쉬운 설명 | 예시 |
|---|---|---|
| **수식** | 셀에 `=`로 시작해 계산하게 하는 식 | `=AVERAGE(B2:B50)` |
| **함수** | 자주 쓰는 계산을 이름으로 묶어 둔 것 | `AVERAGE`, `IF`, `VLOOKUP` |
| **매크로** | 엑셀에서 하는 작업을 기록하거나 코드로 만들어 버튼 하나로 반복하게 하는 기능 | 시트 이름 일괄 변경 |
| **VBA** | 엑셀 매크로를 만드는 프로그래밍 언어 (Visual Basic for Applications) | `Sub 요약만들기() ... End Sub` |
| **.xlsx / .xlsm** | `.xlsx`는 일반 엑셀 파일, `.xlsm`은 **매크로가 들어 있는** 엑셀 파일 | 매크로를 저장하려면 `.xlsm`으로 |
| **.xltm** | 매크로가 들어 있는 엑셀 **서식 파일**(템플릿) | 유기인 시퀀스 템플릿 |
| **개발 도구 탭** | 매크로·VBA를 쓰려면 켜야 하는 엑셀 메뉴 | 파일 → 옵션 → 리본 사용자 지정 |

## 2단계 이후 (미리 보기)

| 용어 | 쉬운 설명 |
|---|---|
| **파이썬 (Python)** | 문법이 쉬워 데이터 분석·자동화에 많이 쓰는 프로그래밍 언어 |
| **코드** | 컴퓨터에게 시킬 일을 적은 글 |
| **실행** | 코드를 컴퓨터가 읽고 그대로 해 보게 하는 것 |
| **라이브러리 (패키지)** | 다른 사람이 만들어 둔 코드 묶음. 설치해서 가져다 씀 (예: pandas) |
| **주피터 노트북 (.ipynb)** | 설명 글과 코드, 실행 결과를 한 문서에 함께 담는 파일 |
| **Google Colab** | 설치 없이 웹 브라우저에서 주피터 노트북을 실행하게 해 주는 구글 서비스 |
| **터미널** | 마우스 대신 글자로 명령을 입력해 컴퓨터를 다루는 창 |
| **경로 (path)** | 파일이 어디 있는지 나타내는 주소 (예: `C:\Users\나\문서\data.xlsx`) |
| **Git / GitHub** | Git은 파일 변경 이력을 저장하는 프로그램, GitHub는 그 기록을 인터넷에 올려 두는 서비스 |
