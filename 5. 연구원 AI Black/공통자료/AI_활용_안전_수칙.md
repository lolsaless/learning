# AI 활용 안전 수칙

> AI는 똑똑한 동료지만, **외부 회사의 서버**에서 돌아갑니다.
> AI 창에 붙여 넣은 내용은 그 회사로 전송된다는 것을 항상 기억하세요.

---

## 1. 넣으면 안 되는 정보 🚫

| 구분 | 예시 | 대신 이렇게 |
|---|---|---|
| **개인정보** | 이름, 주민등록번호, 전화번호, 주소, 사번, 차량번호 | `홍길동` → `직원A`, 번호는 `010-0000-0000`처럼 바꾸기 |
| **민원·신고 내용** | 민원인 정보, 신고 내용 원문 | 내용을 일반화해서 설명 |
| **비공개 업무 자료** | 결재 전 문서, 내부 감사 자료, 미공개 검사 결과 | 구조만 설명하고 숫자는 가짜로 |
| **업체 정보** | 검사 대상 업체명과 결과를 함께 | `A사업장`, `B시설`로 바꾸기 |
| **계정·보안 정보** | 비밀번호, 인증서, 내부 시스템 주소, API 키 | 절대 넣지 않기 |

### 데이터를 AI에게 보여 줘야 할 때
1. **열 이름과 형식만** 알려 주세요. (예: "A열은 시설명, B열은 CO2 ppm 숫자")
2. 예시가 필요하면 **가짜 데이터 3~5줄**을 만들어 보여 주세요.
3. AI가 만든 코드를 **내 PC에서** 실제 데이터에 실행하세요. → 실제 데이터는 PC 밖으로 나가지 않습니다.

> 💡 이 방법이 이 과정 전체의 기본 원칙입니다.
> "**AI에게는 구조를, 내 PC에서는 실제 데이터를.**"

---

## 2. AI 답변은 반드시 확인하기 ✅

AI는 모르는 것도 **그럴듯하게 지어낼 수 있습니다.** 이것을 **환각(hallucination)** 이라고 합니다.

### 특히 조심할 것
- **기준값·법령·고시 번호:** "실내공기질 관리법 시행규칙 별표 ○"처럼 구체적일수록 의심하고 원문을 확인하세요.
- **숫자 계산:** 평균·합계 등은 엑셀이나 코드로 다시 계산해 확인하세요.
- **출처·논문:** AI가 알려 준 논문 제목이나 링크가 실제로 없는 경우가 있습니다.
- **최신 정보:** AI는 학습한 시점 이후의 변경 사항을 모를 수 있습니다.

### 확인하는 습관 3가지
1. "**근거가 뭐야?**", "**확실하지 않은 부분을 표시해 줘**"라고 되묻기
2. 중요한 내용은 **원문(법령, 공정시험기준, 공식 홈페이지)** 으로 확인
3. 코드는 **작은 예제로 먼저 실행**해서 결과가 맞는지 확인한 뒤 실제 데이터에 적용

---

## 3. 저작권과 출처

- AI가 만든 글·그림을 공식 문서나 발표에 쓸 때는 **기관 지침**을 확인하세요.
- 다른 사람의 글·코드를 AI에 넣어 바꿔 쓰는 경우, 원래 자료의 **이용 조건(라이선스)** 을 지켜야 합니다.
- 보고서에 AI의 도움을 받았다면, 필요한 경우 "생성형 AI를 활용하여 초안 작성" 등으로 밝혀 두는 것이 좋습니다.

---

## 4. 웹 데이터 수집 규칙 (6단계에서 자세히)

- 사이트의 **이용약관**과 `robots.txt`(수집 허용 범위)를 먼저 확인합니다.
- 요청 사이에 **충분한 대기 시간**을 둡니다. 서버에 부담을 주면 접속이 차단되거나 문제가 될 수 있습니다.
- 공공데이터포털처럼 **공식 API**가 있으면 API를 우선 사용합니다.
- 로그인이 필요한 페이지, 보안 정책으로 막아 둔 페이지를 우회하지 않습니다.

---

## 5. 한 장 요약

```
1. 개인정보·업체명·비공개 자료는 AI에 넣지 않는다.
2. AI에게는 "구조와 가짜 예시"만, 실제 데이터는 내 PC에서 처리한다.
3. 기준값·법령·숫자·출처는 반드시 원문으로 확인한다.
4. 코드는 작은 예제로 먼저 실행해 본다.
5. 웹 수집은 약관을 지키고 천천히 한다.
```
