# 터미널 명령어 치트시트

> **터미널**은 마우스 대신 **글자로 명령**해서 컴퓨터를 다루는 창입니다.
> Mac은 **터미널(zsh)**, Windows는 **PowerShell**을 기준으로 합니다.

## 터미널 여는 법

| | Mac | Windows |
|---|---|---|
| 프로그램 | 터미널 (Terminal) | PowerShell (또는 Windows 터미널) |
| 여는 법 | `Command + Space` → "터미널" 입력 → Enter | `시작` 버튼 오른쪽 클릭 → **[터미널]** 또는 **[Windows PowerShell]** |
| VS Code 안에서 | `Ctrl + `` ` (백틱, 숫자 1 왼쪽 키) | `Ctrl + `` ` |
| 처음 위치 | 내 홈 폴더 `/Users/내아이디` | 내 홈 폴더 `C:\Users\내아이디` |

---

## 자주 쓰는 명령

| 하는 일 | Mac (zsh) | Windows (PowerShell) | 예시 |
|---|---|---|---|
| 지금 위치 보기 | `pwd` | `pwd` | |
| 목록 보기 | `ls` | `ls` 또는 `dir` | |
| 숨김 파일까지 목록 | `ls -a` | `ls -Force` | `.git`, `.venv` 확인 |
| 폴더 이동 | `cd 폴더이름` | `cd 폴더이름` | `cd Documents` |
| 한 단계 위로 | `cd ..` | `cd ..` | |
| 홈 폴더로 | `cd ~` | `cd ~` | |
| 폴더 만들기 | `mkdir 이름` | `mkdir 이름` | `mkdir ai-black` |
| 빈 파일 만들기 | `touch 이름` | `New-Item 이름` | `touch memo.txt` |
| 파일 내용 보기 | `cat 이름` | `cat 이름` | `cat memo.txt` |
| 복사 | `cp 원본 사본` | `cp 원본 사본` | |
| 이동·이름 바꾸기 | `mv 원래 새것` | `mv 원래 새것` | |
| 삭제 (⚠️ 휴지통 안 감) | `rm 이름` | `rm 이름` | |
| 지금 폴더를 탐색기로 열기 | `open .` | `explorer .` | |
| 지금 폴더를 VS Code로 열기 | `code .` | `code .` | |
| 화면 지우기 | `clear` | `cls` 또는 `clear` | |
| 명령 멈추기 | `Ctrl + C` | `Ctrl + C` | 실행 중인 프로그램 중단 |

> PowerShell은 `ls`, `cd`, `pwd`, `cat`, `cp`, `mv`, `rm`, `mkdir` 같은 Mac식 명령도 대부분 알아듣습니다.

## 시간을 아끼는 요령

| 요령 | 방법 |
|---|---|
| **자동 완성** | 이름을 몇 글자 치고 `Tab` 키 → 나머지가 자동으로 채워짐 |
| **이전 명령** | `↑` 키로 방금 쓴 명령 다시 불러오기 |
| **공백이 있는 이름** | 따옴표로 감싸기: `cd "5. 연구원 AI Black"` |
| **폴더 끌어다 놓기** | 탐색기·Finder에서 폴더를 터미널 창으로 끌어오면 경로가 자동 입력됨 |

---

## 경로 읽는 법

| | Mac | Windows |
|---|---|---|
| 구분 기호 | `/` (슬래시) | `\` (역슬래시) |
| 절대 경로 예 | `/Users/hong/Documents/data.xlsx` | `C:\Users\hong\Documents\data.xlsx` |
| 홈 폴더 | `~` | `~` 또는 `$HOME` |
| 지금 폴더 | `.` | `.` |
| 위 폴더 | `..` | `..` |

- **절대 경로:** 맨 처음(최상위)부터 적은 전체 주소
- **상대 경로:** 지금 위치를 기준으로 적은 주소 (예: `data/측정.xlsx`, `../05회/파일.xlsx`)

## 이 과정에서 자주 쓰는 명령 (2단계 이후)

| 하는 일 | Mac | Windows |
|---|---|---|
| 파이썬 버전 | `python3.13 --version` | `py -3.13 --version` |
| 파이썬 파일 실행 | `python3.13 파일.py` (가상환경 안: `python 파일.py`) | `py -3.13 파일.py` (가상환경 안: `python 파일.py`) |
| 가상환경 만들기 | `python3.13 -m venv .venv` | `py -3.13 -m venv .venv` |
| 가상환경 켜기 | `source .venv/bin/activate` | `.venv\Scripts\Activate.ps1` |
| 가상환경 끄기 | `deactivate` | `deactivate` |
| 라이브러리 설치 | `pip install pandas` | `pip install pandas` |
| 목록으로 설치 | `pip install -r requirements.txt` | `pip install -r requirements.txt` |
| Git 상태 보기 | `git status` | `git status` |
