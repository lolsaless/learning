# 프롬프트 템플릿 모음

> **프롬프트(prompt)** 는 AI에게 보내는 질문이나 지시문입니다.
> 아래 템플릿의 `[ ]` 부분을 내 상황에 맞게 바꿔서 그대로 복사해 쓰세요.

---

## 0. 좋은 프롬프트의 5요소

어떤 질문이든 아래 5가지를 채우면 답이 좋아집니다. 모두 쓸 필요는 없지만, **많이 채울수록 원하는 답에 가까워집니다.**

| 요소 | 뜻 | 예시 |
|---|---|---|
| **① 역할** | AI에게 어떤 전문가처럼 답할지 알려 주기 | "너는 환경 분석 실험실의 품질관리 담당자야." |
| **② 맥락** | 내 상황·배경·대상 설명 | "나는 실내공기질 측정 결과를 시청에 보고하는 연구원이야." |
| **③ 할 일** | AI가 해야 할 일을 분명하게 | "아래 측정 결과를 보고 기준 초과 여부를 판단해 줘." |
| **④ 형식** | 답을 어떤 모양으로 받을지 | "표로 정리해 줘. 열은 시설명, 항목, 측정값, 기준, 판정." |
| **⑤ 제약** | 지켜야 할 조건 | "기준은 아래 표의 값만 써. 모르는 건 모른다고 해." |

**외우는 법:** "**누가(역할)·왜(맥락)·무엇을(할 일)·어떻게(형식)·조건(제약)**"

## 1. 문서 작업

### 1-1. 공문·문서 요약
```
너는 공공기관 문서를 읽고 핵심을 정리하는 담당자야.
아래 공문을 읽고 다음 형식으로 요약해 줘.

- 한 줄 요약:
- 요청 사항 (누가, 무엇을, 언제까지):
- 우리 팀이 해야 할 일:
- 첨부·참고 자료:

공문에 없는 내용은 지어내지 말고 "공문에 없음"이라고 적어 줘.

[공문 내용 붙여넣기 — 개인정보는 지우고]
```

### 1-2. 보고서 초안
```
너는 [환경 연구 기관]의 연구원이야.
[보고 대상: 예) 과장님께 올리는 내부 보고서]를 쓰려고 해.

주제: [예) 2025년 3분기 실내공기질 검사 결과]
들어갈 내용:
1. [검사 개요: 기간, 시설 수]
2. [주요 결과: 기준 초과 시설 수와 항목]
3. [향후 조치]

형식: 개조식(~함, ~임), A4 1쪽 분량, 제목과 소제목 포함.
숫자는 내가 준 값만 쓰고, 없는 값은 [ ]로 비워 둬.

[내가 가진 숫자·자료]
```

### 1-3. 메일·안내문 작성
```
[받는 사람: 예) 측정 대상 시설 담당자]에게 보낼 [메일/안내문]을 써 줘.
목적: [예) 다음 주 실내공기질 측정 일정 안내]
꼭 들어갈 내용: [날짜, 시간, 준비 사항, 연락처]
말투: 정중하지만 간결하게. 5문장 이내.
```

## 2. 엑셀 작업

### 2-1. 수식 만들기
```
엑셀 수식을 만들어 줘.

[표 구조]
- A열: 측정 시각, B열: CO2(ppm), C열: 온도, D열: 습도
- 데이터는 2행부터 50행까지 있어.

[하고 싶은 것]
- F2 칸에 CO2 평균을 소수점 첫째 자리까지 구하고 싶어.
- G2 칸에는 평균이 1000 이상이면 "부적합", 아니면 "적합"이라고 나오게 하고 싶어.

수식과 함께, 수식이 무슨 뜻인지 초보자도 알 수 있게 한 줄씩 설명해 줘.
```

### 2-2. VBA 매크로 만들기
```
엑셀 VBA 매크로를 만들어 줘. 나는 VBA를 처음 써.

[파일 구조]
- [시트 구성 설명]

[하고 싶은 것]
- [예) 측정지점 시트마다 CO2 평균을 구해서 '요약' 시트에 한 줄씩 적기]

[조건]
- 코드에 한글 주석을 자세히 달아 줘.
- 매크로를 어디에 붙여 넣고 어떻게 실행하는지 단계별로 알려 줘.
- 실행 전에 원본 파일을 백업하라는 안내도 넣어 줘.
```

## 3. 코드 작업 (2단계 이후)

### 3-1. 코드 만들기
```
파이썬 코드를 만들어 줘. 나는 파이썬 초보야.

[목적] [예) 폴더 안의 측정 결과 엑셀 파일을 하나로 합치기]
[입력] [예) data 폴더 안의 .xlsx 파일 여러 개. 모두 열 구성이 같음: 시설명, 항목, 측정값]
[출력] [예) 합친결과.xlsx 한 개]
[환경] [예) Windows, VS Code, Python 3.13]

조건:
- 한 줄씩 한글 주석을 달아 줘.
- 필요한 라이브러리 설치 명령도 알려 줘.
- 실행 방법을 단계별로 알려 줘.
```

### 3-2. 오류 해결
```
파이썬 코드를 실행했더니 오류가 났어. 원인과 해결 방법을 알려 줘.

[내가 하려던 것] [예) 엑셀 파일 읽기]
[실행한 코드]
(코드 붙여넣기)

[오류 메시지 전체]
(오류 메시지 전체를 그대로 붙여넣기 — 일부만 붙이지 말 것)

[환경] [Mac / Windows], Python [버전]
초보자도 이해하게 원인을 먼저 설명하고, 고친 코드 전체를 보여 줘.
```

### 3-3. 코드 설명 듣기
```
아래 코드가 무슨 일을 하는지 초보자에게 설명하듯 알려 줘.
1. 전체가 하는 일을 3줄로 요약
2. 한 줄씩(또는 한 덩어리씩) 설명
3. 내가 고쳐 쓸 때 바꿔야 할 부분(파일 이름, 경로 등)

(코드 붙여넣기)
```

## 4. 데이터 분석 (4단계 이후)

```
너는 환경 데이터 분석 전문가야.
아래 데이터는 [무엇을 언제 어디서 측정한 자료]야.

[열 설명]
- [열 이름]: [뜻, 단위]

[알고 싶은 것]
1. [예) 시설군별 평균 농도]
2. [예) 기준 초과 비율]

분석 방법을 먼저 설명하고, 파이썬(pandas) 코드로 보여 줘.
결과를 해석할 때 주의할 점(표본 수, 이상치 등)도 알려 줘.
```

## 5. 답을 더 좋게 만드는 후속 질문

AI의 첫 답이 마음에 들지 않을 때 이어서 쓰는 말입니다.

| 상황 | 이렇게 말해 보세요 |
|---|---|
| 너무 길다 | "핵심만 5줄로 줄여 줘." |
| 너무 어렵다 | "초등학생에게 설명하듯 다시 설명해 줘." |
| 형식이 다르다 | "표로 다시 정리해 줘. 열은 ○○, ○○로." |
| 맞는지 모르겠다 | "이 답의 근거가 뭐야? 확실하지 않은 부분을 표시해 줘." |
| 다른 방법이 궁금하다 | "다른 방법 2가지를 더 알려 주고 장단점을 비교해 줘." |
| 단계가 빠졌다 | "처음 하는 사람 기준으로 단계를 하나도 빼지 말고 다시 알려 줘." |
| 예시가 필요하다 | "실제 예시 데이터를 3줄 만들어서 보여 줘." |
