## 오늘의 목표

1. **VS Code**를 설치하고 한국어·Python·Jupyter 확장을 설치한다.
2. VS Code에서 **폴더 열기 → 파일 만들기 → 실행하기**를 할 수 있다.
3. VS Code가 알려 주는 **오류 표시(빨간 밑줄)** 를 읽고 고친다.
4. **첫 주피터 노트북**을 VS Code에서 실행한다.

## VS Code란?

**코드를 쓰기 위한 메모장 + 실행기 + 터미널**을 하나로 합친 프로그램입니다. Microsoft가 무료로 제공합니다.

| 메모장으로 코드 쓰기 (09회) | VS Code |
|---|---|
| 글자가 모두 같은 색 | 코드 종류별로 **색깔**이 달라 읽기 쉬움 |
| 오타를 실행해야 앎 | 실행 전에 **빨간 밑줄**로 알려 줌 |
| 들여쓰기를 직접 맞춤 | **자동**으로 맞춰 줌 |
| 실행은 터미널에서 따로 | **▶ 버튼** 하나로 실행, 터미널도 안에 있음 |
| `.ipynb`를 못 엶 | 주피터 노트북을 바로 열고 실행 |

## 2. 설치 (15분)

### 2-1. VS Code 설치

| | 명령 (08회에서 배운 방법) | 웹사이트에서 받기 |
|---|---|---|
| Mac | `brew install --cask visual-studio-code` | `https://code.visualstudio.com` → Download |
| Windows | `winget install --id Microsoft.VisualStudioCode -e --source winget` | 같음. 설치 중 **"PATH에 추가"** 와 **"Code(으)로 열기" 작업 추가** 체크 권장 |

확인 (터미널 새로 열기):
```bash
code --version
```
- Mac에서 `code: command not found`이면: VS Code 실행 → `Command + Shift + P` → **"Shell Command: Install 'code' command in PATH"**

### 2-2. 확장(Extension) 설치

왼쪽 세로 막대의 **네모 4개 아이콘**(확장, `Ctrl + Shift + X` / Mac `Command + Shift + X`) → 검색해서 **[설치]**

| 확장 | 만든 곳 | 하는 일 |
|---|---|---|
| **Korean Language Pack for Visual Studio Code** | Microsoft | 메뉴를 한국어로. 설치 후 오른쪽 아래 **[Change Language and Restart]** |
| **Python** | Microsoft | 파이썬 실행, 오류 표시, 자동 완성 (Pylance가 함께 설치됨) |

> ⚠️ 이름이 비슷한 확장이 많습니다. **만든 곳이 Microsoft**인지 확인하세요. (08회 "진짜인지 확인하기"와 같은 습관)

## 3. 화면 둘러보기와 폴더 열기 (10분)

### VS Code는 "파일"이 아니라 "폴더"를 연다
[파일] → **[폴더 열기]** → 07회에 만든 `Documents/ai-black` 선택 → "이 폴더의 작성자를 신뢰하십니까?" → **[예, 작성자를 신뢰합니다]**

### 화면 구성
```
┌──┬──────────────┬────────────────────────────────┐
│  │ 탐색기        │  편집기 (코드를 쓰는 곳)          │
│ 활│ ai-black     │                                │
│ 동│  ├ 01_practice│                                │
│ 막│  ├ 02_homework│                                │
│ 대│  └ 03_my_...  ├────────────────────────────────┤
│  │              │  터미널 (Ctrl + `)               │
└──┴──────────────┴────────────────────────────────┘
                                 상태 표시줄 (아래쪽 파란 줄)
```

| 부분 | 하는 일 |
|---|---|
| 활동 막대 (맨 왼쪽 아이콘들) | 탐색기, 검색, Git(12회), 확장 |
| 탐색기 | 열어 둔 폴더의 파일 목록. 여기서 파일·폴더 만들기 가능 |
| 편집기 | 파일 내용. 탭으로 여러 파일을 열 수 있음 |
| 터미널 | **보기 → 터미널** 또는 `Ctrl + `` ` ` (Mac도 Ctrl). 07~09회에 쓴 그 터미널이 VS Code 안에 열림 |

### 꼭 알아야 할 단축키 3개
| 하는 일 | Windows | Mac |
|---|---|---|
| 저장 | `Ctrl + S` | `Command + S` |
| 명령 팔레트 (모든 기능 검색) | `Ctrl + Shift + P` | `Command + Shift + P` |
| 터미널 열기·닫기 | `Ctrl + `` ` `` | `Ctrl + `` ` `` |

> 💡 **자동 저장 켜기:** [파일] → **[자동 저장]** 체크. 저장을 잊어서 "고쳤는데 결과가 그대로"인 실수를 막아 줍니다.

## 4. 파이썬 파일 실행과 오류 고치기 (13분)

### 4-1. 파이썬 인터프리터 고르기
`.py` 파일을 열면 오른쪽 아래(상태 표시줄)에 파이썬 버전이 보입니다. 클릭하거나 명령 팔레트에서 **"Python: Select Interpreter"(Python: 인터프리터 선택)** → **Python 3.13** 선택

> **인터프리터** = 코드를 읽고 실행하는 파이썬 프로그램. PC에 파이썬이 여러 개면 어느 것으로 실행할지 골라야 합니다.

### 4-2. 실행
- 편집기 오른쪽 위 **▶ (Python 파일 실행)** 클릭 → 아래 터미널에 결과
- VS Code는 내부적으로 `python3.13 파일.py`(Windows는 해당 python.exe)를 대신 입력해 준 것입니다.

### 4-3. 오류 고치기 — `fix_me.py`
`실습지.md` Part C를 함께 진행합니다.
- 빨간 물결 밑줄 = 오류, 노란 밑줄 = 경고
- 밑줄에 마우스를 올리면 **설명**이 나옵니다.
- 아래쪽 **[문제]** 탭(`Ctrl + Shift + M`)에 오류 목록이 모입니다.

> 💬 **강사 멘트 예시:** "VS Code의 오류 설명은 영어지만, 그 문장을 그대로 AI에게 붙이면 한국어로 풀어 줍니다. 오류 메시지는 **무서운 것이 아니라 힌트**입니다."

## 5. 첫 주피터 노트북 (17분)

1. `first_notebook.ipynb`를 `ai-black/01_practice`로 복사하고 VS Code에서 엽니다.
2. 첫 코드 셀에서 **Shift + Enter** → 오른쪽 위에 **커널 선택** 창이 뜹니다.

### 커널(Kernel) 고르기 — 오늘은 VS Code에게 맡긴다
**커널** = 노트북의 코드를 실행하는 파이썬입니다. 노트북은 `ipykernel`이라는 라이브러리가 설치된 파이썬만 커널로 쓸 수 있습니다.

1. **[Python 환경...]** (Python Environments) 선택
2. **[+ Python 환경 만들기]** (Create Python Environment) 선택
3. **[Venv]** 선택 → **Python 3.13** 선택
4. VS Code가 `ai-black` 폴더 안에 **`.venv`** 라는 폴더를 만들고, 필요한 것(`ipykernel`)을 설치합니다. (1~2분)
5. 오른쪽 위에 `.venv (Python 3.13.x)`가 보이면 준비 완료 → 다시 **Shift + Enter**

> 💬 **강사 멘트 예시:** "방금 VS Code가 **가상환경**이라는 것을 만들었습니다. 이게 무엇이고 왜 필요한지는 **다음 시간(11회)** 에 직접 만들어 보며 배웁니다. 오늘은 '노트북을 실행하려면 커널이 필요하다'만 기억하세요."

> ⚠️ **"설치하시겠습니까? ipykernel"** 같은 창이 뜨면 **[설치]** 를 누르세요. Mac에서 `.venv`가 아닌 Homebrew 파이썬을 골랐다면 설치가 실패할 수 있습니다(`externally-managed-environment`) → 위 순서대로 `.venv`를 만들어 선택하세요.

3. 노트북의 안내를 따라 끝까지 실행하고, **5. 직접 해 보기**를 수행합니다.

## 강사용 참고

| 증상 | 해결 |
|---|---|
| ▶ 버튼이 안 보임 | Python 확장 미설치, 또는 파일 확장자가 `.py`가 아님 |
| 실행했는데 `python3.13` 대신 다른 버전으로 실행됨 | 오른쪽 아래 인터프리터를 Python 3.13으로 다시 선택 |
| 한국어 메뉴로 안 바뀜 | 명령 팔레트 → "Configure Display Language" → `ko` → 재시작 |
| 노트북 커널 목록에 3.13이 없음 | 명령 팔레트 → "Python: Select Interpreter" → [인터프리터 경로 입력] → Mac `/opt/homebrew/bin/python3.13`(Intel `/usr/local/bin/python3.13`), Windows는 `py --list-paths`로 확인한 경로 |
| `.venv` 만들기가 오래 걸림 | 기관 네트워크에서 `ipykernel` 내려받기가 느릴 수 있음. 기다리거나 개인 네트워크 사용 |
