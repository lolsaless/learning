## Part E. `.py` vs `.ipynb`

| | `.py` 파일 | `.ipynb` 노트북 |
|---|---|---|
| 실행 단위 | 파일 전체를 처음부터 끝까지 | 셀 하나씩 |
| 결과가 보이는 곳 | 터미널 | 각 셀 바로 아래 |
| 설명 글 넣기 | `#` 주석으로만 | 마크다운 셀로 제목·표·목록까지 |
| 이럴 때 좋다 | 완성된 프로그램, 반복 실행하는 자동화 도구 (6단계) | 분석 과정 기록, 단계별 실험, 보고서 (4~5단계) |

## 과제 예시 (`my_notebook.ipynb`의 코드 셀)

```python
# 측정 지점별 CO2 측정값 (가상 데이터)
office = [612, 645, 701, 688, 720]
meeting_room = [880, 960, 1040, 1110, 1075]
```
```python
limit = 1000
for name, values in [("사무실", office), ("회의실", meeting_room)]:
    average = sum(values) / len(values)
    result = "부적합" if average >= limit else "적합"
    print(name, "평균:", round(average, 1), "ppm /", result)
```
결과:
```
사무실 평균: 673.2 ppm / 적합
회의실 평균: 1013.0 ppm / 부적합
```
