# 11회 과제 — 가상환경 지우고 다시 만들기

> **제출:** 다음 수업 시작 전까지
> **예상 소요 시간:** 30분

---

## 왜 하나요?
가상환경은 **언제든 지우고 다시 만들 수 있다**는 것을 몸으로 익히기 위해서입니다.
`requirements.txt`만 있으면 새 PC에서도, 망가진 환경에서도 몇 분 만에 똑같이 다시 만들 수 있습니다.

---

## 할 일

### 1. 지우기
1. VS Code를 닫습니다. (VS Code가 `.venv`를 쓰고 있으면 지워지지 않을 수 있음)
2. 탐색기·Finder에서 `ai-black/.venv` 폴더를 **휴지통으로** 옮깁니다. (숨김 파일 보기가 켜져 있어야 보입니다)

### 2. 다시 만들기
터미널에서 **강의노트의 순서 요약(①~⑥)** 을 보지 않고 해 보세요. 막히면 그때 보거나 AI에게 물어봅니다.

### 3. 확인
- `check_setup.py`를 실행해 라이브러리 4개가 모두 ✅ 인지 확인
- `venv_first_data.ipynb`를 **[다시 시작] → [모두 실행]**

### 4. 라이브러리 하나 추가해 보기 (도전)
1. 가상환경을 켠 상태에서 `pip install openpyxl` 처럼, 이미 설치된 것이 아닌 **새 라이브러리 하나**를 설치해 보세요.
   - 추천: `tabulate` (표를 예쁘게 출력하는 작은 라이브러리)
2. `requirements.txt`를 VS Code로 열어 맨 아래에 `tabulate`를 한 줄 추가하고 저장합니다.
3. AI에게 물어보세요:
   ```
   파이썬 가상환경에서 pip freeze > requirements.txt 와
   requirements.txt에 라이브러리 이름만 직접 적는 방법의 차이를 초보자에게 설명해 줘.
   각각 언제 쓰면 좋은지도 알려 줘.
   ```
