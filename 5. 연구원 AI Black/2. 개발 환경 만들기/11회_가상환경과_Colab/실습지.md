## Part A. 가상환경 만들기

### 준비
- `5. 연구원 AI Black/requirements.txt`를 `Documents/ai-black` 폴더로 **복사**합니다.
- VS Code로 `ai-black` 폴더를 열고, 터미널(`Ctrl + `` ` ``)을 엽니다.
- 터미널 줄 앞에 이미 `(.venv)`가 있으면 `deactivate`를 먼저 입력해 끕니다.

### 따라 하기
| 단계 | Mac | Windows | 결과 ✔ |
|---|---|---|---|
| 1. 위치 확인 | `pwd` → `.../ai-black` | `pwd` → `...\ai-black` | |
| 2. 만들기 | `python3.13 -m venv .venv` | `py -3.13 -m venv .venv` | |
| 3. 켜기 | `source .venv/bin/activate` | `.venv\Scripts\Activate.ps1` | |
| 4. 켜졌는지 | 줄 앞에 `(.venv)` | 줄 앞에 `(.venv)` | |
| 5. 어떤 파이썬? | `which python` | `where.exe python` | |
