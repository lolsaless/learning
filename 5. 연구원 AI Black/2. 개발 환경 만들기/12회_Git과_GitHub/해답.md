# 12회 해답 및 강사용 참고

## 실습지 — 기대 결과

### Part C
- `git init` 직후 `git status`: `.gitignore`, `01_practice/`, `02_homework/`, `03_my_project/`(비어 있으면 안 보임), `requirements.txt` 등이 빨간색 (Untracked files)
  - **`.venv`가 없어야 정상** — `.gitignore`가 동작하고 있다는 뜻
  - 빈 폴더(`03_my_project`)는 Git이 기록하지 않습니다. 파일이 하나라도 있어야 올라갑니다.
- `git add .` 후: **초록색** (Changes to be committed)
- `git commit` 결과 예: `[main (root-commit) 1a2b3c4] ai-black 저장소 시작: 07~11회 실습과 과제`
- `git log --oneline` 예: `1a2b3c4 (HEAD -> main) ai-black 저장소 시작: 07~11회 실습과 과제`

### Part F
- clone한 폴더에는 `.venv`가 **없습니다.** (`.gitignore`로 올리지 않았기 때문) → 다른 PC에서는 `requirements.txt`로 새로 만들어야 함
- `git pull` 전: `other_pc_memo.txt` 없음 → 후: 생김. 터미널에 `1 file changed` 같은 메시지

## 2단계 정리 퀴즈 정답

| 번호 | 정답 |
|---|---|
| 1 | ③ |
| 2 | `pwd`–지금 위치 보기, `ls`–목록 보기, `cd`–폴더 이동, `mkdir`–폴더 만들기 |
| 3 | 패키지 관리자 |
| 4 | Mac `python3.13` / Windows `py -3.13` |
| 5 | `.py`: 오른쪽 위 ▶ 버튼 (또는 터미널에서 실행) / 노트북: Shift + Enter (또는 셀 왼쪽 ▶) |
| 6 | ③ (가상환경은 PC·운영체제마다 다시 만든다) |
| 7 | Mac `source .venv/bin/activate` / Windows `.venv\Scripts\Activate.ps1` |
| 8 | `requirements.txt`에 적힌 라이브러리를 (켜져 있는 가상환경에) 한꺼번에 설치 |
| 9 | 데이터가 외부(구글) 서버로 나가지 않고, 파일도 사라지지 않음 |
| 10 | commit / push / pull / clone |

### 서술형 모범 답안
> 작업을 **시작할 때** `git pull`로 다른 PC에서 올린 최신 내용을 받고, 작업을 **끝낼 때** `commit`으로 기록하고 `push`로 올린다. `.venv`는 `.gitignore`로 올리지 않고, 각 PC에서 `requirements.txt`로 한 번씩 만든다. 라이브러리를 추가했으면 `requirements.txt`도 고쳐서 함께 올린다.
