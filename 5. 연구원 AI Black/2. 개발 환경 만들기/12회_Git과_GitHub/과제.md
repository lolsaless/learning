# 12회 과제 — GitHub에 과제 정리해 올리기

> **제출:** 다음 수업 시작 전까지 — **GitHub 저장소 링크**로 제출
> **예상 소요 시간:** 30~40분

---

## 할 일

### 1. 과제 폴더 정리
`ai-black/02_homework` 아래를 회차별로 정리하세요. (예시)
```
02_homework/
├── week04/        07회 과제 (memo.txt 등)
├── week05/        09·10회 과제 (my_first_program.py, my_notebook.ipynb)
└── week06/        11·12회 과제
```
- 폴더를 옮긴 뒤 **커밋**하세요. 메시지 예: `과제 폴더를 주차별로 정리`

### 2. README.md 만들기
`ai-black` 폴더에 `README.md` 파일을 만들고 아래 내용을 채웁니다. (`.md`는 GitHub가 첫 화면에 예쁘게 보여 주는 문서입니다)

```markdown
# 연구원 AI Black — (내 이름)의 학습 저장소

## 폴더 구성
- `01_practice`: 수업 중 실습
- `02_homework`: 주차별 과제
- `03_my_project`: 나만의 프로젝트

## 개발 환경
- 운영체제: (Mac / Windows)
- Python 3.13, VS Code
- 가상환경 만들기: (내 운영체제의 명령을 적기)

## 지금까지 배운 것
- (한 줄씩 3가지 이상)
```

> 💡 마크다운 문법이 궁금하면 AI에게 "GitHub README.md에 자주 쓰는 마크다운 문법을 예시와 함께 알려 줘"라고 물어보세요.
> VS Code에서 `.md` 파일을 열고 오른쪽 위 **미리 보기 아이콘**(또는 `Ctrl/Command + Shift + V`)을 누르면 보이는 모양을 확인할 수 있습니다.

### 3. 올리기
- 커밋 메시지: `README 작성`
- push 후 GitHub 저장소 첫 화면에 README가 보이는지 확인

### 4. 집이나 다른 PC에서 해 보기 (선택)
다른 PC가 있다면 그 PC에서 `gh repo clone ai-black` → `.venv` 만들기 → `pip install -r requirements.txt` → 노트북 하나 실행
(다른 PC에도 Python 3.13, VS Code, Git, gh 설치가 필요합니다)
