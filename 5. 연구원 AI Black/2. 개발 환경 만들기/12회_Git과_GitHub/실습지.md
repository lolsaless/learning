## Part A. Git 사용자 설정

```bash
git config --global user.name "내 이름"
git config --global user.email "GitHub가입이메일"
git config --global init.defaultBranch main
git config --global core.quotepath false
```
확인:
```bash
git config --global --list
```
- `user.name`, `user.email`이 보이나요? (예 / 아니오)

> `core.quotepath false`는 한글 파일 이름이 `\354\240...`처럼 깨져 보이지 않게 하는 설정입니다.

## Part D. GitHub에 올리기

```bash
gh repo create ai-black --private --source=. --push
```
- `--private`: 나만 볼 수 있는 **비공개** 저장소
- `--source=.`: 지금 폴더(`.`)를 올림
- `--push`: 만들자마자 올리기

브라우저에서 확인:
```bash
gh repo view --web
```
| 확인 | ✔ |
|---|---|
| 저장소 이름 옆에 **Private** 표시 | |
| `01_practice`, `02_homework`, `requirements.txt`가 보임 | |
| `.venv` 폴더가 **보이지 않음** | |
| 커밋 메시지가 보임 | |

## Part E. VS Code 버튼으로 커밋·푸시하기

1. `01_practice/hello_vscode.py`를 열어 맨 아래에 한 줄 추가하고 저장:
   ```python
   print("Git으로 기록한 첫 변경입니다.")
   ```
2. 왼쪽 **소스 제어** 아이콘(`Ctrl + Shift + G`) → 변경된 파일 옆 **M** 표시 확인
3. 파일 이름을 클릭 → **왼쪽(이전) / 오른쪽(지금)** 비교 화면 확인
4. 메시지 칸에 `hello_vscode.py에 출력 한 줄 추가` 입력 → **[✓ 커밋]**
   - "변경 내용을 스테이징하시겠습니까?" → **[예]** 또는 **[항상]**
5. **[변경 내용 동기화]** (또는 `…` → [푸시])
6. GitHub 웹에서 파일 내용이 바뀌었는지 확인 → 위쪽 **커밋 수(예: 2 commits)** 클릭해서 기록 보기

## Part F. 다른 PC 흉내 내기 (clone → push → pull)

### 1. "다른 PC"에 받기
VS Code 터미널에서:
```bash
cd ..
gh repo clone ai-black ai-black-other-pc
cd ai-black-other-pc
ls
```
- `ai-black`과 같은 파일들이 보이나요? `.venv`는 있나요? ______

### 2. "다른 PC"에서 고치고 올리기
```bash
echo "다른 PC에서 만든 메모" > other_pc_memo.txt       # Mac
"다른 PC에서 만든 메모" | Out-File other_pc_memo.txt -Encoding utf8   # Windows
git add .
git commit -m "다른 PC에서 메모 추가"
git push
```

### 3. 원래 PC에서 받기
```bash
cd ../ai-black
ls                       # other_pc_memo.txt가 아직 없음
git pull
ls                       # 이제 보임!
```
- `git pull` 전후로 무엇이 달라졌나요? ______________________________________

### 4. 정리
