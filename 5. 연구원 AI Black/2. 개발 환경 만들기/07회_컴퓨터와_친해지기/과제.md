# 07회 과제 — AI에게 물어 터미널 미션 해결하기

> **제출:** 다음 수업 시작 전까지
> **예상 소요 시간:** 20~30분

---

## 할 일

아래 미션을 **터미널 명령으로만** 해결하세요. 모르는 명령은 AI에게 물어봅니다.

### AI에게 물을 때 꼭 넣을 것 (맥락)
- 내 운영체제: **Mac(zsh)** 인지 **Windows(PowerShell)** 인지
- 지금 위치와 하고 싶은 일

```
나는 [Mac 터미널(zsh) / Windows PowerShell]을 처음 쓰는 초보야.
지금 [Documents/ai-black] 폴더에 있어.
[하고 싶은 일]을 하는 명령을 알려 주고, 명령의 각 부분이 무슨 뜻인지 설명해 줘.
```

### 미션
1. `ai-black/02_homework` 폴더 안에 `week04` 폴더를 만드세요.
2. `week04` 폴더 안에 `memo.txt` 파일을 만들고, 내용으로 "07회 과제"라고 적으세요.
3. `memo.txt`를 **복사**해서 `memo_backup.txt`를 만드세요.
4. `week04` 폴더의 목록을 보고 두 파일이 있는지 확인하세요.
5. 터미널에서 `ai-black` 폴더 전체의 구조를 **나무 모양**으로 보는 방법을 AI에게 물어 실행해 보세요.
   - 힌트: Mac은 `tree` 프로그램 설치가 필요할 수 있습니다 (08회에서 배울 Homebrew로 설치 가능). Windows는 `tree /F`.
