## 2. 파일·폴더·확장자·경로 (15분)

### 폴더 = 서랍, 파일 = 서류
- **폴더(디렉터리)** 는 서랍, **파일**은 서랍 속 서류입니다.
- 서랍 안에 또 서랍을 넣을 수 있듯, 폴더 안에 폴더가 들어갑니다.

### 확장자 = 서류의 종류 표시
파일 이름의 **마지막 점(.) 뒤**에 있는 글자입니다. 컴퓨터는 확장자를 보고 **어떤 프로그램으로 열지** 정합니다.

| 확장자 | 종류 | 여는 프로그램 |
|---|---|---|
| `.xlsx` / `.xlsm` | 엑셀 / 매크로 엑셀 | 엑셀 |
| `.csv` | 쉼표로 구분된 표 (글자만 있음) | 엑셀, 메모장, 파이썬 |
| `.txt` | 글자만 있는 문서 | 메모장, 텍스트 편집기 |
| `.md` | 마크다운 문서 (지금 이 강의노트) | VS Code, GitHub |
| `.py` | 파이썬 코드 | VS Code |
| `.ipynb` | 주피터 노트북 | VS Code, Colab |
| `.html` | 웹 페이지 | 웹 브라우저 |

### 경로 = 파일의 주소
"서류가 어디 있나요?"에 대한 답입니다.

| | Mac | Windows |
|---|---|---|
| 예 | `/Users/hong/Documents/ai-black/data.xlsx` | `C:\Users\hong\Documents\ai-black\data.xlsx` |
| 구분 기호 | `/` | `\` |
| 맨 앞 | `/` (최상위) | `C:\` (C 드라이브) |

- **절대 경로:** 맨 처음부터 적은 전체 주소 (집 주소 전체)
- **상대 경로:** 지금 있는 곳을 기준으로 한 주소 ("옆 방", "위층") → `data/측정.xlsx`, `../다른폴더`
  - `.` = 지금 폴더, `..` = 한 단계 위 폴더

> 💬 **강사 시연:** Finder(Mac)에서 파일 선택 → `Command + Option + C` 로 경로 복사 / Windows 탐색기에서 파일 선택 → `Shift + 오른쪽 클릭` → **[경로로 복사]**. 메모장에 붙여 넣어 실제 경로를 보여 주세요.

### 이름 짓기 규칙 (앞으로 계속 지킬 것)
| 권장 | 피하기 | 이유 |
|---|---|---|
| `ai-black`, `co2_report.py` | `AI Black 최종(진짜최종).py` | 공백·괄호는 터미널에서 따옴표가 필요하고 오류가 잘 남 |
| 영어 소문자, 숫자, `-`, `_` | `/ \ : * ? " < > |` | 운영체제가 금지하는 문자 |
| `2025-04-08_결과.xlsx` | `4월8일결과.xlsx` | 날짜를 `연-월-일`로 쓰면 이름순 정렬 = 날짜순 |

> 한글 파일 이름도 쓸 수는 있습니다. 다만 **코드 파일과 폴더 이름은 영어**로 하면 오류가 줄어듭니다.

## 3. 확장자·숨김 파일 보이게 하기 (5분)

개발 작업에서는 확장자와 숨김 파일(`.git`, `.venv`, `.gitignore`, `.DS_Store` 등 **점으로 시작하는 파일**)을 볼 수 있어야 합니다.

### Mac
- **확장자:** Finder → 메뉴 [Finder] → [설정] → [고급] → **"모든 파일 확장자 보기"** 체크
- **숨김 파일:** Finder 창에서 `Command + Shift + .` (마침표) → 다시 누르면 숨김

### Windows 11
- 탐색기 → 위쪽 **[보기]** → **[표시]** → **[파일 확장명]**, **[숨긴 항목]** 체크
- (Windows 10: 탐색기 [보기] 탭 → "파일 확장명", "숨긴 항목" 체크)

## 4. 터미널 열기와 첫 명령 (10분)

`공통자료/터미널_명령어_치트시트.md`를 화면에 띄우고 함께 따라 합니다.

### 열기
- **Mac:** `Command + Space` → "터미널" → Enter
- **Windows:** 시작 버튼 오른쪽 클릭 → **[터미널]** (또는 [Windows PowerShell])

### 첫 명령 3개

```bash
pwd        # 지금 내가 있는 위치(폴더) 보기
ls         # 지금 폴더 안의 목록 보기
cd Documents   # Documents(문서) 폴더로 이동
```

> 💬 **강사 멘트 예시:** "터미널은 '말로 하는 탐색기'입니다. 탐색기에서 더블클릭으로 폴더에 들어가는 것을 `cd`로, 목록을 보는 것을 `ls`로 합니다. 같은 일을 하는 다른 방법일 뿐입니다."

### 요령 3가지 (꼭 알려 주기)
1. **Tab 자동 완성:** `cd Doc`까지 치고 `Tab` → `Documents`로 완성
2. **↑ 키:** 방금 쓴 명령 다시 불러오기
3. **Ctrl + C:** 명령이 멈추지 않을 때 중단

## 6. 정리 (8분)

### 오늘의 핵심 3줄
1. **확장자**는 파일의 종류, **경로**는 파일의 주소다.
2. **터미널**은 글자로 하는 탐색기다. `pwd`(위치), `ls`(목록), `cd`(이동), `mkdir`(만들기).
3. 코드·폴더 이름은 **영어 소문자 + `-` `_`** 로, 공백 없이.

## 강사용 참고

### 자주 나오는 질문
| 질문 | 답변 |
|---|---|
| 터미널에서 실수로 파일을 지우면? | `rm`으로 지운 파일은 **휴지통에 가지 않습니다.** 그래서 오늘은 `rm`을 연습하지 않습니다. 지우기는 탐색기·Finder로 하세요. |
| Windows의 명령 프롬프트(cmd)와 PowerShell 차이는? | 둘 다 터미널이지만 명령이 조금 다릅니다. 이 과정은 **PowerShell**로 통일합니다. |
| Mac 터미널 맨 앞의 `%` 기호는? | 명령을 입력하라는 표시(프롬프트)입니다. 명령을 복사할 때 `%`나 `$`는 빼고 입력합니다. |
| OneDrive 안의 문서 폴더라고 나와요 (Windows) | Windows는 문서 폴더가 OneDrive로 동기화되는 경우가 있습니다. 경로에 `OneDrive`가 들어가도 괜찮지만, 이후 가상환경(`.venv`)까지 동기화되면 느려질 수 있어 `C:\Users\내아이디\ai-black`처럼 **홈 폴더 바로 아래**에 만드는 것도 방법입니다. |
