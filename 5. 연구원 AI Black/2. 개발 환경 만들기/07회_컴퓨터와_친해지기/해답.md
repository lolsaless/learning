| 미션 | Mac 예시 결과 | Windows 예시 결과 |
|---|---|---|
| 1 `pwd` | `/Users/hong` | `C:\Users\hong` |

### B2. 공백이 있는 이름
- `cd test folder` → Mac: `cd: string not in pwd: test` 같은 오류 / Windows: `test` 폴더를 찾을 수 없다는 오류 또는 인수 오류
- 터미널은 **공백을 "다음 단어"로 인식**하기 때문입니다. 따옴표로 감싸야 하나의 이름이 됩니다.
- 실습 후 `test folder`는 탐색기·Finder로 지우게 하세요.

## 과제 — 모범 답안

### Mac (zsh)
```bash
cd ~/Documents/ai-black/02_homework
mkdir week04
cd week04
echo "07회 과제" > memo.txt
cp memo.txt memo_backup.txt
ls
# 미션 5
brew install tree        # 08회 이후 가능
tree ~/Documents/ai-black
```
- Homebrew 설치 전이라면 `find ~/Documents/ai-black` 로도 전체 목록을 볼 수 있습니다.

### Windows (PowerShell)
```powershell
cd ~\Documents\ai-black\02_homework
mkdir week04
cd week04
"07회 과제" | Out-File memo.txt -Encoding utf8
Copy-Item memo.txt memo_backup.txt      # 또는 cp memo.txt memo_backup.txt
ls
# 미션 5
tree /F ~\Documents\ai-black
```

### 예상 결과 (`tree`)
```
ai-black
├── 01_practice
│   └── hello.txt
├── 02_homework
│   └── week04
│       ├── memo.txt
│       └── memo_backup.txt
└── 03_my_project
```
