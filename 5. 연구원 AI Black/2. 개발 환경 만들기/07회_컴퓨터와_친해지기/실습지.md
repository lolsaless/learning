# 07회 실습지 — 터미널 미션

> **준비:** 터미널(Mac) 또는 PowerShell(Windows)을 엽니다.
> 명령을 입력할 때 맨 앞의 `%`, `$`, `PS>` 같은 기호는 **빼고** 입력하세요.
> 명령 옆의 `# ...`는 설명이므로 입력하지 않아도 됩니다.

---

## 미션 1. 나는 어디에 있나?

```bash
pwd
```
- 결과: ______________________________________
- 이것은 내 **홈 폴더**입니다. Mac은 `/Users/내아이디`, Windows는 `C:\Users\내아이디` 모양입니다.

## 미션 2. 무엇이 있나?

```bash
ls
```
- 보이는 폴더 3개를 적어 보세요: ______ / ______ / ______
- `Documents`(또는 `문서`)가 있나요? (예 / 아니오)

숨김 파일까지 보려면:
```bash
ls -a          # Mac
ls -Force      # Windows
```
- 점(.)으로 시작하는 이름이 보이나요? 하나만 적어 보세요: ______

## 미션 3. 문서 폴더로 이동하기

```bash
cd Documents
pwd
```
- `pwd` 결과가 `.../Documents`로 바뀌었나요? (예 / 아니오)
- 💡 `cd Doc`까지만 치고 **Tab** 키를 눌러 보세요. 나머지가 자동으로 채워집니다.

> Windows에서 `Documents`가 없다면 `cd ~\OneDrive\문서` 또는 `cd ~\OneDrive\Documents`를 시도해 보세요.

## 미션 4. 작업 폴더 만들기

```bash
mkdir ai-black
cd ai-black
mkdir 01_practice 02_homework 03_my_project
ls
```
- 폴더 3개가 보이나요? (예 / 아니오)

## 미션 5. 탐색기·Finder로 확인하기

```bash
open .         # Mac
explorer .     # Windows
```
- 탐색기·Finder 창이 열리고 방금 만든 폴더 3개가 보이나요? (예 / 아니오)
- 그 창에서 `01_practice` 폴더 안에 **새 텍스트 파일**을 하나 만들어 보세요. (Mac은 다음 미션에서 터미널로 만듭니다)

## 미션 6. 파일 만들고 내용 넣기

```bash
cd 01_practice
```

Mac:
```bash
echo "안녕하세요, 터미널!" > hello.txt
cat hello.txt
```

Windows:
```powershell
"안녕하세요, 터미널!" | Out-File hello.txt -Encoding utf8
cat hello.txt
```

- 화면에 "안녕하세요, 터미널!"이 보이나요? (예 / 아니오)

한 단계 위로 올라가 전체 모양을 확인합니다.
```bash
cd ..
pwd
ls
```

## 보너스 미션 (시간이 남으면)

### B1. 경로 복사해서 이동하기
1. 탐색기·Finder에서 `03_my_project` 폴더의 **경로를 복사**합니다.
   - Mac: 폴더 선택 → `Command + Option + C`
   - Windows: 폴더 선택 → `Shift + 오른쪽 클릭` → **[경로로 복사]**
2. 터미널에 `cd ` (cd와 공백)를 입력하고 붙여 넣기 → Enter
3. `pwd`로 확인

### B2. 공백이 있는 이름
```bash
mkdir "test folder"
cd test folder        # ← 이렇게 하면 어떻게 될까요?
cd "test folder"      # ← 이건?
```
- 따옴표가 없을 때 무슨 일이 일어났나요? ______________________
- → 그래서 폴더 이름에 공백을 쓰지 않는 게 좋습니다.
