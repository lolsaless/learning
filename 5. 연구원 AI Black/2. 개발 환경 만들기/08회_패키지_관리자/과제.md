# 08회 과제 — 업무에 쓸 프로그램 하나 설치하기

> **제출:** 다음 수업 시작 전까지
> **예상 소요 시간:** 20분

---

## 할 일

평소 웹사이트에서 내려받아 설치하던 프로그램 중 하나를 **패키지 관리자로 찾아 설치**해 보세요.

### 순서
1. 설치할 프로그램 고르기 (아래 예시 참고, 또는 내가 쓰는 프로그램)
2. `brew search 이름` / `winget search 이름` 으로 찾기
3. 찾은 이름(또는 ID)이 **진짜 그 프로그램인지** 확인
   - Mac: `brew info 이름` → 홈페이지 주소 확인
   - Windows: `winget show --id 아이디` → 게시자(Publisher)·홈페이지 확인
4. 설치하고 실행되는지 확인
5. 모르는 것은 AI에게 물어보기 (운영체제를 꼭 밝히기)

### 예시 프로그램

| 프로그램 | Mac (Homebrew) | Windows (winget ID) |
|---|---|---|
| 크롬 | `brew install --cask google-chrome` | `Google.Chrome` |
| 7-Zip / 압축 | `brew install --cask keka` | `7zip.7zip` |
| 노트 앱 Obsidian | `brew install --cask obsidian` | `Obsidian.Obsidian` |
| GitHub Desktop (S06에서 사용) | `brew install --cask github` | `GitHub.GitHubDesktop` |

> 💡 Mac에서 `--cask`는 "창이 있는 일반 앱"을 설치할 때 붙입니다. `git`, `tree` 같은 터미널 프로그램은 `--cask` 없이 설치합니다.
> ⚠️ 이미 설치된 프로그램이면 건너뛰고 다른 것을 고르세요.
