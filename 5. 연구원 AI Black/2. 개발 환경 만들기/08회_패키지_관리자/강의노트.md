## 오늘의 목표

1. **패키지 관리자**가 무엇이고 왜 쓰는지 안다.
2. Mac은 **Homebrew**, Windows는 **winget**을 준비한다.
3. 패키지 관리자로 **Git**을 설치하고 버전을 확인한다.
4. 프로그램 **검색·설치·업데이트·목록 보기** 명령을 쓴다.

## 2. 패키지 관리자란? (10분)

### 비유: 터미널용 앱스토어
| 지금까지 | 패키지 관리자 |
|---|---|
| 웹사이트 찾기 → 설치 파일 내려받기 → 더블클릭 → 다음, 다음, 다음… | `brew install git` 한 줄 |
| 업데이트는 프로그램마다 따로 | `brew upgrade` 한 줄로 전부 |
| 어디에 설치됐는지 모름 | 정해진 위치에 정리됨 |

### 운영체제별 패키지 관리자
| 운영체제 | 이 과정에서 쓰는 것 | 특징 |
|---|---|---|
| Mac | **Homebrew** (`brew`) | 개발자들이 가장 많이 쓰는 Mac 패키지 관리자. 별도 설치 필요 |
| Windows | **winget** | Windows 10(최신 업데이트)·11에 **기본 포함**. Microsoft 공식 |
| Windows (심화) | WSL2 + Homebrew | Windows 안에 리눅스를 설치해 Mac과 같은 방식으로 쓰기 → **보충 S04** |

> 💬 **강사 멘트 예시:** "AI에게 설치 방법을 물으면 대부분 `brew install ...`이나 `winget install ...` 같은 한 줄 명령을 알려 줍니다. 오늘부터 이 한 줄을 그대로 실행할 수 있게 됩니다."

### ⚠️ 설치 명령을 실행하기 전에
- **출처를 확인**하세요. 공식 사이트(`brew.sh`, Microsoft 문서)나 신뢰할 수 있는 안내의 명령만 실행합니다.
- 인터넷에서 본 "아무 명령"이나 붙여 넣지 않습니다. 의심스러우면 **AI에게 "이 명령이 무슨 일을 하는지 설명해 줘"** 라고 먼저 물어보세요.

## 3. 운영체제별 준비 (25분)

### 3-1. Mac — Homebrew 설치

**① 칩 확인** — 06회 과제에서 확인한 값 (Apple 실리콘 / Intel)

**② 설치 명령** (공식 사이트 `https://brew.sh` 첫 화면의 명령과 같습니다)
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```
- **로그인 비밀번호**를 물어보면 입력합니다. **입력해도 화면에 아무것도 안 보이는 것이 정상**입니다. 입력 후 Enter.
- "Press RETURN to continue" → Enter
- Xcode 명령줄 도구(Command Line Tools)를 설치하겠냐는 창이 뜨면 **[설치]**. 수 분 걸립니다.

**③ PATH 설정 (가장 많이 빠뜨리는 단계!)**
설치가 끝나면 마지막에 **"Next steps"** 가 나옵니다. 거기 적힌 두 줄을 그대로 실행합니다.

Apple 실리콘(M1~M4):
```bash
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"
```
Intel Mac은 보통 `/usr/local`에 설치되어 이 단계가 필요 없습니다. (Next steps에 안내가 있으면 그대로 따릅니다)

**④ 확인**
```bash
brew --version     # Homebrew 4.x.x
brew --prefix      # Apple 실리콘: /opt/homebrew, Intel: /usr/local
brew doctor        # "Your system is ready to brew." 이면 최고
```

> 📎 더 자세한 설정(업데이트, 정리, 문제 해결)은 `3. Python/1. brew setup/Homebrew_설정_가이드.md`(Apple 실리콘), `intel-mac-brew-github-setup.md`(Intel)를 참고하세요.

### 3-2. Windows — winget 확인

winget은 대부분 이미 설치되어 있습니다. PowerShell에서 확인합니다.
```powershell
winget --version
```
- `v1.x.x`가 나오면 준비 완료
- 오류가 나면: **Microsoft Store** → "앱 설치 관리자" 검색 → [업데이트] 또는 [설치] → PowerShell **새로 열기**

처음 `winget`을 쓰면 원본 약관 동의(`Y/N`)를 물어볼 수 있습니다 → `Y` 입력.

## 4. 실습: Git 설치와 기본 명령 (15분)

`실습지.md`를 따라 합니다.

| 하는 일 | Mac | Windows |
|---|---|---|
| 검색 | `brew search git` | `winget search git` |
| 정보 보기 | `brew info git` | `winget show --id Git.Git` |
| **설치** | `brew install git` | `winget install --id Git.Git -e --source winget` |
| 설치 목록 | `brew list` | `winget list` |
| 업데이트 확인 | `brew outdated` | `winget upgrade` |
| 전부 업데이트 | `brew upgrade` | `winget upgrade --all` |

> Windows에서 Git을 설치한 뒤에는 **PowerShell을 닫고 새로 열어야** `git` 명령이 인식됩니다.

## 강사용 참고

### 자주 나는 문제
| 증상 | 해결 |
|---|---|
| (Mac) 비밀번호 입력이 안 됨 | 화면에 표시되지 않을 뿐 입력되고 있습니다. 끝까지 치고 Enter |
| (Mac) `command not found: brew` | PATH 설정(③)을 안 함 → `공통자료/자주_나는_오류_모음.md` |
| (Mac) 회사 Mac에서 관리자 권한 없음 | 관리자 계정이 필요. 정보화 담당자에게 요청 |
| (Windows) `winget` 인식 안 됨 | Microsoft Store에서 "앱 설치 관리자" 업데이트 |
| (Windows) 설치 중 관리자 승인 창 | **[예]** 클릭 (사용자 계정 컨트롤) |
| 기관 네트워크에서 설치가 멈춤 | 보안 프록시·방화벽 때문일 수 있음. 정보화 담당자에게 문의하거나 개인 네트워크에서 설치 |

### 설치 시간
- Homebrew 설치(Command Line Tools 포함)는 인터넷 속도에 따라 **10~20분** 걸릴 수 있습니다. 설치가 도는 동안 2절의 설명을 이어 가면 시간이 절약됩니다.
