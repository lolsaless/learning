## Part B. Git 설치

### 1. 먼저 검색해 보기

Mac:
```bash
brew search git
brew info git
```
Windows:
```powershell
winget search git
winget show --id Git.Git
```
- 검색 결과에 비슷한 이름이 여러 개 나오나요? (예 / 아니오)
- 그래서 Windows에서는 정확한 **ID(`Git.Git`)** 로 설치합니다.

### 2. 설치

Mac:
```bash
brew install git
```
Windows:
```powershell
winget install --id Git.Git -e --source winget
```
- `-e`는 "ID가 **정확히** 같은 것만", `--source winget`은 "winget 공식 저장소에서"라는 뜻입니다.
- Windows는 설치 후 **PowerShell을 닫고 새로 여세요.**

### 3. 확인
```bash
git --version
```
- 내 결과: ______________________________________

> 💡 Mac에는 처음부터 Apple이 넣어 둔 Git이 있을 수 있습니다. `which git` 결과가 `/opt/homebrew/bin/git`(Intel: `/usr/local/bin/git`)이면 Homebrew로 설치한 Git을 쓰고 있는 것입니다.

## Part C. 하나 더 설치해 보기 — `tree`

07회 과제의 "나무 모양 폴더 보기"를 해결합니다.

Mac:
```bash
brew install tree
tree ~/Documents/ai-black
```

Windows는 `tree`가 기본으로 들어 있습니다.
```powershell
tree /F ~\Documents\ai-black
```

## Part D. 관리 명령 연습

| 하는 일 | Mac | Windows | 해 봤나 ✔ |
|---|---|---|---|
| 설치된 목록 | `brew list` | `winget list` | |
| 업데이트할 것 확인 | `brew outdated` | `winget upgrade` | |
| (선택) 전부 업데이트 | `brew upgrade` | `winget upgrade --all` | |

> ⚠️ `winget upgrade --all`은 PC에 설치된 많은 프로그램을 한꺼번에 업데이트합니다. 기관 PC라면 업무 프로그램에 영향이 없는지 확인한 뒤 실행하세요. 오늘은 **확인(`winget upgrade`)만** 해도 충분합니다.
