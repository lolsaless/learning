# 08회 해답 및 강사용 참고

## 실습지 — 기대 결과

### Part A
| 명령 | Mac(Apple 실리콘) | Mac(Intel) |
|---|---|---|
| `brew --version` | `Homebrew 4.x.x` | 같음 |
| `brew --prefix` | `/opt/homebrew` | `/usr/local` |
| `brew doctor` | `Your system is ready to brew.` (경고가 몇 개 나와도 대부분 괜찮음) | 같음 |

- Windows `winget --version` → `v1.x.x`

### Part B
- `git --version` → Mac `git version 2.x.x`, Windows `git version 2.x.x.windows.1`
- Mac `which git` → `/opt/homebrew/bin/git` (Intel: `/usr/local/bin/git`)
  - `/usr/bin/git`이 나오면 Apple 기본 Git입니다. 새 터미널을 열어도 그대로면 PATH 설정(`brew shellenv`)을 다시 확인하세요.

### Part E — VS Code 설치 명령 (10회에서 실행)
| | 명령 |
|---|---|
| Mac | `brew install --cask visual-studio-code` |
| Windows | `winget install --id Microsoft.VisualStudioCode -e --source winget` |

- **출처 확인 방법:** Homebrew는 `https://formulae.brew.sh`에서 이름 검색, winget은 `winget show --id ...`로 게시자(Microsoft Corporation) 확인

## 과제 — 모범 답안 (Windows 예)

```
1. 설치한 프로그램: 7-Zip
2. 검색: winget search 7zip → 이름 7-Zip, ID 7zip.7zip
3. 확인: winget show --id 7zip.7zip → Publisher: Igor Pavlov, Homepage: https://www.7-zip.org/
4. 설치: winget install --id 7zip.7zip -e --source winget
5. 막힌 점: 관리자 승인 창이 떠서 [예] 클릭
6. 점검표: winget, Git ✅
```

## 피드백 포인트
- 3번(진짜 프로그램인지 확인)을 했는지가 가장 중요합니다. 이름이 비슷한 다른 프로그램을 설치하는 실수를 막는 습관입니다.
- 패키지 관리자에 없는 프로그램도 있습니다(국내 업무용 프로그램 등). 그럴 때는 원래대로 공식 사이트에서 설치하면 된다고 안내하세요.
