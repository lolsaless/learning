# S05 해답 및 강사용 참고

## 연습 미션 해설
1. `Ctrl/Command + D`는 **같은 글자**를 차례로 선택합니다. `values`를 바꾸면 `len(values)` 안의 것까지 함께 바뀌므로 정상 동작합니다. 다만 주석이나 문자열 안의 같은 글자까지 선택될 수 있어 주의가 필요합니다.
2. `F2`(기호 이름 바꾸기)는 Pylance가 **파이썬 변수로서의 `values`만** 찾아 바꿉니다. 주석 안의 글자는 건드리지 않습니다. → 변수 이름을 바꿀 때는 **F2가 더 안전**합니다.
3. 주석 처리하면 해당 `print`가 실행되지 않아 출력 줄이 줄어듭니다.
4. `limit = 1000`을 맨 위로 올려도 `average` 계산보다 위에 있으므로 결과는 같습니다. 반대로 **사용하는 곳보다 아래로** 옮기면 `NameError`가 납니다. → 파이썬은 **위에서 아래로** 실행된다는 것을 확인하는 좋은 실험입니다.

## 설정 JSON 관련 자주 나는 문제
| 증상 | 원인·해결 |
|---|---|
| 붙여 넣었더니 빨간 밑줄 | 앞 줄 끝에 **쉼표(,)** 가 빠졌거나, 마지막 항목 뒤에 쉼표가 남음 |
| 설정이 두 번 있다고 경고 | 같은 이름의 설정이 이미 있음 → 하나만 남기기 |
| `//` 주석에 빨간 줄 | VS Code 설정 파일은 주석을 허용합니다. 오른쪽 아래 언어가 **"JSON with Comments"** 인지 확인 |
