## 목표
- 자주 쓰는 **단축키**로 작업 속도를 높인다.
- **설정 동기화**로 여러 PC(Mac·Windows)의 VS Code를 똑같이 맞춘다.
- 이 과정에 유용한 **확장**과 **설정**을 적용한다.

## 1. 꼭 쓰는 단축키 (20분)

> Mac은 `Ctrl` 대신 대부분 `Command`. 단, 터미널 열기는 Mac도 `Ctrl + `` ` ``

| 하는 일 | Windows | Mac | 연습 ✔ |
|---|---|---|---|
| 명령 팔레트 (모든 기능 검색) | `Ctrl + Shift + P` | `Command + Shift + P` | |
| 파일 이름으로 빨리 열기 | `Ctrl + P` | `Command + P` | |
| 터미널 열기·닫기 | `Ctrl + `` ` `` | `Ctrl + `` ` `` | |
| 사이드바 숨기기·보이기 | `Ctrl + B` | `Command + B` | |
| 줄 주석 켜기·끄기 | `Ctrl + /` | `Command + /` | |
| 줄 위·아래로 옮기기 | `Alt + ↑/↓` | `Option + ↑/↓` | |
| 줄 복제 | `Shift + Alt + ↓` | `Shift + Option + ↓` | |
| 같은 단어 함께 선택 | `Ctrl + D` (여러 번) | `Command + D` | |
| 여러 곳에 커서 | `Alt + 클릭` | `Option + 클릭` | |
| 폴더 전체에서 찾기 | `Ctrl + Shift + F` | `Command + Shift + F` | |
| 이름 한꺼번에 바꾸기 (파이썬 변수) | `F2` | `F2` | |
| 정의로 이동 | `F12` | `F12` | |
| 확대·축소 | `Ctrl + = / -` | `Command + = / -` | |

### 연습 미션
`ai-black/01_practice/first_program.py`를 열고:
1. `Ctrl/Command + D`로 `values`를 모두 선택해 `co2_values`로 한꺼번에 바꾸기 → 실행해서 정상 동작 확인
2. 원래대로 되돌리기: 변수 이름 위에서 `F2` → `values` 입력 → Enter (F2는 **진짜 그 변수만** 골라서 바꿈)
3. `print` 줄 3개를 선택하고 `Ctrl/Command + /`로 주석 처리 → 실행 → 다시 주석 해제
4. `limit = 1000` 줄을 `Alt/Option + ↑`로 맨 위로 옮기기

> 💡 단축키 목록 전체: 명령 팔레트 → **"기본 설정: 바로 가기 키 열기"**. 또는 AI에게 "VS Code에서 [하고 싶은 일] 단축키 알려 줘 (Mac)".

## 2. 설정 동기화 — 여러 PC를 똑같이 (15분)

Mac mini, MacBook, Windows를 번갈아 쓴다면, 확장·설정·단축키를 **GitHub 계정으로 동기화**할 수 있습니다.

1. VS Code 왼쪽 아래 **사람 모양(계정) 아이콘** → **[백업 및 동기화 설정...]** (Backup and Sync Settings)
2. 동기화할 항목 확인 (설정, 바로 가기 키, 확장, UI 상태 등) → **[로그인]**
3. **[GitHub로 로그인]** → 브라우저에서 승인
4. 다른 PC의 VS Code에서도 같은 GitHub 계정으로 1~3 반복 → 설정·확장이 자동으로 맞춰짐

> ⚠️ **확장은 PC마다 다시 설치되지만, 가상환경(.venv)이나 파이썬은 동기화되지 않습니다.** (11회: PC마다 `requirements.txt`로 만들기)

## 4. 추천 설정 적용 (10분)

1. 명령 팔레트 → **"기본 설정: 사용자 설정 열기(JSON)"** (Preferences: Open User Settings (JSON))
2. `vscode_settings_예시.json`을 열어 원하는 줄을 복사해 `{ }` 안에 붙여 넣기
3. 저장 → 바로 적용

| 설정 | 효과 |
|---|---|
| `files.autoSave` | 다른 창을 클릭하면 자동 저장 |
| `files.exclude` | 탐색기에서 `.DS_Store`, `__pycache__` 등을 숨김 (파일을 지우는 것은 아님) |
| `python.terminal.activateEnvironment` | 터미널을 열면 `.venv` 자동으로 켜기 |
| `notebook.lineNumbers` | 노트북 셀에 줄 번호 |

> 💡 JSON 파일이 어렵다면 **[설정] 화면(`Ctrl/Command + ,`)** 에서 검색해 체크박스로 바꿔도 됩니다. 예: 검색창에 `auto save`
