## 강사 운영 팁
- **설치 전에 기관 PC 정책을 확인하세요.** WSL은 가상화 기능이 필요하고, 보안 정책으로 막혀 있는 경우가 많습니다. 개인 노트북에서 하는 것을 권장합니다.
- 재부팅이 필요하므로 **수업 시작 직후** `wsl --install`을 실행하고, 재부팅을 기다리는 동안 설명을 진행하세요.
- 수강생이 Windows 파이썬(`py -3.13`)과 WSL 파이썬(`python3.13`)을 섞어 쓰면 혼란스러워합니다. "**VS Code 왼쪽 아래에 `WSL: Ubuntu`가 보이면 리눅스 세계, 안 보이면 Windows 세계**"로 구분하게 하세요.

## Mac 명령과의 대응

| 하는 일 | Mac (zsh) | WSL Ubuntu (bash) | Windows (PowerShell) |
|---|---|---|---|
| 설정 파일 | `~/.zprofile` | `~/.bashrc` | — |
| 패키지 설치 | `brew install` | `brew install` (또는 `sudo apt install`) | `winget install` |
| 파이썬 | `python3.13` | `python3.13` | `py -3.13` |
| 가상환경 켜기 | `source .venv/bin/activate` | `source .venv/bin/activate` | `.venv\Scripts\Activate.ps1` |
| 탐색기 열기 | `open .` | `explorer.exe .` | `explorer .` |
