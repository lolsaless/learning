## 2. 파이썬이란? (10분)

### 파이썬 = 컴퓨터에게 일을 시키는 언어
- 영어 문장과 비슷하게 읽혀서 **배우기 쉽습니다.**
- **데이터 분석, 엑셀 자동화, 웹 수집, 그래프**에 필요한 도구(라이브러리)가 아주 많습니다.
- AI가 **가장 잘 쓰는 언어** 중 하나입니다. AI에게 코드를 부탁하면 파이썬으로 주는 경우가 많습니다.

```python
values = [612, 845, 1020]
print(sum(values) / len(values))   # 평균 출력
```
→ 영어를 몰라도 "값들의 합을 개수로 나눠서 출력한다"는 느낌이 옵니다.

### 왜 R 대신 파이썬?
이 저장소에는 R 코드도 많지만, 이 과정은 **파이썬 하나로 통일**합니다.
- 데이터 분석뿐 아니라 **업무 프로그램·웹앱·자동화**까지 한 언어로 할 수 있습니다.
- 기존 R 코드는 4~5단계에서 **파이썬으로 바꿔서** 실습합니다. (`00_커리큘럼/03_R_파이썬_변환_대응표.md`)

### 왜 3.13 버전인가?
- 파이썬은 매년 새 버전이 나옵니다(3.12 → 3.13 → 3.14 → …).
- **막 나온 새 버전은 일부 라이브러리가 아직 지원하지 않을 수 있습니다.**
- 이 과정은 라이브러리 지원이 충분한 **3.13**으로 통일합니다. **수강생·강사·여러 PC가 같은 버전**이면 "내 PC에서는 되는데…" 문제가 줄어듭니다.
- 그래서 명령에 버전을 붙여 씁니다: Mac `python3.13`, Windows `py -3.13`

## 3. 설치 (25분)

### 3-1. Mac — Homebrew로 설치

```bash
brew install python@3.13
```

확인:
```bash
python3.13 --version        # Python 3.13.x
which python3.13            # /opt/homebrew/bin/python3.13 (Intel: /usr/local/bin/python3.13)
```

> 💡 **`python3`만 치면?** Mac에는 Apple이 넣어 둔 `python3`나 Homebrew의 다른 버전이 있을 수 있어, 버전이 다르게 나올 수 있습니다. 그래서 이 과정에서는 **`python3.13`** 을 씁니다. 11회에서 가상환경을 만든 뒤에는 그냥 `python`이라고 써도 됩니다.

### 3-2. Windows — python.org 설치 파일 (권장)

설치 화면의 **체크박스 하나**가 중요해서, 화면을 보며 설치하는 방법을 권장합니다.

1. `https://www.python.org/downloads/windows/` 접속
2. **Python 3.13.x** 중 가장 높은 번호의 **"Windows installer (64-bit)"** 내려받기
3. 설치 파일 실행 → 첫 화면 아래쪽에서
   - ✅ **Use admin privileges when installing py.exe** (있으면 체크)
   - ✅ **Add python.exe to PATH** ← **반드시 체크!**
4. **[Install Now]** 클릭 → 완료 화면에 "Disable path length limit"이 보이면 클릭
5. **PowerShell을 새로 열고** 확인:
```powershell
py -3.13 --version      # Python 3.13.x
py --list               # 설치된 파이썬 목록 (-V:3.13 *)
python --version        # Python 3.13.x (PATH 체크를 했다면)
```

> 💡 **`py`는 무엇인가요?** Windows용 **파이썬 실행기(런처)** 입니다. 여러 버전이 설치되어 있어도 `py -3.13`처럼 원하는 버전을 골라 실행합니다. PATH 설정과 관계없이 동작해서 이 과정의 기본 명령으로 씁니다.

**다른 방법 (winget):**
```powershell
winget install --id Python.Python.3.13 -e --source winget
```
- 빠르지만 PATH 설정 여부를 고를 수 없습니다. 이 경우에도 `py -3.13`은 동작합니다.

### 3-3. Windows에서 `python`을 쳤더니 Microsoft Store가 열린다면
[설정] → [앱] → [고급 앱 설정] → **[앱 실행 별칭]** → `python.exe`, `python3.exe` 항목 **끄기** → PowerShell 새로 열기

## 4. 대화형 파이썬 (10분)

터미널에서 파이썬을 켜면 **한 줄씩 바로 실행**할 수 있습니다. 계산기처럼 써 봅니다.

```bash
python3.13      # Mac
py -3.13        # Windows
```
화면이 `>>>`로 바뀌면 성공입니다.

```python
>>> 1 + 2
3
>>> (612 + 845 + 1020) / 3
825.6666666666666
>>> print("안녕하세요")
안녕하세요
>>> exit()
```

- `>>>`는 "파이썬이 명령을 기다린다"는 표시입니다.
- 끝낼 때는 `exit()` (또는 Mac `Ctrl + D`, Windows `Ctrl + Z` → Enter)

## 5. 파이썬 파일 실행 (10분)

대화형은 연습용이고, 실제 프로그램은 **`.py` 파일**에 저장해 두고 실행합니다.

1. 이 회차 폴더의 `check_setup.py`, `first_program.py`를 07회에 만든 `ai-black/01_practice` 폴더로 **복사**합니다.
2. 터미널에서 그 폴더로 이동해 실행합니다.

```bash
cd ~/Documents/ai-black/01_practice
python3.13 check_setup.py        # Mac
py -3.13 check_setup.py          # Windows
```
→ 파이썬 버전, 위치, 라이브러리 상태가 표로 나옵니다. (라이브러리는 아직 ⬜ 미설치가 정상)

```bash
python3.13 first_program.py      # Mac
py -3.13 first_program.py        # Windows
```
→ CO2 평균과 판정이 나옵니다.

> 💬 **강사 멘트 예시:** "01회에 Colab에서 AI가 만든 코드를 실행했던 것 기억하시죠? 오늘은 그걸 **여러분의 PC에서** 했습니다. 이제 인터넷 없이도, 외부 서버에 데이터를 보내지 않고도 프로그램을 돌릴 수 있습니다."

## 강사용 참고

| 증상 | 해결 |
|---|---|
| (Mac) `python3.13: command not found` | `brew install python@3.13`이 끝났는지, `brew --prefix` 경로가 PATH에 있는지 확인 (`공통자료/자주_나는_오류_모음.md`) |
| (Windows) `py`도 인식 안 됨 | 설치 첫 화면에서 py launcher 설치를 끈 경우 → 설치 파일 다시 실행 → [Modify] → py launcher 체크 |
| (Windows) 이미 다른 버전(3.10 등)이 있음 | 지워도 되고 둬도 됩니다. `py -3.13`으로 3.13을 지정해 쓰면 됩니다 |
| 한글이 깨져서 출력됨 (Windows) | Windows Terminal/PowerShell 최신 버전에서는 대부분 정상. 깨지면 `chcp 65001` 입력 후 다시 실행 |
| 기관 PC 보안 프로그램이 python.exe 실행을 막음 | 정보화 담당자에게 예외 등록 요청 |
