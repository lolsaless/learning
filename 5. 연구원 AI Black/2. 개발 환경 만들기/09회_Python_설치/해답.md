## 과제 해답 (`solution_my_first_program.py`)

```
측정 지점 : 1층 사무실
측정 횟수 : 8 회
최댓값    : 720 ppm
최솟값    : 612 ppm
평균      : 684.1 ppm
판정      : 적합
기준 초과 횟수 : 0 회
```

### 도전 과제 — 추가 코드 예
```python
over_count = 0
for value in values:
    if value >= limit:
        over_count = over_count + 1
print("기준 초과 횟수 :", over_count, "회")
```
- AI는 `over_count = sum(1 for v in values if v >= limit)` 처럼 **한 줄**로 주기도 합니다. 둘 다 정답입니다. 한 줄짜리를 받은 수강생에게는 "이 한 줄을 풀어서 써 달라고 AI에게 다시 요청해 보세요"라고 안내하면 좋은 학습이 됩니다. (16회 반복문 예고)
- 측정값을 `1020, 1100` 등으로 바꿔 초과 횟수가 바뀌는지 **스스로 시험해 보게** 하세요.

## 자주 나는 과제 오류
| 오류 | 원인 | 해결 |
|---|---|---|
| `SyntaxError: invalid character '，'` | 한글 입력 상태에서 쉼표(，)를 입력 | 영문 쉼표 `,`로 |
| `SyntaxError: invalid syntax` (Mac) | 텍스트 편집기가 서식 있는 텍스트(.rtf)로 저장 | [포맷] → [일반 텍스트로 만들기] 후 다시 저장 |
| `IndentationError` | `if` 아래 줄의 들여쓰기(공백 4칸)가 어긋남 | 들여쓰기를 공백 4칸으로 맞추기 |
| `can't open file ... No such file or directory` | 터미널 위치(`pwd`)와 파일 위치가 다름 | `cd`로 파일이 있는 폴더로 이동 |

> 이런 오류들 때문에 다음 시간에 **VS Code**를 설치합니다. VS Code는 들여쓰기·괄호·따옴표를 자동으로 맞춰 주고, 잘못된 곳에 빨간 밑줄을 그어 줍니다.
