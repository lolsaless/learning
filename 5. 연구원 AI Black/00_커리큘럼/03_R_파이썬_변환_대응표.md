# R → 파이썬 변환 대응표

이 과정은 **파이썬만** 사용합니다. 기존에 직접 작성한 R 코드는 아래 표에 따라 파이썬 실습으로 바꿔서 사용합니다.

## 변환 원칙

1. **R 코드를 한 줄씩 그대로 옮기지 않습니다.** 하는 일(목적)을 살려서 초보자가 읽기 쉬운 파이썬 코드로 다시 씁니다.
2. **PC 고정 경로는 쓰지 않습니다.** `D:/github/...` 같은 `setwd()` 경로는 실습 폴더 기준 상대경로로 바꿉니다.
3. **실습 데이터는 가짜 데이터를 씁니다.** 열 구조는 원본과 같고, 업체명·담당자명은 가상의 값으로 바꿉니다.
4. **R 패키지는 아래 파이썬 라이브러리로 바꿉니다.**

| R | Python | 용도 |
|---|---|---|
| `tidyverse` (`dplyr`, `tidyr`) | `pandas` | 표 데이터 처리 |
| `readxl`, `writexl` | `pandas` + `openpyxl` | 엑셀 읽고 쓰기 |
| `ggplot2`, `ggpubr`, `ggrepel` | `matplotlib`, `seaborn` (+ `adjustText`) | 그래프 |
| `MASS::fitdistr`, `car::qqPlot`, `ks.test` | `scipy.stats` | 분포 추정·정규성 검정 |
| `lm`, `cor` | `scipy.stats`, `statsmodels` | 상관·회귀 |
| `factoextra`, `ggfortify` | `scikit-learn` | 주성분 분석·군집 |
| `forecast`, `xts` | `pandas`, `statsmodels` | 시계열 |
| `httr`, `rvest`, `jsonlite` | `requests`, `BeautifulSoup`, `pandas.read_html` | 웹 수집 |
| `RSelenium` | `selenium` | 브라우저 자동화 |
| `shiny` | `streamlit` | 웹앱 |
| `leaflet` | `folium` | 지도 |
| `magick` | `Pillow` | 이미지 처리 |
| R Markdown | Jupyter Notebook | 분석 보고서 |
