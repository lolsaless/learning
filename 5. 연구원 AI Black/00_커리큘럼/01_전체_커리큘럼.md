# 전체 커리큘럼 — AI를 활용한 문제 해결

## 1. 과정 목표

이 과정을 마친 연구원은 다음을 할 수 있습니다.

1. **문제 찾기** — 내 업무에서 반복되거나 시간이 많이 드는 일을 찾아 "자동화할 문제"로 정리한다.
2. **AI에게 일 시키기** — 원하는 결과가 나오도록 AI에게 질문(프롬프트)을 쓰고, AI의 답을 검증한다.
3. **코드 읽고 고치기** — AI가 만든 파이썬 코드를 읽고, 오류가 나면 원인을 찾아 고친다.
4. **데이터 다루기** — 엑셀·CSV 측정 데이터를 정리·분석하고 그래프와 통계로 보고한다.
5. **업무 도구 만들기** — 웹 수집, 문서 처리, 웹앱 등 동료가 쓸 수 있는 프로그램을 만든다.
6. **관리하기** — Git·GitHub로 코드를 저장·공유하고, 여러 PC에서 같은 환경으로 작업한다.

> **이 과정의 관점:** 문법을 외우는 것이 목표가 아닙니다.
> "AI가 코드를 써 주고, 사람은 **문제를 정의하고, 결과를 검증하고, 고치는 일**을 한다"는 방식으로 배웁니다.
> 그래서 모든 회차에 "AI에게 이렇게 물어보세요" 실습이 들어갑니다.

## 2. 운영 방식

### 수업 구성 (1회 60~70분 기준)

| 순서 | 시간 | 내용 |
|---|---|---|
| ① 복습·과제 확인 | 10분 | 지난 과제 함께 보기, 막힌 부분 해결 |
| ② 개념 설명 | 15~20분 | 오늘 배울 내용을 업무 예시로 설명 |
| ③ 따라 하기 실습 | 20~25분 | 강사와 함께 `실습.ipynb` 실행 |
| ④ AI와 함께 풀기 | 10분 | 같은 문제를 AI에게 시켜 보고 결과 비교·검증 |
| ⑤ 정리·과제 안내 | 5분 | 오늘의 핵심 3줄 정리, 과제 안내 |

### 정규 수업과 보충 실습

- **정규 수업(52회):** 주 2회. 이것만으로 과정이 완성되도록 구성했습니다.
- **보충 실습(26회):** 주마다 1개씩 있습니다. 주 3회 수업하는 주에 사용하거나, 진도가 빠른 수강생의 추가 과제로 씁니다.
  보충 실습을 건너뛰어도 다음 정규 수업을 듣는 데 문제가 없습니다.

### 수강생 PC 환경

강사와 수강생이 Mac(Apple Silicon·Intel)과 Windows를 섞어 쓰는 상황을 기준으로 합니다.
설치·설정이 운영체제마다 다른 부분은 **Mac / Windows를 나눠서** 설명합니다.

| 항목 | Mac | Windows |
|---|---|---|
| 패키지 관리자 | Homebrew | winget (기본) / WSL2 + Homebrew (보충 S04) |
| 터미널 | 터미널(zsh) | PowerShell |
| Python 설치 | `brew install python` | `winget install Python.Python.3.13` 또는 python.org 설치 파일 |

> Python 버전은 수업 시작 시점의 안정 버전(3.12 이상)을 사용합니다.

### 평가 방식 (부담 없는 점검용)

| 항목 | 비중 | 내용 |
|---|---|---|
| 회차 과제 | 40% | 매 회차 짧은 과제 제출 (GitHub에 올리기 — 2단계 이후) |
| 단계 미니 프로젝트 | 30% | 3·4·5·6단계 끝에 작은 프로젝트 |
| 종합 프로젝트 | 30% | 내 업무 문제를 해결하는 프로그램 + 발표 |

## 3. 단계별 학습 목표

### 1단계. AI와 친해지기 (1~3주, 1~6회)
- AI 채팅 도구(ChatGPT, Claude, Gemini)의 차이와 쓰임새를 안다.
- **좋은 프롬프트의 5요소**(역할·맥락·할 일·형식·제약)로 질문을 쓴다.
- 내 업무 목록에서 자동화 후보를 고르고 "문제 정의서"를 쓴다.
- AI 답변의 오류(환각)를 확인하는 습관과 **기관 자료·개인정보를 AI에 넣지 않는 원칙**을 익힌다.
- 활용 자료: `0. 업무자동화 강의/AI 활용, 업무 속 문제 찾기.pdf`, `5. Excel` 성적서 매크로

### 2단계. 개발 환경 만들기 (4~6주, 7~12회)
- 파일·폴더·경로·확장자의 개념을 이해하고 터미널을 열어 기본 명령을 쓴다.
- Mac은 Homebrew, Windows는 winget으로 프로그램을 설치한다.
- Python과 VS Code를 설치하고 `.py`와 `.ipynb`를 실행한다.
- 가상환경(venv)과 `requirements.txt`로 프로젝트마다 환경을 분리한다.
- Git·GitHub로 코드를 저장(commit)하고 올린다(push). 여러 PC에서 같은 저장소를 쓴다.
- 활용 자료: `3. Python/1. brew setup` 가이드 5종

### 3단계. 파이썬 기초 (7~11주, 13~22회)
- 변수·자료형·리스트·딕셔너리·조건문·반복문·함수를 **측정값 판정 예제**로 익힌다.
- 문자열 처리로 시료명·접수번호를 다룬다.
- 파일과 폴더를 코드로 다루고, 오류 메시지를 읽어 AI와 함께 해결한다.
- 미니 프로젝트: **헬륨 봄베 사용시간 계산기**를 직접 다시 만든다.
- 활용 자료: R 코드 연습(`for구문`, `몬테카를로`, `XML`), `2. 수질환경/5. 헬륨 봄베 사용시간 계산기`

### 4단계. 데이터 다루기 (12~15주, 23~30회)
- pandas로 엑셀·CSV를 읽고, 고르고, 거르고, 요약한다.
- 여러 표를 합치고(merge), 모양을 바꾼다(melt/pivot).
- 결측치·중복·형식 오류를 정리하고, 이름 마스킹·시료명 재부여 같은 정제 작업을 한다.
- 미니 프로젝트: **실내공기질 분기 실적보고 자동화**
- 활용 자료: `실내공기 분기 보고서.R`, `출장기록 데이터 처리.R`, `시료 이름 정제.R`, `1. 실내공기질/1. 분기별 실적보고`, `0. 업무자동화 강의/1. 정보공개청구`

### 5단계. 시각화와 통계 (16~19주, 31~38회)
- matplotlib·seaborn으로 막대·선·산점도·상자그림·히스토그램을 그린다 (한글 폰트 포함).
- IQR로 이상치를 찾고, 로그 변환과 정규성 검정을 한다.
- 상관·회귀, t-검정·분산분석·비모수 검정을 실행하고 결과를 해석한다.
- 미니 프로젝트: **2023 연구사업 데이터 분석 리포트**를 주피터 노트북으로 작성
- 활용 자료: 2023 연구사업 R 코드(중금속, 양이온, 정규성, 페놀 회귀), 환경통계 교재 데이터(Ch04~18)

### 6단계. 업무 프로그램 만들기 (20~23주, 39~46회)
- 웹 페이지와 공공 API에서 데이터를 수집한다 (requests, Selenium). 수집 시 지켜야 할 규칙을 안다.
- PDF·OCR로 문서에서 데이터를 꺼내고, 엑셀·워드 문서를 자동으로 만든다.
- Streamlit으로 웹앱과 대시보드를 만들고, 실행파일·단일 HTML로 배포한다.
- 미니 프로젝트: **기존 업무 도구 하나를 골라 개선판 만들기**
- 활용 자료: 웹 크롤링 R 코드 4종, `2. 수질환경`의 OCR·장비대장·공문 추출기·한탄강 대시보드, `1. 실내공기질/2. 출장지 관리 지도`

### 7단계. 심화·종합 프로젝트 (24~26주, 47~52회)
- Claude Code·Codex 같은 **AI 코딩 도구에게 작업 지시서를 써서** 프로그램을 만든다.
- 프로젝트 폴더 구조·README·테스트·버전 관리 등 "남이 쓸 수 있는 코드" 습관을 익힌다.
- 내 업무 문제로 종합 프로젝트를 기획·개발·발표한다.
- 활용 자료: `0.prompt_*.md` 지시서 사례, 공문 추출기 v1.0→v2.2 개선 이력, GCMS AutoTune Viewer(테스트 포함)
