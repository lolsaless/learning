## 문제 1
- 피드백 기준: 기준 문장의 "이상/초과/미만/이하"가 `>=`, `>`, `<`, `<=`로 **정확히** 옮겨졌는지, 경계값으로 확인했는지.

## 문제 2
```python
recovery = 125
if 80 <= recovery <= 120:
    result = "적합"
elif 70 <= recovery < 80 or 120 < recovery <= 130:
    result = "주의 - 재확인"
else:
    result = "부적합 - 재분석"
print(recovery, "→", result)
```

| recovery | 결과 |
|---|---|
| 65 | 부적합 - 재분석 |
| 75 | 주의 - 재확인 |
| 80 | 적합 |
| 100 | 적합 |
| 120 | 적합 |
| 125 | 주의 - 재확인 |
| 140 | 부적합 - 재분석 |

## 문제 3
```python
lod = 0.05
value = 0.372
if value < lod:
    text = "불검출(<LOD)"
else:
    text = f"{value:.2f}"
print(text)
```
| value | 결과 |
|---|---|
| 0.03 | 불검출(<LOD) |
| 0.05 | 0.05 (같으면 검출로 처리 — 기준 문구에 따라 다를 수 있음) |
| 0.372 | 0.37 |

## 문제 4
- **원인:** `elif pm10 > 30:`이 200에서도 참이라, 아래 조건까지 가지 않고 `"보통"`에서 멈춤. elif는 **처음 참인 곳 하나만** 실행.
- **고친 코드** (작은 값부터 위쪽 경계로):
```python
pm10 = 200
if pm10 <= 30:
    grade = "좋음"
elif pm10 <= 80:
    grade = "보통"
elif pm10 <= 150:
    grade = "나쁨"
else:
    grade = "매우나쁨"
print(grade)     # 매우나쁨
```
- 또는 큰 값부터 (`if pm10 > 150` → `elif pm10 > 80` → …) 써도 정답.
