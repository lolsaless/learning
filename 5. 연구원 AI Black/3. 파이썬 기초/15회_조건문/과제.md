## 문제 1. 내 업무의 판정 기준
내 업무에서 쓰는 판정 기준 하나를 골라 마크다운 셀에 **문장 그대로** 적고, 그 기준을 조건문으로 옮기세요.
- 예: "CO2 1,000 ppm **이상**이면 부적합", "회수율 80~120 % **범위 밖**이면 재분석"
- 경계값(정확히 기준값일 때)으로도 실행해 결과가 문장과 맞는지 확인하세요.

## 문제 2. 회수율 판정 (QC)
첨가 회수율 `recovery`(%)를 판정하세요. (수업용 예시 기준)
- 80 이상 120 이하 → `"적합"`
- 70 이상 80 미만, 또는 120 초과 130 이하 → `"주의 - 재확인"`
- 그 외 → `"부적합 - 재분석"`

`recovery`를 65, 75, 80, 100, 120, 125, 140으로 바꿔 결과를 표로 정리하세요.

## 문제 3. 검출한계 처리
`value`(측정값)와 `lod`(검출한계)가 있을 때
- `value < lod` 이면 `"불검출(<LOD)"`
- 아니면 측정값을 소수 2자리 문자열로 (예: `"0.37"`)

`lod = 0.05`, `value` = 0.03, 0.05, 0.372 로 확인하세요.

## 문제 4. 순서가 틀린 코드 고치기
아래 코드는 PM10이 200이어도 `"보통"`이 나옵니다. 왜 그런지 마크다운 셀에 설명하고 고치세요.
```python
pm10 = 200
if pm10 <= 30:
    grade = "좋음"
elif pm10 > 30:
    grade = "보통"
elif pm10 > 80:
    grade = "나쁨"
elif pm10 > 150:
    grade = "매우나쁨"
print(grade)
```
