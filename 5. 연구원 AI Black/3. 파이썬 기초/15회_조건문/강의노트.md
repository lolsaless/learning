## 오늘의 목표
1. `if` · `elif` · `else`로 조건에 따라 다른 일을 하게 한다.
2. `and` · `or` · `not`으로 조건을 조합한다.
3. **들여쓰기**가 문법의 일부라는 것을 안다.
4. 측정값 **판정기**와 **등급 분류기**를 만든다.

## 꼭 짚어 줄 것

| 개념 | 설명 포인트 |
|---|---|
| 들여쓰기 | 파이썬은 들여쓰기로 "어디까지가 if의 덩어리인지" 판단. VS Code는 `:` 뒤 Enter 시 자동 들여쓰기 |
| 경계값 | `>=`(이상)와 `>`(초과)를 **업무 기준 문구에 맞게**. "기준 초과"인지 "기준 이상"인지 원문 확인 |
| elif 순서 | 넓은 조건을 먼저 쓰면 아래 조건은 영영 실행 안 됨 (예: `<= 150`을 맨 위에) |
| 유효성 검사 먼저 | 측정 오류(음수, 범위 밖)를 **판정보다 먼저** 걸러야 엉뚱한 "적합"이 안 나옴 |
| 한 줄 if | `result = "부적합" if v >= limit else "적합"` — 16회에서 다시 등장 |

> 💬 **강사 멘트 예시:** "판정 기준을 코드로 옮길 때 가장 중요한 건 문법이 아니라 **기준 문구를 정확히 읽는 것**입니다. '이상'과 '초과' 하나 차이로 결과가 바뀝니다. AI도 이걸 자주 틀립니다."

> ⚠️ 노트북의 기준값·등급 구간은 **수업용 예시**입니다.

## 자주 나는 오류 (오늘)

| 오류 | 원인 | 해결 |
|---|---|---|
| `SyntaxError: expected ':'` | `if co2 >= limit` 뒤 콜론 누락 | `:` 추가 |
| `IndentationError: expected an indented block` | if 다음 줄 들여쓰기 없음 | 공백 4칸 |
| `IndentationError: unindent does not match` | 들여쓰기 칸 수가 섞임 (3칸, 4칸) | VS Code에서 줄 전체 선택 후 `Shift+Tab` → `Tab`으로 다시 맞추기 |
| `SyntaxError: invalid syntax` (`if co2 = 1000`) | `=`(담기)를 비교에 씀 | `==` |
