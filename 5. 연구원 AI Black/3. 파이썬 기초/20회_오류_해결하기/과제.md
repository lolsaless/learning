## 문제 2. 견고한 변환 함수
측정 기록의 값을 숫자로 바꾸는 함수 `to_number(text)`를 만드세요.
- 앞뒤 공백 제거 후 `float`으로 변환해 돌려주기
- 쉼표가 들어간 숫자 `"1,020"` → `1020.0`
- 변환할 수 없으면(`"N/A"`, `""`, `"-"`, `"불검출"`) **`None`** 돌려주기 (`try/except`)
- 아래로 확인:
```python
tests = [" 612 ", "1,020", "45.2", "N/A", "", "-", "불검출", "9OO"]
for t in tests:
    print(repr(t), "→", to_number(t))
```
