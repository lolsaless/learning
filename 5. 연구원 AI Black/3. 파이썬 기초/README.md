# 3단계. 파이썬 기초 (7~11주, 13~22회)

> AI가 만든 코드를 **읽고, 검증하고, 고칠 수 있을 만큼** 파이썬 문법을 익힙니다.
> 모든 예제는 측정값·시료·기준 판정·출장기록 같은 **업무 상황**(가상 데이터)입니다.

## 수업 방식 — 노트북 하나로 한 회차

| 파일 | 누가 | 내용 |
|---|---|---|
| `강의노트.md` | 강사 | 목표, 시간 계획, 꼭 짚을 것, 자주 나는 오류 |
| `실습.ipynb` | 수강생 | 설명 → 예제 → 🧪 연습(빈 칸 `# ✍️ 여기에 코드를 작성하세요`) |
| `해답.ipynb` | 강사 | 같은 노트북에 답이 채워진 것. **모두 끝까지 실행해 확인함** |
| `과제.md` / `해답.md` | 수강생 / 강사 | 과제와 해답 (해답 코드는 실행해 확인함) |
| `solution_*.py` | 강사 | 과제 해답 프로그램 (19·22회) |

수강생은 `실습.ipynb`를 `ai-black/01_practice/weekNN/`으로 복사해서 씁니다. 커널은 `.venv`.

## 3단계의 흐름

```
13 값 → 14 여러 값 → 15 판정 → 16 일괄 판정 → 17 함수로 묶기
      → 18 지저분한 글자 정리 → 19 파일 수백 개 → 20 오류 고치기 → 21 날짜
      → 22 모두 합쳐 업무 도구 완성 (헬륨 계산기)
```

- 04회 **문제 정의서**의 사례(이름·코드 분리, 출장기간 분리, 항목명 통일)를 18회에서 실제 코드로 해결합니다.
- 05회 엑셀 매크로로 했던 CO2 요약을 19회에서 파이썬으로, 폴더 단위로 합니다.
- 22회에서 원본 `helium_calc.py`를 **읽을 수 있게** 되는 것이 3단계의 목표 점검입니다.
