# 19회 과제 — 측정 폴더 자동 요약 프로그램

> **제출:** `02_homework/week10/summarize_folder.py` (+ 실행 결과 CSV) → commit → push
> **예상 소요 시간:** 40분

이번 과제는 노트북이 아니라 **`.py` 파일**로 만듭니다. 노트북에서 만든 코드를 "프로그램"으로 옮기는 연습입니다.

## 요구 사항
`summarize_folder.py`를 실행하면:
1. 같은 폴더의 `data/` 안 모든 `.csv` 파일을 읽고
2. 파일마다 CO2 **측정 수, 평균, 최대, 최소, 판정**과 함께 **Temp_C 평균**, **RH 평균**도 계산해서
3. `output/CO2_요약.csv` (엑셀에서 한글이 깨지지 않게)로 저장하고
4. 화면에 `4개 파일 요약 완료 (부적합 2곳)` 처럼 한 줄 보고를 출력합니다.

## 조건
- 함수를 2개 이상 쓰세요. (예: `read_rows(path)`, `summarize(rows)`)
- 파일 맨 위에 docstring으로 **프로그램 설명과 실행 방법**을 적으세요.
- 실행: 터미널에서 `python summarize_folder.py` (가상환경 켠 상태)

## 도전 (선택)
- `data` 폴더에 내 가상 측정 파일을 하나 더 만들어 넣고 다시 실행 → 결과에 자동으로 추가되는지 확인
- 경로를 코드 안에 고정하지 말고, **`.py` 파일이 있는 폴더 기준**으로 찾게 하기
  (힌트: `Path(__file__).parent` — AI에게 `__file__`이 무엇인지 물어보세요)

> 💡 노트북에서 `Path.cwd()`는 노트북 폴더였지만, `.py`를 터미널에서 실행하면 `Path.cwd()`는 **터미널의 현재 위치**입니다. 다른 폴더에서 실행해도 동작하게 하려면 `Path(__file__).parent`를 씁니다.
