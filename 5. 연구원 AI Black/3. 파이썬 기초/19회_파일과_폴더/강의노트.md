# 19회. 파일과 폴더 — 측정 파일 여러 개를 코드로

| 항목 | 내용 |
|---|---|
| 단계 | 3단계. 파이썬 기초 |
| 주차 | 10주차 첫 수업 |
| 시간 | 70분 |
| 수업 파일 | `실습.ipynb`(수강생), `해답.ipynb`(강사), `data/`(가상 측정 CSV 4개 + 메모), `과제.md`, `해답.md` |
| 준비 | 노트북과 **`data` 폴더를 함께** `ai-black/01_practice/week10/`으로 복사 |

## 오늘의 목표
1. `pathlib`로 경로를 만들고 폴더 안 파일 목록을 얻는다.
2. 텍스트 파일을 읽고 쓴다 (`encoding="utf-8"`).
3. `csv` 모듈로 CSV를 읽고 파일마다 요약한다.
4. 요약 결과를 엑셀에서 열리는 CSV(`utf-8-sig`)로 저장한다.
5. 파일을 규칙에 맞는 이름으로 복사한다.

## 꼭 짚어 줄 것

| 개념 | 설명 포인트 |
|---|---|
| 지금 위치(`Path.cwd()`) | 노트북은 **노트북 파일이 있는 폴더**에서 실행됨. `data` 폴더를 함께 복사해야 하는 이유 |
| `"w"` 덮어쓰기 | 원본 파일 이름으로 `"w"`를 열면 **원본이 지워짐**. 결과는 항상 `output` 같은 별도 폴더에 |
| CSV 값은 문자열 | `"723" > "1000"` 은 **True** (글자 비교!). 반드시 숫자로 바꾼 뒤 비교 |
| `utf-8-sig` | 엑셀 더블클릭으로 한글이 깨지지 않게 하는 저장 방식. 4단계 `to_csv`에서도 그대로 사용 |
| 4단계 예고 | 오늘 30줄로 한 일을 pandas는 몇 줄로 함. 하지만 **안에서 일어나는 일**을 알면 오류를 고칠 수 있음 |

> 💬 **강사 멘트 예시:** "측정 파일이 4개든 400개든, 오늘 만든 코드는 그대로 동작합니다. 바로 이 지점이 **엑셀 수작업에서 자동화로 넘어가는 순간**입니다."

## 자주 나는 오류 (오늘)

| 오류 | 원인 | 해결 |
|---|---|---|
| `FileNotFoundError: ... data/...` | 노트북만 복사하고 `data` 폴더를 빠뜨림, 또는 다른 위치에서 실행 | `Path.cwd()` 출력해서 위치 확인 |
| `UnicodeDecodeError: 'utf-8' codec can't decode` | 엑셀에서 "CSV(쉼표로 분리)"로 저장한 파일은 `cp949`일 수 있음 | `encoding="cp949"` 로 읽기 (4단계에서 자세히) |
| `KeyError: 'CO2_ppm'` | 열 이름이 다름 (공백, 대소문자, BOM) | `print(rows[0].keys())`로 실제 열 이름 확인 |
| 엑셀에서 한글 깨짐 | `utf-8`로 저장 | `utf-8-sig`로 저장 |
