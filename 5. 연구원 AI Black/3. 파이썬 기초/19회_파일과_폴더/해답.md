## 해답 코드의 포인트 (수업에서 설명)

| 코드 | 설명 |
|---|---|
| `BASE_DIR = Path(__file__).parent` | `__file__`은 **지금 실행 중인 .py 파일의 경로**. 그 부모 폴더를 기준으로 `data`를 찾으므로 터미널 위치와 관계없이 동작 |
| `path.stem.split("_", 1)` | 밑줄이 여러 개여도 **첫 번째에서만** 나눔 → 장소 이름에 `_`가 있어도 안전 |
| `def main():` + `if __name__ == "__main__":` | "직접 실행했을 때만 main을 실행"하는 파이썬 관례. AI가 만든 프로그램에 거의 항상 있음 |
| 상수 대문자 (`CO2_LIMIT`) | 바뀔 수 있는 설정값을 맨 위에 모아 두면 고치기 쉬움 |

## 피드백 포인트
- 함수를 나눴는지, docstring에 실행 방법이 있는지
- `Temp_C`, `RH`를 `float()`으로 바꿨는지 (`int("21.4")`는 오류)
- 결과 CSV를 **엑셀로 열어 한글이 보이는지** 직접 확인했는지
