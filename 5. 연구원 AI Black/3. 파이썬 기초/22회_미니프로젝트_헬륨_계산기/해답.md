## 실행 예 1 — 기본값 + 유량 50
```
헬륨 봄베 사용 가능 시간 계산기 (Enter = 기본값)
압력 단위 psi/bar/mpa/kpa/atm [psi]:
봄베 용적(L) [47.0]:
현재 게이지압(psi) [600.0]:
출구 압력(psi) [80.0]:
교체 여유압(psi) [0.0]:
장비별 유량(mL/min)을 입력하세요. 빈 줄이면 입력을 마칩니다.
  유량 1: 50
  유량 2:

===== 결과 =====
총 유량          : 50 mL/min
사용 가능 가스량 : 1663.0 L (1 atm 환산)
사용 가능 시간   : 23일 2시간 21분 (23.10 일)
압력 유지 종료   : (실행 시각 + 23일 2시간 21분) 경
[주 단위 예상 게이지압]
  + 0주     600.0 psi
  + 1주     442.4 psi
  + 2주     284.8 psi
  + 3주     127.2 psi
```

사용 가능 가스량 : 1600.3 L (1 atm 환산)

## 해답 코드의 포인트

| 코드 | 설명 |
|---|---|
| `ask_number(prompt, default)` | 빈 입력 → 기본값, 숫자 아님 → **다시 묻기** (`while True` + `try/except` + `return`) |
| `ask_flows()` | 빈 줄이 나올 때까지 반복, 최소 1개 확인 |
| `input(...).strip().lower() or "psi"` | 빈 문자열은 거짓이므로 `or` 뒤의 기본값이 쓰임 (21회 "빈 문자열은 거짓") |
| `while week * 10080 <= total_minutes` | 1주 = 10080분. 숫자에 주석을 달아 두면 읽기 쉬움 |

## 피드백 포인트
- 검증 값 두 개가 **정확히** 일치하는지
- 잘못된 입력에서 프로그램이 **멈추지 않는지**
- 함수마다 docstring이 있는지, `main()` 구조인지
- 도전 과제(argparse)를 했다면, AI 코드를 **설명할 수 있는지** 질문해 보세요
