# 22회 과제 — 헬륨 계산기를 프로그램(.py)으로

> **제출:** `03_my_project/helium/helium_mini.py` → commit → push
> **예상 소요 시간:** 60분

수업에서 노트북으로 만든 계산기를, 동료가 터미널에서 실행할 수 있는 **프로그램**으로 옮깁니다.

## 요구 사항
1. 실행하면 질문을 하나씩 하고 답을 받습니다. (`input()`)
   - 압력 단위, 봄베 용적, 현재 게이지압, 출구 압력, 교체 여유압
   - 장비별 유량: **빈 줄을 입력할 때까지** 여러 개 받아 합산 (최소 1개)
2. **Enter만 누르면 기본값**을 씁니다. (용적 47, 게이지압 600, 출구 80, 여유 0, 단위 psi)
3. 숫자가 아닌 값을 입력하면 **멈추지 말고 다시 묻습니다.** (20회 `try/except`)
4. 결과: 총 유량, 사용 가능 가스량, 사용 가능 시간, **지금 시각 기준** 종료 예상 시각, 주 단위 예상 압력
5. 파일 맨 위 docstring에 **설명과 실행 방법**, 함수마다 docstring
6. `def main():` + `if __name__ == "__main__": main()` 구조 (19회 해답 참고)
