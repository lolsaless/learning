## 오늘의 목표
3단계에서 배운 것을 모두 써서 **실제 업무 도구를 처음부터** 만든다. 그리고 원본 프로그램과 결과를 비교해 **검증**한다.

## 진행 방식 — "작은 함수 6개 → 조립 → 검증"

| 단계 | 만들 것 | 쓰는 문법 | 확인 값 |
|---|---|---|---|
| 0 | 문제 이해 (원본 README의 공식) | — | 47 L·600 psi·80 psi·50 mL/min → 1663.0 L, 23일 2시간 21분 |
| 1 | `to_psi(value, unit)` | 딕셔너리, `lower()`, `raise` | 5.5 bar → 79.77 psi |
| 2 | `usable_gas_l(...)` | 계산, `max(…, 0)` | 1663.0 L |
| 3 | `minutes_left(gas_l, flows)` | 리스트 합, 예외 | 33260분 |
| 4 | `fmt_duration(minutes)` | `divmod`, f-string | 23일 2시간 20분 (← 왜 21분이 아닌지 토론) |
| 5 | `end_time(start, minutes)` | `timedelta` | 2025-04-08 09:00 → 2025-05-01 11:20 |
| 6 | `weekly_table(...)` | `while`, 튜플 리스트 | 600.0 / 442.4 / 284.8 / 127.2 |
| 7 | `calculate(...)` 조립 + 출력 | 함수 조립 | |
| 8 | 원본과 비교 (입력 3가지) | 검증 | 아래 표 |

### 8단계 검증 표 (원본 `helium_calc.py`로 확인한 값)

| 입력 | 가스량 | 사용 가능 시간 |
|---|---|---|
| 47 L, 600 psi, 출구 80, [50] | 1663.0 L | 23일 2시간 21분 |
| 47 L, 500 psi, 출구 80, 여유 20, [30, 20] | 1279.3 L | 17일 18시간 25분 |

## 시간 계획

| 시간 | 내용 |
|---|---|
| 0~10분 | 21회 과제 확인, 원본 계산기(`helium_calc.html`) 브라우저로 열어 보여 주기 |
| 10~15분 | 0단계 — 공식과 확인 값. "**만들기 전에 정답을 먼저 정한다**" |
| 15~50분 | 1~6단계 — 수강생이 단계마다 직접 작성. 막히면 AI 사용 가능, 단 **확인 값이 나와야 통과** |
| 50~62분 | 7~8단계 — 조립, 원본과 비교 |

## 꼭 짚어 줄 것

| 포인트 | 설명 |
|---|---|
| 정답 먼저 | 코드를 쓰기 전에 **확인 값**을 정해 두는 습관 (20회 검산) |
| 4단계의 20분 vs 21분 | 반올림한 중간값(1663.0)으로 계산하면 1분 차이. **반올림은 마지막에 한 번만** — 실제 보고서 숫자에서도 중요 |
| 함수 분리의 장점 | 단계마다 확인할 수 있어 **어디서 틀렸는지** 바로 찾음. 한 덩어리로 짰다면? |
| 원본 읽기 | `argparse`(명령줄 옵션)만 빼면 모두 배운 문법. 수강생이 스스로 읽고 설명하게 하기 |
| 업무 지식 | 유량은 **봄베에서 나가는 모든 가스의 합**(컬럼+스플릿/퍼지+헤드스페이스)이어야 함 (원본 README). 코드보다 입력값이 정확해야 결과가 맞음 |
