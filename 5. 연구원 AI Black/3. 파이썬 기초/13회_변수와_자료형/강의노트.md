## 3단계를 시작하며 — 수업 방식

3단계(13~22회)는 **주피터 노트북 한 개로 수업 전체를 진행**합니다.

```
노트북 구성:  설명(마크다운) → 예제 코드(실행) → 🧪 연습(직접 작성) → … → 정리
```

| 파일 | 누가 | 내용 |
|---|---|---|
| `실습.ipynb` | 수강생 | 연습 칸이 `# ✍️ 여기에 코드를 작성하세요` 로 비어 있음 |
| `해답.ipynb` | 강사 | 같은 노트북에 예시 답안이 채워져 있음 (끝까지 실행 확인함) |

### 3단계의 원칙: "외우지 말고, 읽고 고칠 수 있게"
- 목표는 문법 암기가 아니라 **AI가 만든 코드를 읽고, 이상한 곳을 찾고, 고치는 것**입니다.
- 연습 문제가 막히면 **AI에게 물어봐도 됩니다.** 단, 받은 코드를 **한 줄씩 설명할 수 있을 때까지** 이해하고 넘어갑니다.
- 모든 예제는 **측정값·시료·기준 판정** 같은 업무 상황입니다.

## 오늘의 목표
1. 값을 **변수**에 담고 꺼내 쓴다.
2. 기본 **자료형** 4가지(`int`, `float`, `str`, `bool`)를 구분한다.
3. 계산 연산자, `round`, **형 변환**을 쓴다.
4. 측정값 **단위 환산**(ppm ↔ mg/㎥)을 코드로 한다.

## 꼭 짚어 줄 것

| 개념 | 설명 포인트 |
|---|---|
| `=` vs `==` | `=`는 담기, `==`는 같은지 묻기. 초보자 오류 1위 |
| `/` 결과 | 나누어떨어져도 `7 / 7 = 1.0` (실수). 정수 몫은 `//` |
| 숫자 문자열 | `"612" + "845"` = `'612845'`. **엑셀·CSV에서 읽은 값**에서 4단계 내내 만나는 문제 |
| f-string | `f"{average:.1f}"` → 소수 1자리. 결과 보고 문장을 만들 때 가장 많이 씀 |
| 단위 환산 | 공식은 **업무 지식**, 코드는 그 공식을 옮긴 것. "공식이 맞는지는 사람이 확인"을 강조 |

> 💬 **강사 멘트 예시:** "오늘 배운 변수·계산·f-string만으로도, 측정값 몇 개를 받아 평균을 내고 결과 문장을 만드는 일은 할 수 있습니다. 다음 시간에는 측정값이 **수십 개**일 때를 다룹니다."

## 자주 나는 오류 (오늘)

| 오류 | 원인 | 해결 |
|---|---|---|
| `NameError: name 'co2' is not defined` | 변수를 만든 셀을 실행하지 않음, 또는 오타 | 위 셀부터 다시 실행, 이름 확인 |
| `TypeError: can only concatenate str (not "int") to str` | `"CO2 " + 1036` 처럼 글자와 숫자를 `+` | `str(1036)` 또는 f-string |
| `SyntaxError: invalid syntax` (f-string) | 따옴표 앞 `f` 누락 또는 중괄호 짝 안 맞음 | `f"...{변수}..."` 모양 확인 |
| `ValueError: invalid literal for int()` | `int("45.2")` 처럼 소수 문자열을 정수로 | `float("45.2")` |
