
## 문제 2
```python
values_total = 35 + 41 + 38 + 52 + 47 + 44
average = values_total / 6
limit = 50
print("합계:", values_total)              # 257
print("평균:", round(average, 1))         # 42.8
print("기준 이상인가?", average >= limit)  # False
```

## 문제 4 (가)
```python
co2_ppm = 1500

```

## 문제 5
```python
count_1f = "5"
count_2f = 7
total = int(count_1f) + count_2f
print("총 측정 횟수: " + str(total) + "회")
# 또는
print(f"총 측정 횟수: {int(count_1f) + count_2f}회")
```
- 원인: 문자열 `"5"`와 정수 `7`을 `+`로 이을 수 없음 (`TypeError`). 계산은 숫자로, 출력은 문자열로.
