## 문제 1
```python
values = [612, 645, 701, 688, 720, 1012, 695, 1088, 710, 702]
print("횟수:", len(values))
print("평균:", round(sum(values) / len(values), 1))
print("최대:", max(values), "최소:", min(values))
print("큰 값 3개:", sorted(values, reverse=True)[:3])   # [1088, 1012, 720]
```

## 문제 3
```python
samples = [
    {"id": "S-01", "place": "1층 로비", "item": "PM2.5", "value": 23.4},
    {"id": "S-02", "place": "2층 사무실", "item": "CO2", "value": 845},
    {"id": "S-03", "place": "3층 회의실", "item": "CO2", "value": 1120},
]
print(samples[1]["place"])
last = samples[-1]
print(last["value"] >= limits[last["item"]])   # True
```
- `limits[last["item"]]`처럼 **꺼낸 값을 다시 키로 쓰는** 부분을 이해했는지 확인하세요. 4단계에서 자주 나오는 모양입니다.
