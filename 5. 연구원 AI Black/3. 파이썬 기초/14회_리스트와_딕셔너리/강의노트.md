# 14회. 리스트와 딕셔너리 — 여러 값을 한 번에

| 항목 | 내용 |
|---|---|
| 단계 | 3단계. 파이썬 기초 |
| 주차 | 7주차 두 번째 수업 |
| 시간 | 60~70분 |
| 수업 파일 | `실습.ipynb`(수강생), `해답.ipynb`(강사), `과제.md`, `해답.md` |

## 오늘의 목표
1. **리스트**로 측정값 여러 개를 담고, 꺼내고, 추가·삭제한다.
2. `len`, `sum`, `max`, `min`, `sorted`로 요약한다.
3. **딕셔너리**로 "이름표 → 값"(항목 → 기준값)을 다룬다.
4. **딕셔너리의 리스트**로 시료 목록(표)을 만든다.

## 시간 계획

| 시간 | 노트북 구간 | 핵심 |
|---|---|---|
| 0~10분 | 13회 과제 확인 | 문제 5(문자열+숫자 오류)를 함께 보기 |
| 10~25분 | 1. 리스트, 꺼내기, 요약 | **인덱스는 0부터**, 슬라이싱 `[1:4]`는 4 **앞까지**, 🧪 연습 1 |
| 25~35분 | 바꾸기·추가·삭제 | `append`, `remove`, `in`, 🧪 연습 2 |
| 35~48분 | 2. 딕셔너리 | 엑셀 VLOOKUP 비유, `.get()`으로 오류 피하기, 🧪 연습 3 |
| 48~62분 | 3. 딕셔너리의 리스트 | "엑셀 표의 행 = 딕셔너리 하나", 🧪 연습 4·5 |
| 62~70분 | 정리 | 과제 안내 |

## 꼭 짚어 줄 것

| 개념 | 설명 포인트 |
|---|---|
| 인덱스 0부터 | "첫 번째 = 0번". 엑셀의 1행부터와 달라 가장 많이 헷갈림 |
| `[1:4]` | 끝 번호는 **포함 안 됨**. "4번 문 앞에서 멈춘다" |
| 리스트 vs 딕셔너리 | **순서**로 찾으면 리스트, **이름**으로 찾으면 딕셔너리 |
| `KeyError` | 없는 키를 `limits["라돈"]`으로 꺼내면 오류 → `.get("라돈", 기본값)` |
| 딕셔너리의 리스트 | 4단계 pandas 표의 원형. "이걸 표로 보면 어떤 모양일까?"를 그려 보게 하기 |

> 💬 **강사 멘트 예시:** "엑셀에서 한 열은 리스트, 기준값표는 딕셔너리, 표 전체는 딕셔너리의 리스트입니다. 모양만 알면 AI가 만든 데이터 코드가 훨씬 잘 읽힙니다."

> ⚠️ 노트북의 기준값(`limits`)은 **수업용 예시**입니다. 실제 기준과 다를 수 있다고 안내하세요.

## 자주 나는 오류 (오늘)

| 오류 | 원인 | 해결 |
|---|---|---|
| `IndexError: list index out of range` | 7개짜리 리스트에서 `co2[7]` | 마지막은 `co2[6]` 또는 `co2[-1]` |
| `KeyError: '라돈'` | 딕셔너리에 없는 키 | `in`으로 확인하거나 `.get()` |
| `ValueError: list.remove(x): x not in list` | 리스트에 없는 값을 `remove` | `if 값 in 리스트:` 로 먼저 확인 (15회) |
| `TypeError: list indices must be integers` | `samples["value"]`처럼 리스트에 이름으로 접근 | `samples[0]["value"]` — 먼저 몇 번째인지 |
