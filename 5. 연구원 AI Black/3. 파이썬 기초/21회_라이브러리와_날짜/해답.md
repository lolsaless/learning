# 21회 해답 (과제)

> 수업 중 연습 문제의 답은 `해답.ipynb`에 있습니다. 아래 코드는 문제 1~4를 모두 푼 예시이며, 실행 결과를 확인했습니다.

```python
from datetime import datetime, timedelta

equipment = [
    {"name": "GC-MS",      "last": "2024-11-20", "cycle_days": 365},
    {"name": "HPLC",       "last": "2025-03-02", "cycle_days": 180},
    {"name": "저울(0.1mg)", "last": "2024-05-20", "cycle_days": 365},
    {"name": "CO2 측정기",  "last": "2024-12-10", "cycle_days": 180},
]
today = datetime.strptime("2025-06-01", "%Y-%m-%d")
WEEKDAYS = ["월", "화", "수", "목", "금", "토", "일"]


def adjust_to_weekday(d):
    """토요일은 하루, 일요일은 이틀 앞당겨 금요일로."""
    if d.weekday() == 5:
        return d - timedelta(days=1)
    if d.weekday() == 6:
        return d - timedelta(days=2)
    return d


def status(left):
    if left < 0:
        return "교정 기한 지남"
    if left <= 30:
        return "30일 이내 교정 필요"
    return "정상"


def schedule(adjust=False):
    rows = []
    for e in equipment:
        due = datetime.strptime(e["last"], "%Y-%m-%d") + timedelta(days=e["cycle_days"])
        if adjust:
            due = adjust_to_weekday(due)
        left = (due - today).days
        rows.append({"name": e["name"], "due": due, "left": left, "status": status(left)})
    return sorted(rows, key=lambda r: r["left"])


for title, adjust in [("문제 1~3", False), ("문제 4 (주말 → 금요일)", True)]:
    print(f"[{title}]")
    for r in schedule(adjust):
        print(f"{r['name']:<10} {r['due']:%Y-%m-%d} ({WEEKDAYS[r['due'].weekday()]})  "
              f"{r['left']:>4}일 남음  {r['status']}")
```

## 피드백 포인트
- **문제 2:** 경계값(남은 일수 0일, 30일)을 조건에 맞게 처리했는지
- **문제 3:** `sorted(…, key=lambda r: r["left"])` — `lambda`는 "이름 없는 한 줄 함수". `key`에 "무엇을 기준으로 정렬할지" 알려 줍니다. AI에게 물어보고 설명할 수 있는지 확인하세요.
- **문제 4:** CO2 측정기의 교정일이 일요일(06-08) → 금요일(06-06)로 앞당겨져 남은 일수도 7일 → 5일로 바뀝니다.
- 이 과제의 결과를 **엑셀 파일로 저장**하는 것은 4단계(pandas)에서 한 줄로 할 수 있습니다.
