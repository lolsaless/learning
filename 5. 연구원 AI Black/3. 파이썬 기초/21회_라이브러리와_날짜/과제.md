today = "2025-06-01"      # 기준일 (실제로는 datetime.now()를 쓰지만, 결과를 맞춰 보려고 고정)

## 문제 1. 다음 교정일
장비마다 **다음 교정일** = 마지막 교정일 + 교정 주기(일)를 `YYYY-MM-DD (요일)` 형식으로 출력하세요.

## 문제 2. 남은 일수와 상태
기준일(`today`)부터 다음 교정일까지 **남은 일수**를 구하고, 상태를 붙이세요.
- 남은 일수 < 0 → `"교정 기한 지남"`
- 0 ≤ 남은 일수 ≤ 30 → `"30일 이내 교정 필요"`
- 그 외 → `"정상"`

## 문제 3. 정렬된 일정표
**남은 일수가 적은 순서**로 정렬해 아래처럼 출력하세요.
```
CO2 측정기   2025-06-08 (일)   7일 남음   30일 이내 교정 필요
...
```
- 힌트: 결과를 딕셔너리의 리스트로 만든 뒤 `sorted(결과, key=lambda r: r["left"])` — `lambda`가 무엇인지 AI에게 물어보세요.

## 문제 4 (도전). 주말이면 앞당기기
다음 교정일이 토요일이면 **금요일로**, 일요일이면 **금요일로** 앞당기는 함수 `adjust_to_weekday(d)`를 만들어 문제 3에 적용하세요.
