| 항목 | 내용 |
|---|---|
| 단계 | 3단계. 파이썬 기초 |
| 주차 | 11주차 첫 수업 |
| 시간 | 60~70분 |
| 수업 파일 | `실습.ipynb`(수강생), `해답.ipynb`(강사), `과제.md`, `해답.md` |

## 오늘의 목표
1. `import`로 **표준 라이브러리**를 불러 쓴다.
2. `statistics`로 평균·중앙값·표준편차를, `math`로 올림·내림을 계산한다.
3. `datetime`으로 날짜 문자열을 날짜로 바꾸고 기간을 계산한다.
4. 출장기록의 **출장 시간**과 접수 건의 **처리 일수**를 구한다.

## 꼭 짚어 줄 것

| 개념 | 설명 포인트 |
|---|---|
| 날짜는 "글자"가 아니다 | `"2025-04-17" - "2025-04-08"`은 안 됨. 날짜로 바꿔야 계산 가능. 엑셀에서 날짜가 "텍스트"로 들어가 계산이 안 되던 경험과 연결 |
| 형식 문자열 | `%m`(월)과 `%M`(분)은 다름! 가장 흔한 실수 |
| 기간의 단위 | `timedelta.days`는 **날 수만**, 시간까지는 `total_seconds()` |
| 처리 일수 기준 | "접수일 다음 날부터 셀지", "공휴일 포함할지"는 **업무 규칙**. 코드 전에 규칙을 정해야 함 |

> 💬 **강사 멘트 예시:** "처리 기한 관리, 재측정 예정일, 장비 교정 주기… 날짜 계산은 업무 곳곳에 있습니다. 엑셀로는 수식이 복잡해지지만, 파이썬에서는 `timedelta` 한 줄입니다. 다음 시간 헬륨 계산기의 '종료 예상 시각'도 오늘 배운 것으로 만듭니다."

## 자주 나는 오류 (오늘)

| 오류 | 원인 | 해결 |
|---|---|---|
| `ValueError: time data '2025-04-08' does not match format '%Y-%m-%d %H:%M'` | 형식과 글자 모양이 다름 | 시간이 없으면 `"%Y-%m-%d"` |
| `TypeError: unsupported operand type(s) for -: 'str' and 'str'` | 문자열 날짜끼리 빼기 | `strptime`으로 먼저 변환 |
| 결과가 이상한 분(分) | `%M`과 `%m` 혼동 | 월 `%m`, 분 `%M` |
| `AttributeError: type object 'datetime.datetime' has no attribute 'datetime'` | `from datetime import datetime` 후 `datetime.datetime(...)` | `import` 모양에 맞춰 `datetime(...)` |
