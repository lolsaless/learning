## 오늘의 목표
1. `for`로 리스트 값을 하나씩 꺼내 같은 일을 반복한다.
2. 반복하며 **개수 세기·합계** 같은 누적 계산을 한다.
3. `range`, `enumerate`, `zip`, `.items()`를 쓴다.
4. `while`과 `break`로 조건이 될 때까지 반복한다.
5. 기존 R 반복문을 파이썬으로 옮긴다.

## 꼭 짚어 줄 것

| 개념 | 설명 포인트 |
|---|---|
| 누적 변수 위치 | `count = 0`을 반복 **안**에 두면 매번 0으로 초기화됨 → 흔한 실수 |
| `range(1, 21)` | 끝 번호 미포함. R의 `1:20`과 다름 |
| `enumerate(…, 1)` | 번호를 1부터. "몇 번째 측정"을 출력할 때 |
| `while` 무한 반복 | 조건 안의 값이 반복 안에서 **바뀌는지** 확인. 멈추는 법(중단 버튼) 미리 알려 주기 |
| 리스트 컴프리헨션 | **쓰는 것보다 읽는 것**이 목표. AI 코드에서 자주 보임 |

> 💬 **강사 멘트 예시:** "오늘 연습 2에서 시료 5개를 판정했죠? 4단계에서는 엑셀 파일 수백 줄을 같은 방식으로 판정합니다. 반복문은 **사람이 지치는 일**을 대신하는 문법입니다."

## 자주 나는 오류 (오늘)

| 증상 | 원인 | 해결 |
|---|---|---|
| 합계가 마지막 값과 같음 | `total = 0`이 반복 안에 있음 | 반복 위로 옮기기 |
| `TypeError: 'int' object is not iterable` | `for i in 20:` | `for i in range(20):` |
| 노트북 셀이 끝나지 않음 (`[*]` 표시) | `while` 무한 반복 | [중단] 버튼 → 조건 변수가 바뀌는지 확인 |
| 결과가 한 번만 출력됨 | `print`가 반복 밖으로 빠짐 (들여쓰기) | 들여쓰기 확인 |
