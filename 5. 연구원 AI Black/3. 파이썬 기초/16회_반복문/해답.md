for r in records:

## 문제 2
```python
for item in limits:
    count, total, failed = 0, 0, 0
    for r in records:
        if r["item"] == item:
            count += 1
            total += r["value"]
            if r["value"] >= limits[item]:
                failed += 1
    print(f"{item}: {count}건, 평균 {total / count:.1f}, 부적합 {failed}건")
```
결과:
```
CO2: 4건, 평균 923.0, 부적합 2건
HCHO: 4건, 평균 67.9, 부적합 1건
```

## 문제 3
```python
failed_places = []
for r in records:
    if r["value"] >= limits[r["item"]] and r["place"] not in failed_places:
        failed_places.append(r["place"])
print(failed_places)     # ['B요양원', 'D어린이집']
```
- B요양원은 CO2·HCHO 둘 다 부적합이지만 **한 번만** 들어가야 합니다.
- `set`(세트)을 아는 수강생은 `sorted(set(...))`로 풀어도 정답.

## 문제 4
```python
values = [1250, 1180, 1090, 1030, 985, 960, 955]
for i, v in enumerate(values):
    if v < 1000:
        print(f"{i * 5}분 후 처음으로 1000 미만 ({v} ppm)")   # 20분 후 (985)
        break
```
`while` 버전:
```python
i = 0
while values[i] >= 1000:
    i += 1
print(f"{i * 5}분 후 ({values[i]} ppm)")
```
- `while` 버전은 1000 미만인 값이 **하나도 없으면** `IndexError`가 납니다. 이런 경우까지 생각하는지 물어보세요.
