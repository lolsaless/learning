# 18회 해답 (과제)

> 수업 중 연습 문제의 답은 `해답.ipynb`에 있습니다. 아래 코드는 문제 1~4를 한 번에 푼 예시이며, 실행 결과를 확인했습니다.

```python
import re
rows = [
    "1|수질환경팀/연구사|김민수(X0000101)|2025-04-08 09:30 ~ 2025-04-08 17:00|가평군 청평면",
    "2|수질환경팀/연구관|이서연(X0000102)|2025-04-09 --:-- ~ 2025-04-09 --:--|포천시 신북면",
    "소계: 2건",
    "3|대기환경팀/연구사|박지훈(X0000103)|2025-04-10 13:00 ~ 2025-04-11 12:00|연천군 전곡읍",
]

def split_period(period):
    """'날짜 시간 ~ 날짜 시간' → [출발일, 출발시간, 도착일, 도착시간] ('--:--'는 빈 문자열)"""
    start, end = period.split(" ~ ")
    parts = start.split(" ") + end.split(" ")
    return ["" if p == "--:--" else p for p in parts]

trips = []
for row in rows:
    if row.startswith("소계"):
        continue
    no, team_pos, name_code, period, place = row.split("|")
    team, position = team_pos.split("/")
    name = name_code.split("(")[0]
    start_date, start_time, end_date, end_time = split_period(period)
    trips.append({"no": int(no), "team": team, "position": position, "name": name,
                  "start_date": start_date, "start_time": start_time,
                  "end_date": end_date, "end_time": end_time, "place": place})
for t in trips:
    print(t)

def mask_name(name):
    """첫 글자와 마지막 글자만 남기고 가운데를 *로. 두 글자면 뒤 글자를 *로."""
    if len(name) <= 2:
        return name[0] + "*" * (len(name) - 1)
    return name[0] + "*" * (len(name) - 2) + name[-1]

for n in ["김민수", "이서연", "홍길", "남궁민수"]:
    print(n, "→", mask_name(n))

memo = "1층 PM10 48 PM2.5 23, 2층 PM10 61 PM2.5 38"
print([int(v) for v in re.findall(r"PM2\.5\s*(\d+)", memo)])
```

## 피드백 포인트
- **문제 2:** `split_period`처럼 반복되는 처리를 **함수로 묶었는지** (17회 연결)
- **문제 3:** 길이별로 경우를 나눴는지. `"*" * 2` 처럼 문자열 곱하기를 활용했는지
- **문제 4:** `PM2.5`의 점(`.`)은 정규표현식에서 "아무 글자"라는 뜻이라 `PM2\.5`로 써야 정확합니다. `r"PM2.5\s*(\d+)"`도 이 예에서는 동작하지만, AI가 준 패턴에서 이런 부분을 **질문해 보는 습관**이 중요합니다.
- 이 과제는 28·29회(데이터 정제)에서 **pandas로 수천 줄을 한 번에** 처리하는 방식으로 다시 풉니다.
