## 오늘의 목표
1. 슬라이싱과 `split`으로 문자열에서 필요한 부분을 꺼낸다.
2. `strip`, `replace`, `upper`, `startswith` 등으로 정리한다.
3. 같은 것을 다르게 쓴 값을 **표준 이름 사전**으로 통일한다.
4. 정규표현식으로 글 속의 숫자·패턴을 찾는다.

## 꼭 짚어 줄 것

| 개념 | 설명 포인트 |
|---|---|
| 04회와 연결 | "04회 문제 정의서의 **방해 요소**를 오늘 코드로 해결합니다." 동기 부여에 가장 좋음 |
| `split` 결과는 리스트 | `a, b = s.split("-")`는 **조각 수가 정확히 2개**일 때만 동작 |
| R은 1부터, 파이썬은 0부터 | R 코드를 옮길 때 가장 흔한 실수 |
| 표준 이름 사전 | 코드로 "추측"하지 말고 **사람이 정한 대응표**를 쓰는 것이 안전. 새 표기가 나오면 사전에 추가 |
| 정규표현식 | 외우지 않음. AI에게 **예시 문자열과 원하는 결과**를 주고 만들게 한 뒤, **결과를 눈으로 확인** |

> 💬 **강사 멘트 예시:** "04회에서 '이름(코드)', '날짜 시간 ~ 날짜 시간' 때문에 엑셀 수식이 길어졌던 것 기억하시죠? 파이썬에서는 `split` 두세 번이면 됩니다. 그리고 이 코드는 **4,000줄이어도 똑같이** 동작합니다."

## 자주 나는 오류 (오늘)

| 오류 | 원인 | 해결 |
|---|---|---|
| `ValueError: too many values to unpack (expected 2)` | `a, b = s.split("-")`인데 `-`가 2개 이상 | 조각 수 확인, `s.split("-", 1)` (한 번만 나누기) |
| `ValueError: not enough values to unpack` | 구분 기호가 없는 값(예: `"소계: 2건"`) | `if "(" in s:` 로 먼저 확인 (28회 데이터 정제에서 본격적으로) |
| `AttributeError: 'int' object has no attribute 'split'` | 숫자에 문자열 메서드 | `str(값).split(...)` |
| 정규표현식 결과가 빈 리스트 | 패턴의 `\` 처리 | 패턴 앞에 `r` 붙이기: `r"\d+"` |
