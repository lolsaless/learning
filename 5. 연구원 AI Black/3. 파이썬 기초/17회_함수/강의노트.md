## 오늘의 목표
1. `def`로 함수를 만들고 호출한다.
2. **매개변수**(입력)와 **`return`**(출력)을 이해한다.
3. **기본값**, 여러 값 돌려주기, **docstring**을 쓴다.
4. 단위 환산·판정·요약 함수를 만들어 **조립**한다.

## 꼭 짚어 줄 것

| 개념 | 설명 포인트 |
|---|---|
| 만들기 vs 부르기 | `def` 셀만 실행하면 아무 일도 안 일어남. **불러야** 실행 |
| `return` vs `print` | 가장 많이 헷갈리는 부분. "print는 보여 주기, return은 건네주기". `a = show_only(...)`가 `None`인 예제를 꼭 보여 주기 |
| 매개변수 이름 | 함수 안의 `value`, `limit`은 **함수 안에서만** 쓰는 이름. 밖의 변수와 이름이 같아도 별개 |
| 한 함수 = 한 가지 일 | `summarize` / `judge` / `report_line` 분리. AI에게 코드를 받을 때도 "함수로 나눠 줘"라고 요청하면 읽기 쉬워짐 |
| 엑셀 함수와 비교 | `=AVERAGE(B2:B10)` → `summarize(values)["mean"]`. 이미 쓰고 있던 개념 |

> 💬 **강사 멘트 예시:** "기준이 1000에서 900으로 바뀌면? 함수가 없으면 판정하는 곳을 전부 찾아 고쳐야 하지만, 함수가 있으면 **한 곳**만 고치면 됩니다. 6단계에서 업무 프로그램을 만들 때 이게 가장 큰 차이를 만듭니다."

## 자주 나는 오류 (오늘)

| 오류 | 원인 | 해결 |
|---|---|---|
| `NameError: name 'judge' is not defined` | `def` 셀을 실행하지 않음 | 함수를 만든 셀부터 실행 |
| `TypeError: judge() missing 1 required positional argument: 'limit'` | 입력을 덜 줌 | `judge(값, 기준)` 또는 기본값 설정 |
| 결과가 `None` | `return` 대신 `print`를 씀, 또는 return이 빠짐 | `return` 추가 |
| `TypeError: 'NoneType' object is not subscriptable` | `None`인 결과에서 `["mean"]`을 꺼냄 | 함수가 `return` 하는지 확인 |
