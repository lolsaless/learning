## 문제 1
```python
import statistics

def rsd(values):
    """반복 측정값의 상대표준편차(%)를 소수 2자리로 돌려준다."""
    return round(statistics.stdev(values) / statistics.mean(values) * 100, 2)

print(rsd([10.2, 10.5, 9.9, 10.1, 10.3]))    # 2.19
```
- `statistics.stdev`는 **표본 표준편차**(n−1로 나눔)입니다. 엑셀 `STDEV.S`와 같은 값입니다. (`STDEV.P`와 비교해 보게 하면 좋은 검산 연습)

## 문제 2
```python
def judge(value, limit, mode="이상"):
    """mode가 '이상'이면 value >= limit, '초과'면 value > limit 일 때 부적합."""
    if mode == "초과":
        over = value > limit
    else:
        over = value >= limit
    return "부적합" if over else "적합"

print(judge(1000, 1000))                 # 부적합
print(judge(1000, 1000, mode="초과"))    # 적합
```

## 문제 3 (예: 검량선 농도)
```python
def conc_from_area(area, slope, intercept, dilution=1):
    """
    검량선(면적 = 기울기 × 농도 + 절편)으로 시료 농도를 계산한다.

    매개변수: area 피크 면적, slope 기울기, intercept 절편, dilution 희석배수(기본 1)
    반환값: 농도 (검량선 단위)
    """
    return (area - intercept) / slope * dilution

print(round(conc_from_area(15230, 1520.5, 35.2), 3))        # 9.993
print(round(conc_from_area(15230, 1520.5, 35.2, 10), 2))    # 99.93
```
- 피드백 포인트: docstring, **검산 기록**이 있는지.

## 문제 4
```python
def summarize(values):
    return {"count": len(values), "mean": round(sum(values) / len(values), 1),
            "max": max(values), "min": min(values)}

def qc_report(name, values, rsd_limit=5):
    s = summarize(values)
    r = rsd(values)
    result = "적합" if r <= rsd_limit else "재측정"
    return f"{name}: {s['count']}회, 평균 {s['mean']}, RSD {r} % → {result}"

print(qc_report("표준용액 A", [10.2, 10.5, 9.9, 10.1, 10.3]))
# 표준용액 A: 5회, 평균 10.2, RSD 2.19 % → 적합
```
