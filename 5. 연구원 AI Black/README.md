# 연구원 AI Black

> **AI를 활용한 문제 해결** — 연구원을 위한 6개월 AI·파이썬 실무 과정

프로그래밍을 한 번도 해 보지 않은 연구원이 **AI의 도움을 받아 자기 업무의 문제를 스스로 해결**할 수 있게 되는 것이 이 과정의 목표입니다.
강의에 쓰는 예제는 모두 실제 업무(실내공기질, 수질, 연구사업, 공문 처리)에서 가져왔습니다.

---

## 과정 한눈에 보기

| 항목 | 내용 |
|---|---|
| 기간 | 26주 (약 6개월) |
| 정규 수업 | 주 2회 × 1시간 이상 → **52회** |
| 보충 실습 | 주 1회 (주 3회 수업하는 주에 사용) → **26회** |
| 확장 트랙 | 웹 기술(HTML·JavaScript·Node.js)과 다양한 문제 해결 방법 → **14회** (선택) |
| 대상 | 연구원 2명 (AI·프로그래밍 초보) |
| 언어 | **Python** (R은 사용하지 않음. 기존 R 코드는 모두 파이썬으로 바꿔서 사용) |
| 도구 | ChatGPT·Claude 등 AI 채팅, VS Code, Jupyter Notebook, Git·GitHub (확장 트랙: HTML·JavaScript·Node.js) |
| 자료 형식 | 강의 노트 `.md`, 실습 `.ipynb`(주피터 노트북), 완성 코드 `.py` |

## 7단계 구성

| 단계 | 주차 | 회차 | 이 단계를 마치면 할 수 있는 것 |
|---|---|---|---|
| 1. AI와 친해지기 | 1~3주 | 1~6회 | AI에게 원하는 답을 얻는 질문을 쓰고, 내 업무에서 자동화할 문제를 찾는다 |
| 2. 개발 환경 만들기 | 4~6주 | 7~12회 | 내 PC(Mac·Windows)에 Python·VS Code·Git을 설치하고 GitHub에 코드를 올린다 |
| 3. 파이썬 기초 | 7~11주 | 13~22회 | AI가 만든 코드를 읽고 고칠 수 있을 만큼 파이썬 문법을 이해한다 |
| 4. 데이터 다루기 | 12~15주 | 23~30회 | 엑셀·CSV 데이터를 pandas로 불러와 정리·합치기·요약한다 |
| 5. 시각화와 통계 | 16~19주 | 31~38회 | 그래프를 그리고 이상치·정규성·상관·집단 비교를 분석한다 |
| 6. 업무 프로그램 만들기 | 20~23주 | 39~46회 | 웹 수집, PDF·OCR, 웹앱, 실행파일 등 업무 도구를 만든다 |
| 7. 심화·종합 프로젝트 | 24~26주 | 47~52회 | AI 코딩 도구로 내 업무 문제를 해결하는 프로그램을 완성하고 발표한다 |
| 확장 트랙 (선택) | 병행 또는 연장 | W01~W14 | HTML 대시보드, Node.js, 데스크톱 앱, 구글 시트, SQL 등 문제에 맞는 도구를 골라 쓴다 |

## 폴더 구성

```
5. 연구원 AI Black/
├── README.md                  ← 지금 보고 있는 파일
├── 00_커리큘럼/
│   ├── 01_전체_커리큘럼.md      과정 목표, 단계별 학습 목표, 운영 방법
│   ├── 02_회차별_계획표.md      52회 정규 수업 + 26회 보충 실습 계획
│   └── 03_R_파이썬_변환_대응표.md  기존 R 코드 → 어느 회차의 파이썬 실습이 되는지
├── 1. AI와 친해지기/            ✅ 01~06회 + 보충 S01~S03
├── 2. 개발 환경 만들기/          ✅ 07~12회 + 보충 S04~S06
├── 3. 파이썬 기초/              ✅ 13~22회 + 보충 S07~S11
├── 4. 데이터 다루기/
├── 5. 시각화와 통계/
├── 6. 업무 프로그램 만들기/
├── 7. 심화·종합 프로젝트/
├── 8. 확장 트랙_웹과 다양한 방법/
├── 공통자료/                   용어 사전, 프롬프트 템플릿, AI 안전 수칙, 터미널·파이썬 치트시트, R↔파이썬 대응표, 설치 점검표, 오류 모음
├── requirements.txt           과정에서 쓰는 파이썬 라이브러리 목록 (단계별로 추가)
└── data/                      실습용 데이터 (개인정보가 없는 가상 데이터)
```

각 회차 폴더에는 다음 파일이 들어갑니다.

| 파일 | 내용 |
|---|---|
| `강의노트.md` | 수업 진행 순서, 개념 설명, 시간 배분 |
| `실습지.md` + `*.ipynb` / `*.py` | 수강생이 직접 따라 하는 실습 (1단계는 설치 전이라 주로 `실습지.md`, 2단계부터 노트북·파이썬 파일) |
| `과제.md` | 다음 수업 전까지 해 올 과제 |
| `해답.md` / `해답.py` / `해답.ipynb` | 실습·과제 예시 답안 (강사용) |

## 실습 데이터 원칙

이 저장소는 **공개 저장소**입니다. 실제 업무 데이터에는 업체명·담당자 이름 같은 정보가 들어 있으므로,
실습에는 **열 구조는 실제와 같고 내용은 가짜인 데이터**를 만들어 사용합니다.
