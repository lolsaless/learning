# 헬륨 봄베 사용 가능 시간 계산기

GC-MS, 헤드스페이스 샘플러에 쓰는 헬륨 봄베가 **출구 압력을 유지할 수 있는 시간**을 추정하는 도구입니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `helium_calc.py` | 파이썬 계산기 (대화형 / 명령줄) |
| `helium_calc.html` | 브라우저용 계산기 (파일을 더블클릭하면 실행, 인터넷·설치 불필요) |
| `README_helium_calc.md` | 이 설명서 |

## 입력 항목

| 항목 | 설명 | 예시 |
|---|---|---|
| 봄베 용적 | 봄베 내용적(L). 봄베 어깨 각인 또는 사양서 확인 | 47 L |
| 봄베 현재 게이지압 | 봄베(입구측) 압력계 눈금 | 600 psi |
| 출구 압력 | 레귤레이터 설정(2차) 압력 | 80 psi |
| 교체 여유압 | 출구압에 더해 미리 교체할 여유 (선택) | 20 psi |
| 유량 | 장비별 헬륨 소비량 (mL/min, 대기압 기준). 여러 개 입력 시 합산 | 50 mL/min |
| 압력 단위 | psi, bar, MPa, kPa, atm | psi |

> 유량은 GC 컬럼 유량 + 스플릿/퍼지 벤트 유량 + 헤드스페이스 캐리어·가압 가스 등 **해당 봄베에서 나가는 모든 가스의 합**을 넣어야 합니다. 장비 메서드(또는 장비 표시값)로 확인하세요.

## 계산 원리

온도가 일정하고 이상기체라고 가정하면 가스량은 절대압에 비례합니다. 게이지압 차이는 절대압 차이와 같으므로 다음과 같이 계산합니다.

```
사용 가능 가스량(L) = 용적(L) × (현재 게이지압 − 출구압 − 여유압) ÷ 14.696 psi
사용 가능 시간(min) = 사용 가능 가스량(L) × 1000 ÷ 총 유량(mL/min)
```

계산 예: 47 L, 600 psi, 출구 80 psi, 50 mL/min

- 가스량 = 47 × 520 / 14.696 ≈ 1,663 L
- 시간 = 1,663,000 / 50 = 33,260 min ≈ **23.1일**

## 사용법

### 1) HTML
`helium_calc.html`을 브라우저로 열고 값을 입력하면 자동으로 결과가 갱신됩니다.
- `+ 유량 항목 추가`로 장비별 유량을 따로 입력할 수 있습니다.
- 기준 시각을 바꾸면 종료 예상 시각이 그에 맞춰 계산됩니다.
- 결과에는 종료 예상 시각, 사용 가능 시간, 주 단위 예상 압력표가 표시됩니다.

### 2) Python (3.7 이상, 추가 패키지 불필요)

```bash
# 대화형 (질문에 답하기, Enter = 기본값)
python helium_calc.py

# 한 줄 실행
python helium_calc.py -i 600 -o 80 -f 50

# 장비별 유량 합산 + 여유압 + 용적 지정
python helium_calc.py -v 47 -i 500 -o 80 -m 20 -f 30 -f 20

# 단위 변경 (bar)
python helium_calc.py -u bar -v 47 -i 40 -o 5 -f 50
```

| 옵션 | 의미 |
|---|---|
| `-v` | 봄베 용적 L (기본 47) |
| `-i` | 현재 게이지압 |
| `-o` | 출구 압력 |
| `-m` | 교체 여유압 (기본 0) |
| `-f` | 유량 mL/min (여러 번 지정 시 합산) |
| `-u` | 압력 단위 (기본 psi) |

다른 스크립트에서 불러 쓸 수도 있습니다.

```python
from helium_calc import calculate
r = calculate(47, 600, 80, [30, 20], unit="psi", margin=20)
print(r["days"], r["end"])
```

## 한계 및 주의사항

- 온도 변화(실온 ±10 ℃ 정도)에 따라 압력계 눈금이 약 3 % 안팎으로 달라질 수 있습니다.
- 헬륨은 600 psi 부근에서 이상기체와의 차이가 1 % 이내로 작아 보정하지 않았습니다.
- 라인·피팅 미세 누출, 봄베 교체 시 퍼지, 기기 대기(standby) 소비량은 포함되지 않습니다. 유량에 해당 소비량을 더해 입력하세요.
- 레귤레이터는 출구압을 유지하려면 설정압보다 입구압이 어느 정도 높아야 하므로, 교체 여유압(예: 출구압 + 20~50 psi)을 두는 것이 안전합니다.
- GC-MS는 헬륨 부족 시 분석 도중 유량·압력 오류가 발생할 수 있으므로, 시퀀스 시작 전에 남은 시간이 충분한지 확인하세요.
- 본 결과는 **대략적인 추정값**이며, 실제 교체 시점은 압력계 확인으로 판단하세요.
