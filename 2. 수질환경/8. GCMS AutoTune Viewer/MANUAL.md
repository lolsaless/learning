# GC/MS Autotune 판독기 매뉴얼

Agilent 5977 GC/MS의 **Autotune 리포트(PDF·이미지)** 를 OCR로 읽어 항목별로 판정하는 단일 HTML 도구입니다.
파일 하나(`gcms_autotune_viewer.html`)로 동작하며, 인터넷에 연결하지 않고 내 PC 브라우저 안에서만 처리합니다(파일이 외부로 전송되지 않습니다).

---

## 핵심 요약 5줄

1. `gcms_autotune_viewer.html`을 더블클릭해 열고, Autotune PDF를 **끌어다 놓거나** [PDF·이미지 열기]로 불러옵니다.
2. 왼쪽은 **PDF 원본**, 오른쪽은 **OCR로 읽어 다시 정리한 화면**이며, 값을 누르면 원본의 같은 위치가 표시되어 바로 대조할 수 있습니다.
3. 12개 항목(EM Volts, Repeller, Ion Focus 등)을 **정상 / 주의 / 경고 / 확인필요**로 판정하고, 맨 위에 5줄 요약을 보여줍니다.
4. **확인필요**는 "OCR이 불확실하니 원본과 대조하세요"라는 뜻입니다. 값을 더블클릭해 고치거나 Enter로 확정하면 즉시 다시 판정합니다.
5. 결과는 A4 한 장 평가서(인쇄/PDF), CSV, 이력·트렌드 그래프로 남길 수 있습니다.

---

## 1. 준비물과 실행

| 항목 | 내용 |
|---|---|
| 파일 | `gcms_autotune_viewer.html` (약 9.6MB) |
| 브라우저 | 최신 Chrome 또는 Edge 권장 (Chromium 계열에서 시험함) |
| 인터넷 | 불필요 (OCR 엔진·PDF 뷰어·영어 인식 데이터가 파일 안에 포함됨) |
| 설치 | 없음. 파일을 PC에 저장하고 더블클릭 |
| 처리 시간 | 1페이지당 약 10~15초 (첫 페이지는 OCR 엔진 준비로 몇 초 더 걸릴 수 있음) |

> 회사 보안 정책으로 HTML 실행이 막힌 경우에는 브라우저에서 파일을 직접 열어(`Ctrl+O`) 보세요.

## 2. 사용 순서 (처음 쓰는 분용)

1. HTML 파일을 열면 큰 안내 상자가 보입니다.
2. Autotune 스캔 PDF를 상자 위로 **끌어다 놓습니다**. 또는 오른쪽 위 **[PDF · 이미지 열기]** 를 눌러 선택합니다. 여러 파일을 한꺼번에 넣어도 됩니다.
3. 약 10~15초 동안 진행 막대가 표시되고, 끝나면 맨 위에 **종합 판정**과 **핵심 요약 5줄**이 나타납니다.
4. 왼쪽 원본과 오른쪽 정제 화면을 비교하며 "확인필요"로 표시된 값을 점검합니다.
5. 필요하면 값을 고치고, [이력에 저장] 또는 [평가서 인쇄 / PDF 저장]을 누릅니다.

## 3. 화면 구성

### 3-1. 위쪽 버튼

| 버튼 | 기능 |
|---|---|
| PDF · 이미지 열기 | 파일 선택 (PDF, PNG, JPG 등, 여러 개 가능) |
| 이력·트렌드 | 저장한 튠 결과의 변화 그래프 화면으로 이동 |
| CSV 저장 | 현재 파일의 판정 결과와 모든 인식값을 CSV로 저장 |
| 평가서 인쇄 / PDF 저장 | A4 한 장 평가서 출력 (인쇄 창에서 "PDF로 저장" 선택) |
| 설정 | 판정 기준·인식 옵션·영역 위치 보정 |

여러 파일(또는 여러 쪽)을 열면 버튼 아래에 **파일 칩**이 생기며, 칩의 색이 판정 결과입니다. 누르면 해당 파일로 전환됩니다.

### 3-2. 왼쪽: 원본

- **폭 맞춤 / 160% / 240% / 340%** : 확대 비율
- **원본만 / 인식 영역 / 인식값 겹침**
  - 원본만: 스캔 이미지 그대로
  - 인식 영역: OCR이 읽은 위치를 상자로 표시 (노란·빨간 상자는 신뢰도가 낮은 값)
  - 인식값 겹침: 읽은 숫자를 상자 위에 겹쳐서 표시 (원본 숫자와 눈으로 비교하기 좋음)
- **영역 구획** : 프로그램이 OCR 대상으로 잡은 6개 구역(헤더, 파라미터 표, Actual m/z, 온도·압력, Target m/z, Ramp Criteria)을 점선으로 표시
- **원본 새 창** : 원본 PDF를 브라우저 새 탭으로 열기

### 3-3. 오른쪽: 결과

맨 위 **배너**: 종합 판정, 항목별 개수, 핵심 요약 5줄, [이력에 저장] 버튼.

| 탭 | 내용 |
|---|---|
| 인식 화면(재구성) | OCR이 읽은 값을 원본 리포트와 같은 구성으로 다시 그린 화면 |
| 판정 결과 | 12개 항목의 측정값·기준·판정. 항목을 누르면 쉬운 설명과 조치 방법이 펼쳐짐 |
| 이력·트렌드 | 저장한 이력의 그래프·표 |
| OCR 원문 | 영역별 입력 이미지와 OCR이 읽은 원문 (인식이 이상할 때 원인 확인용) |

- **위아래 함께 보기** : 인식 화면과 판정 결과를 한 화면에 나란히 표시
- **다시 인식** : 설정(영역 위치 등)을 바꾼 뒤 현재 파일을 처음부터 다시 판독

## 4. 원본과 비교하는 방법 (이 도구의 핵심)

1. 오른쪽 **인식 화면**에서 값을 **한 번 클릭**하면 왼쪽 원본에서 해당 숫자 위치가 주황색 상자로 강조되고 자동으로 이동합니다.
2. 반대로 원본 위의 상자를 눌러도 오른쪽 값이 강조됩니다.
3. 값 아래 **밑줄 색**은 OCR 신뢰도입니다 (초록: 높음, 노랑: 보통, 빨강: 낮음 → 확인 권장).
4. 값의 **배경색**은 판정 결과입니다 (초록 정상 / 노랑 주의 / 빨강 경고 / 회색 확인필요).
5. 값 위에 마우스를 올리면 신뢰도, "확대 재인식 보정" 여부, 최초 인식값, **읽기 불일치 시 다른 후보값**이 말풍선으로 나옵니다.

### 값을 고치거나 확인 처리하기

- 값을 **더블클릭** → 숫자를 고치고 **Enter** → 즉시 다시 판정됩니다.
- 읽은 값이 맞다면 고치지 않고 **Enter만** 눌러도 "사람이 확인함"으로 확정되어 해당 항목의 "확인필요"가 풀립니다.
- 고친 값은 ✎ 표시가 붙고, 판정표에도 "수정값 반영"으로 표시됩니다.
- **Esc** 는 취소입니다.

## 5. 판정 항목과 기본 기준

판정은 4단계입니다.

| 판정 | 의미 |
|---|---|
| 정상 | 기준 이내 |
| 주의 | 기준에 가깝거나 약간 벗어남 → 추세 확인·점검 계획 |
| 경고 | 기준을 분명히 벗어남 → 조치 필요 |
| 확인필요 | OCR 신뢰도가 낮거나 물리적으로 불가능한 값이라 자동 판정을 보류함 → 원본 대조 |

| # | 항목 | 정상 기준 (기본값) | 벗어날 때 |
|---|---|---|---|
| 1 | Mass 배정 정확도 | Actual m/z가 69 / 219 / 502 대비 ±0.2 이내 | ±0.4까지 주의, 초과 경고 |
| 2 | Peak Width (PW50) | 0.60 ± 0.05 | ±0.10까지 주의, 초과 경고 |
| 3 | Rel Abund (m/z 219) | 40% 이상 | 경고 |
| 4 | Rel Abund (m/z 502) | 2% 이상 | 경고 |
| 5 | Isotope Ratio | 이론값(1.08 / 4.32 / 10.09%)의 ±20%, Iso Abund 1,000 이상 | 주의 |
| 6 | m/z 69 절대 Abundance | 200,000 ~ 550,000 | 하한의 50% 이상이면 주의, 미만 경고. 상한 초과 주의 |
| 7 | EM Volts | 1,600V 이하 | 2,800V까지 주의, 초과 경고 (한계 3,000V) |
| 8 | Repeller | 리포트에 인쇄된 Ramp Criteria 상한 대비 90% 미만 | 주의 |
| 9 | Ion Focus | 리포트에 인쇄된 상한 대비 85% 미만 | 주의 |
| 10 | Air/Water | H₂O·N₂·O₂ 모두 m/z 69 대비 10% 미만 | 주의 |
| 11 | Hi Vac (분석기 압력) | 1.0e-06 ~ 1.4e-04 Torr | 하한 미만 주의(게이지 이상 가능), 상한 초과 경고 |
| 12 | Turbo Speed | 95% 이상 (정상 100%) | 경고 |

> 이 기준값은 Agilent 5977 시리즈 권장값을 바탕으로 한 **기본값**입니다. 기관 내부 기준이 따로 있으면 [설정]에서 바꾸세요. 같은 장비라도 사용 기간에 따라 EM Volts·Repeller·Ion Focus는 점점 오르는 것이 정상이므로, **절대값보다 이력의 추세**를 함께 보는 것이 좋습니다.

### 종합 판정 규칙

- 경고가 하나라도 있으면 **경고**
- 확인필요가 6개 이상이면 **확인필요** (인식이 제대로 되지 않은 문서)
- 주의 또는 확인필요가 있으면 **주의**
- 모두 정상이면 **정상**

### "확인필요"가 뜨는 경우

1. OCR 신뢰도가 설정값(기본 60%)보다 낮은 값이 해당 항목 계산에 쓰였을 때
2. 읽은 값이 물리적으로 불가능할 때 (예: 69 기준 이온이 63.00으로 읽힘)
3. 같은 칸을 여러 번 읽었는데 결과가 갈릴 때 (예: 9와 5 혼동 → "읽기 불일치")
4. 값을 읽지 못했을 때

이 경우 틀린 값으로 "정상"이나 "경고"가 나가지 않도록 판정을 보류합니다. 원본과 대조한 뒤 값을 고치거나 Enter로 확정하세요.

## 6. 설정

### 판정 기준
위 표의 숫자를 바꿀 수 있습니다. [저장하고 다시 판정]을 누르면 열려 있는 모든 파일에 즉시 반영됩니다. [기본값으로 되돌리기]도 있습니다. 설정은 이 브라우저에 저장됩니다.

### 인식 옵션
- **확대해서 다시 읽기(권장)** : 신뢰도가 낮거나 이상한 숫자를 확대·여러 방식으로 반복 판독해 다수결로 정합니다. 켜 두는 것을 권장합니다.
- **저신뢰 기준(%)** : 이 값보다 낮으면 해당 판정을 "확인필요"로 보류합니다.
- **인식 완료 시 이력에 자동 저장** : 기본은 꺼짐입니다. 틀리게 읽힌 값이 이력에 섞일 수 있어 확인 후 [이력에 저장]을 누르는 것을 권장합니다.

### 영역 위치 보정
스캔 여백이 표준 양식과 달라 OCR 영역이 어긋나면 가로/세로 이동(%)과 크기 배율(%)로 조정합니다.
1. 원본 위 [영역 구획]을 켜서 점선 상자가 숫자 위에 맞는지 확인
2. 설정에서 이동·배율 조정 → 저장
3. [다시 인식] 클릭

## 7. 이력과 트렌드

- 배너의 **[이력에 저장]** 을 누르면 튠 일시별로 EM Volts, Repeller, Ion Focus, Rel Abund 502, m/z 69 Abundance, Hi Vac, Air/Water 등이 저장됩니다. 같은 튠 일시·장비 S/N이면 덮어씁니다.
- [이력·트렌드] 탭에는 항목별 그래프(점선은 기준선)와 이력 표가 있습니다. "직전 대비" 변화량과 "추세 주의" 표시도 나옵니다.
- **이력 CSV** : 엑셀에서 열 수 있는 CSV
- **이력 백업(JSON) / 백업 불러오기** : 다른 PC나 브라우저로 옮길 때 사용
- 이력은 **사용 중인 브라우저에만** 저장됩니다. 브라우저 데이터를 지우거나 다른 브라우저를 쓰면 보이지 않으므로 가끔 백업하세요.

## 8. 평가서 출력

[평가서 인쇄 / PDF 저장] → 인쇄 창에서 대상 **PDF로 저장**(또는 프린터) 선택 → A4 한 장에 종합 판정, 핵심 요약 5줄, 12개 항목 표가 들어갑니다. 수정한 값이 있으면 그 값이 반영됩니다.

## 9. 알려진 한계와 주의

| 한계 | 설명 |
|---|---|
| 표준 양식 전용 | Agilent MassHunter의 Autotune 인쇄 양식(A4 세로)을 기준으로 영역을 고정해 읽습니다. 다른 양식은 지원하지 않습니다. |
| 사진 촬영본 | 카메라로 찍어 기울어지거나 여백이 다른 사진은 일부만 읽힙니다(확인필요가 많이 뜸). **스캔 PDF를 권장**합니다. |
| 숫자 오독 | 스캔 글꼴에서 9↔5, 0↔G 등을 가끔 혼동합니다. 프로그램이 반복 판독으로 줄이고, 불확실하면 "확인필요"로 알립니다. 중요한 값은 원본과 한 번 대조하세요. |
| 시험 범위 | 개발 중 시험은 샘플 PDF 1건(62개 값 중 61개 정확, 나머지 1개는 읽기 불일치로 표시)과 Chromium 환경에서 진행했습니다. 다른 장비·스캐너 문서로 처음 쓸 때는 결과를 원본과 충분히 대조하세요. |
| 판정은 참고용 | 자동 판정은 점검을 돕는 도구입니다. 최종 판단과 조치는 담당자의 확인이 필요합니다. |

## 10. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 아무 반응이 없음 | PDF/이미지 파일인지 확인. 브라우저를 새로고침한 뒤 다시 시도 |
| "Autotune 리포트로 보기 어렵다"는 경고 | 다른 문서이거나 영역이 크게 어긋남. [영역 구획]으로 확인 후 영역 위치 보정 |
| 값이 대부분 "—"로 나옴 | 스캔 여백/기울기 문제. 영역 위치 보정 후 [다시 인식], 또는 다시 스캔 |
| 특정 숫자가 계속 틀림 | 해당 값 더블클릭 후 수정. [OCR 원문] 탭에서 원문 확인 |
| 이력이 사라짐 | 브라우저 데이터 삭제/다른 브라우저 사용. 백업(JSON)을 불러오기 |
| 인쇄 시 두 장으로 나옴 | 인쇄 창에서 용지 A4, 배율 100%(기본값), 여백 기본 선택 |


```bash
npm install          # pdfjs-dist, tesseract.js, tesseract.js-core, @tesseract.js-data/eng 설치
node build.js        # gcms_autotune_viewer.html 생성 (약 9.6MB)
```

`npm install`과 빌드는 인터넷이 되는 PC에서 한 번만 하면 되고, 결과 HTML은 오프라인 PC로 옮겨 쓰면 됩니다.

## 처리 흐름 (app.js)

1. **렌더링** : pdf.js로 페이지를 폭 2481px(A4 300dpi)로 그림 (이미지는 같은 폭으로 정규화)
2. **영역 자르기** : `ROI_DEF`의 비율 좌표로 6개 구역을 잘라냄 (`roiRect`, 위치 보정 반영)
3. **OCR** : Tesseract.js(LSTM, 영어)로 구역별 판독. 파라미터 표는 격자선이 점선이라 원본 그대로 psm 4로 읽고, 격자선 제거본(psm 6)을 보조로 사용
4. **파싱** : 줄·단어 좌표(bbox)와 정규식으로 값 추출 (`parseHeader/Param/Actual/Temp/Target/Ramp`). `fixLine`이 숫자 사이의 C·G·O 등을 0으로 보정
5. **재인식·투표** (`refineFields`) : 신뢰도가 낮은 칸을 배율(1·3·4배)과 모드(psm 7·8)를 바꿔 5회 판독해 다수결. 의견이 갈리면 `disputed`로 표시하고 신뢰도를 낮춤
6. **판정** (`evaluate`) : `crit`(판정 기준)을 적용해 12개 항목 판정, 5줄 요약 생성(`composeSummary`)
7. **화면** : 원본·오버레이·재구성·판정·트렌드·OCR 원문 렌더링, 필드 클릭/편집 시 재판정

## 자주 바꾸는 곳

| 하고 싶은 일 | 위치 |
|---|---|
| 판정 기준 기본값 변경 | `app.js`의 `DEFAULT_CRIT` |
| 설정 창에 항목 추가 | `CRIT_FIELDS`, `evaluate()` |
| OCR 구역 위치 조정 | `ROI_DEF` (페이지 대비 비율) |
| 항목 설명·조치 문구 수정 | `EXPLAIN` |
| 이력 그래프 항목 추가 | `METRICS`, `makeRecord()` |
| 평가서(인쇄) 레이아웃 | `template.html`의 `#printSheet`와 `@media print`, `printSheet()` |
| 화면 색상·글꼴 | `template.html` 상단 CSS 변수(`:root`) |

## 오프라인 동작 방식 (참고)

- 모든 라이브러리를 HTML 안에 넣었습니다 (`<script type="text/plain">` 영역).
- Tesseract.js 워커 앞에 코어(wasm) 소스를 붙이고, 워커 안의 `fetch`를 가로채 내장된 영어 학습 데이터를 반환하므로 외부 주소를 호출하지 않습니다. (`app.js`의 `getOcr()`에 있는 `https://offline.invalid/...` 주소는 실제로 접속되지 않는 자리표시용입니다.)
