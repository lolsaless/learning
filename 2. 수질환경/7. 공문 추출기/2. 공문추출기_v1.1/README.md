# 검사의뢰 공문 추출기 v1.1

수질검사 의뢰 공문(ODT)을 공문 폴더에서 모두 읽어 **시료 1개당 1행**으로 보여 주고, 엑셀 저장·완료 체크·성적처리완료 이동·원본 보기를 하는 프로그램입니다.

## 바로 쓰기

| 판 | 실행 | 필요한 것 |
|---|---|---|
| HTML 판 | `공문추출기.html`을 **Edge**로 열기 → [공문 폴더 선택] | Edge 또는 Chrome |
| 파이썬 판 | `python 공문추출기.py` | Python 3.8 이상 (추가 설치 없음) |

두 판은 같은 규칙으로 같은 결과를 만들고, 공문 폴더의 `_처리상태.json`·`기준표.xlsx`를 함께 씁니다.

## v1.1에서 바뀐 것
1. `시료명`처럼 열 제목이 달라도 시료 표를 인식 (동두천시 공문 문제 해결)
2. `BOD(20이하)`, `SS(20 이하)`, `T-P(0.5미만)` 등 항목 안 기준 표기 분리
3. 접수일 최근 순 정렬, 열 순서: 접수일 · 의뢰기관 · 의뢰자 · 발신명의 · 시행 · 시료번호 · 검사항목 · 시료채취일
4. 행을 누르면 추출 결과와 **원본 공문을 나란히** 표시, 원본 파일 열기
