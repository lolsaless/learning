# 검사의뢰 공문 추출기 — 매뉴얼 v2.1

- 파일: `공문추출기.html` (HTML 판, 약 1.6MB, 한 파일)
- 버전: **v2.1** (2026-10-27) — 기능은 v2.0과 같고, **소스를 부품 60개로 나누고 빌드 도구(Windows·Mac)를 붙였다.** 변경 내용은 `변경이력.md`, 수정 방법은 `수정방법.md`, 부품 목록은 `부품지도.md`
- 실행 환경: Windows PC, **Microsoft Edge** 또는 Chrome 최신 버전. 인터넷이 없어도 동작한다(공휴일 자동 갱신만 인터넷 사용, 없으면 내장 목록).
- 파이썬 판(`공문추출기.py`)은 **v1.1 그대로**다. v2.0 기능(공문별 폴더·처리기한·성적서 대조·이력 문서)은 HTML 판에만 있다. → 4장

## 1. 최초 기획

### 1.1 목적
수질검사 의뢰 공문(ODT)을 하나씩 열어 옮겨 적는 일을 없애고(v1), 접수부터 성적서 발행·완료까지 **한 화면에서 처리기한과 진행 상황을 관리**한다(v2).

1. 공문 폴더에 의뢰공문을 저장하면 시료 1개당 1행으로 보여 준다.
2. 의뢰공문마다 `의뢰기관_제목_시행번호` 폴더를 만들어 공문·첨부·시행공문·성적서를 한곳에 모은다.
3. 시료접수일을 넣으면 [별표 2] 표준처리기간으로 기한과 남은 일수를 계산하고, 임박하면 빨간색으로 알린다.
4. 시행공문(결과 알림)과 시험성적서(PDF)를 공문번호·시료명으로 의뢰공문과 자동으로 짝짓는다.
5. 메모·이력을 남기고, 공문·성적서 그림이 들어간 **이력 문서(Word·PDF)**를 만든다.

**기술 메모**
- PDF 읽기·그리기는 **pdf.js 3.11.174**(Mozilla, Apache-2.0)를 HTML 안에 넣었다. 인터넷 없이 동작한다(그래서 파일이 1.6MB).
- 그 밖에는 외부 라이브러리가 없다. ZIP 해제는 브라우저 기능을 쓰고, 엑셀·Word·PDF 작성기는 직접 만들었다.
- 공문 → 그림: 원본 미리보기 HTML을 SVG 안에 넣어 그림(canvas)으로 바꾼다. HWPX는 표를 HTML로 다시 그린 뒤 같은 방식으로 바꾼다.
- 이력 PDF는 A4 쪽을 그림으로 그려 묶는다(글자 검색 안 됨). 글자 편집이 필요하면 Word로 만든다.

## 3. 설치 및 사용 (HTML 판)

### 3.1 설치
설치 없음. `공문추출기.html`을 원하는 곳에 두고 **Edge로 연다**. v1.x에서 올리는 경우 HTML 파일만 바꾼다(`_처리상태.json`·`기준표.xlsx`는 그대로 사용).

### 3.2 폴더 구성

```
공문/                                         ← 공문 폴더 (이름 자유)
├─ 새 의뢰공문.odt, 첨부.hwpx                    ← 새로 받은 공문은 그냥 여기에 저장
├─ 수질오염도 검사 결과 알림[14-10-4].odt          ← 시행공문 (발송 후 저장)
├─ 시험성적서(2772600788-01).pdf                 ← 성적서
├─ 파주시_폐수오염도 검사 의뢰[14-10-4]_기후위기대응과-31655/   ← 공문별 폴더 (자동 생성)
│   ├─ 폐수오염도 검사 의뢰[14-10-4].odt
│   └─ (처리 완료 시) 시행공문.odt · 시험성적서.pdf · 이력_….docx
├─ 성적서 및 시행 공문/                           ← (선택) 의뢰공문이 없는 하위 폴더는 '받은 파일함'으로 읽음
├─ 성적처리완료/                                  ← 처리 완료한 공문 폴더
├─ 기준표.xlsx                                  ← (선택)
├─ _처리상태.json   ← 완료 체크·처리 기록
├─ _시료이력.json   ← 시료접수일·13시 이전·메모·이력·직접 입력 시료 (v2.0)
└─ _설정.json       ← 휴일·처리기간·처리기한 기준·폴더 정리 설정 (v2.0)
```

- `_`로 시작하는 파일, `기준표*`, `공문추출기*`로 시작하는 파일·폴더는 읽지 않는다.
- 하위 폴더 안에 **의뢰공문이 있으면 공문 폴더**, 없으면 시행공문·성적서·첨부를 넣어 두는 **받은 파일함**으로 본다.

### 3.3 처음 실행
1. **[공문 폴더 선택]** → 폴더 고르기 → **[파일 보기 및 편집 허용]**.
2. 정리되지 않은 의뢰공문이 있으면 **"공문별 폴더 정리"** 창이 뜬다. [정리하기]를 누르면 공문마다 폴더를 만들고 공문과 붙임 파일을 옮긴다. "앞으로 자동으로 정리"를 켜 두면 다음부터 새 공문은 묻지 않고 정리한다(설정 → 기타에서 변경).
3. 공휴일은 연결할 때 인터넷에서 가져온다(30일마다 갱신). 내부망이면 내장 2026·2027년 목록을 쓴다.

| `*` | 처리기간이 준용(확인 필요)이거나 설정되지 않은 항목이 섞여 있음 — 칸에 마우스를 올리면 내용 표시 |
| <span>시행 ✔</span> <span>성적서 3/3</span> | 시행공문 일치 / 성적서가 시료 3개 모두 일치. `△`·노랑 = 일부 일치 또는 기관명 확인 필요, 회색 `—` = 아직 없음 |
| 왼쪽 초록 줄 | 시행공문·성적서가 모두 도착해 완료 가능한 공문 |
| `첨부`·`직접` 꼬리표 | 시료 목록을 첨부 HWPX에서 읽음 / 직접 입력함 |

### 3.5 일상 업무 순서
1. 의뢰공문(+붙임 HWPX)을 공문 폴더에 저장 → 창으로 돌아오면 자동으로 읽고 공문별 폴더로 정리.
2. 시료가 들어오면 **[시료접수일]** 칸을 눌러 달력에서 날짜 선택(13시 이전 접수면 상세 패널에서 체크). 처리기한·남은 일수가 바로 계산된다.
3. 매일 **보기 → 처리기한 임박·초과**로 급한 시료 확인.
4. 시행공문(결과 알림 ODT)과 성적서 PDF를 공문 폴더(또는 받은 파일함 폴더)에 저장 → 자동으로 짝지어 `시행 ✔ 성적서 n/n` 표시.
5. 확인한 공문을 **완료 체크** → **[완료 체크한 공문 처리 완료]** → 시행공문·성적서가 공문 폴더로 들어가고, 공문 폴더는 `성적처리완료`로 이동.
6. 필요하면 상세 패널에서 메모·이력을 적고 **[이력 문서 Word/PDF]**.

### 3.6 특이 공문 (시료 목록을 HWPX로 첨부한 공문)
- 본문에서 시료 표를 못 찾으면, 같은 공문 폴더(정리 전이면 같은 폴더에서 **붙임 이름이 맞는** 파일)의 HWPX 표를 읽는다.
- `의뢰항목`처럼 검사항목 열이 있는 표가 시료 목록이 되고, `하천명`·`소하천명`·`지점명` 열이 시료번호가 된다. 병합된 항목 칸은 모든 행에 적용하고, `(추가) COD, 클로로필a`는 그 행에만 더한다.
- 같은 이름이 있는 다른 표(대상하천 목록)의 시군·위치는 **채취지점**에 넣는다.
- 붙임 이름이 다르거나 HWP(구형)·스캔 그림이라 못 읽으면 → 상세 패널 **[시료 직접 입력]**: 엑셀·한글 표를 복사해 붙여넣기(탭 구분, 첫 줄 머리글 자동 인식, 병합 칸 빈칸은 위 값 사용). 저장하면 `_시료이력.json`에 보관되어 다시 열어도 유지된다. [직접 입력을 지우고 자동 추출로 되돌리기]로 해제.

| 특이 공문 실데이터 결과 | |
|---|---|
| 붙임 이름 대조 | `대상하천.hwpx`·`의뢰항목.hwpx` 모두 일치(점수 1.0) |
| 시료 | 13개 (신천1(신천상류) … 마개미천), 용암교·청담천-상은 COD·클로로필a 추가 |
| 채취지점 | `시군: 양주시 / 수질측정지점 위치: 백석읍 오산3리(방성천 합류전)` 등 |

### 3.7 처리기한 ([별표 2] 표준처리기간)

| 일수 | 항목 |
|---|---|
| 2일 | pH, 수온(온도), DO — 현장 측정 |
| 5일 | SS, COD, 색도, 총대장균군 |
| 7일 | T-P(총인), T-N(총질소), 페놀류, 시안, 불소, n-H(노말헥산추출물질), ABS |
| 8일 | 철, 아연, 구리, 카드뮴, 납, 망간, 크롬, 6가크롬 |
| 9일 | BOD |
| 11일 | 수은, 비소 (TCE·PCE·VOC 등) |
| 준용(확인 필요) | TOC 5일(COD 준용), 대장균군 5일(총대장균군 준용) — `*` 표시 |
| 설정 필요 | 생태독성, 클로로필a — 별표에 없음. [휴일·처리기간 → 처리기간]에서 일수 입력 |

**계산 규칙**
1. 시작: 시료접수일. **13시 이후 접수(기본)** 는 접수일을 세지 않고, **13시 이전 접수**를 체크하면 접수일이 근무일일 때 1일째로 센다(비고 1).
2. 토·일·공휴일·지정 휴일을 빼고 근무일로 n일째 날이 **처리기한**.
3. **처리기한 기준(전체 설정)**: 한 시료에 항목이 여러 개면 — **가장 긴 항목**(기본) 또는 **가장 짧은 항목**. [휴일·처리기간 → 처리기간] 맨 위에서 고른다.
4. 남은 기간 = 오늘 다음 날부터 기한까지의 근무일 수(기한 당일 = `오늘 마감`). 기한이 지나면 **달력일**로 `n일 초과`(2.나).

**예시** (2026년, 13시 이후 접수)

| 접수 | 항목 | 기준 | 처리기한 |
|---|---|---|---|
| 10.26(월) | SS 5일 | — | 화·수·목·금(4) + 다음 월 → **11.02(월)** |
| 10.26(월) | BOD·SS·T-P | 긴 항목(BOD 9일) | **11.06(금)** |
| 10.26(월) | BOD·SS·T-P | 짧은 항목(SS 5일) | **11.02(월)** |
| 10.02(금) | SS 5일 | — | 10.05 대체공휴일·10.09 한글날 제외 → **10.13(화)** |
| 10.24(토) | SS 5일 | — | 토요일 접수 → **10.30(금)** |

### 3.8 휴일 달력 ([휴일·처리기간])
- **휴일 달력** 탭: 빨강 = 공휴일, 주황 = 지정 휴일, 초록 = 근무일로 지정.
  - 평일을 누르면 **지정 휴일**(기관 휴무일·창립기념일 등).
  - 공휴일·토·일을 누르면 **근무일로 지정**(토요 근무 등).
  - 다시 누르면 원래대로.
- [인터넷에서 공휴일 다시 가져오기]: `holidays.hyunbin.page`(우주항공청 특일 정보 기반) → 안 되면 `date.nager.at`. 대체공휴일·선거일 포함. 실패하면 내장 목록(2026·2027)을 쓴다.
- 설정은 `_설정.json`에 저장되어 같은 공문 폴더를 쓰는 다른 PC에도 적용된다.

### 3.9 시행공문·성적서 대조 규칙

| 대상 | 일치 조건 |
|---|---|
| 시행공문 | 본문의 `○○과-번호(날짜)호` 번호 = 의뢰공문의 **시행** 번호, 앞의 기관명이 의뢰기관과 맞음(다르면 `△ 기관 확인`) |
| 성적서 | **공문번호** = 시행 번호 **그리고** 시료명 = 시료번호(공백·괄호 무시) **그리고** 의뢰기관이 맞음(`경기도기후환경관리과` ⊃ `경기도`) |
| 일치(초록) | 의뢰공문의 모든 시료가 성적서에 있고, 공문에 없는 시료가 없음 |
| 일부(노랑) | 일부 시료만 있거나(예: 동두천 중간부적합 성적서 1/3), 공문에 없는 시료가 섞였거나, 기관명이 다름 |

- 한 성적서 파일에 두 공문의 시료가 있으면(예: `환경과-27386`·`27513`) 두 공문 모두에 연결된다.
- 공문 폴더 안에 직접 넣은 시행공문·성적서는 번호가 달라도 그 공문 것으로 본다.
- 짝을 못 찾은 파일은 알림줄 [목록 보기]에서 확인하고, 상세 패널 [첨부 파일] 칸의 "짝을 찾지 못한 파일 — 이 공문에 넣기"로 직접 옮길 수 있다.

### 3.10 처리 완료 · 되돌리기
- [처리 완료] 창에서 공문별 시행공문·성적서 상태를 보여 준다.
  - 일치한 시행공문·성적서 → 공문 폴더로 **이동**.
  - 아직 처리하지 않은 다른 공문도 쓰는 성적서 → **복사**(원본은 남김). 마지막 공문을 처리할 때 이동한다.
  - "일부만 일치하는 파일도 함께 옮기기"를 켜면 노랑 파일도 옮긴다.
  - "공문 폴더를 성적처리완료로 옮기기"(기본 켬)
- 폴더 이동은 파일을 하나씩 옮기고, 중간에 실패하면 옮긴 파일을 되돌린다. 한글·PDF 뷰어에서 파일이 열려 있으면 실패 안내가 나오고 완료 체크는 남는다.
- **되돌리기**: 보기 → 성적처리완료 폴더 → [되돌리기] → 공문 폴더가 통째로 돌아온다(시행공문·성적서 포함). v1.x에서 옮긴 낱개 ODT도 그대로 되돌릴 수 있다.

### 3.11 메모 · 이력 · 이력 문서
- **메모**: 공문별 자유 메모(자동 저장).
- **시료 이력**: 일자·시료(전체 또는 특정 시료)·내용을 추가. 시료접수일 입력, 폴더 정리, 처리 완료, 되돌리기, 직접 입력, 이력 문서 작성은 **자동 기록**(회색)된다. ✕로 삭제.
- **[이력 문서 Word] / [이력 문서 PDF]**
  - 대상: 공문 전체 또는 시료 하나(성적서는 그 시료의 쪽만, 이력은 그 시료+전체 항목만).
  - 순서: 요약(의뢰기관·공문번호·접수·시료접수일·채취자·폴더) → 시료 표(처리기한·성적서 접수번호·결과·판정) → **그림**: 의뢰공문(워터마크 선택) · 시행공문 · 시험성적서 · 추가 자료(공문 폴더의 HWPX·그림·PDF) → **메모·이력 글**.
  - 있는 문서만 들어간다(의뢰공문만 있으면 의뢰공문만).
  - 기본 저장 위치는 **공문 폴더**(`이력_시료번호_날짜.docx`). 끄면 저장 위치를 묻는다. `이력_`으로 시작하는 파일은 다음 이력 문서의 추가 자료에서 빠진다.
  - HWP(구형)·TIF 등 그림으로 못 바꾸는 파일은 이름만 적힌다.

### 3.12 워터마크 (시료접수일 표시)
- 도구줄 또는 문서 보기의 **접수일 워터마크**를 켜면, 시료접수일을 **입력한** 공문의 의뢰공문 우측 상단에 빨간 도장 모양으로 `시료접수일 2026. 10. 22.(목)`을 표시한다(13시 이전 접수면 함께 표시).
- 화면, [새 창으로 크게 보기·인쇄], 이력 문서에 들어간다. **원본 ODT 파일은 바꾸지 않는다.**

## 7. 주의
- `_처리상태.json`·`_시료이력.json`·`_설정.json`은 지우지 않는다(완료 체크·메모·이력·시료접수일·휴일 설정이 사라짐).
- 원본 공문·성적서 파일의 **내용은 바꾸지 않는다**(읽기·옮기기·복사만). 워터마크는 화면·인쇄·이력 문서에만 그린다.
- 처리기간은 [별표 2]를 기본으로 하되, 준용·미설정 항목(`*`)은 기관 기준으로 확인해 설정한다.
- `공문추출기.html`을 직접 고치지 않는다(빌드 때 덮어씀). 고칠 때는 `소스/`의 부품을 고치고 빌드한다.
- 실제 Windows 업무 PC(Edge·한글·PDF 뷰어 파일 잠금, 공유폴더, 빌드_windows.bat) 환경은 개발 중 시험하지 못했다. 처음에는 공문 한두 건으로 폴더 정리·처리 완료·되돌리기를 확인한다.
