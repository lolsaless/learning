# 검사의뢰 공문 추출기 v2.2

수질검사 의뢰 공문(ODT)을 공문 폴더에서 모두 읽어 **시료 1개당 1행**으로 보여 주고, 공문별 폴더 정리 · 처리기한 관리 · 시행공문/성적서 대조 · 메모·이력 문서까지 한 화면에서 처리합니다.

## 쓰기
`공문추출기.html`을 **Edge**로 열고 → [공문 폴더 선택] → [파일 보기 및 편집 허용]. (기능 설명: `문서/매뉴얼_v2.2.md`)

## 고치기 (v2.1부터)
1. `문서/부품지도.md`에서 고칠 부품을 찾는다.
2. `소스/` 안의 그 파일만 고친다.
3. **Windows `빌드_windows.bat` / Mac `빌드_mac.command`** 더블클릭 → `공문추출기.html`이 새로 만들어진다.

자세한 방법: `문서/수정방법.md`
