# 검사의뢰 공문 추출기 — 변경 이력

## v1.1 (2026-10-22)

### 1. 시료 표 미인식 문제 해결 (동두천시 공문)

**현상**
`개인하수처리(오수처리)시설 방류수 수질검사 의뢰(동두천-10-1~3)` 공문에서 상단·하단(의뢰기관, 시행·접수, 주소 등)은 정상으로 읽혔지만 시료 표를 찾지 못해 "시료표 미인식"으로 표시됨.

**원인**
이 공문의 시료 표는 시료번호 열 제목이 **`시료명`**이다.

| 연번 | 시료명 | 지역 | 검사의뢰항목 | 시료채취량 및 채취용기 | 업종 | 채수목적 |
|---|---|---|---|---|---|---|
| 1 | 동두천-10-1 | 기타 | BOD, SS | PE 2L × 1병 | 소매점 | 지도점검 |

v1.0은 열 제목에 `번호`가 있어야만(`시료번호`, `검사지시번호`, `검사의뢰번호`) 시료 표로 판정했기 때문에 표 전체를 건너뛰었다.

**조치** — 열 제목만 보지 않고 **칸 안의 값 모양**까지 함께 판정
1. 열 제목에 `번호`가 있으면 그 열 (`검체번호` 추가)
2. 열 제목이 `시료명`·`검체명`·`시료코드` 등이면서 값의 60% 이상이 시료번호 모양(숫자-숫자, 날짜 아님)이면 그 열
3. 열 제목이 낯설어도 검사항목 열이 있는 표라면, 값이 시료번호 모양인 열을 찾아 사용
4. 시료번호로 쓰지 않은 `시료명`(예: 오수·폐수)은 `업종/성상`으로 보관

**결과**: 동두천-10-1, 10-2, 10-3 → 3행 정상 추출 (지역 기타, 업종 소매점·집회장·공중화장실, 채수목적은 `기타` 열). 표·본문 모두 채취일이 없어 "채취일자 확인 필요"로 표시됨 (설계대로).

### 2. 검사항목 안의 기준 표기 일반화
`BOD(20이하), SS(20이하)`처럼 항목 칸에 기준을 함께 적는 양식과 유사 표기를 모두 분리한다.

| 공문 표기 | 결과 |
|---|---|
| `BOD(20이하)`, `SS(20 이하)`, `BOD (20㎎/L 이하)` | 항목 BOD/SS, 기준 20 |
| `BOD(기준 20)`, `TOC(≤25)` | 기준 20 / 25 |
| `T-P(0.5미만)` | 기준 `0.5 미만` |
| `pH(5.8~8.6)` | 기준 `5.8~8.6` |
| `대장균군(3,000개/mL)` | 기준 `3,000` |
| `BOD 20이하`, `SS: 20` | 기준 20 (항목명이 사전에 있을 때만) |
| `n-H(광)(5)` | 항목 n-H(광), 기준 5 (기존 유지) |
| `n-H(광)`, `6가크롬`, `BOD5` | 기준 없음 (잘못 분리하지 않음) |

### 3. 화면·엑셀
- 접수일 **최근 순(내림차순)** 기본 정렬 (같은 날은 접수번호 큰 순). 접수일 머리글을 누르면 오래된 순으로 전환.
- 기본 열 순서: **접수일 · 의뢰기관 · 의뢰자 · 발신명의 · 시행 · 시료번호 · 검사항목 · 시료채취일** (+ 확인필요). 기준·지역구분·채취자·접수번호 등은 [열 선택]에서 켬.
- 엑셀 열 순서도 같은 순서로 변경 (`상태` 다음에 위 8개 열).
- v1.0에서 저장한 열 선택은 쓰지 않고 새 기본값을 적용 (HTML: `odt-cols-v11`, 파이썬: `cols_v11`).

### 4. 원본 보기
- **HTML 판**: 행을 누르면 오른쪽 패널에 **추출 결과와 원본 공문이 나란히** 표시. [추출 결과]·[원본 보기]·[나란히] 전환(선택 기억), [새 창으로 크게 보기](인쇄 가능), [원본 파일 열기](내려받아 한글로 열기).
- **파이썬 판**: 하단·추출 결과 창에 [원본 미리보기](서식 그대로 브라우저 창), [원본 파일 열기](한글 등 기본 프로그램으로 바로 열기). 명령줄 `--preview`, `--preview-out` 추가.
- 원본 미리보기는 ODT 안의 쪽 너비, 표 열 너비·테두리·병합, 글꼴 크기·굵기·정렬, 로고 그림을 읽어 다시 그린다.

- 엑셀 저장(전 셀 텍스트), 기준표 양식 생성
