# 검사의뢰 공문 추출기 v2.0

수질검사 의뢰 공문(ODT)을 공문 폴더에서 모두 읽어 **시료 1개당 1행**으로 보여 주고, 공문별 폴더 정리 · 처리기한 관리 · 시행공문/성적서 대조 · 메모·이력 문서까지 한 화면에서 처리합니다.

## 바로 쓰기
`공문추출기.html`을 **Edge**로 열고 → [공문 폴더 선택] → [파일 보기 및 편집 허용].

## v2.0에서 바뀐 것
1. 시료 목록을 **HWPX로 첨부한 공문** 처리 (못 읽으면 [시료 직접 입력]으로 붙여넣기)
2. **시행공문·시험성적서(PDF)** 를 읽어 공문번호·시료명·의뢰기관으로 자동 대조
3. 공문마다 **`의뢰기관_제목_시행번호` 폴더** 자동 생성, 처리 완료 시 시행공문·성적서를 폴더로 옮기고 폴더째 `성적처리완료`로
4. 시료접수일 **달력** 입력 → [별표 2] **처리기한·남은 일수**, 임박 빨간색. 기준은 **가장 긴 항목 / 가장 짧은 항목** 중 선택
5. **공휴일 자동**(인터넷, 없으면 내장 2026·2027) + 클릭으로 **지정 휴일**
6. 공문·시료별 **메모·이력**, 공문·시행공문·성적서·추가 자료를 그림으로 넣은 **이력 문서(Word·PDF)**
7. 의뢰공문 우측 상단 **시료접수일 워터마크** (켜고 끄기, 원본 파일은 그대로)
