# 시험장비관리대장 DB 프로그램 사용법

한글 문서(시험장비관리대장)를 **엑셀 마스터 + HTML 카탈로그 + Word 양식**으로 바꾸고 관리하는 프로그램입니다.
Windows + VS Code + Python 3.10 이상 기준입니다.

---

## 1. 파일 구성

같은 폴더에 아래 4개 파일을 함께 두세요. (`ledger_common.py`가 없으면 나머지 둘이 실행되지 않습니다.)

| 파일 | 역할 | 직접 실행 |
|---|---|---|
| `equipment_extract.py` | 한글 문서(HWP)에서 데이터·사진을 추출해 엑셀/DB/CSV/사진 생성. 끝에서 HTML·Word를 자동 생성 | O |
| `make_catalog.py` | 마스터 엑셀 → HTML 카탈로그 (금액 필터, 엑셀 내보내기, 양식 인쇄) | O |
| `make_ledger_docx.py` | 마스터 엑셀 → 시험장비관리대장 양식 Word 문서 | O |
| `ledger_common.py` | 위 두 스크립트가 공유하는 엑셀 읽기 규칙·양식 치수 | X (불러 쓰기만 함) |

---

## 2. 설치 (최초 1회)

VS Code 터미널에서:

```
pip install olefile pandas openpyxl Pillow python-docx
```

- SQLite는 Python에 기본 포함되어 있어 따로 설치하지 않습니다.
- `.db` 파일을 눈으로 보려면 VS Code 확장 **SQLite Viewer** 또는 **DB Browser for SQLite**(무료)를 사용하세요.

---

## 3. 처음 실행하기 (한글 문서 → 모든 결과물)

1. 스크립트 4개와 한글 문서(예: `장비관리대장.hwpx`)를 한 폴더에 둡니다.
2. VS Code에서 그 폴더를 열고 터미널에서 실행합니다.

```
python equipment_extract.py 장비관리대장.hwpx --docx
```

3. `output` 폴더에 결과가 만들어집니다.

| 결과물 | 내용 |
|---|---|
| `equipment.xlsx` | **마스터 엑셀** (아래 4절 참고) |
| `catalog.html` | HTML 카탈로그 (브라우저로 열기) |
| `ledger.docx` | 시험장비관리대장 Word 양식 (`--docx`를 붙였을 때만) |
| `images/` | 장비 사진 원본 PNG (`04-장비-05_1.png` 형식, 사진이 여러 장이면 `_2`, `_3`…) |
| `logo.png` | 양식 왼쪽 위 로고 |
| `equipment.db` | SQLite 데이터베이스 |
| `csv/` | 테이블별 CSV (UTF-8 BOM, 엑셀에서 한글 정상 표시) |
| `report.txt` | 추출 리포트 (누락·경고·확인 필요 목록) |

> 파일 경로에 공백이나 한글이 있으면 따옴표로 감싸세요: `python equipment_extract.py "내 문서\장비관리대장.hwpx"`

### 옵션

| 옵션 | 설명 |
|---|---|
| `--out 폴더` | 결과 폴더 지정 (기본 `output`) |
| `--limit 5` | 앞 5건만 시험 실행 |
| `--debug-record 04-장비-43` | 해당 장비의 셀 구조와 파싱 결과를 화면에 출력 (파일은 만들지 않음) |
| `--no-thumbs` | 엑셀 photos 시트에 썸네일을 넣지 않음 |
| `--no-html` | HTML 카탈로그 생성 생략 |
| `--docx` | Word 양식(`ledger.docx`)도 생성 (전체 약 17MB, 사진 포함) |

스크립트 맨 위의 `HWP_PATH`, `OUT_DIR`를 고쳐 두면 인자 없이 `python equipment_extract.py`만으로도 실행됩니다.

## 4. 마스터 엑셀 (`equipment.xlsx`)

앞으로 **이 엑셀이 원본 데이터**입니다. 고치거나 추가하는 것은 이 파일에서 하세요.

### 시트 구성

| 시트 | 내용 |
|---|---|
| `equipment` | 장비 1건 = 1행 |
| `components` | 장비구성내역 (관리번호, 연번, 장비명, 수량, 단위) |
| `history` | 수리·교정 이력 (관리번호, 일자, 내용, 교정 여부, 성적서번호, 불확도) |
| `photos` | 사진 목록 (관리번호, 순번, 파일경로, 크기, 썸네일) |

### equipment 시트의 열

| 열 | 설명 |
|---|---|
| 순번 | 추출 순서 번호 |
| 관리번호 | `04-장비-05` (괄호 없음). **다른 시트와 연결하는 기준 값** |
| 물품명, 스펙, 제조사, 제조국 | 형식 및 규격 / 제작회사(제조국) |
| 도입시기(날짜) | `YYYY-MM-DD` (기간·복수 날짜는 첫 날짜만) |
| price_raw | 원문 도입가격 (`1 086 000`, `7,590,000 x 2대` 등) |
| price_krw | 정수 금액. `x N대` 표기는 **단가**, `+`·괄호 병기는 **합계** |
| 장비대수 | `x N대` 표기면 N, 아니면 1. 총액 = price_krw × 장비대수 |
| 도입 회사명, 도입처 주소 | 도입처 |
| 연락처 | 대표 전화번호 1개 |
| 사용 용도 | 용도 및 특기사항 |
| 상태 | 신품 / 중고품 |
| 내용 | 주요 성능 및 특징 (줄바꿈 유지) |
| 물품분류번호 | `41115404-23680632` 형식 (내용에서 추출) |
| 관리 이력 | 이관·관리전환 문구 (내용에서 추출) |
| 연락처 비고 | 대표번호 외 담당자·팩스·두 번째 번호 등 원문 |

### 엑셀을 고칠 때 주의

- **관리번호를 바꾸면** `components`, `history`, `photos` 시트의 관리번호도 똑같이 바꿔야 연결이 유지됩니다.
- 행을 정렬하거나 지워도 됩니다. 시트 간 연결은 순번이 아니라 관리번호로 합니다.
- **사진을 추가**하려면 사진 파일을 `images` 폴더에 넣고, `photos` 시트에 행을 추가합니다 (`mgmt_no`, `seq`, `file_path` = `images/파일명.png`).
- 열 머리글 이름을 바꾸면 `ledger_common.py`의 `COLS`도 같은 이름으로 고쳐야 합니다.
- `연락처 비고` 등 없어도 되는 열은 삭제해도 동작합니다. 필수는 `관리번호` 열입니다.
- `사진`은 엑셀과 **같은 폴더 기준** `images/…` 경로를 찾습니다. 엑셀만 다른 곳으로 옮기면 사진이 빠집니다.

---

## 5. ⚠ 가장 중요한 주의: 다시 추출하면 엑셀 수정이 사라집니다

`equipment_extract.py`는 한글 문서에서 처음부터 다시 만들기 때문에, 이미 수정한 `equipment.xlsx`를 **덮어씁니다.**

| 하려는 일 | 실행할 것 |
|---|---|
| 처음 한 번, 또는 한글 문서를 다시 추출 | `equipment_extract.py` (덮어써도 되는 폴더에서, 또는 `--out`을 새 폴더로) |
| **엑셀을 고친 뒤** HTML/Word 갱신 | `make_catalog.py`, `make_ledger_docx.py` 만 실행 |

권장: 추출을 끝낸 뒤 `equipment.xlsx`를 별도 폴더로 복사해 그것을 마스터로 쓰고, `images/`, `logo.png`도 같이 옮기세요.

## 6. HTML 카탈로그

### 생성 / 갱신

```
python make_catalog.py output/equipment.xlsx
```

| 옵션 | 설명 |
|---|---|
| `--out 파일.html` | 저장 위치 (기본: 엑셀과 같은 폴더의 `catalog.html`) |
| `--photo-max 800` | HTML에 넣을 사진 최대 크기(px, 기본 640). 키우면 선명하지만 파일이 커집니다 |

`catalog.html`은 **파일 하나**(약 2MB, 사진 포함)이고 인터넷 없이 브라우저에서 열립니다. 더블클릭하면 됩니다.

### 화면 기능

- **검색**: 관리번호, 물품명, 제조사, 도입처, 성능 등 전체 텍스트 (공백으로 여러 단어 = 모두 포함)
- **금액 필터**
  - 기준 선택: **단가**(도입가격) / **총액**(단가 × 장비대수)
  - 최소~최대 입력, 단위 선택(원 / 만원 / 억원)
  - 빠른 구간 버튼: 100만 미만 · 100만~1천만 · 1천만~1억 · 1억 이상
  - 금액 정보가 없는 장비는 금액 필터를 켜면 제외됩니다
- 도입연도 범위, 제조국, 사진 있는 장비만 보기
- 정렬: 순번 / 금액 / 도입일 / 물품명
- 카드 보기 ↔ 표 보기, 장비를 클릭하면 상세(사진, 성능, 구성내역, 이력)
- 상단에 필터 결과 건수, 금액 합계, 사진 있는 건수

### 엑셀로 내보내기

`엑셀로 내보내기 (N건)` 버튼 → **현재 필터 결과만** `.xlsx`로 저장됩니다.
사진은 제외하고 텍스트만 들어가며, 시트는 `equipment`(마스터와 같은 열), `components`, `history`입니다.
파일명은 `장비목록_날짜_시각.xlsx`입니다.

### 양식으로 인쇄

`양식으로 인쇄 (N건)` 버튼 → 현재 필터 결과를 원본 **시험장비관리대장 양식(가로 A4, 앞면+뒷면)** 으로 새 창에 엽니다.
새 창의 `인쇄 / PDF 저장` 버튼으로 인쇄하거나 PDF로 저장합니다. 장비 상세 창의 `이 장비 양식으로 인쇄`는 한 건만 엽니다.

- 새 창이 안 열리면 브라우저의 **팝업 차단을 해제**하세요.
- 인쇄 창에서 **배율 100%**, **여백 없음/기본**으로 두면 한 장비가 2쪽으로 맞게 나옵니다.

## 7. Word 양식 생성 (`make_ledger_docx.py`)

원본 양식과 같은 표 격자로 장비마다 **앞면 1쪽 + 뒷면 1쪽**을 만듭니다.

```
python make_ledger_docx.py output/equipment.xlsx
```

| 옵션 | 설명 |
|---|---|
| `--out 파일` | 저장 위치 (기본: 엑셀과 같은 폴더의 `ledger.docx`) |
| `--only 04-장비-05,04-장비-43` | 지정한 관리번호만 생성 (**처음에는 한 건으로 확인 권장**) |
| `--per-file` | 장비별로 파일을 따로 생성 (`ledger_docx/` 폴더) |
| `--font "맑은 고딕"` | 글꼴 지정. 기본은 원본 글꼴 `경기천년바탕 Regular` |

- **한글(HWP)로 쓰려면**: 만든 `.docx`를 한글에서 열고 `.hwp` / `.hwpx`로 다시 저장하세요. (프로그램이 `.hwpx`를 직접 만들지는 않습니다.)
- 원본 글꼴이 PC에 없으면 다른 글꼴로 대체되어 줄바꿈이 달라지고 쪽이 넘칠 수 있습니다. 그때는 `--font "바탕"` 등으로 지정하세요.
- 자동 조정되는 부분
  - 장비구성내역이 5행을 넘으면 행 높이를 줄여 한 쪽에 맞춥니다.
  - 주요 성능 글이 길면 글자 크기를 10 → 6.5pt까지 줄입니다.
  - 이력이 18건을 넘으면 뒷면이 추가로 이어집니다 (왼쪽 9칸 → 오른쪽 9칸 순서).
  - 사진은 최대 4장까지 (1장 크게 / 2장 나란히 / 3~4장 2×2).
- 로고는 엑셀과 같은 폴더의 `logo.png`를 씁니다. 없으면 로고 없이 만들어집니다.

## 8. SQLite DB 보기 / 활용

`equipment.db`는 `equipment`, `components`, `history`, `photos` 4개 테이블입니다.
(DB의 열 이름은 영문이며, 마스터 엑셀과 열 구성이 조금 다릅니다. 예: `price_krw`, `unit_count`, `condition`.)

파이썬으로 바로 읽기:

```python
import sqlite3, pandas as pd
con = sqlite3.connect("output/equipment.db")
df = pd.read_sql("select mgmt_no, name, price_krw, unit_count from equipment where price_krw >= 10000000", con)
print(df)
```

> 엑셀을 수정해서 마스터로 쓰는 경우 DB는 수정 내용을 반영하지 않습니다. DB는 최초 추출 시점의 기록입니다.

## 9. 눈으로 확인해야 할 부분 (현재 문서 기준)

`report.txt`에 자동으로 정리됩니다.

- **양식이 다른 장비**: 04-장비-64는 형식및규격·제작회사·주소·전화번호가 비어 있고, 04-장비-68은 주소가 비어 있습니다 (원본 양식이 달라서 해당 칸이 없음).
- **도입가격 6건**: 04-장비-64(합산), 89·90·93·101(단가×대수), 92(괄호 병기)는 규칙에 따라 계산한 값이므로 원문(`price_raw`)과 대조하세요.
- **04-장비-91의 장비대수**: 코드는 1로 채웁니다.
- **주요 성능(내용)이 빈 장비 29건**: 원본 셀이 실제로 비어 있는 것을 확인한 경우(04-장비-43)가 있습니다. 나머지도 원본과 대조를 권합니다.
- **입고시 상태**: 현재 문서는 60건 모두 신품으로 체크되어 있습니다.
- **04-장비-07~08**(범위 표기), **04-장비-08**(제목에 "(X)")은 경고만 표시하고 의미는 판단하지 않습니다.
- 도입년월일이 기간·복수 날짜(예: `2010.04.23.~ 05.06.`)인 경우 **첫 날짜만** 정규화되어 들어갑니다.
- 원문의 오탈자(예: `이온크로마토그패피`)는 그대로 보존합니다.

## 10. 문제 해결

| 증상 | 해결 |
|---|---|
| `ModuleNotFoundError: No module named ...` | 2절의 `pip install` 명령을 다시 실행 |
| `HWP(OLE) 형식이 아닙니다` | 파일이 진짜 `.hwpx`(ZIP)인 경우입니다. 한글에서 **`.hwp`로 다시 저장**해서 사용 (이 프로그램은 구형 바이너리 HWP 5.0을 읽습니다) |
| `입력 파일을 찾을 수 없습니다` | 파일 경로 확인, 공백·한글이 있으면 따옴표 사용 |
| 카탈로그·Word에 사진이 없음 | 엑셀과 같은 폴더에 `images/`가 있는지, `photos` 시트의 경로가 맞는지 확인 |
| `ledger_common` import 오류 | 4개 파일이 같은 폴더에 있는지 확인 |
| 양식 인쇄 창이 안 열림 | 브라우저 팝업 허용 |
| Word 문서가 쪽수가 늘어남 | `--font`로 PC에 있는 글꼴 지정, 성능·구성 내용이 매우 긴 장비인지 확인 |
| 엑셀 수정 내용이 사라짐 | 5절 참고. 수정 후에는 `equipment_extract.py`를 다시 실행하지 마세요 |
| 엑셀에서 열 이름을 바꿨더니 값이 안 나옴 | `ledger_common.py`의 `COLS`를 바뀐 머리글과 똑같이 수정 |

## 11. 자주 쓰는 명령 모음

```
# 처음 전체 실행 (엑셀 + HTML + Word)
python equipment_extract.py 장비관리대장.hwpx --docx

# 5건만 시험
python equipment_extract.py 장비관리대장.hwpx --limit 5

# 특정 장비 파싱 결과 확인
python equipment_extract.py 장비관리대장.hwpx --debug-record 04-장비-43

# 엑셀 수정 후 HTML 카탈로그 갱신
```
