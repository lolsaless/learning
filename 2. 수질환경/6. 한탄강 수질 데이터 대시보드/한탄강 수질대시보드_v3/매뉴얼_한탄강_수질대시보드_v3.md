# 한탄강 수계 수질 대시보드 매뉴얼 (v3)

> 엑셀 DB 한 개와 `대시보드_열기.bat` 하나로 그래프 보기 → 경향 분석 → 지점 정보 수정·저장까지 처리하는 도구

---

## 1. 최초 기획

### 1.1 배경
- 원래 자료는 **월별 시트**와 **항목별 요약 시트**로 나뉘어 있어 매달 옮겨 적는 반복 작업이 많았다.
- v1에서 DB를 한 장으로 재구성하고 대시보드를 만들었다.
- v2에서 V월드 지도, 종단 그래프, 자료 점검을 추가했다.
- v3는 사용자 검토 의견을 반영한 버전이다.

### 1.2 v3 요구사항과 반영 결과
| 번호 | 요구사항 | 반영 내용 |
|---|---|---|
| 1 | 잘못 제공된 측정망 좌표(hwpx) 적용분 제거 | 포천천3 좌표를 원래 추정값으로 되돌렸다. 측정망지점 시트, 지도 참고 레이어, 가져오기 기능을 모두 삭제했다. |
| 2 | 분류체계 정리 | 임의로 만든 '수계' 묶음(본류/영평천 수계/신천 수계)을 없앴다. **하천명(대분류) 15개 → 시료번호** 2단계로 바꾸고, 엑셀 열 이름도 `지점명` → **`시료번호`** 로 통일했다. |
| 3 | HTML에서 주소 직접 수정 | **지점 관리** 화면을 추가했다. 하천명·시군·주소·위도·경도·좌표상태·비고를 고치고 [변경 저장]을 누르면 DB 엑셀에 바로 저장된다. 지도를 눌러 위치를 지정할 수 있고, V월드 검색도 쓸 수 있다. |
| 4 | 경향 검토용 분석 기능 | **경향 분석** 화면을 추가했다. ① 추세 검정(Mann-Kendall·Sen 기울기) ② 항목 간 상관(Spearman, 산점도) ③ 월별 분포(상자그림) ④ 기준 초과율 |
| 5 | 대분류 클릭 시 시료번호별 색 자동 지정 | 하천명을 누르면 그 하천만 보이고, 시료번호마다 다른 색이 자동으로 정해진다. 최대 16개까지 고유 색을 쓴다. 🎲 버튼으로 무작위 재배정하고, ●로 직접 지정한다. |
| 6 | 값이 튀는 지점 선 강조 | **⚡ 특이 경향**: 기간 안에서 값이 급변한 시료번호를 자동으로 찾아 **굵은 점선 + 빛나는 테두리**로 그리고, 급변한 점은 ◆로 표시한다. 기준 z와 색은 바꿀 수 있다. |
| 7 | 전체 재검토 | 아래 1.3 참조 |

### 1.3 재검토 후 고친 사항
| 문제 | 수정 |
|---|---|
| 기본값으로 '한탄강 연4'가 강조되어 있어서, 한탄강을 골라도 나머지 3개 지점이 흐리게 보였다 | 기본 강조를 없앴다. 16개 이하일 때는 모든 시료번호가 제 색으로 보이고, ☆ 강조한 지점만 더 굵게 그린다. |
| 시료번호가 9개 이상(신천 13개)이면 모두 회색으로 보였다 | 16색 팔레트를 쓴다. 9~16번째는 같은 계열의 진한/연한 색에 네모(▪) 표식을 붙여 구분한다. |
| V월드 배경지도를 쓰려면 로컬 서버가 따로 필요했다 | `serve.py`가 서버 역할(지도·저장·V월드 검색)을 모두 맡는다. 엑셀을 고친 뒤 **새로고침하면 자동으로 다시 만든다.** |
| 월별 결과를 가져온 뒤 대시보드를 다시 만들어야 했다 | 서버가 켜져 있으면 새로고침(F5)만 하면 반영된다. |
| 이전 버전 서버가 같은 포트를 쓰고 있으면 저장이 되지 않았다 | 포트 충돌을 감지해 안내한다. |
| 추세 변화율이 9개월 자료를 연간으로 늘려 과장되었다 | 24개월 미만이면 **기간 전체 변화율**로 표시한다. |

### 2.1 분류체계(하천명 15개)
한탄강(4) · 포천천(3) · 금현천(1) · 송우천(1) · 영평천(5) · 외북천(2) · 수입천(1) · 신천(13) · 능안천(1) · 효촌천(1) · 덕계천(1) · 마개미천(1) · 회암천(1) · 청담천(1) · 상패천(1)

- 괄호 안은 시료번호 개수이다.
- 하천명은 '지점 관리'에서 바꿀 수 있다. 바꾸면 왼쪽 패널, 종단 그래프, 표의 묶음이 모두 따라 바뀐다.
- **정렬순서**는 하천 안에서 **상류 → 하류** 순서로 매긴다. 종단 그래프가 이 순서를 쓴다.

### 2.2 좌표상태
| 값 | 의미 |
|---|---|
| 확인 | 지도에서 직접 지정했거나 현장에서 확인한 좌표. V월드 일괄 검색이 바꾸지 않는다. |
| 브이월드 | V월드 검색 결과 |
| 추정 / 미입력 | 주소로 추정한 값 / 좌표 없음. 지도에서 점선 원으로 표시된다. |

현재 37개 시료번호의 좌표는 모두 **'추정'** 상태이다. '지점 관리'에서 보정하기를 권장한다.

### 3.1 분석 방법 설명
| 분석 | 방법 | 읽는 법 |
|---|---|---|
| **추세 검정** | **Mann-Kendall 검정**: 모든 두 시점 쌍의 증감 부호를 세어 단조 추세가 있는지 본다. 분포 가정이 없고 이상값에 강해 수질 추세 분석의 표준이다. **Sen 기울기**: 모든 쌍 기울기의 중앙값이다. 자료가 3년 이상이면 **계절 Mann-Kendall**(같은 달끼리 비교)로 자동 전환한다. | 진한 색은 p<0.05, 옅은 색은 p<0.1. 빨강 = 증가, 파랑 = 감소. 칸을 누르면 측정값과 Sen 추세선이 그려진다. |
| **항목 간 상관** | **Spearman 순위상관 ρ**(같은 시료·같은 달 값끼리 비교) + 산점도(로그 축 선택 가능) | SS·색도·T-P가 함께 높으면 강우 유출·토사 영향, BOD·TOC·T-N이 함께 높으면 오수 영향을 의심할 수 있다. 상관은 인과관계가 아니다. |
| **월별 분포** | 달마다 전체 시료번호 값의 상자그림(Tukey 1.5×IQR). 상자 밖 이상치에는 시료번호 이름을 표시한다. | 상자 전체가 오르면 수계 전체 요인(강우·계절), 점 하나만 튀면 국지 요인이다. |
| **기준 초과율** | 기준(목표·등급 상한·직접 입력)을 넘은 횟수 ÷ 측정 횟수 | 평균이 낮아도 초과율이 높으면 간헐적 오염원을 점검할 대상이다. |
| **⚡ 특이 경향** | 시료번호별 로버스트 z = 0.6745 × (값 − 중앙값) ÷ MAD의 최대값이 기준 이상(기본 8)이면 급변으로 본다. | 시계열에서 굵은 점선과 빛 테두리, 급변한 점은 ◆. 범례에서 이름을 누르면 강조된다. |

> 현재 자료는 9개월분이라 추세 검정은 **참고용**이다. 계절 변동과 장기 추세를 구분하려면 3년 이상 자료가 필요하다.

## 4. 설치 및 사용

### 4.1 설치(최초 1회)
1. Python 3.9 이상을 설치한다(**"Add python.exe to PATH"** 체크).
2. `대시보드_열기.bat`을 처음 실행하면 openpyxl을 자동으로 설치한다.
3. V월드 인증키의 서비스 URL에 `http://localhost:8765`를 등록한다. 배경지도와 검색에 필요하다.

### 4.2 평소 사용
1. **`대시보드_열기.bat`** 을 더블클릭한다. 검은 서버 창이 뜨고 브라우저에서 대시보드가 열린다.
2. 다 쓰면 서버 창을 닫는다. 창을 닫으면 저장·지도·검색 기능이 멈춘다.

### 4.3 매월 갱신
1. `도구모음.bat` → **2. 월별 결과 엑셀 가져오기** → 결과 파일을 끌어다 놓고 Enter.
2. 서버가 켜져 있으면 브라우저에서 **F5**만 누르면 된다. 꺼져 있으면 `대시보드_열기.bat`을 실행한다.
3. **자료 점검** 탭에서 이상값 의심·전월 동일 값을 확인하고, 잘못된 값은 엑셀에서 고친 뒤 F5.

### 4.4 주소·좌표 수정 (지점 관리)
1. 상단 **지점 관리** 탭을 연다. 지도 배너의 [정보 수정]이나 자료 점검의 [수정]을 눌러도 된다.
2. 칸을 고친다. 고친 칸은 노란색으로 표시된다.
3. 좌표를 넣는 방법
   - **[지도]**: 지도 화면으로 이동해 위치를 누른다. 좌표상태가 '확인'으로 바뀐다.
   - **[V월드]**: 주소의 지번과 다리 이름으로 후보를 찾는다. 원하는 후보를 누르면 적용된다. 시군 경계 밖 결과에는 ⚠가 붙는다.
   - 위도·경도를 직접 입력해도 된다.
4. **[변경 저장]** 을 누르면 DB 엑셀 지점정보 시트에 저장되고(이전 파일은 `백업` 폴더에 복사), 대시보드가 다시 열린다.
   - 엑셀에서 DB 파일을 열어 둔 상태면 저장되지 않는다. 엑셀을 닫고 다시 누른다.
   - HTML 파일을 직접 열었을 때는 수정 내용이 이 브라우저에만 임시 보관된다. `대시보드_열기.bat`로 열어 저장하거나, [표 복사]로 복사해 엑셀 지점정보 시트에 붙여넣는다.
5. [변경 취소]를 누르면 저장하지 않은 수정 내용이 모두 사라진다.

### 4.5 화면 사용법
| 화면·기능 | 설명 |
|---|---|
| 왼쪽 패널 | **하천명(굵은 글씨)을 누르면** 그 하천의 시료번호만 보이고 색이 자동으로 정해진다. 체크박스로 하천 전체 또는 시료번호를 고른다. ☆ 강조, ● 색 직접 지정(오른쪽 클릭: 자동색), ⚡ 특이 경향 표시 |

| ⚡ 특이 경향 | 표시 옵션에서 켜고 끈다. 기준 z(기본 8, 클수록 엄격)와 색은 색상 옵션에서 바꾼다. |
| 시계열 · 종단 · 히트맵 · 지도 · 연도별 색도 · 자료 점검 | v2와 같다. 종단은 하천명 기준으로 구성된다. |

| 인쇄·PDF | 선택한 시료번호·기간으로 7개 항목 그래프와 통계표 출력 |

## 6. 문제 해결
| 증상 | 해결 |
|---|---|
| 지점 관리에 "파일로 열림"이라고 나온다 | HTML을 직접 열었다. `대시보드_열기.bat`로 연다. |
| "포트를 다른 프로그램이 쓰고 있습니다" | 이전 버전 서버 창(v2 `대시보드_열기.bat`)을 닫고 다시 실행한다. |
| 저장 시 "엑셀에서 열려 있습니다" | DB 엑셀을 닫고 [변경 저장]을 다시 누른다. |
| V월드 검색·지도 실패 | 인터넷·방화벽(api.vworld.kr) 확인. 인증키 서비스 URL에 `http://localhost:8765`가 있는지 확인. 필요하면 설정 시트 VWORLD_DOMAIN에 등록한 주소를 입력한다. |
| 엑셀을 고쳤는데 반영이 안 된다 | 엑셀에서 저장했는지 확인하고 브라우저에서 F5. 서버가 꺼져 있으면 `대시보드_열기.bat` 실행 |
| 잘못 저장했다 | `백업` 폴더의 직전 파일을 복사해 되돌린다. |
