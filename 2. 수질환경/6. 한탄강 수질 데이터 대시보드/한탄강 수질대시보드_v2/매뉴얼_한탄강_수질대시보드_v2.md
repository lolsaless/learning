# 한탄강 수계 수질 대시보드 매뉴얼 (v2)

> 엑셀 DB 한 개를 고치고 `도구모음.bat` 메뉴 한 번으로 인터랙티브 HTML 대시보드를 다시 만드는 도구

---

## 1. 최초 기획

### 1.1 배경
- 기존 자료는 **월별 시트(202601~202609)** 와 **항목별 요약 시트(TOC·BOD·SS·TN·TP·색도)** 로 나뉘어 있었다. 매달 같은 값을 요약 시트 7장에 옮겨 적어야 해서 반복 작업이 많았다.
- v1에서 엑셀을 DB 한 장으로 재구성하고 HTML 대시보드를 만들었다.
- v1을 검토한 뒤 정리한 문제점(아래 1.3)을 v2에서 개선했다.

### 1.2 v1 요구사항(유지)
| 요구사항 | 구현 |
|---|---|
| 항목·지점(또는 전체) 선택 → 시계열 | 상단 항목 버튼 + 왼쪽 지점 패널(수계/하천 단위 일괄 선택) |
| 지점 평균보다 높거나 낮으면 포인트·값 표시 | ▲·▼ 표식과 값 라벨, 평균선 |
| 그래프 아래 데이터 표 | 월별 값 + 최대·최소·평균·표준편차·등급(또는 목표 달성) |
| 기본 색상 + 체크한 지점만 강조 | ☆ 강조 → 자동 색 지정, ● 눌러 색 직접 지정 |
| 색도 전체 지점 한눈에 | 히트맵(지점×월) |
| 지도에서 지점 클릭 → 그래프 배너 | 지도 화면 + 오른쪽 배너 |

### 1.3 v2 개선 내역
| 구분 | v1 문제 | v2 개선 |
|---|---|---|
| 지도 배경 | CARTO 정책 변경으로 "API Key Required" 문구가 뜸 | **V월드 배경지도**(일반·백지도·위성·하이브리드·야간). 불러오지 못하면 안내를 띄우고 시군 경계 화면으로 자동 전환 |
| 지점 좌표 | 37개 지점 모두 주소로 추정한 값 | 국가수질측정망 좌표 가져오기(포천천3 적용), **V월드 주소·다리 이름 검색으로 자동 보정** 도구, 추정 좌표는 지도에서 점선 테두리로 표시 |
| ▲▼ 판정 | 평균과 조금만 달라도 표시되어 거의 모든 값에 표시가 붙음 | 기본 **평균 ± 1σ 밖**일 때만 표시. 평균 ± p%, 전체, 끄기 중에서 선택. 정상 범위 띠 표시 |
| 분석 관점 | 상류→하류 흐름을 볼 수 없음 | **상·하류 종단 그래프** + 구간별 변화표(상류 대비 30% 이상 증가 구간 ▲ 표시) |
| 이상치 | 극단값(164도) 때문에 y축이 늘어나 나머지 지점이 바닥에 눌림 | y축 선택: 선형 / **이상치 잘라 보기** / 로그 |
| 빈 달 | 측정하지 않은 달도 선으로 이어 그림(COD) | 기본은 빈 달을 끊어 그림. 옵션으로 잇기 가능 |
| 자료 품질 | 전월 동일 값 점검 1가지뿐 | **자료 점검** 화면: 이상값 의심(지점 중앙값 대비), 전월 동일, 엑셀 검토표시, 정량한계 미만(`<0.5`), 같은 달 중복 채취, 추정 좌표 |
| 요약(KPI) | 37개 지점을 섞은 평균이라 의미가 약함 | 최근월 평균과 전월 대비 변화(상승·하락 지점 수), 기간 평균 최고 지점, 단일 최고값(점검 표시 포함), 기준 달성, 점검 건수 |
| 연도 비교 | 2026년(1~9월)을 연평균과 그대로 비교 | 부분 연도 경고문과 그래프 음영 표시 |
| 반복 작업 | 매월 행을 손으로 붙여넣기 | **월별 결과 가져오기**(YYYYMM 시트를 자동 추가, 같은 달은 교체) |
| 보고서 | 그림 저장만 가능 | **인쇄·PDF**(선택 지점·기간의 7개 항목 그래프와 통계표) |
| 설정 | 화면을 원래대로 되돌릴 수 없음 | `처음 화면으로` 버튼. DB `설정` 시트에서 기본값 지정 |

### 1.4 설계 원칙
1. **데이터는 엑셀 한 곳에만**: 요약값은 대시보드가 계산한다.
2. **1행 = 1지점 1회 채취(long 형식)**.
3. **단일 HTML 파일**: 라이브러리까지 파일 안에 넣어 내부망에서도 그래프가 열린다. 배경지도만 인터넷이 필요하다.
4. **DB 쓰기는 모두 공통 모듈(`wq_common.py`)이 맡는다**: 어떤 도구로 저장해도 양식이 같고, 저장 전에 `백업` 폴더로 자동 복사한다.

## 2. 엑셀 DB 구조 (`한탄강_수질DB.xlsx`)

| 시트 | 내용 | 갱신 시점 |
|---|---|---|
| 안내 | 입력 규칙 요약 | - |
| **측정결과** | 조사연월·채취일·지점명·TOC·COD·BOD·SS·T-N·T-P·색도·검토표시·비고 | **매월**(가져오기 도구 사용 가능) |
| 지점정보 | 정렬순서·지점ID·지점명·하천명·수계·시군·주소·위도·경도·**좌표상태·좌표출처**·비고 | 지점 변경 시 |
| 항목정보 | 항목·표시명·단위·소수자리·설명 | 거의 없음 |
| 기준값 | 하천 생활환경기준 등급 상한(TOC·BOD·SS·T-P), 색도 목표(15도) | 기준 변경 시 |
| 연평균색도 | 2019~2025 지점별 연평균 색도 | 연 1회 |
| **설정** (v2) | V월드 인증키, 기본 배경지도, ▲▼ 판정 기준, 이상값 기준, 정량한계 처리 | 필요할 때 |
| **측정망지점** (v2) | 국가수질측정망 23개 지점 좌표(지도 참고 레이어) | 측정망 자료 변경 시 |

### 2.1 측정결과 입력 규칙
- **조사연월**: `2026-10` 형식. **지점명**은 지점정보와 같아야 한다(드롭다운 제공).
- **값이 없으면 빈칸**. 정량한계 미만은 **`<0.5`** 처럼 입력한다. 계산 방법은 `설정 > 정량한계_처리`(한계값 / 절반 / 제외)에서 정하고, 표에는 `<0.5`로 표시된다.
- **검토표시**에 `검토필요`를 적으면 자료 점검에 나타난다. 비고에 항목명(예: `BOD, SS 재분석`)을 적으면 그 항목에만 표시된다.

### 2.2 설정 시트
| 설정 | 기본값 | 설명 |
|---|---|---|
| VWORLD_KEY | (발급 키) | V월드 배경지도·좌표 검색. 비우면 시군 경계만 표시 |
| VWORLD_DOMAIN | (빈칸) | 인증키 발급 때 등록한 서비스 URL. 좌표 검색이 거절되면 입력 |
| 기본배경지도 | 자동 | 자동 = 라이트 화면은 일반 지도, 다크 화면은 야간 지도 |
| 기본항목 | 색도 | 처음 열 때 보이는 항목 |
| 평균대비_판정 / _k / _p | 표준편차 / 1 / 30 | ▲▼ 기준(평균 ± k·σ, 평균 ± p%, 전체) |
| 이상값_기준 / 이상값_배율 | 6 / 5 | 지점 중앙값에서 크게 벗어나고(로버스트 z ≥ 6) 중앙값의 5배 이상(또는 1/5 이하)이면 '이상값 의심' |
| 전월동일_항목수 | 4 | 전월과 같은 값이 4개 항목 이상이면 '전월 동일' |
| 정량한계_처리 | 한계값 | `<0.5` 계산 방법 |

### 2.3 좌표상태 값
| 값 | 의미 | 좌표 도구가 바꾸는가 |
|---|---|---|
| 확인 | 현장 GPS 등으로 확인한 좌표 | **바꾸지 않음** |
| 측정망 | 국가수질측정망 좌표(같은 다리) | V월드 `--all`일 때만 |
| 브이월드 | V월드 지번·장소 검색 결과 | V월드 `--all`일 때만 |
| 추정 / 미입력 | 주소로 추정한 값 / 없음 | 바꿈 |

### 2.4 이번 자료에서 확인된 사항
- 원본 요약 시트 222건(지점×항목의 최대·최소·평균·표준편차·등급)과 대시보드 계산값이 **모두 일치**한다(v1·v2 모두 검증).
- 받은 좌표표(hwpx)는 **국가수질측정망 23개 지점**이다. 조사 지점 37개 중 같은 위치는 **포천천3(농본교) 1곳**뿐이라 그 좌표만 적용했다(기존 추정값과 4.8km 차이). 나머지 36곳은 V월드 좌표 보정이 필요하다.
- 자동 점검 결과
  - **이상값 의심 20건**. 그중 다음 값은 입력 확인을 권장한다.
    1. 외북천2·3, 8월 T-P 0.821·0.827: 평소 값의 약 10배라 소수점 오류일 가능성이 있다.
    2. 금현천·송우천, 4월 T-P: 두 지점 모두 0.253으로 같다.
    3. 신천9, 5월 색도 164도.
    4. 청담천, 3·4월 SS 186·125.
  - **전월 동일 13건**: 9월 13개 지점의 BOD·SS·T-N·T-P·색도가 8월과 같다.

## 4. 설치 및 사용

### 4.1 설치(최초 1회)
1. Python 3.9 이상을 설치한다. 설치할 때 **"Add python.exe to PATH"** 를 체크한다.
2. `도구모음.bat`을 처음 실행하면 openpyxl을 자동으로 설치한다.
3. **V월드 서비스 URL 확인**: V월드 오픈API 인증키 관리 화면에서 키의 서비스 URL에 `http://localhost:8765`가 들어 있는지 확인하고, 없으면 추가하거나 새로 발급한다. 이 주소로 열어야 배경지도가 나온다.

### 4.2 매월 갱신
1. `도구모음.bat` → **2. 월별 결과 엑셀 가져오기** → 결과 파일(YYYYMM 시트)을 창에 끌어다 놓고 Enter.
   - 같은 달을 다시 가져오면 기존 값이 교체되므로 중복되지 않는다.
   - 직접 입력하려면 측정결과 시트에 행을 추가해도 된다.
2. **1. 대시보드 만들기** → HTML이 생성되고 브라우저에서 열린다.
3. **자료 점검** 탭에서 이상값 의심·전월 동일 값을 확인하고, 잘못된 값은 엑셀에서 고친 뒤 1번을 다시 실행한다.

### 4.3 좌표 보정(최초 1회, 지점이 바뀔 때)
1. **3. 국가측정망 좌표표(hwpx) 가져오기**: 측정망 지점이 지도 참고 레이어로 들어가고, 같은 다리 지점에는 좌표가 적용된다.
2. **4. V월드로 지점 좌표 자동 보정**
   - 먼저 결과를 미리보기로 보여준다. Y를 입력하면 저장한다.
   - 결과는 `좌표보정_결과.csv`에도 저장된다. 열어서 '이전 좌표와 거리'가 큰 지점을 확인한다.
   - 검색에 실패한 지점은 기존 좌표를 유지한다. 현장 좌표를 직접 입력하고 좌표상태를 `확인`으로 바꾼다.
3. 1번으로 대시보드를 다시 만든다.

### 4.4 화면 사용법
| 화면·기능 | 설명 |
|---|---|
| 상단 항목 버튼 | TOC·COD·BOD·SS·T-N·T-P·색도 전환 |
| 왼쪽 지점 패널 | 체크박스로 지점 선택, 수계·하천 일괄 선택, ☆ 강조, ● 색상(오른쪽 클릭: 기본색) |
| ▲▼ 판정 | 평균 ± k·σ 밖(기본) / 평균 ± p% 밖 / 평균과 다르면 모두 / 표시 안 함 |
| 평균선과 정상 범위 띠 | 강조 지점이 1~2개일 때 평균 ± k·σ 범위를 옅은 띠로 표시 |
| y축 | 선형 / **이상치 잘라 보기**(📍 표시 = 잘린 값, 라벨은 실제 값) / 로그 |
| **시계열** | 월별 추이 + 데이터 표(▲▼, 점검 표시, 채취일 툴팁) |
| **상·하류 종단** | 하천을 고르면 상류→하류로 월별 선(최근월은 굵게)과 기간 평균(점선) 표시. 범례에서 월 켜기/끄기. 아래 표는 상류 대비 변화와 변화율 |
| **히트맵** | 지점×월 전체. 측정값 또는 지점 평균 대비(%). 칸을 누르면 시계열로 이동 |
| **지도** | V월드 배경(일반·백지도·위성·하이브리드·야간·경계만), 값 라벨(겹치면 자동으로 숨김), 국가측정망(◇), 추정 좌표(점선 원). 지점을 누르면 그래프 배너 |
| **연도별 색도** | 2019년~. 올해(*)는 측정결과로 계산하고 부분 연도 경고 표시 |
| **자료 점검** | 유형별 필터, `보기`를 누르면 해당 지점·항목 시계열로 이동, 목록 복사 |
| 인쇄·PDF | 지금 선택한 지점·기간으로 7개 항목 그래프와 통계표를 인쇄. 인쇄 창에서 'PDF로 저장' 선택 |
| 처음 화면으로 | 브라우저에 저장된 선택·색상·옵션을 지우고 DB 설정값으로 돌아감 |

### 4.5 지점 추가·변경
- 월별 결과 가져오기에서 처음 보는 지점은 지점정보에 자동으로 추가된다(좌표는 비어 있음). 이후 4.3 절차로 좌표를 넣는다.
- 정렬순서는 **같은 하천 안에서 상류→하류 순서**로 매긴다. 종단 그래프가 이 순서를 따른다.

## 5. 배포 방법

| 방법 | 대상 | 방법 |
|---|---|---|
| **HTML 파일 공유** | 결과만 보는 사람 | `한탄강_수질대시보드.html` 한 개 전달(약 1.4MB). Python 설치 불필요. 그래프·표·점검은 바로 동작. 배경지도는 받은 PC에서 V월드 서비스 URL 조건에 맞아야 표시되고, 맞지 않으면 시군 경계로 자동 전환 |
| 외부 공유(키 제외) | 기관 밖 | `python 02_build_dashboard.py --no-key` → V월드 키를 넣지 않은 HTML |
| 폴더 공유 | 데이터 담당자 | 폴더 전체 압축 전달. 받은 사람은 4.1 설치 후 사용 |
| 가벼운 버전 | 인터넷 환경 | `python 02_build_dashboard.py --cdn` (라이브러리를 인터넷에서 불러옴) |

### 참고
- V월드 인증키는 HTML 안에 들어간다. 키는 서비스 URL로 사용 범위가 제한되지만, 기관 밖으로 보낼 때는 `--no-key`를 권장한다.
- 지점 연결선은 지점을 이은 **모식선**이며 실제 하천 경로가 아니다(기본값 끔). 실제 하천은 V월드 배경지도에서 확인한다.
- 등급·목표 판정은 **선택 기간 평균** 기준이다. 연간 판정은 12개월 자료가 모두 들어온 뒤에 한다.

## 6. 문제 해결
| 증상 | 원인·해결 |
|---|---|
| 지도에 "V월드 배경지도를 불러오지 못했습니다" | ① HTML을 파일로 직접 열었다 → `대시보드_열기.bat` 사용 ② 인증키 서비스 URL에 `http://localhost:8765`가 없다 ③ 인터넷·방화벽에서 api.vworld.kr이 막혀 있다 |
| 좌표 보정 "V월드 서버에 연결하지 못했습니다" | 인터넷·방화벽 확인. 내부망 PC면 인터넷 PC에서 실행 |
| 좌표 보정 "인증키 오류" | 설정 시트 VWORLD_KEY 확인. 계속 거절되면 VWORLD_DOMAIN에 등록한 서비스 URL 입력 |
| "엑셀에서 열려 있습니다" | DB 엑셀을 닫고 다시 실행(가져오기·좌표 도구는 DB에 저장하므로) |
| `지점정보에 없는 지점명` 경고 | 측정결과 지점명 오타 → 드롭다운 값으로 수정 |
| 숫자가 아닌 값 경고 | `-`, `없음` 같은 문자 → 빈칸으로. 정량한계 미만은 `<0.5` 형식 |
| 잘못 저장했다 | `백업` 폴더에서 직전 파일을 복사해 되돌린다 |
