# 한탄강 수계 수질 대시보드 매뉴얼

> 엑셀 DB 한 개를 고치고 버튼 한 번으로 인터랙티브 HTML 대시보드를 다시 만드는 도구

---

## 1. 최초 기획

### 1.1 배경
- 기존 자료는 **월별 시트(202601~202609)** 와 **항목별 요약 시트(TOC·BOD·SS·TN·TP·색도)** 로 나뉘어 있다.
- 매달 같은 값을 7개 요약 시트에 옮겨 적어야 해서 반복 작업이 많고, 옮겨 적는 중에 오류가 생길 수 있다.
- 그래프로 한눈에 보려면 엑셀 차트를 매번 새로 만들어야 한다.

### 1.2 목표
| 요구사항 | 구현 |
|---|---|
| 항목·지점(또는 전체) 선택 → 시계열 | 상단 항목 버튼 + 왼쪽 지점 패널(수계/하천 단위 일괄 선택) |
| 지점 평균보다 높거나 낮으면 포인트·값 표시 | ▲(평균 초과)·▼(평균 미만) 표식과 값 라벨, 지점 평균선 |
| 그래프 아래 데이터 표 | 월별 값 + 최대·최소·평균·표준편차·등급(또는 목표 달성) |
| 기본 색상 + 체크한 지점만 강조 | ☆ 강조 → 자동으로 색 지정, ● 눌러 원하는 색 직접 지정 |
| 색도 전체 지점 한눈에 | **히트맵**(지점×월) 화면 |
| 지도에서 지점 클릭 → 그래프 배너 | **지도** 화면, 클릭하면 오른쪽 배너에 그래프와 7개 항목 최근값 |
| (추가) 과거 추이 | **연도별 색도** 화면(2019~현재) |

### 1.3 설계 원칙
1. **데이터는 엑셀 한 곳에만**: 요약 시트는 만들지 않고 대시보드가 바로 계산한다.
2. **1행 = 1지점 1회 채취(long 형식)**: 달이 늘어나도 행만 추가하면 된다.
3. **단일 HTML 파일**: 라이브러리까지 파일 안에 넣어 내부망·오프라인에서도 열린다.

## 2. 엑셀 DB 구조 (`한탄강_수질DB.xlsx`)

| 시트 | 내용 | 갱신 시점 |
|---|---|---|
| 안내 | 입력 규칙 요약 | - |
| **측정결과** | 조사연월·채취일·지점명·TOC·COD·BOD·SS·T-N·T-P·색도·검토표시·비고 | **매월** |
| 지점정보 | 정렬순서·지점ID·지점명·하천명·수계·시군·주소·**위도·경도**·좌표상태·비고 | 지점 변경 시 |
| 항목정보 | 항목·표시명·단위·소수자리·설명 | 거의 없음 |
| 기준값 | 하천 생활환경기준 등급 상한(TOC·BOD·SS·T-P), 색도 목표(15도) | 기준 변경 시 |
| 연평균색도 | 2019~2025 지점별 연평균 색도(중단 지점 포함) | 연 1회 |

### 2.1 측정결과 입력 규칙
- **조사연월**: `2026-10` 형식(텍스트).
- **지점명**: 지점정보의 지점명과 정확히 같아야 한다. 셀에 드롭다운이 있다.
- **값이 없으면 빈칸**으로 둔다. `-` 같은 문자를 넣으면 숫자로 읽지 못해 빈 값으로 처리된다.
- 같은 지점을 한 달에 두 번 채취했다면 두 행 모두 입력해도 된다. 대시보드는 평균값을 쓰고 실행 창에 안내를 띄운다.
- **검토표시**에 `검토필요`를 적으면 대시보드 표와 히트맵에 점선 테두리로 표시된다.

### 2.2 변환 시 발견한 사항
- 기존 요약 시트 6개와 월별 원자료를 비교한 결과 **222개 지점×항목의 최대·최소·평균·편차·등급이 모두 일치**했다.
- **2026년 9월 13개 지점**(신천15·17·17-2·18·18-1·20, 능안천, 효촌천, 덕계천-하, 마개미천, 회암천_중, 청담천, 상패천)은 BOD·SS·T-N·T-P·색도가 8월과 완전히 같다. 복사해서 넣은 값일 가능성이 높아 `검토필요`로 표시했다. 실제 9월 값을 넣고 표시를 지우면 된다.
- 색도 목표 15도는 원본 '목표기준 달성여부' 판정 결과와 맞도록 정한 값이다(연평균 15도 이하 = 달성). 실제 기준이 다르면 `기준값` 시트에서 고친다.
- **지점 좌표(위도·경도)는 주소를 바탕으로 추정한 값**이다(좌표상태 = `추정`). 각 좌표가 해당 시·군 경계 안에 들어가는지는 확인했지만, 현장 GPS 좌표로 바꾸고 `확인`으로 고치는 것을 권장한다.

## 3. 개발 과정

| 단계 | 작업 | 결과물 |
|---|---|---|
| ① 원본 검토 | 월별 시트 9개·요약 시트 7개 구조 분석, 요약값과 원자료 대조, 반복 입력 의심 값 탐지 | 검토 결과(2.2절) |
| ② DB 재구성 | 월별 시트를 long 형식 한 장으로 합치고 지점·항목·기준 정보를 분리 | `01_convert_legacy.py`, `한탄강_수질DB.xlsx` |
| ③ 지도 배경 | 시군 경계(포천·양주·동두천·연천과 주변 시군)를 간략화해 내장 | `lib/sigungu.geojson` |
| ④ 대시보드 | Python이 엑셀을 읽어 JSON으로 만들고 HTML 템플릿에 넣음 | `02_build_dashboard.py`, `template.html` |
| ⑤ 검증 | 대시보드 계산값과 원본 요약 시트 222건 비교(전부 일치), 라이트/다크·모바일 화면 확인 | - |

### 3.1 사용 기술
| 구분 | 기술 | 비고 |
|---|---|---|
| 데이터 처리 | Python 3 + openpyxl | pandas 없이 동작 |
| 그래프 | Apache ECharts 5.5.1 | Canvas 렌더링, 라벨 겹침 자동 숨김 |
| 지도 | Leaflet 1.9.4 + CARTO 배경지도 | 인터넷이 없으면 시군 경계만 표시 |
| 화면 | HTML/CSS/JavaScript(프레임워크 없음) | 라이트·다크 모드, 모바일 화면 지원 |

### 3.2 파일 구성
```
한탄강_수질대시보드/
├─ 한탄강_수질DB.xlsx            ← 매월 여기만 수정
├─ 대시보드_만들기.bat            ← 더블클릭하면 HTML 생성 후 열림
├─ 한탄강_수질대시보드.html       ← 결과물(이 파일 하나만 공유하면 됨)
├─ 기존엑셀_변환하기.bat          ← 예전 월별 시트 형식 엑셀을 DB로 변환
├─ 01_convert_legacy.py
├─ 02_build_dashboard.py
├─ coords.py                      ← 변환 시 쓰는 추정 좌표
├─ template.html                  ← 화면 디자인·기능
└─ lib/  (echarts.min.js, leaflet.js, leaflet.css, sigungu.geojson)
```

## 4. 설치 및 사용

### 4.1 설치(최초 1회)
1. Python 3.9 이상을 설치한다. 설치 화면에서 **"Add python.exe to PATH"** 를 체크한다.
2. 명령 프롬프트에서 아래를 실행한다. `대시보드_만들기.bat`이 없으면 자동으로 설치한다.
   ```bash
   pip install openpyxl
   ```
3. VS Code에서 쓸 때는 폴더를 열고 터미널에서 실행하면 된다.
   ```bash
   python 02_build_dashboard.py
   ```

### 4.2 매월 갱신
1. `한탄강_수질DB.xlsx` → **측정결과** 시트 맨 아래에 이번 달 37개 지점 행을 추가한다.
2. 파일을 저장하고 닫는다(엑셀이 열려 있어도 읽을 수는 있지만, 저장하지 않은 내용은 반영되지 않는다).
3. **`대시보드_만들기.bat`** 을 더블클릭한다. 완료되면 HTML이 자동으로 열린다.

### 4.3 화면 사용법
| 화면 | 기능 |
|---|---|
| 상단 항목 버튼 | TOC·COD·BOD·SS·T-N·T-P·색도 전환 |
| 왼쪽 지점 패널 | 체크박스로 지점 선택. 수계·하천 체크박스로 묶음 선택. `○○수계만` 버튼 |
| ☆ (강조) | 누르면 그 지점만 진한 색 + ▲▼ 표식 + 값 라벨. 나머지는 회색 배경선 |
| ● (색상) | 누르면 색상 선택 창. 고른 색은 저장된다. **오른쪽 클릭하면 기본색으로 복귀** |
| 표시 옵션 | ▲▼ 포인트, 값 라벨(자동/모든 지점/끄기), 평균선, 기준선, 기간 |
| 색상 옵션 | 평균 초과·미만 표식 색과 기본 선 색 변경, `색상 초기화` |
| 시계열 | 그래프 위에 마우스를 올리면 그 달의 지점별 값(▲▼ 포함). 범례 이름을 누르면 강조 전환 |
| 데이터 표 | 지점명을 누르면 강조 전환. `표 복사` → 엑셀에 그대로 붙여넣기. `CSV 저장` |
| 히트맵 | 지점×월 전체를 한눈에. `지점 평균 대비(%)`로 바꾸면 평소보다 높은 달이 빨갛게 표시. 칸을 누르면 시계열로 이동 |
| 지도 | 원 색 = 값 크기. 기준(최근 측정월/기간 평균/특정 월) 선택. **지점 클릭 → 그래프 배너** |
| 연도별 색도 | 2019년부터 연평균 색도 추이. 올해(*)는 측정결과로 자동 계산. 중단 지점도 볼 수 있음 |

- 지점 선택·강조·색상 설정은 **사용 중인 브라우저에 저장**되어 다음에 열어도 유지된다.
- ▲▼ 판정 기준은 **선택한 기간 안에서 그 지점의 평균**이다. 기간을 바꾸면 판정도 바뀐다.

### 4.4 지점 추가·변경
1. `지점정보` 시트에 한 줄을 추가한다(정렬순서, 지점명, 하천명, 수계, 위도, 경도).
2. 이후 `측정결과`에서 그 지점명을 쓰면 된다. 정렬순서는 상류→하류 순으로 매기면 그래프·표 순서가 자연스럽다.

## 5. 배포 방법

| 방법 | 대상 | 방법 |
|---|---|---|
| **HTML 파일 공유(권장)** | 결과만 보는 사람 | `한탄강_수질대시보드.html` 한 개를 메일·메신저·공유폴더로 전달. Python 설치가 필요 없고 Edge·Chrome으로 바로 열린다(약 1.3MB) |
| 폴더 공유 | 데이터를 갱신하는 담당자 | 폴더 전체를 압축해 전달. 받은 사람은 4.1 설치 후 4.2 절차로 갱신 |
| 가벼운 버전 | 인터넷이 되는 환경 | `python 02_build_dashboard.py --cdn` → 라이브러리를 인터넷에서 불러오는 약 190KB 파일 |

### 참고
- **배경지도(도로·하천 그림)** 는 인터넷이 필요하다. 내부망에서는 시군 경계와 지점만 보인다. 지점 연결선은 지점을 상류→하류 순으로 이은 **모식선**이며 실제 하천 경로가 아니다.
- 생활환경기준 판정은 기간 평균값을 `기준값` 시트 상한과 비교한다(원본 요약 시트와 같은 방식).

## 6. 문제 해결
| 증상 | 원인·해결 |
|---|---|
| `python`을 찾을 수 없음 | Python 설치 시 PATH 추가를 체크하지 않음 → 재설치 또는 `py 02_build_dashboard.py` |
| `지점정보에 없는 지점명` 경고 | 측정결과의 지점명 오타·띄어쓰기 차이 → 드롭다운 값으로 수정 |
| `조사연월 형식 오류` | `2026-10` 형식으로 수정 |
| 그래프에 값이 안 보임 | 숫자 셀에 문자(예: `-`, `<0.5`)가 들어감 → 빈칸 또는 숫자로 수정 |
| 지도 위치가 이상함 | `지점정보`의 위도·경도를 수정 후 다시 생성 |
