# 한탄강 수계 수질 대시보드 매뉴얼 (v3.1)

> 엑셀 DB 한 개로 그래프 보기 → 경향 분석 → 지점·설정 수정까지 하는 도구.
> v3.1부터 프로그램이 **부품 49개**로 나뉘어 있어서, 고칠 일이 생기면 **해당 부품 하나만** 고치고 빌드한다.

| 하고 싶은 일 | 실행할 것 |
|---|---|
| 대시보드 보기·저장 | Windows `대시보드_열기_windows.bat` / Mac `대시보드_열기_mac.command` |
| 프로그램 고친 뒤 HTML 다시 만들기 | Windows `빌드_windows.bat` / Mac `빌드_mac.command` |
| 월별 가져오기·V월드 일괄·공유용 등 | Windows `도구모음_windows.bat` / Mac `도구모음_mac.command` |
| 어느 부품을 고칠지 찾기 | `문서/부품지도.md` |
| 고치는 방법·규칙 | `문서/수정방법.md` |

## 1. 최초 기획

### 1.1 배경
- 한탄강 수계 37개 시료번호, 7개 항목(TOC·COD·BOD·SS·T-N·T-P·색도)의 월별 결과를 보는 도구다.
- 원래 자료는 월별 시트와 항목별 요약 시트로 나뉘어 있어서 매달 옮겨 적는 일이 많았다.
- v1~v3에서 다음을 차례로 만들었다.
  - 엑셀 DB 재구성, 대시보드
  - V월드 지도, 경향 분석, 지점 관리
- v3까지는 HTML 템플릿 한 파일(약 1,600줄)에 모든 코드가 섞여 있었다. 그래서 작은 수정에도 전체 코드를 다시 읽어야 했다.

### 1.2 v3.1 요구사항과 반영 결과
| 번호 | 요구사항 | 반영 내용 |
|---|---|---|
| 1 | 코드를 파트별로 분리 | 8개 폴더, 부품 49개로 나눴다. 나눈 기준은 1.3 참조 |
| 2 | 수정한 파트만 고쳐 반영 | 부품 하나를 고친 뒤 빌드하면 HTML 한 파일로 다시 합쳐진다. 서버를 켜 두었으면 **새로고침(F5)만으로 자동 반영**된다. |
| 3 | 분리할 파트는 Claude가 판단 | 디자인 9 · 화면 틀 3 · 화면별(자리+동작) 9쌍 · 공통 계산 7 · 설정·API 키 1쌍 · 시작 3 |

| 6 | API 키 입력 (파트 예시에 포함) | **설정** 탭 신설: V월드 키 입력·연결 시험, 화면 기본값, 자료 점검 기준 |

### 1.3 부품을 나눈 기준
| 기준 | 이유 | 예 |
|---|---|---|
| **고치는 사람 기준으로 묶기** | "색을 바꾸고 싶다"면 디자인 폴더만, "히트맵을 바꾸고 싶다"면 히트맵 부품만 열면 되게 | `01_디자인/01_색상_글꼴.css`, `40_화면/13_히트맵.js` |
| **화면 1개 = 자리(HTML) + 동작(JS) 2개** | 화면을 더하거나 뺄 때 두 파일과 목록 한 줄만 바꾸면 되게 | `02_화면/14_지도.html` + `40_화면/14_지도.js` |
| **여러 화면이 함께 쓰는 계산은 공통으로** | 같은 통계를 화면마다 따로 고치지 않게 | `20_공통/02_통계_판정.js`(평균·▲▼ 판정), `05_추이차트.js`(꺾은선) |

| **한 부품은 약 200줄 이하**(최대 171줄) | 한 번에 읽고 고칠 수 있는 크기 | 경향 분석은 통계 계산(16)과 화면(17)으로 나눔 |

### 2.2 사용한 방법
| 방법 | 설명 |
|---|---|
| **빌드(조립)** | `소스/빌드목록.txt`에 적힌 순서대로 부품을 이어 붙여 HTML 한 파일을 만든다.<br>• CSS는 `<style>` 한 곳에, 화면 자리는 본문에 넣는다.<br>• 프로그램 코드는 `<script>` 한 곳에 넣는다.<br>• 엑셀 DB 데이터를 넣는다.<br>• 부품마다 `/* ===== 부품: 경로 ===== */` 표시를 남겨, 오류가 났을 때 어느 부품인지 찾을 수 있다. |
| **화면 등록표** | 각 화면 부품이 맨 위에서 `registerView({id, label, render, bind})`로 자기를 등록한다. 상단 탭·화면 전환·버튼 연결은 이 표를 보고 자동으로 만들어진다. |
| **빌드 전 검사** | 목록·파일, 이름 중복, 문법(부품별 줄 번호까지), `</script>`, id 중복, 화면 짝, 외부 주소, 버전을 검사한다. 하나라도 걸리면 HTML을 만들지 않는다. 그래서 쓰던 화면이 깨지지 않는다. |
| **부품지도 자동 생성** | 부품 머리말(하는 일·주요 이름·이럴 때 고침)과 `소스/자주하는수정.txt`를 모아 `문서/부품지도.md`를 만든다. 코드와 문서가 어긋나지 않는다. |
| **간단 빌드** | Python이 없는 PC용이다. 검사 없이 조립만 하고, 데이터는 지난번 빌드 때 저장한 `빌드결과/_data.js`를 쓴다. 결과는 `build.py --cache`와 같다. |

### 2.3 검증 결과
| 검증 | 결과 |
|---|---|
| v3와 같은 기능인지 | 9개 탭·분석 4종 화면 오류 0. 원본 엑셀 요약 시트와 통계 **222건 일치**. 화면 통계 = Python 계산 **259건 일치** |
| 빌드 시험(`시험/빌드_시험.py`) | **17/17 통과**<br>• 고장 넣기 5종: 이름 중복, 없는 파일, `</script>`, 화면 자리 없음, 문법 오류<br>• 5종 모두 막았고, 기존 HTML이 그대로 남았다.<br>• 간단 빌드(sh) 결과가 Python 빌드와 글자 하나까지 같다. |
| 화면 통합 시험(`시험/화면_통합시험.py`) | **13/13 통과**<br>• 신천 13개가 모두 다른 색, ⚡ 표시, 설정 임시 저장<br>• 서버 모드: 주소·설정 저장 → 엑셀 반영, 백업 생성, 부품 수정 → 자동 빌드, 망가진 부품 → 이전 화면 유지 |
| 화면 크기·테마 | 폭 400px(휴대폰)에서 모든 탭 가로 넘침 없음, 다크 모드 정상 |
| **미검증** | ① PowerShell 간단 빌드(`build_simple.ps1`): 작업 환경에 PowerShell이 없어 실행하지 못함<br>② Windows에서 `.bat` 더블클릭<br>③ Mac Finder에서 `.command` 더블클릭: Linux bash로만 실행해 봄<br>④ 실제 V월드 배경지도·[연결 시험]·주소 검색: 작업 환경에서 V월드 접속 차단 |

### 2.4 분석 방법 (v3와 같음)
| 분석 | 방법 | 읽는 법 | 한계 |
|---|---|---|---|
| 추세 검정 | **Mann-Kendall 검정**(모든 두 시점 쌍의 증감 부호로 단조 추세 판단) + **Sen 기울기**(모든 쌍 기울기의 중앙값). 3년 이상이면 계절 검정(같은 달끼리 비교) | 진한 색 p<0.05, 옅은 색 p<0.1. 빨강 증가·파랑 감소 | 현재 9개월 자료라 **참고용**. 24개월 미만은 연간 환산하지 않고 기간 전체 변화율로 표시 |
| 항목 간 상관 | **Spearman 순위상관 ρ** + 산점도 | SS·색도·T-P가 함께 높으면 강우 유출, BOD·TOC·T-N이 함께 높으면 오수 영향을 의심 | 상관은 인과가 아니다 |
| 월별 분포 | 상자그림(Tukey 1.5×IQR, 상자 밖 점에 시료번호 표시) | 상자 전체가 오르면 수계 전체 요인, 점 하나면 국지 요인 | 한 달 37개 값 |
| 기준 초과율 | 기준 초과 횟수 ÷ 측정 횟수 | 평균이 낮아도 초과율이 높으면 간헐 오염원 점검 | 측정 9회 이하 |
| ⚡ 특이 경향 | 로버스트 z = 0.6745×(값−중앙값)÷MAD(중앙값에서 떨어진 거리의 중앙값). 최대값이 기준(기본 8) 이상이면 급변 | 굵은 점선·빛 테두리, 급변한 점은 ◆ | 값이 거의 일정하면 작은 변화도 크게 잡힐 수 있음 |

## 3. 설치 및 사용

### 3.1 설치(최초 1회)
| 순서 | Windows | Mac |
|---|---|---|
| 1 | python.org에서 Python 3.9 이상 설치(**"Add python.exe to PATH" 체크**) | 터미널에서 `python3 --version` 확인. 없으면 python.org에서 설치 |
| 2 | 압축을 **푼 뒤** 폴더에서 실행(압축 파일 안에서 실행하면 안 됨) | 압축을 푼 뒤, 처음 한 번은 `.command` 파일을 **오른쪽 클릭 → 열기**(“확인되지 않은 개발자” 안내 통과) |
| 3 | `대시보드_열기_windows.bat` 첫 실행 때 openpyxl(엑셀 읽기 패키지)을 자동 설치 | `대시보드_열기_mac.command` 첫 실행 때 자동 설치 |
| 4 | V월드 인증키의 서비스 URL에 `http://localhost:8765` 등록(배경지도·주소 검색용) | 같음 |
| 선택 | Node.js(LTS) 설치 시 빌드 때 문법 검사까지 함 | 같음 |

> Mac에서 "권한이 없어 열 수 없음"이 나오면 터미널에서 폴더로 이동한 뒤 `chmod +x *.command tools/build_simple.sh`를 실행한다.

### 3.3 처음 실행
1. `대시보드_열기_windows.bat`(Mac은 `_mac.command`)를 더블클릭한다.
2. 검은 서버 창이 뜨고, 브라우저(Edge·Chrome)에 대시보드가 열린다. 주소는 `http://localhost:8765/…`이다.
3. 다 쓰면 서버 창을 닫는다. 닫으면 저장·V월드 지도·자동 빌드가 멈춘다. 이미 열린 화면의 그래프는 그대로 볼 수 있다.

> HTML 파일을 직접 더블클릭해도 그래프·분석·점검은 모두 동작한다. 엑셀 저장과 V월드 배경지도만 동작하지 않는다(이 경우 지도는 시군 경계만 표시).

### 3.4 화면 구성
| 위치·탭 | 내용 |
|---|---|
| 왼쪽 패널 | **하천명(굵은 글씨)을 누르면** 그 하천의 시료번호만 선택되고 색이 자동으로 정해진다.<br>• 체크박스: 하천 전체 또는 시료번호 선택<br>• ☆ 강조, ● 색 직접 지정, 🎲 색 다시 배정<br>• 기간·표시 옵션 |
| 상단 | 항목 선택(TOC~색도), 탭, 라이트/다크, 인쇄 |
| 시계열 | 꺾은선 + 데이터 표. ▲▼ = 평균±kσ 벗어남, ⚡ = 특이 경향 |
| 종단 | 하천별 상류→하류 변화, 구간 변화 30% 이상 표시 |
| 히트맵 | 시료번호×월 색칸(측정값 / 평균 대비) |
| 지도 | V월드 배경 + 시료번호 원. 원을 누르면 그래프 배너. [정보 수정]으로 지점 관리 이동 |
| 연도별 색도 | 2019~2025 연평균 색도 |
| 경향 분석 | 추세 검정 / 항목 간 상관 / 월별 분포 / 기준 초과율 (2.4 참조) |
| 자료 점검 | 이상값 의심·전월 동일 값·좌표 추정. 탭 옆 숫자 = 확인할 건수 |
| 지점 관리 | 하천명·시군·주소·좌표 수정 → 엑셀 저장 |
| **설정** (신규) | V월드 키·화면 기본값·자료 점검 기준 (3.7 참조) |

### 3.5 일상 업무 순서 (매월)
1. `도구모음` → **2. 월별 결과 엑셀 가져오기** → 결과 파일을 창에 끌어다 놓고 Enter.
2. 서버가 켜져 있으면 브라우저에서 **F5**. 꺼져 있으면 `대시보드_열기`를 실행한다.
3. **자료 점검** 탭에서 이상값 의심·전월 동일 값을 확인한다. 잘못된 값은 엑셀 DB에서 고치고 저장한 뒤 F5를 누른다.
4. 필요하면 **인쇄·PDF**로 보고서를 출력한다.

### 3.6 주소·좌표 수정 (지점 관리)
1. **지점 관리** 탭을 연다. 고친 칸은 노란색으로 표시된다.
2. 좌표 넣기
   - [지도]: 지도에서 위치를 누른다. 좌표상태가 '확인'이 된다.
   - [V월드]: 주소로 후보를 찾는다.
   - 위도·경도를 직접 입력해도 된다.
3. **[변경 저장]** → DB 지점정보 시트에 저장된다. 이전 파일은 `백업/`에 복사된다.
   - 엑셀에서 DB를 열어 두면 저장되지 않는다. 엑셀을 닫고 다시 누른다.
   - HTML을 직접 열었을 때는 이 브라우저에만 임시 보관된다. [표 복사]로 엑셀에 붙여넣거나, 서버로 열어 저장한다.

### 3.7 설정 (V월드 API 키 등)
| 묶음 | 항목 |
|---|---|
| V월드 | 인증키(가림/보기), [연결 시험], 서비스 URL 안내 |
| 화면 기본값 | 기본 배경지도, 기본 항목, ▲▼ 판정(평균±kσ / ±% / 전체), 특이 경향 기준 z |
| 자료 점검 기준 | 이상값 기준 z·배율, 전월 동일 판정, 정량한계 처리 |
| 기타 | 그 밖의 설정 시트 값 |

- **서버로 열었을 때**: [저장] → DB 설정 시트에 저장(저장 전 백업) → 자동으로 다시 빌드.
- **파일로 열었을 때**: [저장] → **이 브라우저에만** 저장된다. [이 브라우저 임시값 지우기]로 원래 값으로 돌아간다.
- **[연결 시험]**: V월드 지도 조각 1장을 요청해 키가 맞는지 본다. 실패하면 키, 서비스 URL 등록, 인터넷·방화벽을 확인한다.

### 3.8 프로그램을 고칠 때 (요약)
1. `문서/부품지도.md`에서 고칠 부품을 찾는다.
2. 그 파일만 VS Code로 고친다.
3. `빌드_windows.bat` / `빌드_mac.command` 실행. 서버를 켜 두었으면 F5만 누른다.
4. 오류가 나면 메시지가 부품 이름과 줄 번호를 알려 준다. 이때 기존 HTML은 그대로 남는다.

자세한 내용은 `문서/수정방법.md`에 있다.

### 3.9 표시 의미
| 표시 | 의미 |
|---|---|
| 노란 칸 | 확인 필요(고쳤지만 저장 전, 자료 점검 대상) |
| 회색 | 중복·전월 동일 값 |
| 빨강 | 실패(저장 실패, 빌드 오류, 기준 초과) |
| 연녹색 | 완료(저장됨, 연결 시험 성공) |
| ▲ / ▼ | 평균보다 높음/낮음(설정한 판정 기준) |
| ⚡ · ◆ | 특이 경향 시료번호 · 급변한 점 |
| 점선 원(지도) | 좌표가 '추정' 또는 '미입력' |

## 6. 문제 해결
| 증상 | 원인·조치 |
|---|---|
| 지점 관리·설정에 "파일로 열림" | HTML을 직접 열었다. `대시보드_열기`로 연다 |
| "포트를 다른 프로그램이 쓰고 있습니다" | 이전 버전 서버 창(v2·v3 `대시보드_열기.bat`)을 닫고 다시 실행 |
| 저장 시 "엑셀에서 열려 있습니다" | DB 엑셀을 닫고 다시 저장 |
| 부품을 고쳤는데 화면이 그대로 | 서버 창에 `[빌드 오류]`가 있는지 확인. 오류면 이전 화면을 유지한다. 메시지의 부품·줄을 고치고 F5 |
| 빌드 오류 메시지 | `문서/수정방법.md` 2장 검사 표 참조 |
| 빌드 후 화면이 비거나 버튼이 안 됨 | F12 → 콘솔 빨간 줄 위쪽의 `부품:` 표시로 부품 확인. 급하면 `빌드결과/이전/`의 직전 HTML 사용 |
| V월드 지도·검색·연결 시험 실패 | 인증키, 서비스 URL(`http://localhost:8765`), 인터넷·방화벽(api.vworld.kr) 확인. 행정망에서 차단되면 시군 경계 지도만 쓴다 |
| Mac에서 `.command`가 열리지 않음 | 오른쪽 클릭 → 열기. 그래도 안 되면 `chmod +x *.command tools/build_simple.sh` |
| Windows 빌드에서 PowerShell 실행 차단 | 기관 보안 정책 때문이다. Python을 설치하면 PowerShell을 쓰지 않는다 |
| 잘못 저장했다 | `백업/`의 직전 DB를 복사해 되돌린다 |

## 7. 주의
1. **`한탄강_수질대시보드.html`은 직접 고치지 않는다.** 다음 빌드 때 덮어써진다. 항상 `소스/` 부품을 고친다.
2. `10_외부라이브러리`(ECharts·Leaflet·시군 경계)는 고치지 않는다.
3. 부품 맨 앞의 `function`·`const` 이름이 다른 부품과 겹치면 안 된다. 빌드가 막아 준다.
4. V월드 키는 DB 설정 시트와 일반 HTML에 들어 있다. 외부에는 **공유용**(키 제외) 파일만 보낸다.
5. 원본 DB는 저장할 때마다 `백업/`에 복사된다. `백업/`이 커지면 오래된 파일을 정리한다.
6. **자료 확인 필요**: 현재 DB의 **2026-09 자료 13개 시료번호**가 전월(2026-08)과 5개 이상 항목 값이 같다. 자료 점검 탭에 '전월 동일'로 표시된다. 복사 입력이었는지 원자료로 확인이 필요하다. 프로그램은 값을 고치지 않았다.
7. 37개 시료번호 좌표는 모두 '추정' 상태다. 지점 관리에서 보정하기를 권장한다.
8. 추세 검정은 자료가 9개월뿐이라 참고용이다.
9. 미검증 항목(2.3)은 실제 PC에서 처음 쓸 때 확인한다. 특히 Windows `빌드_windows.bat`(Python 없는 PC의 PowerShell 경로)과 Mac `.command` 더블클릭이 해당한다.
