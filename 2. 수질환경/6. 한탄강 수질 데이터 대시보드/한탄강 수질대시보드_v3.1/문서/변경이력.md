# 한탄강 수계 수질 대시보드 — 변경이력

버전마다 **증상 → 원인 → 수정 → 회귀 검증 결과** 순서로 적는다. 맨 위가 최신 버전이다(빌드가 `소스/버전.txt`와 맞는지 확인한다).

### 2. 빌드 도구(부품 → HTML)
| 구분 | 내용 |
|---|---|
| 수정 | ① `tools/build.py`가 부품을 조립하고 검사한다.<br>　• 검사 항목: 목록·파일, 이름 중복, 문법(Node.js 있을 때, 부품별 줄 번호까지), `</script>`, id 중복, 화면 등록↔화면 자리 짝, 외부 주소, 버전<br>　• 오류가 있으면 HTML을 만들지 않는다.<br>　• 이전 HTML은 5개까지 보관하고, `문서/부품지도.md`를 자동으로 만든다.<br>　• 옵션: `--check`(검사만), `--watch`(저장할 때마다 자동 빌드), `--cache`(지난번 데이터로 조립), `--no-key`(공유용)<br>② Python이 없을 때 쓰는 간단 빌드: Windows `tools/build_simple.ps1`, Mac `tools/build_simple.sh`<br>③ 실행 파일: `빌드_windows.bat` · `빌드_mac.command`, `대시보드_열기_windows.bat` · `대시보드_열기_mac.command`, `도구모음_windows.bat` · `도구모음_mac.command`<br>④ Python 스크립트를 `tools/`로 모으고 이름을 바꿨다(01~04 → convert_legacy · data_builder · import_month · coords_tool). |
| 검증 | `시험/빌드_시험.py` 17/17 통과.<br>　• 고장 넣기 5종(이름 중복, 없는 파일, `</script>`, 화면 자리 없음, 문법 오류) 모두 막았고, 기존 HTML도 그대로 남았다.<br>　• 문법 오류는 `40_화면/12_종단.js 의 84번째 줄`처럼 정확한 부품을 가리켰다.<br>　• 간단 빌드(sh) 결과가 `build.py --cache`와 **글자 하나까지 같았다**.<br>　• **미검증**: PowerShell 간단 빌드(작업 환경에 PowerShell이 없어 실행하지 못함), Mac Finder에서 `.command` 더블클릭(Linux bash로만 실행해 봄), Windows `.bat` 실행 |

### 3. 서버가 부품 수정도 자동 반영
| 구분 | 내용 |
|---|---|
| 수정 | `tools/serve.py`가 DB 엑셀뿐 아니라 `소스/` 부품이 바뀐 것도 감지해 새로고침(F5) 때 다시 빌드한다. 빌드 오류가 나면 이전 화면을 그대로 보여 주고 서버 창에 오류를 적는다. 소스·.py·.xlsx 파일을 웹으로 내려받지 못하게 막았다. |
| 검증 | 서버 시험: 부품 수정 → 새로고침 → 탭 이름 바뀜 확인. 부품을 망가뜨려도 이전 화면이 유지됨. |
